## Summary

- Add TileLang scan operators with `T.cummax` alongside the existing `T.cumsum` path.
- Split scan code from reduce code across the TileOp, backend lowering, template, language, and test layers.
- Keep the public `T.cumsum` API compatible while adding `T.cummax` support.

## Changes

- Add `src/op/scan.{h,cc}` for scan TileOps and move scan registration/layout logic out of `src/op/reduce.*`.
- Add common backend scan lowering plus CUDA/ROCm scan registration files.
- Move CUDA/HIP scan templates into `tl_templates/*/scan.h` and include them from backend codegen.
- Add `tilelang/language/scan_op.py` and export `cumsum`/`cummax` from the scan language module.
- Consolidate scan tests under `test_tilelang_language_scan.py` and add CuTeDSL scan codegen coverage.
