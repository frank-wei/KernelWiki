## Summary

This PR generalizes the TCGEN05 GEMM examples to support NVIDIA Thor/SM110a while preserving SM100 compatibility, and adds a 2-CTA Stream-K scheduler for workloads with under-filled persistent waves.

## Changes

- Rename `examples/gemm_sm100` to `examples/gemm_tcgen05`, as these kernels rely on TCGEN05 capabilities rather than being exclusive to SM100.
- Generalize the architecture guard used by `warpgroup_reg_alloc` and `warpgroup_reg_dealloc` to support Thor/SM110a targets.
- Add a 2-CTA TCGEN05 Stream-K scheduler for GEMMs with under-filled persistent waves and sufficiently long K dimensions.

The Stream-K implementation splits the under-filled tail wave along the K dimension and distributes its work across the resident clusters. Partial accumulators are stored in a workspace and combined before the epilogue, while the remaining full waves continue to use ordinary data-parallel persistent scheduling.

## Performance

The kernels were tuned independently for each shape on an NVIDIA Thor T5000. The following table reports BF16 GEMM latency in milliseconds; the best result in each row is shown in **bold**.
