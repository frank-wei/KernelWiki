## Summary

- Put auto producer/consumer warp-specialized producer work in the low `threadIdx.x` partition.
- Keep consumer work logically zero-based when it moves to the high thread partition.
- Handle CUDA GEMM and sparse GEMM emitter thread IDs correctly under shifted thread bounds.

## Changes

- Reworked the producer/consumer WS branch predicates so producer code is guarded by `threadIdx.x < producer_extent` and consumer-only postlude code remains in the consumer partition.
- Remapped consumer-side `threadIdx.x` uses in the WS transform while keeping tile-op `thread_var` physical through dispatch.
- Derived `emitter_thread_var = thread_var - thread_bounds.min` only at CUDA MMA/WGMMA GEMM emitter construction sites that need local lane and warp layout IDs.
- Updated source-level assertions and added pass-level coverage for producer-first auto WS placement.
