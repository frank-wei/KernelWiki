## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Fixes #2381.

Add assert that block_K is a multiple of micro_size_k in CUDA MMA GEMM backends to prevent silent miscompilation. The CUDA MMA path uses a floor-divide loop over micro_size_k and silently drops the K-tail when block_K is not a multiple. The ROCm backends already guard this case; the fix adds an identical assert.

I checked that the changed Python files still parse correctly.
