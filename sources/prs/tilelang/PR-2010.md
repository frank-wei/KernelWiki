## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
### Summary

This PR converts most examples in the TileLang repo that are suitable for eager style to eager style.

### Motivation

We currently have a mix of styles across examples. Converting eligible examples to eager style makes the example set more consistent, easier to read, and better aligned with the recommended usage pattern.

### Notes

Not all examples are migrated in this PR. Some are intentionally left unchanged because:

* eager style is not a good fit for them, or
* they depend on older TileLang versions that do not yet support eager style (for example, examples with dedicated `requirements.txt`)
