## Summary

- move the dequantization helpers from `tilelang/quantize/` to `examples/dequantize_gemm/quantize/`
- move the sparse compression recipe from `tilelang/utils/sparse.py` to `examples/gemm_sp/sparse_utils.py`
- update examples, benchmarks, tests, and sparse GEMM documentation to use the example-local helpers
- keep the lightweight sparse layout contract in core because CUDA sparse MMA codegen depends on it

## Rationale

Neither moved module has a TileLang core consumer; they are recipes used by examples, benchmarks, and tests. Keeping them under `tilelang/` exposes them as package APIs and ships their example-only implementation in the wheel.

This intentionally removes the old `tilelang.quantize` and `tilelang.utils.sparse` import paths rather than retaining package-level compatibility shims.
