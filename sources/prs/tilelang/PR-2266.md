## Summary

- Fix cached kernel restore paths so adapters accept cached source objects, direct source strings, or missing source values consistently.
- Fix TileLang Metal source codegen on Linux by using TVM's Metal module fallback path when the runtime Metal factory is unavailable.

## Changes

- Add a shared cached-source normalization helper in `BaseKernelAdapter`.
- Update TVM FFI, Cython, NVRTC, and CuTeDSL database restore paths to use normalized cached source values before reading `.text`.
- Use `MetalModuleCreateWithFallback` from TVM target codegen for TileLang Metal modules and remove the unused TileLang runtime Metal module wrapper.
- Preserve real Metal runtime behavior when the runtime factory is registered, while allowing source inspection on non-Metal builds.
