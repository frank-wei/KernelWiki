## Summary

Add `T.gemm` support for Apple Metal using `simdgroup_matrix` 8×8 operations (`simdgroup_load/store/multiply_accumulate`). Works on all Apple Silicon (M1-M5) without requiring a TVM fork.

## Key Changes

- **codegen_metal.cc/h**: Fork TVM Metal codegen to tilelang with simdgroup intrinsic emission and 128-bit vectorized copy
- **gemm_metal.py**: `GemmMetal` tile operator for shared×shared GEMM
- **metal_macro_generator.py**: `MPSIntrinEmitter` generating simdgroup load/store/MMA TIR macros with multi-warp partition
- **metal_fragment_to_simdgroup.py**: Pass that rewrites `local.fragment` GEMM accumulators to `metal.simdgroup` scope before layout inference, so users write target-agnostic `alloc_fragment` + `T.gemm` code
- **LowerSIMDGroupCopy** in copy.cc: fragment→device store via `simdgroup_store` with correct warp partition offsets

## Tests

24 Metal tests:
- 3 codegen tests (cross-platform, no Metal GPU required)
- 5 GEMM correctness tests (various tile sizes)
- 6+5+5 simdgroup store tests (codegen + correctness)
