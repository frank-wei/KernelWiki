## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`T.import_source`, `T.Kernel(prelude=...)`, and raw `pragma_import_c` attributes can consume the next generated line when source lacks a final newline or ends in a backslash. Imported helpers also need backend headers and must appear before generated helpers, including Ascend VF functions.

Introduce `CodeGenTileLangCBase` for CUDA, HIP, CPU C, Ascend C++, Metal, and C host codegen. It intercepts imports before backend attribute handling and emits headers, imports, then generated declarations and functions. Each import gets two separating newlines. Optional `#line` emission stays in the shared base, with Metal and C host builders wired into the same option. `LowerOpaqueBlock` leaves the source text unchanged.

Validation:

- Reconfigured and rebuilt with CUDA, HIP, and Ascend enabled; Metal source codegen is included.
- Focused import, line-directive, and Ascend VF regressions: 83 passed, 1 skipped, including 15 CUDA execution tests with the kernel cache disabled.
- Related codegen and launch suites: 405 passed, 16 skipped.
- Generated CPU C and C host C++ compiled and ran with the expected output.
- Repository formatting hooks and whitespace checks passed.

HIP, Metal, and Ascend
<!-- upstream-excerpt-end -->
