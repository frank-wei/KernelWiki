## 📌 Description

Closes #5690.

Adds a `backend="cake"` route for the SM120 (RTX PRO 6000 Blackwell / RTX 5090, GB202) DeepSeek-V4 NVFP4 sparse-MLA
decode (`kv_cache_format="nvfp4"`, `Dsv4Nvfp4Layout`: 224 B E2M1 nope + 128 B BF16 rope + 28 E4M3 scales per token,
runtime page size incl. 32, runtime page stride). The kernels are generated from a Weave IR program (one 320-thread CTA
per token × 16-head block: 8 math warps + 2 gather warps, 16 B `cp.async` gather of 64-candidate chunks into a 2-stage
ring, native-scale NVFP4 QK on `mma.sync m16n8k64 kind::mxf4nvf4`, fp32 base-2 online softmax, FP8 PV on
`kind::f8f6f4 m16n8k32`, one or two 16-head tiles per CTA sharing one gather, split-K with a merge program) and cover
the same surface as the hand-written SM120 NVFP4 route from #5763: 8..128 heads (incl. 48/80/96/112), any positive page
size, `-1` masks and `topk_length`, dual cache (`extra_kv_cache` with its own page size), attention sink, `lse_scale`,
caller-owned split scratc
<!-- upstream-excerpt-end -->
