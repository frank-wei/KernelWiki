Title: perf(cake_ssd_combined): capability-routed one-launch and tail-wave exact-scan programs for Blackwell

## Summary

This PR updates the cake backend of the Mamba2 SSD combined chunk-scan prefill (`SSDCombined(backend="cake")`) on Blackwell sm_100a (B200) and sm_103a (GB300). On sm_103a, the seq_idx triple form now runs as one launch, using exactone programs that build the sequence table in-kernel. On GB300 this measured A/B geomeans of 1.2906 and 1.2652 over two 17-row runs. Rows of 512 items, which left 13.5 % / 15.8 % of the SMs idle, now use 2-CTA pair programs that split one item across the pair (geomean 1.0124 on B200 and 1.0196 on GB300, 6-row set). Every consumer thread now releases the aux-ring "empty" mbarrier, so compute-sanitizer racecheck reports 0 records on the exact-scan, look-back and three-phase kernels (geomean 0.9977–1.0003).
