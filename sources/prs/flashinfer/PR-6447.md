## 📌 Description

Sparse decode often reserves a large token capacity while only a few routes are live. This optimizes the existing SM107 Generic and GenPhase MegaMoE paths by avoiding invalid-slot work, shortening sparse metadata handling and reducing tail synchronization overhead.

- Mask invalid payloads and scores in the separate BF16 reducer, allowing the matching pre-launch combine clear to be omitted. Quantized combine and in-kernel reduction keep their clearing rules.
- Skip invalid histogram/scatter work. Fence rewritten shared-memory data into the async proxy before TMA publication; a CTA barrier alone is insufficient. GenPhase publishes the last valid route extent, transfers its aligned metadata prefix and uses a bounded shorter sort path, preserving holes and route IDs.
- Reuse the existing padded scale-factor prefix for refinement scheduling.
- Admit GenPhase `(256,64,128)` for the qualified MXFP8 E4M3 and mixed MXFP4/MXFP8 paths, with matching SFB/TMEM indexing, gather participation and live-row Gather4 transaction counts. Add the configurations to the offline tuning menu.
- Use counted non-aligned barriers in warp-role branc
