## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Cake's `causal_conv1d` training kernel family has one variant with two programs, and this PR delivers both. The forward program maps BF16 `x` to BF16 `y` with fused SiLU. The backward program produces BF16 `dx` and FP32 `dweight` using a fixed-order, bitwise-reproducible reduction. Both work on packed sequences (device-side `cu_seqlens`) with width 4, BF16 activations in [S, C] layout (S packed tokens, C channels) and FP32 weights [C, 4]. This PR re-renders the backward program as a per-warp shared-memory pipeline with eight channels per thread (one program for sm_100a/sm_103a, another for sm_107a). It also ships the same forward program with a clipped row copy for a partial last channel tile. The results are numerically unchanged. The baseline is the previous Cake version, shipped by #6782. Against it, the backward geometric-mean speedup over the 14 shapes is 1.266x on GB300 (range 1.065x–1.384x), 1.227x on B200 (1.063x–1.333x) and 1.230x on R200 (0.987x–1.309x; the C=128 row is within run-to-run noise, re-measured at 0.998x and 0.992x). Forward time is unchanged within noise (geometric-mean speedup 1.000x on GB300, 1.001x on B200 and 0.999x on R200). Times are median kernel times
<!-- upstream-excerpt-end -->
