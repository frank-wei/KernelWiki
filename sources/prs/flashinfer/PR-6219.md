## Summary

Extends the experimental SM120a (RTX PRO 6000 Blackwell / RTX 5090) FP8 paged MQA-logits route of the DeepSeek sparse-attention indexer decode path (`flashinfer.sm120_paged_mqa_logits`, Cake generated-program export; follow-up to #6180 and #6199) to **next_n 3, 5 and 6** for 32 and 64 indexer heads, so every DeepSeek-Sparse speculative depth vLLM uses (`num_speculative_tokens` 2..5 -> next_n 3..6) has a native kernel on these GPUs instead of the padded next_n 4 / 8 fallback.

- 9 new logits programs (18 total: heads {32, 64} x page {64, 128} x next_n 1..6, minus 64 heads x page 128 which is not an engine shape); the scheduler program is re-exported from the same producer.
- Q-atom rule, a function of `next_n` only (so `get_paged_mqa_logits_metadata` keeps DeepGEMM's head-count-free signature): next_n 3 scores each request from **one 3-token Q atom** (DeepGEMM runs 2+1 and streams the KV twice); next_n 5 and 6 keep DeepGEMM's own 2-token atoms (three per request). `policy.next_n_atoms` = `{1: 1, 2: 1, 3: 1, 4: 1, 5: 3, 6: 3}`; `split_kv` 128 unchanged.
