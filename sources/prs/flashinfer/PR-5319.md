## 📌 Description

@humansand

Reduce the cost of deterministic CuTe DSL MoE finalize for W4A4 per-tensor/per-token NVFP4 activation scaling and W4A16 BF16 activations when `use_fused_finalize=False`.

- **Reduction:** replace the native standalone finalizer with a shared CuTe kernel. Reduce top-k slots in ascending order using FP32 round-to-nearest FMA with flush-to-zero behavior matching native `--use_fast_math`, then convert once to BF16. Negative routes are skipped before loading expert output; all-masked tokens write zero.
- **Layouts:** preserve W4A4 expanded rows (`token * top_k + slot`) and W4A16 permuted rows selected by the routing map. `input_is_expanded` specializes address selection at compile time; permuted row zero remains valid. Both paths use contiguous, aligned BF16 vectors of eight elements.
- **PDL:** issue FC2's dependent-launch hint after its input dependency wait, allowing the standalone finalizer to prepare early. It preloads already-completed routing metadata, then waits before all FC2-output reads. W4A16's previous FC2 tail hint moves to this point for unfused output; the fused hint remains unchanged.
