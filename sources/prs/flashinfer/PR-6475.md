## 📌 Description

- **FP8, GeForce boards (RTX 5090 / GB202):** `kind::mxf8f6f4` MMA with a unit UE8M0 scale instead of the legacy plain-e4m3 `mma.sync.aligned.m16n8k32.row.col.f32.e4m3.e4m3.f32` form — 2048 vs 1024 FLOP/clk/SM issue limit on GeForce. - **FP8, both boards:** raster group 64 (was 16).
- **NVFP4, both boards:** producer-warpgroup form (384 threads: 8 `mma.sync` warps + a dedicated TMA producer warpgroup) instead of the folded producer.
