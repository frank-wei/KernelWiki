## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`sm103_mxfp8_mxfp8_bf16_cake` is the experimental Cake backend of FlashInfer's `moe_ep` MegaMoE EP16 kernel family (`MoEEpMegaLayer` API). It takes MXFP8 E4M3 activations and MXFP8 E4M3 weights with E8M0 block-32 scales and produces BF16 output. It runs EP16 over NVSHMEM symmetric memory with hidden 3072, intermediate 5120, 512 experts (32 per rank), top-8 and at most 64 tokens per rank. The other variants of this MXFP8 × MXFP8 → BF16 configuration are the CuTe-DSL `sm100_mxfp8_mxfp8_bf16_cutedsl` backend in its legacy inference form and in its GenPhase form (`knobs=None` heuristic, `knobs="auto"` autotune). This PR regenerates the Cake backend's six device kernels (publish_push, local_pack, fc1, fc2, combine, quantize_weights) from their Cake sources and replaces the version shipped by PR #6759. Bindings, host path and tests are unchanged. Compared with the previous Cake kernels from PR #6759, measured on the same 16 GPUs in the same session, the speedup ranges from 0.997x to 1.005x across the six shapes below. T is the global token count, and hot-set routing sends 50% of tokens to a hot expert set.
