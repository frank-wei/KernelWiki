## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
FlashInfer's `mm_bf16_fp4` multiplies BF16 activations by FP4 (E2M1) weights that carry E4M3 block scales, with FP32 accumulation. Cake ships it as two backend variants that differ in operand layout. `blackwell-native` uses cuDNN-ABI layouts and produces BF16 or FP16 output. `blackwell-tiled` uses CuTe-ABI prepared-tile layouts and produces BF16 output. This PR regenerates both variants as 97 programs across 20 kernel kinds, replacing the previous Cake generation of the same kernels on `main` (#5990). Speedup is the previous time divided by this PR's time. Across the 22 shape and GPU combinations it ranges from 1.36x to 3.90x, with a geometric mean of 2.18x on GB300 and 2.16x on B200.

**NVIDIA GB300 (sm_103a), CUDA 13.3:** median CUPTI kernel time in us, cold L2, PDL on; alpha calibrated and BF16 output unless noted.
