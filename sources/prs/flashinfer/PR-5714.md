## 📌 Description

Follow-up to #5692 (fused MoE gate_up projection for Blackwell SM100a: pair + tail kernels, mixed-schedule route,
routing-aware route rule).  The prepared API
`flashinfer.gemm.prepare_group_gemm_fp8_nt_groupwise_contiguous_silu_quant(a, b, a_scale, b_scale, m_indices).launch()`
and its contract are unchanged.  Two changes, both bit-identical to the three-kernel chain on every routing tested (data
movement order, accumulation order and rounding points are untouched):

- **Two-fragment TMEM drain at a 232 / 40 register split (pair, tail and mixed-schedule kernels).**  The accumulator warps
  drain each published 128-column TMEM partial as two back-to-back 16-column `tcgen05.ld` fragments per pair with one
  `tcgen05.wait::ld` (four waits per K128 block instead of eight; same loads, same FMA operands and K order per element).
