## 📌 Description

Fuse NVFP4 input quantization and route staging for Rubin MegaMoE, and use a fused checker for expert-ID bounds, duplicate routes and finite scores. Standard MegaMoE and GenPhase share these preparation paths.

The routing checker reuses compiled code across token counts and keeps separate assertion buffers for each captured shape. Unsupported layouts and dtypes retain the Torch path.
