## Summary

- Add an SM100 CuTe DSL kernel that fuses the Kimi K3 width-four depthwise
  causal convolution, SiLU, recurrent KDA update, and gated RMSNorm.
- Add the public `flashinfer.fused_kda_decode` API, API documentation, and an
  `fi_trace` definition.
- Preserve the production paged-cache layouts and update both the convolution
  cache and FP32 recurrent state in-place.
- Support the Kimi K3 decode configurations with head dimension 128 and
  12, 24, 48, or 96 heads.
- Add all 17 production-shape correctness cases and a CUDA Graph capture/replay
  test.
