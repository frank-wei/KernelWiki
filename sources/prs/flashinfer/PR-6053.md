## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Related to #6052. Addresses #6165.

Adds experimental **Cake MoE training** with BF16 or native MXFP8 routed experts and a BF16 shared expert, for Blackwell (`sm_100a`, `sm_103a`) and Rubin (`sm_107a`). It includes:
- context-only recompute;
- clamped SwiGLU;
- 256- and 288-expert layouts;
- variable per-rank sequence lengths, including empty ranks.

This update reports two of the four (GPU, precision) combinations against [MoK #17](https://github.com/cursor/mixture-of-kittens/pull/17): **GB300 BF16** (EP4–EP64) and **Rubin MXFP8** (EP4; EP8 and EP16 pending). GB300 MXFP8 and Rubin BF16 are implemented and pass the same correctness checks; their tables will follow.

## API

- **`flashinfer.mok.prepare_mok_bf16(..., clamped_swiglu=False, fp32_wgrad=False)`** returns the adapter: scheduling, a fused forward, a fused backward, and a context-only `recompute_forward_context`. Recompute follows MoK's semantics: dispatch, the gate/up GEMMs and SwiGLU, without the down projection, combine or output epilogue.
- **MXFP8 routed experts:** pass the routed weights as `(data, scale, ...)` tuples in MoK #17's layout; `quantize_mok_mxfp8_weights` produces them, bitwise equal to the reference recip
