This is a regenerated export of the Cake all-gather matmul backend. It changes which calls run the CTA-pair main kernel on SM100a (B200). No kernel program changes, and SM103a is unchanged.

This PR builds on #6566 (SM103a CTA-pair main kernel for two gate/up shapes), which in turn builds on #6501. Neither is merged yet. The branch was created from #6566's branch `cake-agmm-sm103a-cg2-gate-up-regions`, and the PR targets `main` so that CI runs. Until #6566 merges, the GitHub diff also contains the #6501 and #6566 commits; this PR's own change is one commit: the SM100a region points, the world-size-8 pair twin now delivered for SM100a, and the regenerated tests. Please merge it after #6566.

The change has two parts:

1. **Nine SM100a region points.** Before this PR, SM100a had no CTA-pair regions, so every SM100a call ran the single-CTA main kernel. The SM100a table now has nine entries in the schema from #6566. Each entry is a single point: one padded row count and one N, both taken from a measured inventory shape. The selection rule is unchanged.
