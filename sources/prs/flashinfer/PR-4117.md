## Summary
- migrate the WY output-only GDN decode kernel from deprecated `cute.experimental` decorators to the unified CuTe DSL decorators
- compile SM12x kernels for the device-specific `sm_120a` / `sm_121a` target
- include compute capability in the in-process compile cache key

The kernel uses no experimental-only APIs; the unified DSL supports its TMA, mbarrier, cluster-launch, and occupancy controls. The experimental path emitted a Core MLIR `sm_121` attribute that `nvidia-cutlass-dsl==4.6.1` rejects before compilation.

Closes #3995.
