## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`minimax_h3_qkv_quantize_pack` is the MiniMax H3 fused QKV quantize + pack kernel. Cake has eight variants of it: MXFP8 output and NVFP4 output, each with pack factor P = 1, 2, 4 and 8. This PR delivers all eight on sm_100a and sm_103a. The baseline is the previous Cake version of the same kernel: the loader shipped at FlashInfer main 23f3e8f6. Each variant was timed on the six shapes in the owner's shape list. On GB300 (sm_103a), the geomean speedup is 1.000 for all eight variants. On B200 (sm_100a), it is 1.000 for six variants, 0.999 (a slowdown) for MXFP8_P8 and 1.001 for NVFP4_P8.

### MXFP8_P1 on sm_100a (B200)

NVIDIA B200 (sm_100a), CUDA 13.4, driver 580.82.07. previous = shipped Cake loader at FlashInfer 23f3e8f63b66; new = this PR's export; median GPU time (CUPTI, cold L2), 3 groups × 128 iterations; speedup = previous / new.

| shape | previous (µs) | new (µs) | speedup |
|---|---:|---:|---:|
| M=33472, unit | 321.455 | 321.327 | 1.000 |
| M=38592, unit | 369.726 | 369.839 | 1.000 |
| M=48768, unit | 465.039 | 464.991 | 1.000 |
| M=58944, unit | 560.734 | 560.863 | 1.000 |
| M=74240, unit | 703.759 | 704.062 | 1.000 |
| M=109952, unit | 1038.077 | 1037.886 | 1.000 |
