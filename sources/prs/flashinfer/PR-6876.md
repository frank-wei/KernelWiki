## Summary

Issue #6661 was written against an older main. Three merged commits changed this family before the base. The largest was #6758, the BF16 half of the same family. It deleted all 85 checked-in host bindings, and the 34 TF32 ones (9,497 lines) have been rendered from one template since. It also trimmed the shared runtime (6,478 -> 5,832 lines) and the host shim (3,264 -> 3,169), moved TMA-descriptor encoding into the prepare branch and folded 8 BF16 clusters. This PR is the TF32 half and uses the same three mechanics. It removes dead host code from the shared runtime, moves the device helpers of the 34 TF32 kernel sources into one shared header, and folds 24 kernel clones onto 9 bodies selected by compile definitions. `csrc/kda/tf32/` goes from 35 entries / 97,009 lines to 21 entries / 41,231 lines. Module names, kernel symbols, bindings and launch arguments do not change.
