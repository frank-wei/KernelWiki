## Kimi-K3 NVFP4 SiTU experts: SM103 8192/16384-token rows with an 8-bit per-tile FC2 partial

Route the SM103 (B300) 8192- and 16384-token rows of the Kimi-K3 NVFP4 SiTU experts to an FC2 program that stores its result as an 8-bit per-tile partial (signed INT8, one FP32 scale per 128×128 tile) and to the finalize program that consumes that partial, instead of the BF16 expert output. The route keeps the generic eight stages (quantize, routing, FC1, FC2, finalize) with the tile-128 FC1 already in the tree; the pre-shuffled scale-factor writer and the FC1 that loads its images are no longer launched on SM103 for those rows. The SM100 route of the same rows (pre-shuffled scale factors, nine kernels) is unchanged, and so is every other token count. This change is stacked on the single-token fused quantization + routing FC1 of #6194 and its data-pointer test revision; the PR diff therefore includes those commits until #6194 merges.
