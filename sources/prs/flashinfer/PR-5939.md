## Summary

The Cake-generated non-CP GDN backend (`csrc/gdn/cake`) shipped 112 kernel files that differed only in their
`#define` block, four SM100/SM103 copies that differed in one statement, 108 host shims with a shared 218-line
preamble, and a 56K-line manifest pinned by SHA-256. This PR keeps the compiled kernels identical and removes the
duplication at the file level:

- One kernel source per distinct body (112 -> 41 files). The varying constants of each variant are recorded in the
  manifest as `defines` and passed to `nvcc` as `-D` flags, so every variant still compiles to the same kernel. Three
  prefill variants keep their original file with in-file defines (`dvsplit_initial_bf16state_135bfa59984f`,
  `..._d8b5b50285af`, `dvsplit_initial_f16io_f481beb70ea9`): for these value sets nvcc 13.4 (sm_103a) schedules the
