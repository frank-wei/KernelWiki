## Summary

The Cake variable block-sparse attention (VSA) family had duplicated kernel and launcher sources, unused host code, and a second rendering of the SM90 kernels in CuTe DSL. This PR merges the duplicated sources, removes the unused code and the CuTe DSL rendering, and adds the CPU planner tests to CI. Generated device code does not change: the SM100/SM103 change was checked for identical SASS, and no SM90 device translation unit is modified. Launch behaviour, routes, the public API, defaults and error types also stay the same. `backend="cake_cute"` is still accepted as an alias of `"cake"`.

Scope:
- SM100/SM103 kernels: `csrc/cake_vsa`, `flashinfer/jit/cake_vsa.py`, `flashinfer/cake_vsa.py`.
- SM90 (Hopper) kernels: `csrc/cake_vsa_sm90`, `flashinfer/jit/cake_vsa_sm90.py`, and the planner `flashinfer/cake_vsa_sm90.py`. Both are reached through `VariableBlockSparseAttentionWrapper(backend="cake")` in `flashinfer/sparse.py`.
