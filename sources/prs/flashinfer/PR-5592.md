## 📌 Description

Follow-up to #5567 (fused MoE gate_up projection for Blackwell SM100a). The prepared API
`flashinfer.gemm.prepare_group_gemm_fp8_nt_groupwise_contiguous_silu_quant(a, b, a_scale, b_scale, m_indices).launch()`
and its contract are unchanged; this PR makes the operator fast on **non-uniform expert routings** — experts whose
128-row block count is odd, empty experts, mixed tails — where the merged program paid one dummy 128-row block per odd
expert and N tile (a whole extra wave on the wide-EP32 gate_up shape).

Three generated routes replace the three-kernel chain (`group_gemm_fp8_nt_groupwise_contiguous` (#4734) +
`silu_and_mul` + `per_token_group_quant_8bit(group_size=128)`), selected by the host from `M` and, when known, the routing:
