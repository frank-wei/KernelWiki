## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`cake_causal_conv1d_train` has one data-type variant: BF16 in/out with FP32 math, a packed width-4 depthwise causal conv fused with SiLU, with a forward and a backward program. This PR replaces the sm_100a and sm_103a backward program with its 2-D TMA stage-load version (one 2-D TMA box per tensor and pipeline stage on the per-row copy path). The baseline is the previous Cake version of this kernel in FlashInfer, the backward program from PR #6816.
