## 📌 Description

`chunk_gated_delta_rule` ignored `use_qk_l2norm_in_kernel=True` on the native prefill paths. Callers passing unnormalized Q/K could get incorrect results or NaNs. This PR normalizes Q/K before dispatch when the flag is enabled. The CuTe DSL kernel handles both tensors in one launch, accumulates in FP32 with epsilon `1e-6`, and casts back to the input dtype. Calls with the flag disabled keep their existing behavior.

The normalization helper supports BF16, FP16, and FP32 with any positive D up to 64 KiB per row, including non-power-of-two sizes. That means D up to 32,768 for BF16/FP16 and 16,384 for FP32. Copy width follows row alignment, and wider rows use a reduction across multiple warps. Existing GDN backend shape requirements still apply.

### Normalization performance

I benchmarked Q/K normalization on NVIDIA B200 (SM100) against the original kernel in this PR, FLA, and cuDNN Frost. The updated kernel is 1.61–1.67× faster than the original across the 25 shapes tested.
