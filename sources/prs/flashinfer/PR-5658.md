## Summary

Adds the `tmem` kernel family to the experimental SM110 XQA package: the D512 tree attention schedule on the
tcgen05 tensor-memory accumulator path, one 128-row Q tile x one 256-column output half per 512-thread CTA, with
Q and K/V fetched once per thread-block cluster by TMA multicast. It is exported for all four D512 cache modes
(FP16/FP8 x page128/contiguous) at GQA ratio 8 (Hq = 8 x Hkv, the validated shape family; the frozen trace is
specialised per ratio) and `kernel="auto"` now selects it there, because under the strict cold-L2 protocol it beats
both the previous kernel of record (`register_mma_auto`, PRs #5293 / #5597) and the upstream TensorRT Edge XQA
