## Summary

Closes #5799. The experimental Kimi-K3 fused MoE router is regenerated from its source program so that one kernel source serves both supported architectures and both route block alignments; the per-architecture module trees are replaced by a small registry and a thin launcher.

- **Arch-neutral programs.** 14 programs replace 43 per-architecture, per-`block_m` module pairs. The warp-per-row persistent kernel (GW), the two 4-CTA-cluster builders (Q4S, Q4SP) and the five small-batch cluster kernels (token counts 1, 2, 4, 8, 16) are one source each for SM100 and SM103; their few architecture-specific lines sit behind `__CUDA_ARCH__` guards. The one-join plan builders (L, LP) and the bitmap builder (M) keep one source per architecture because their schedules differ (SM100 L/LP use a one-barrier prefix retrace; M's owner scratch is 256 rows on SM100 and 2048 on SM103).
- **`block_m` is a compile-line define**, `-DBLOCK_M=8|16`, with an `#ifndef BLOCK_M` / `#error` guard, instead of a second copy of every module.
