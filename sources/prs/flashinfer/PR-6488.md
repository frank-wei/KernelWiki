## 📌 Description

After [#5276 — feat(moe): add Rubin locality-domain execution](https://github.com/flashinfer-ai/flashinfer/pull/5276) was merged, [PyTorch updated its stream-execution API in pytorch/pytorch#199128](https://github.com/pytorch/pytorch/pull/199128) to require explicit callback input sequences. This PR updates FlashInfer to that upstream API change and restores compatibility with the newer PyTorch nightly builds.

The updated API is `execute_on_streams(streams, fn, *inputs)`: callback arguments come from the supplied input sequences, rather than an implicitly supplied stream index. FlashInfer's existing two-argument calls reflected the earlier interface and are incompatible with this newer contract. Both FC1 and FC2 now explicitly pass the locality-domain shard indices:

```python
torch.cuda.execute_on_streams(
    localized_streams, callback, range(len(localized_streams))
)
```
