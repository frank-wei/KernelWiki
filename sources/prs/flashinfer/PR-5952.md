## Cake fused BF16 QK RMSNorm + NeoX RoPE + paged KV append (SM90 / SM100 / SM103)

Adds `flashinfer.cake_fused_qk_rmsnorm_rope_append_paged_kv_cache` (re-exported from `flashinfer.rope`): one launch that
unpacks a packed BF16 `qkv [T, (Hq + 2 Hkv) * 128]`, applies optional per-head FP32 RMSNorm (`qk_norm_policy` 0 none / 1
RoPE→norm / 2 norm→RoPE), NeoX RoPE from an FP32 `cos_sin [max_pos, 128]` table, writes BF16 `out_q [T, Hq, 128]`, appends K/V
into paged NHD BF16 caches through a dense `[B, max_pages]` page table (or caller-owned `out_k`/`out_v`) and zeroes the unused
tail of each request's last page. `(Hq, Hkv)` in {(8, 1), (64, 8)}; sm_90a (H100/H200), sm_100a (B200), sm_103a (B300).

Generated sources: `csrc/cake_fused_qk_rope_append/{sm_90a,sm_100a,sm_103a}/*` + manifest (rendered by Cake
