## 📌 Description

Extend QToken-KvBlock-Sparse-Attention to G1–G8, D64/D128/D256, and semantic KV blocks of 4/8/16/32/64/128 tokens. Support shared or per-KV-head sparse patterns and persistent execution. Existing QToken entry points remain compatible.

### Interface

| Input/config | Contract |
| --- | --- |
| Packed Q | `[T,Hq,D]`; device `qo_indptr` partitions request-safe groups of at most G |
| Fixed Q | `[B,Nq,G,Hq,D]`; plan for `B*Nq` groups |
| KV cache | Separate HND K/V tensors `[pages,Hkv,page_size,D]` |
| Physical pages | Dense `block_table[num_requests,max_pages]` |
| Sparse patterns | `indexer_block_ids[T,K]` when shared; `[T,Hkv,K]` otherwise |
| Group capacity | `G*(Hq/Hkv) <= 128`; partial groups are supported |
| Split permission | `split_kv=False` disables splitting; True permits useful splits, independently of Q layout |

`share_pattern_across_kv_heads` defaults to True for QToken and False for the existing Q-block sparse APIs. Both support either setting. Q/K/V/output may be matching FP16/BF16, or FP8 E4M3 Q/K/V with FP16/BF16 output.
