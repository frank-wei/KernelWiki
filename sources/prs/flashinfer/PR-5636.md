## Summary

Round 4 of the radix top-k -> sparse top-p -> sampling pipeline (`flashinfer.cake_sampling`): a new frozen kernel bundle on top of #5607, plus a k-aware dispatch table and a cheaper host launch path.

- **Stage 1, streaming template** (vocabularies above the register-resident capacity, large batches): the filtered elements are gathered into a candidate list shared by the cluster and the remaining radix passes run on that list instead of re-streaming the row; new (8,16) streaming variant. Stage alone 11-22 % faster at V = 262144.
- **Fused small-k tail**: for `top_k_max <= 64` the stage-2/3 work (sort, prefix, top-p cut, one Philox draw) runs on one warp at the end of the stage-1 kernel, so the call is a single launch; the two-launch form stays for larger k and both forms are bit-identical.
