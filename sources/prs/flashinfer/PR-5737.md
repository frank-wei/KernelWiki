Extends the native 64-query-head DSA sparse-attention training kernels (`flashinfer.experimental.cake_dsa_train`, #5704) with:

- **SM107 (Rubin R200) generated programs** for the forward and backward kernels (`csrc/cake_dsa_h64_train/sm_107a/`), regenerated
  together with the SM100 and SM103 programs from the same source revision (one module table for the three architectures).
- **Strided / packed trainer layouts** (GLM-5.2 style, #5675): `q_rope` taken directly from the pre-absorb `q[T,64,256]` slice
  (channels 192:256, head stride 256), `kv` rows read in place from packed `[Tkv,576]` or `[Tkv,704]` buffers (latent `0:512` ‖
  rope `512:576`, optional 128-channel indexer key), `dq` written into caller views, and the backward's latent+rope `dK/dV`
  accumulated straight into a caller-provided packed fp32 `[Tkv,576]` buffer (`dkv_acc`) with an optional destination-row map
  applied in the kernel epilogue — no `contiguous()` / `cat` / `index_add_` copies.
