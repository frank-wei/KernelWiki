## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Cake's `causal_conv1d` training kernel family has two programs, and this PR delivers both. The forward program maps BF16 `x` to BF16 `y` with fused SiLU. The backward program produces BF16 `dx` and FP32 `dweight` using a fixed-order, bitwise-reproducible reduction. Both work on packed sequences (device-side `cu_seqlens`, zero history at the beginning of each document) with width 4, BF16 activations in [S, C] layout (S packed tokens, C channels) and FP32 weights [C, 4]. No other data type, layout or fused form is shipped. No previous Cake version of this kernel exists, so the baseline is the flash-linear-attention (FLA) 0.5.2 Triton `causal_conv1d`: its forward kernel for forward, and its `dx` and `dweight` kernels for backward. FLA and Cake were measured interleaved on the same inputs (median kernel time, cold L2). Across the 14 shapes below, the speedup over FLA is 1.476x–1.918x forward and 4.082x–4.864x backward on GB300, 1.406x–1.842x forward and 4.036x–4.494x backward on B200, and 1.414x–1.986x forward and 3.563x–3.933x backward on R200.

**NVIDIA GB300 (sm_103a).** Driver 580.159.03, CUDA 13.0 runtime (torch 2.14.1+cu130).

| S | C | FLA fwd (µs) | Cake fwd (µs) | Fwd speedup
