## Summary

`deepgemm_mixed_gemm` (mixed FP8 E4M3 x packed FP4 E2M1 GEMM, BF16 output, SM100a/SM103a) becomes one runtime-shape kernel family instead of twelve per-shape programs per architecture.

- **Eight schedule programs, one source each for both architectures.** The shipped catalog carried 24 generated programs (12 per architecture) specialised on `M`, `N`, `K` and the SM count; the sm_103a copies differed from the sm_100a ones only in the persistent-loop stride. The family now has eight programs (four normal schedules BM128 x BN{128,160,224,256}, three swap-AB schedules for small M with BM{16,32,48}, and the BK128 per-128-A-scale schedule), each taking the tile counts and the SM count as kernel arguments and compiled once per architecture from the same source. Only real schedule classes remain template parameters.
