## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
The Cake Sage-FP8 block-sparse attention backend (`flashinfer/cake_sage_block_sparse_attention_backend`) has three kinds of program. The first is the attention forward kernel: head_dim 128, E4M3 Q/K/V with per-token Q scales, per-16-token K scales and per-channel V scales, 64-row query blocks attending to selected 64-token KV blocks (MHA or GQA), and BF16 output with optional LSE. The other two are the fused QK quantizer with V amax (`quantize_qk_vamax`) and the V quantizer (`quantize_v`). The attention kernel ships as one SM100/SM103 kernel and 20 SM120 specializations (RTX PRO 6000 class). This PR updates the SM100/SM103 attention kernel (sm_100a on B200, sm_103a on GB300) and ships it with both quantizers. It also moves the 20 SM120 specializations into the package without changing them, so they compile to the same code as before. The baseline is the previous Cake version on FlashInfer main (`bsa_attn_sm100_blk64_fwd(..., backend="cake")`). Against that baseline, attention is 1.30–1.40× faster and the quantizers are 1.23× faster on GB300; on B200 they are 1.18–1.37× and 1.27× faster.
