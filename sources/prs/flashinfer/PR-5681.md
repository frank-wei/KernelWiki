> Developed by the **CAKE team**, the kernels in this PR **outperform** the relevant **SOTA baselines at the time of merge** on the **vast majority of performance benchmark shapes**, matching them otherwise.

**Implementation policy:** The CAKE team intends to maintain its own independent kernel implementations so that our development does not break any existing upstream implementation. For that reason, we decided not to retain the changes to existing upstream kernels in #5430 and submitted #5681 to revert them. The replacement is provided in #5783 as separate `cake` and `cake_cute` backends. We will modify existing upstream kernels only when there is a specific need to do so.

This PR reverts the CuTe DSL MoE changes from the **CAKE team's** Kimi-K3 SiTU work (optimized on existing kernels by CAKE), since we want to keep CAKE kernel holistic and independent on others' kernel; it introduces no new kernels or SOTA performance comparison.
