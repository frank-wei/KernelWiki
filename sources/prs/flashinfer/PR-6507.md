## 📌 Description

GDN (gated delta rule) chunked prefill and fp32 decode on SM107 (Rubin) ran the Blackwell code paths unchanged and trailed the expected Rubin-vs-GB300 speedup. This PR adds two SM107-only changes. SM100/SM103 code generation and launch configs are unchanged.

### 1. Rubin subclass of the chunked GDN prefill kernel

`RubinGatedDeltaNetChunkedKernel` is a thin subclass: the kernel body is inherited from `GatedDeltaNetChunkedKernel`, and only the following are specialized:

- **Arch tag** `sm_107`.
- **Initial-state load L1 policy: `EVICT_NORMAL`.** The Blackwell class uses `NO_ALLOCATE`, which avoids polluting SM100's small effective L1. SM107 has more L1 headroom, so neighbouring loads reuse sectors of the same lines.
- **Register split without an initial state: 208 / 256 / 40** (compute group 0 / compute group 1 / lightweight warps), up from 216 / 256 / 32. This relieves spills in the lightweight warps; compute group 0 is relieved by the packed math below. The total must stay at or below 504: at 512 the register reallocation can never succeed and the CTA hangs on SM107, so the constructor asserts it.
