## 📌 Description

Follow-up to #6332 (fused QKV projection + QK RMSNorm + RoPE overlapped with the Ulysses head exchange, `flashinfer.comm.QkvNormRopeExchangeOverlap`, implementing the feature request #6304); removes the separate rendezvous launch, one of the three per-call kernel launches of that path.

The Cake backend of `QkvNormRopeExchangeOverlap` currently launches three kernels per call: the two-phase NVLink rendezvous kernel
(route keys `barrier_p0` / `barrier_p1`), the fused producer, and the one-CTA wait kernel. This PR delivers producer programs that fold
the rendezvous into the producer itself and makes them the default launch path on SM90, SM100 and SM103:

* **Folded-rendezvous producers** (`producer_bn128[_pair]_fold{0,1}` / `producer_bn256_pair_fold{0,1}` on SM100 / SM103,
  `producer_bn{128,256}_fold{0,1}` on SM90): the rendezvous of one
