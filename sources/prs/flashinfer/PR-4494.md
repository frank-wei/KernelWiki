## Summary

This PR limits the launch-config changes introduced in #4416 to SM100 and SM103.

- SM100/SM103 use the new M-aware launch configuration.
- Other architectures retain the pre-#4416 dispatch heuristic.
- The compiled-kernel cache is keyed by the selected launch config instead of M, avoiding a separate compilation for every batch size.

## Motivation

The launch configuration introduced in #4416 performs well on GB200 and GB300, but is not consistently beneficial across architectures. Restricting it to SM100/SM103 preserves the measured gains while retaining the previous behavior elsewhere.
