## Summary

The Cake recurrent-KDA decode family (`csrc/kda/flashkda_decode_*`, `cake_kda_decode_*`) and the packed T=1 family (`cake_kda_packed_t1_*`, `cake_flashkda_packed_t1_*`) carried seven kernel bodies that no selector can reach, generator digest comments in every frozen body plus a test pinning them, a per-call `get_device_properties` query on the decode hot path, and two parallel binding-header stacks per family whose text differed only in macro prefixes and the legacy fallback ABI. This PR deletes the unreachable bodies and their variant-list entries, replaces the digest banners with one neutral banner, caches the SM count per device, and serves every surviving body from the shared `cake_kda_decode_binding*.cuh` / `cake_kda_packed_t1_binding.cuh` headers that already existed on `main`. Public API, JIT module names and URIs, backend strings, selection rules and import paths are unchanged; every surviving device body is byte-identical except for the comme
