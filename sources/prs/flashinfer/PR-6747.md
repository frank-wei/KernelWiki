## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR adds Cake-generated sm_107a programs for three kernel families (DeepSeek fused routing, BGMV MoE and concat-MLA-K) and routes them on compute capability 10.7.

GPU: NVIDIA Graphics Device (R200, sm_107a; 212 SMs; compute capability 10.7); driver 620.62; CUDA 13.5 (PyTorch 2.13.0a0). Timing: CUPTI GPU time, cold L2, paired interleaved arms, 100 ms per arm per group x 3 groups; values are medians in microseconds; speedup = baseline median / Cake median (> 1 = Cake faster). Two seeds (17 / 29) per row.

## DeepSeek fused routing (`fused_topk_deepseek`)

FlashInfer's `fused_topk_deepseek` dispatches on (n_group, E) to four kernel forms: `grouped<ScoreT,BiasT,4,8>` (E=256, 8 groups, topk_group 4, topk 8), `grouped<ScoreT,BiasT,1,1>`, `single<…,128>` (n_group == 1, E ≤ 128) and `single<…,384>` (E ≤ 384). Each form covers the nine score/bias dtype pairs of float32, float16 and bfloat16. For compute capability 10.7 only, this PR adds seven multi-token grouped kernels, `grouped_k8g4_mt2` to `grouped_k8g4_mt8`, which handle 2 to 8 tokens per CTA as chosen by the launch header.
