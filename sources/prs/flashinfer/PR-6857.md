## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
The experimental W8A8 MegaMoE EP16 backend `sm103_mxfp8_mxfp8_bf16_cake` has one data-type variant: MXFP8 activations × MXFP8 weights with BF16 output. It runs a single fixed configuration of 16 ranks, 32 experts per rank, hidden 3072, intermediate 5120 and top-8 routing. It is built from six generated device kernels: `publish_push`, `local_pack`, `fc1`, `fc2`, `combine` and `quantize_weights`. This PR regenerates only `fc2` and its manifest entry. `fc2` is the SwapAB FC2 GEMM fused with the routed scatter of its outputs. Every expert-weight (A) and weight-scale (SFA) TMA load in it now carries an L2 evict-first cache hint. The other five kernels and the host package are unchanged. Compared with the kernels on main (PR #6796), forward latency of the full MoE layer is about 0.8% lower (geomean ratio 0.992) across the six shapes below. Per-shape ratios range from 0.986 to 0.995.

**16 × NVIDIA GB300 (sm_103a) in one NVL72 block, CUDA 13.3.** Forward span of the full MoE layer, as the rank-max CUPTI median under CUDA-graph replay. Both arms ran on the same nodes in mirrored pairs. Ratio = this PR / main; lower is better.
