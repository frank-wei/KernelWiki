## 📌 Description

**perf(cute_dsl_mla): let small CuTe-DSL MLA decode launches use more KV splits.**

The CuTe-DSL MLA decode kernel splits each request's KV cache across CTAs and merges the partial results in a separate reducer kernel. The number of splits (`split_kv`) was capped at a static 48. That is plenty once a few work units (requests x 128-row query tiles) share the GPU, but a single long request launches only 2 x 48 = 96 CTAs and leaves more than half of a 208-SM GPU idle (about a third of a 148-SM one).

This change raises the cap only when the launch has too few work units to fill the GPU at 48 splits, which in practice means one or two query tiles: the cap becomes the number of resident 2-CTA clusters divided by the work-unit count, bounded to [48, 128]. On a 208-SM part that is 104 splits for one unit and 52 for two; on a 148-SM part it is 74 for one unit and 48 otherwise. Launches with three or more units on today's parts are unchanged.
