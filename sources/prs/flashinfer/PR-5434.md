## 📌 Description

Add native BF16/E4M3 D512 sparse MLA for prefill and decode on SM100/SM103. One attention pass supports a primary KV pool and an optional extra pool, including SWA + compressed KV, sinks and LSE.

### Optimizations

- Choose query tiles, split-KV, 1CTA/2CTA and persistence from work geometry and SM count to balance occupancy against reduction cost.
- Load page-size-one KV with TMA gather4, prefetched offsets and cached coordinates. Bulk TMA requires 32 verified consecutive physical rows; random compressed KV still gathers.
- Retain K for reuse during PV when shared memory permits; short splits share a softmax warp group across streams.
- Use bounded-anchor softmax in selected BF16 schedules; FP8 keeps exact maxima and correct output-accumulator rescaling.
- Finalize both sources, sinks/LSE and optional output RoPE + quantization in the main kernel or existing split reducer. Packed FP32 rotation, vector stores and eligible asynchronous TMA output stores reduce epilogue overhead.
