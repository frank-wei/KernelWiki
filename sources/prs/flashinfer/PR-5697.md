## 📌 Description

`mm_fp4(..., alpha=per_token_scale)`) on SM100 (B200) and SM103 (GB300): the path is redone as Cake kernel programs
in the Cake kernel-generation harness and exported as generated CUDA sources + a TVM-FFI host binding into
`flashinfer/experimental/cake_nvfp4_per_token/`. Nothing in the CuTe-DSL kernels changes.
