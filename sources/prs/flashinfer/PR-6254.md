## Summary

The `cake_all_gather_matmul` consumer stages each peer's `A_scratch` rows into
shared memory with a TMA (`cp.async.bulk.tensor`, async proxy). `A_scratch` is
written by a peer GPU in the generic proxy — the SM-push path
(`st.volatile.global` over NVLink) or the copy-engine push — and the peer signals
arrival via the ready counter, which the consumer polls with `ld.acquire.sys.global`.
