## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Regenerated export of the Cake all-gather matmul backend from the same generator as #6440, rebased on `main`. This export makes two changes. Both apply to SM103a only:

1. **SM push route band.** A world-size-8 call takes the SM push instead of the copy-engine push when its rows pad to 1024 and its N is at most 1619. In the shape inventory this moves one shape: TP8, M=1024 per rank, N=1280, K=8192, bf16, K-major weight. That shape runs 8.1–8.3 % faster. This change does not touch any kernel.
2. **CTA-pair main kernel for measured regions.** The persistent main GEMM kernel with 256-column tiles gets a CTA-pair twin that runs `tcgen05.mma.cta_group::2` over a cluster of two CTAs. A per-architecture region table decides which calls use it. In the shape inventory this moves four shapes: two world-size-2 bf16 N-major shapes and two TP4 bf16 K-major QKV shapes. These four run 5.8–11.5 % faster.

The speedups come from paired runs on two 8×B300 nodes. Every changed shape is faster on both nodes, and its outputs are bitwise identical. SM100a has an empty band and no regions, so its routes and programs are unchanged.
