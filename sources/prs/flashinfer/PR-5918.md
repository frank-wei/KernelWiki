## What changes

`csrc/cake_minimax_h3_mxfp8_pre_attention` goes from 352 generated files (154,968 lines: 2 architectures x 44 (M, P) routes
x 2 stages x {kernel, binding}) to 3 files (1,542 lines); the family (sources, loaders, host module, tests) is net -153,391
lines without changing a single compiled instruction.

- **One source per stage.** The 176 per-route kernel files of each stage were identical outside their `#define` block
  (stage 1 varies only `M`; stage 2 varies `M`, `P` and three constants derived from them) and the SM100/SM103 trees differed
  only in the hashed symbol. Each stage is now one device source (`..._norm_adaln_quantize_device.cu`,
  `..._qk_rope_destination_pack_device.cu`) with the schedule constants left to the including translation unit.
