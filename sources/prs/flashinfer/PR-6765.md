## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Cake's RMSNorm training kernels for BF16 activations with FP32 row statistics come in four variants: forward, forward with fused residual add, backward, and backward with fused residual gradient. This PR re-exports all four. It replaces the `flashinfer/cake_rmsnorm_train_backend` package that main ships at 1279c565. Compared with that previous Cake version, the geometric-mean speedup over the 56 rows below is 1.002× on B200 (min 0.972×, max 1.038×) and 1.002× on GB300 (min 0.980×, max 1.036×). The largest gains, about 1.03×, are in the backward kernel at hidden size 512 for T ≥ 16172. A few rows under 10 µs are 1–3 % slower.

Kernel latency in ms (steady-state median) and speedup (previous Cake version latency / this PR's latency; above 1x means this PR is faster) on NVIDIA B200 (sm_100a) and NVIDIA GB300 (sm_103a), CUDA 13.4 (nvcc 13.4.92); both versions were timed interleaved on the same GPU, and the residual variants were measured at hidden size 6144 only.

| Variant | Hidden size | Rows (T) | B200: previous Cake version (ms) | B200: this PR (ms) | B200: speedup | GB300: previous Cake version (ms) | GB300: this PR (ms) | GB300: speedup |
|---|---:|---:|---:|---:|---:|---:|---:|-
