## Summary

> Must be merged after https://github.com/flashinfer-ai/flashinfer/pull/4079 and https://github.com/flashinfer-ai/flashinfer/pull/4101

- Adds the first Hopper mega kernel to the moe_ep stack: the kernel team's SM90 pull-style FP8 CuTeDSL MegaMoE (Vincent's `hopper_megamoe`, kernel repo commit `1275b8b`), integrated as a new `sm90_pull_fp8` backend behind the existing `MegaKernelBackend` contract — fused NVSHMEM dispatch + FC1 + SwiGLU + FC2 + combine in one launch, FP8 E4M3/E5M2 with per-tensor or DeepGEMM-style blockwise scaling, native and swap-A/B layouts.

- New oracle test paths: every mega kernel (SM90 **and** the three existing SM100 paths) now has a **multi-rank torch oracle** — real cross-rank EP launches judged against pure-torch global math instead of same-kernel parity.
