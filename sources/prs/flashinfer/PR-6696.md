## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
> Developed by the **CAKE team**, the kernels in this PR **outperform** the relevant **SOTA baselines at the time of merge** on the **vast majority of performance benchmark shapes**, matching them otherwise.

This PR fixes and slims `cake_mxfp4_situ_moe`, the Cake-generated Kimi-K3 W4A8 MXFP4 SiTU routed MoE in `csrc/fused_moe/cake_mxfp4_situ_moe`. It ships as two JIT-only backends for sm_103a: `flashinfer.fused_moe.cake` (CUDA) and `flashinfer.fused_moe.cake_cute` (CuTe DSL). The PR first fixes the `AttributeError` that some plain-chain rows raise on `main`. It then deletes the 16 stages that no executable plan decision selects. Finally, 9 dense GEMM `_nopdl` modules in each backend reuse their PDL twin's kernel source (CUDA) or program (CuTe DSL) instead of keeping a duplicate. There is one commit per step, so four commits in the order below. The three cleanup commits together delete 91 files (89,473 lines): 64 in commit 2, 9 in commit 3 and 18 in commit 4. The per-commit diff stats add up to +9,360 / −108,360, and the module count goes from 152 to 136 (CUDA) and from 140 to 124 (CuTe DSL). Each commit's section below keeps the verification for that step.
