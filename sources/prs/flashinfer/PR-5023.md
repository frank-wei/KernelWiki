## 📌 Description

<!-- What does this PR do? Briefly describe the changes and why they’re needed. -->

This PR adds out-of-place PCIe IPC all-gather and SUM reduce-scatter for
single-node tensor-parallel communication on PCIe systems. It provides
GPU-resident communication paths with topology-aware schedules and
shape-specific launch tuning.

Both operators reuse persistent CUDA IPC workspaces and synchronize through
GPU system-scope flags. Their steady-state paths avoid host-side collective
coordination.

- All-gather: flat push for TP4, recursive doubling for TP2/TP4/TP8, and a
  copy-engine path for supported TP8 topologies.
- Reduce-scatter: flat TP2/TP4 kernels and TP8 kernels that reduce within each
  four-GPU island before exchanging partial sums across islands.
- BF16, FP16, and FP32 support; contiguous rank-2 tensors; CUDA Graph
  capture/replay; optional caller-provided outputs and launch configurations.
- Correctness-checked tuning with exact-shape caching keyed by collective,
  dtype, world size, GPU placement, and workspace limits.
