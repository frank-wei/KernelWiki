## Summary

Adds an **opt-in uncompensated variant** of the SM120 NVFP4 packed-varlen attention for MiniMax-H3 as a separate public function,
`flashinfer.diffusion_ops.minimax_h3_sm120_varlen_attention_nvfp4_nodelta`, beside the existing
`minimax_h3_sm120_varlen_attention_nvfp4` (#5629). Same signature, workspace, plan cache and pre-processing launches; only the attention
kernel differs: Q rows are still quantized after 128-row block-mean centring, but the block-mean term `qm K^T` is **not** added back to
the scores. The trade: a measurably larger FP4 error (relative L2 vs an FP32 oracle about 0.210 vs 0.191 on Gaussian inputs, i.e. 1.10x on
segments of full 128-row blocks, larger on short partial blocks — see the numerics table) for a 1.02-1.10x faster complete operator and a
