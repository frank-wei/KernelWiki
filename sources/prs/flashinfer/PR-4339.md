## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Developed by the **CAKE team**, the kernels in this PR **outperform** the relevant **SOTA baselines at the time of merge** on the **vast majority of performance benchmark shapes**, matching them otherwise.

## Summary

Use size-specific fused routing kernels for tiny, small and medium batches, and a producer/tail path for large batches. The export embeds nine source-identical NVRTC cubins through TVM-FFI and launches them with the CUDA Runtime API. This requires **CUDA 12.8 or newer** and preserves the public routing API and shared-logit softmax semantics.

Current public commit: `3c784bbf9ed3899f962160e10cf4efce18ecd069`.

## Performance

GB300/SM103a, 512 experts, no shared expert. The metric is the cold-L2 strict-CUPTI **sum of GPU kernel durations for the complete operator**, including producer and tail for the large shape. Ratios are medians of six within-round ratios.

| M/k/BM | Stock / export | v53 public / export | Frozen source / export |
| --- | ---: | ---: | ---: |
| 32/8/16 | 1.349352× | 1.160870× | 1× |
| 128/8/16 | 1.211765× | 1.124579× | 1× |
| 8/10/8 | 2.378180× | 1.212903× | 1× |
| 128/10/8 | 1.716815× | 1.157286× | 1× |
| 512/10/8 | 2.132780× | 1.668050× | 1.0041
