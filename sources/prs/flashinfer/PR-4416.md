## 📌 Description

  This PR improves the fused add + RMSNorm + FP4 quantization kernel by:

  - Deriving row parallelism from the number of FP4 scale-factor blocks.
  - Using vectorized shared-memory loads and packed BF16/FP16 operations for the block-size-16 single-CTA path.

## Benchmark

  BF16, block size 16, E4M3 scales, swizzled scale layout, CUDA Graph.

  Shapes:

  - M: 1–1024, powers of two
  - H: 1024–7168, step 1024
  - 77 shapes per GPU

  The unfused baseline includes both the Inductor-compiled add + RMSNorm and the CUDA FP4 conversion.
