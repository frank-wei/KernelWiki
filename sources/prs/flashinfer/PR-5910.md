## Summary

`csrc/tinygemm2_sm100.cu` concatenated six generated kernel sections — pipeline ring depth STAGES in {4, 8, 16} x PDL off/on — whose bodies differed only in their constant blocks (shared-memory offsets, mbarrier count, ring slot/phase arithmetic, one `griddepcontrol` block). This PR replaces them with one `tinygemm2_kernel<int STAGES, bool USE_PDL>` whose six instantiations compile to the same SASS as the former sections (proof below), removes the test-only per-stage FFI exports, replaces the three mutex-guarded static caches in the binding with per-device once-flags, caches the Python dispatch gate, and fixes the docstring and generator-specific type names. Public API, JIT module name (`tinygemm2_sm100`), op name (`tinygemm2_sm100_op`), ring-depth selection rule and `FLASHINFER_DISABLE_TINYGEMM2_SM100` semantics are unchanged; outputs stay bit-identical to `csrc/tinygemm2.cu` (parity tests use `torch.equal`).
