## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Developed by the **CAKE team**, the kernels in this PR **outperform** the relevant **SOTA baselines at the time of merge** on the **vast majority of performance benchmark shapes**, matching them otherwise.

## Summary

Round 5 of the epilogue-fused NVFP4 QKV GEMM for MiniMax-H3 pre-attention (`cake_minimax_h3_nvfp4_pre_attention`, SM100a / SM103a): the SM103a program's epilogue now runs as one 16-warp role with a warp-uniform column set instead of two eight-warp copies of the same code (half the epilogue instruction footprint, no stack frame). The SM100a program is unchanged. Numerics are unchanged: byte-exact against the segmented reference chain on all 44 contract rows on both architectures.

## Performance (paired, same node and session, cold-L2 CUPTI)

SM103a (B300), unified role vs the previously shipped two-role program, 24 production rows, three interleaved reps per row:

| row | two per-set roles (us) | unified role (us) | ratio | mismatched bytes |
|---|---|---|---|---|
| center_p1_4s_m33472 | 1298.1 | 1287.8 | 1.0080 | 0 |
| center_p2_4s_m16736 | 639.8 | 626.7 | 1.0209 | 0 |
