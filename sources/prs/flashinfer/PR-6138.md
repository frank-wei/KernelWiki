## 📌 Description

The pinned NVFP4 MSA decode family writes Q, the dequantized K/V tiles and P into SMEM with generic stores. `tcgen05.mma` then reads them through the async proxy, with no `fence.proxy.async` between the two. On GR100 and B200, repeated calls of the unclustered split-1 instantiation disagree with the first call. This intermittently failed `test_msa_nvfp4_decode_sm100.py::test_out_is_bit_identical_to_the_copy_it_replaces_across_both_families[b64-sq1-pinned]`. Each writer now issues `fence.proxy.async.shared::cta` before the four barriers that hand fresh tiles to the MMA issuer (QK first/second half, PV first/second half).

Run-to-run determinism, C++ TU forced, fixed inputs, seq 8192, calls not bit-identical to the first out of 3,000:

| GPU | row | family | before | after |
|---|---|---|---|---|
| GR100 (cc 10.7, 208 SMs) | b64 | pinned split-1 | 51 | **0** |
| GR100 | b128 | pinned split-1 | 96 | **0** |
| GR100 | b33 | pinned split-1 | 0 | 0 |
| GR100 | b32 / b16 | general | 0 / 0 | 0 / 0 |
| B200 (cc 10.0, 148 SMs) | b64 | pinned split-1 | 3 | **0** |
| B200 | b128 | pinned split-1 | 19 | **0** |
| B200 | b33, b32 / b16
