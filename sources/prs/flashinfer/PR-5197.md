## 📌 Description

### TLDR

Reorganize SM120 sparse MLA into a package with clear ownership and add **DSv4.1 dual-cache attention** (FP8/BF16 compute, FP4/FP8 extra cache), **runtime page/head/topk dispatch** for the six ordinary families, and **per-configuration L2-cold calibration** with unified prepared execution. Fixes empty-effective-KV semantics (#4484), startup calibration recovery (#5142), and the finite-instantiation dispatch gaps reported in #4541/#5135/#5192. 947 tests pass on SM120 (CUDA 12.9 and 13.2) and SM121 (GB10); kernel performance is within 1% of the pre-refactor baseline on a 95-point matrix, with DOTS3 SG 6.9–11.9% faster.

### Features

- **DSv4.1 dual cache**: primary FP8 cache plus optional FP4/FP8 extra cache, independent topk/page sizes, FP8 or BF16 compute. New public APIs `dsv41_fp4_quantize_pack_sparse_mla_cache` / `dsv41_fp4_quantize_append_sparse_mla_cache` with docs, trace templates, and generated examples. The DSv4 compatibility layout accepts page 32, covering vLLM's page-32 DSv4.1 allocation.
