# Add task-scheduled Blackwell attention kernels

## Summary

This change adds experimental FMHA context, FMHA decode, and MLA decode kernels under `flashinfer.attention.prims_ts` for Blackwell GPUs. They are built from CUTLASS 4.7 primitives plus the TS task scheduler. TS composes cooperating load, MMA, online-softmax, correction, reduction, epilogue, and scheduling tasks with their global/shared/tensor-memory resources and pipelines. QK/PV accumulation and softmax state use FP32.

Each component provides reusable `plan()`/`run()` and one-shot APIs; decode also supports standalone launches with caller-owned workspace. Planning validates geometry and compiles a specialization, while `run()` consumes device metadata without host synchronization. Scheduling and reduction remain internal. CUDA Graph capture is supported for all three families; `fi_trace` currently covers FMHA decode and MLA decode, while context tracing is deferred.

## Feature support

- **FMHA context/prefill:** fixed BSHD, packed-ragged THD, and packed-Q paged HND K/V; MHA/GQA; D128/256; FP16/BF16/FP8 input and output; dense, bottom-right causal, and causal left-window masks.
- **FMHA decode:** any positive fixed Q
