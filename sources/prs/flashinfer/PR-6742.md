## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`cake_all_gather_matmul` all-gathers each rank's row-sharded activation and multiplies it by a contiguous `[N, K]` weight. Cake ships it in bf16 and fp16, K-major and N-major weights, world sizes 2, 4 and 8, two main-tile widths and two transport routes (copy engine, SM push). This PR delivers one SM103a (B300) variant: world-size-8 calls with 512 padded rows on the SM-push route publish operand readiness per K-slice (4 slices per peer) instead of once per peer, so each rank's GEMM starts on the first slice while the rest arrive. It adds one push program (`peer_push_wide_ks4`) and six `_ks4` main programs; the GEMM math is unchanged. The table compares it with the previous Cake version of this kernel, the programs of the PR it is opened against (#6624).

| Shape per rank, M × N (world size 8, K = 8192) | Node | Previous version (µs) | This PR (µs) | Speedup |
|---|---|---:|---:|---:|
| 512 × 1280, fp16, K-major weights | node 1 | 177.6 | 171.3 | 1.033 |
| 512 × 1280, fp16, K-major weights | node 2 | 181.3 | 174.1 | 1.045 |
| 512 × 1280, bf16, K-major weights (Llama-3.1-70B TP8 QKV) | node 1 | 170.9 | 176.2 | 1.003 |
