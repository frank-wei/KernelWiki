## Summary

Replaces the hand-written `concat_mla_kv_quant_fp8` CUDA kernel from #5667 with generated Cake kernels behind the same public
API (`flashinfer.concat_mla_kv_quant_fp8(kv_nope, k_pe, key=None, value=None, *, nope_dim=128) -> (key, value)`), dispatched by
compute capability (SM100 / SM103) and by the head-group plan the host computes from `(num_tokens, num_heads)`. This PR is stacked
on #5667 and includes its commits; the API, the in-place semantics and the byte-exact saturating e4m3 cast (RNE, clamp to
+-448, NaN -> 0x7F; verified on all 65536 bf16 input patterns) are unchanged, and the composable torch fallback outside the
dispatch surface is #5667's with the NaN-sign fix of `a0475feae` (see the credit note below).

Why: the generic head-count path of #5667 processes one head pair per warp (1 KB in flight), which leaves 7-32 % against the raw
