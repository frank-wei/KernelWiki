## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Implements steps 2-4 of #6553, which make the Cake-exported packages vendorable. Step 1 (#6571, merged) made each package directory self-contained. This PR does four things:

- Every package now ships a `build.json` manifest.
- All seven packages share one `cake_build.py` loader.
- The bindings include no FlashInfer header.
- The MoK (Mix of Kittens) package gains sm_107a kernels: 8 BF16 kernels are added and 8 MXFP8 kernels are re-rendered for the sm_107a shared-memory descriptor encoding. They are compile-checked with nvcc 13.4 (`compute_107`); this PR includes no sm_107a hardware run.
  These kernels are the Rubin (`sm_107`) build of the MoK forward / recompute / backward paths requested in #6165.

As a result, a package can be built and loaded outside FlashInfer.
