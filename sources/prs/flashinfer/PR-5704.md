Experimental API + Cake backend for the native 64-query-head DeepSeek Sparse Attention training kernels
(top-k sparse MLA with absorbed queries) on SM100 (B200 / GB200; acceptance architecture) and SM103
(GB300; same sources, measured with the same protocol). Addresses #5657 (GLM-5.2: 64 heads, 512 latent + 64 rope query/key
dimensions, 512 value dimensions, top-k 2048, BF16 inputs, FP32 accumulation).
