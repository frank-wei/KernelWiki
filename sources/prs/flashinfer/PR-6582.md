## Summary

This PR updates the generated Cake SSDCombined programs for B200 (sm_100a) and GB300 (sm_103a). It also updates the loader `flashinfer/mamba/cake_ssd_combined.py`. The baseline is the previous release, FlashInfer `36fd76859292ac2ac5aebd0892fc64715569b9da` (PR #6330 merge). The public API is unchanged.

### Program families

`csrc/cake_mamba_ssd_combined/` now holds 49 device sources and 5 host templates. The loader table lists 48 programs.

| Family | Device sources | What it is |
|---|---|---|
| `exact_*` | 12 | Previous-release two-kernel exact scan, retained byte for byte. |
| `exactfused_*` | 12 | Fused single-launch exact scan: preprocess and scan in one launch. |
| `exactpre_*` | 12 | This release's two-kernel exact scan: standalone preprocess, then the main kernel. |
| `chunkpar_*` | 6 | Single-pass chunk-parallel scan with decoupled look-back (fixed Horner fold, range partition). |
| `chunkpar3_*` | 6 | Three-phase chunk-parallel program of the previous release. Its results are bitwise equal to that release. |
| preprocess | 1 | Metadata preprocess kernel. |

`exact_*` binds the 41 start arguments (`_MAIN_ARGS_START`). `exactfused_*` and `exactpre_*` bind all 44
