## Summary

Closes #5798.

Regenerated delivery of `flashinfer/experimental/kimi_k3_tp12_tail` (Kimi-K3 TP12 decode tail: Lamport all-reduce + RMSNorm K1, up-projection reduce-scatter / add / multicast all-gather tail; SM100a / SM103a; twelve ranks). Public entry points, program names, launch configurations and numerics are unchanged.

- **One source per program.** Each of the 9 programs is one `*_kernel.cu` / `*_binding.cu` pair compiled for both SM100a and SM103a; the only per-architecture lowering difference (the shared-memory base pointer) is a `__CUDA_ARCH__` guard inside the source. 44 modules (22 per arch) -> 9 programs; 88 generated files -> 20.
- **K23 keyed by capacity.** The `k23:n512:c*` and `k23:n640:c*` modules were byte-identical, so K23 is now `k23:c4` / `k23:c8` and the rank's column width only sizes the grid.
