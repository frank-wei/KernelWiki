## 📌 Description

 Improves TRT-LLM MoE routing top-k performance by using a two-step fast warp reduction for 64-bit packed FP32 keys on SM100+, and replacing non-power-of-two odd-even transposition sorting with a padded Batcher odd-even merge network. The new sort path preserves descending order while reducing comparator count for non-power-of-two candidate sizes.

This speeds up Large N/T, and non pow of 2 K perf
