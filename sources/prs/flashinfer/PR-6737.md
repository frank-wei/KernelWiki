## Summary

This PR cleans up the Cake-generated MiniMax-H3 diffusion operators:

- **SM100/SM103:** the MLP, FC1+SwiGLU and out-projection GEMM modules. Sources are `csrc/cake_minimax_h3_{mlp,fc1_swiglu,out_proj}_sm10{0,3}a.cu` and loaders are `flashinfer/jit/minimax_h3_*.py`.
- **SM120:** the quantized operators. These are FC1+SwiGLU, MLP, pre-attention, out-projection, and FP8 / NVFP4 varlen attention, including the nodelta entry. Their hosts are under `flashinfer/diffusion_ops/`.
- **Experimental:** the dense NVFP4 attention binding under `flashinfer/experimental/nvfp4_attention/`.

The PR has five commits:

1. Merge each SM100/SM103 operator's `_sm100a.cu` / `_sm103a.cu` pair into one `_sm10x.cu` file. The file reads the architecture minor from `-DMINIMAX_H3_SM_MINOR`.
