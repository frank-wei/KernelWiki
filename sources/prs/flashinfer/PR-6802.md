## Summary

This PR removes duplicated and dead code from the experimental Cake-generated DSA indexer top-k in `flashinfer/experimental/cake_dsa_indexer/`. The family serves `flashinfer.dsa_indexer.dsa_indexer_topk(..., backend="cake")`, JIT only, on sm_100a, sm_103a and sm_107a. The PR does three things:
- It deletes 29 kernel translation units and 57 TVM-FFI bindings. Their build entries now compile a kept sibling source with their own `-D` flags.
- It drops the test-only lever table and unused registry glue.
- It caches the validated dispatch policy per architecture.

The diff against the base is 122 files, +2,829 / -41,042 (net -38,213), all inside the family. Every program keeps its kernel symbol, host-shim namespace, library name, dispatch keys, launch geometry and arguments. Program selection, launch arguments and results are unchanged for every input.
