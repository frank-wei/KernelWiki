## 📌 Description

Fix all actionable findings from an LLM Doc Check audit of the live
https://docs.flashinfer.ai/ site (193 unique findings across a 411-page crawl).

This PR:

- corrects API-contract and factual issues, including speculative-sampling
  return types, POD indptr names, sparse-attention mask/output descriptions,
  grouped GEMM arguments, cascade cache naming, and the current KDA kernel-body
  count;
- fixes malformed RST, typos, grammar, and ambiguous wording across API docs,
  tutorials, and generated API docstrings;
- updates stale descriptions to match the current implementation, including
  grouped-MM backends and autotuning cache behavior.

Findings that were already absent from `main` (live-site deployment lag) or
were generated by inherited standard-library documentation were verified and
left unchanged rather than introducing incorrect source edits.
