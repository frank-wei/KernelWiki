## Summary

Adds the SM120 (GB202: RTX 5090 / RTX PRO 6000 Blackwell) FP8 and NVFP4 **fused MiniMax-H3 attention output projection** requested in #4532 (candidate `5090-K3`), tracked in #4254: `attn_out [M, 7168]` BF16 → per-token FP8 / block-16 NVFP4 activation quantization → `mma.sync` GEMM 7168→5376 with the prepacked quantized weight → fused indexed gate × output + residual → BF16 `[M, 5376]`.

One `sm_120a` kernel launch per call (persistent, one 384-thread CTA per SM): the producer warpgroup's spare warps quantize the activations in M-tile order and publish per-tile ready flags, the TMA producer warp acquires a tile's flag before streaming its operands, and two `setmaxnreg` MMA warpgroups run 256x128 tiles (`kind::f8f6f4` m16n8k32 / `kind::mxf4nvf4` m16n8k64) with the fused dequant → BF16 → `BF16(residual + BF16(gate[gate_index[m]] * o))` epilogue (SGLang `indexed_gate_bf16` round points; out-of-range `gate_index` rows reproduce the residual).
