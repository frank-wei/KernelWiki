## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
> Developed by the **CAKE team**, the kernels in this PR **outperform** the relevant **SOTA baselines at the time of merge** on the **vast majority of performance benchmark shapes**, matching them otherwise.

Adds a standalone Cake-generated fused QK RMSNorm + NeoX RoPE + FP8 E4M3 quantize + NHD paged-KV append route, `flashinfer.cake_fused_qk_rope_fp8_append.cake_fused_qk_rmsnorm_rope_quantize_fp8_append_paged_kv_cache` (re-exported from `flashinfer.rope`), for SM90 (H100/H200), SM100 (B200) and SM103 (B300). Resolves the SM90/SM100 part of #5368. Same layout as the merged BF16 route #5952.

This PR is based on `main` and is self-contained: no code from, and no dependency on, any other pull request. The entry point, argument order and buffer ownership are defined here (see Contract).
