## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`cake_rmsnorm_train` (`flashinfer.cake_rmsnorm_train`) is Cake's family of RMSNorm training kernels in FlashInfer. All of them use one data type: BF16 activations and weight, FP32 statistics (`rstd`) and an FP32 weight gradient from a deterministic (fixed-order, atomic-free) reduction. Cake ships four variants: the plain forward (`y`, `rstd`), the plain backward (`dx`, `dweight`), and the residual-fused forward and backward. This PR adds the plain forward and backward at two new hidden sizes, H=1536 and H=4096, on sm_100a (GB200/B200), sm_103a (GB300) and sm_107a (R200). That is 16 new programs and 32 new build entries, and each architecture has its own tuned program table. The residual-fused variants still reject these two widths. Every previously shipped program is byte-for-byte unchanged.

No earlier Cake version covers these widths, so each row's baseline is the fastest of five non-Cake implementations, measured in the same process on the same GPU with PyTorch 2.14.1+cu130, Triton 3.8.0, liger-kernel 0.8.4 and FlashInfer 0.7.2 (main): `torch.compile` (inductor) RMSNorm forward/backward, eager FP32 autograd, `torch.nn.functional.rms_norm` autograd (`F.rms_norm`), Liger-Kernel RM
<!-- upstream-excerpt-end -->
