## 📌 Description

@humansand

Allow the CUB-backed `top_k_page_table_transform` and `top_k_ragged_transform` APIs to return padded outputs when `k` exceeds the physical score width. For example, width 64 with `k=2048` now selects every valid position and pads the remaining slots with `-1`, matching the fused APIs' existing native behavior.
