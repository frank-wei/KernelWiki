## 📌 Description

Stacked on #6613 (merge that first); the diff against #6613's head is this change.

This PR adds compute capability 10.7 (SM107, Rubin R200) as a target of `flashinfer.comm.QkvNormRopeExchangeOverlap`. That is the fused QKV projection + per-head QK RMSNorm + RoPE + Ulysses exchange session. The generated files are rendered from the upstream generator at 196f4cf2.

What SM107 adds:

* **SM107 producer programs.** The SM107 tcgen05 producer programs have wider SMEM-descriptor address masks. They are therefore delivered as their own content-hashed programs. Three programs are new.
* **Shared programs.** If a stage's SM107 text is identical to an existing program, that program only adds `sm_107a` to its architectures.
* **Tables.** The program and architecture tables have SM107 entries. The plan and world-size tables have SM107 rows.
* **Unsupported devices.** A device whose capability has no program table still raises the explicit error. It never runs another architecture's program.

Defaults on SM107:

| Setting | SM107 default |
|---|---|
| World sizes | 2 and 4 (SM107 nodes carry four GPUs) |
| Folded rendezvous producer (`fold_barrier`) | on, as on the other arch
