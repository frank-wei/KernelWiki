## 📌 Description

Add fused normalization and TP/EP MoE kernels for Muse Spark that combine normalization, gating, residual operations, and communication to reduce intermediate tensors, kernel launches, and data movement.

- **Gated residual RMSNorm fusion:** Fuse RMSNorm, gating, and residual combination into one kernel while preserving the FP32 residual stream.
- **RMSNorm + sigmoid gate fusion:** Fuse per-head RMSNorm and sigmoid gating with runtime-token kernel reuse, full-tile specialization, and PDL support.
- **Gated residual dual norm fusion:** Fuse branch normalization, gated residual combination, and next-layer RMSNorm with optional input scales, scalar gates, FP32 router output, and PDL support.
- **TP MoE finalize fusion:** Fuse TP reduction, per-expert RMSNorm, and weighted expert accumulation directly from permuted GEMM2 rows, with token-owner paths for medium and large token counts.
- **All-gather + gated residual dual norm fusion:** Fuse column all-gather with gated residual dual normalization.
