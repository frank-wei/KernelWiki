## 📌 Description

### Motivation

This PR updates the Blackwell GDN prefill programs used by 84 of the 143 prefill records in the cake_gdn manifest, on sm_100a and sm_103a. We measured 82 engine-shaped prefill rows per architecture. By geometric mean, the exported package is faster than the published package by 1.0103 on GB300 (sm_103a) and 1.0112 on B200 (sm_100a). Outputs are bit-identical on every row. Against `chunk_gated_delta_rule(..., backend="auto")` on the same inputs, the geometric-mean speedup is 1.1546 (GB300) and 1.1544 (B200), with every row above 1.

### What changed

- One commit on top of main `04054522fe3fd7a520714283075731aa80dc3cdf`. The `csrc/gdn/cake` package is unchanged between that base and current main.
- Scope is `csrc/gdn/cake/` only:
  - 14 new generated prefill bodies under `csrc/gdn/cake/cuda/`
  - 8 bodies removed because no record references them any more
  - `csrc/gdn/cake/manifest.json` re-pointed (464 lines changed)

  In total, 15 files changed, +31283 / -3645.
- This PR does not touch Python, host code, the launch ABI, any decode body or any sm_107a output.
