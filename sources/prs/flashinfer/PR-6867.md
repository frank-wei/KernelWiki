## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`fused_qk_rope_fp8_append` fuses Q/K RMSNorm, RoPE, FP8 (e4m3) quantization and the paged K/V cache append into one kernel. Cake has one variant of it, with FP8 e4m3 output. This PR delivers that variant on sm_90a, sm_100a and sm_103a. The baseline is the previous Cake version of the same kernel: the loader shipped at FlashInfer main 23f3e8f6. Across the 30 shapes in the owner's shape list, the geomean speedup is 0.961 on H100 (sm_90a), 0.998 on B200 (sm_100a) and 0.994 on GB300 (sm_103a). All three geomeans are below 1.0, so the new export is slower than the previous version on each architecture. sm_90a has the largest slowdown.

### sm_90a (H100)

NVIDIA H100 80GB HBM3 (sm_90a), CUDA 13.0, driver 535.216.03. previous = shipped Cake loader at FlashInfer 23f3e8f63b66; new = this PR's export; median GPU time (CUPTI, cold L2), 3 groups × 128 iterations; speedup = previous / new.

| shape | previous (µs) | new (µs) | speedup |
|---|---:|---:|---:|
| decode, 8q/1kv heads, q_len 1×32, ctx 2048, page 64, quant 1, norm 0 (T=32) | 2.927 | 3.040 | 0.963 |
| decode, 8q/1kv heads, q_len 1×32, ctx 2048, page 64, quant 1, norm 1 (T=32) | 2.944 | 3.167 | 0.930 |
| decode, 8q/1kv heads, q_len 1×3
