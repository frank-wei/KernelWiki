## Summary

Ports 8 CuTe-DSL grouped-MoE ops for Blackwell SM120/SM121 into `blackwell_sm12x`, covering both currently supported precisions:

- `cute_dsl_sm12x_moe_gemm_{fp8,mxfp8_mxfp4}`
- `cute_dsl_sm12x_fc1_act_{fp8,mxfp8_mxfp4}` (gate-up GEMM fused with SwiGLU/SiTU-GLU)
- `cute_dsl_sm12x_fc1_act_q1_{fp8,mxfp8_mxfp4}` (fc1_act with fused fp8/mxfp8 requantize for fc2)
- `cute_dsl_sm12x_fc2_finalize_{fp8,mxfp8_mxfp4}` (down-projection GEMM fused with routing-weighted token finalize)

All 8 are exported through the public `flashinfer.fused_moe` namespace.
