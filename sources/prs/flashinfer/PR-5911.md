## What changes

`csrc/cake_megamoe_topk_reduce` goes from two byte-identical 645-line per-arch sources plus two manifests to one 143-line
source; the family (generated source, binding, loader, tests) shrinks from 1943 to 692 lines (net -1248) without changing a
single compiled instruction.

- **One source for both targets.** `sm100a/` and `sm103a/` were byte-identical and their manifests differed only in `arch`.
  The single arch-neutral `cake_megamoe_topk_reduce_kernels.cu` is compiled once per exact target with its own `-gencode`
  (`cake_megamoe_topk_reduce_sm100a` / `_sm103a`).
- **Only the helpers the kernel calls.** 49 of the 51 device helper functions were never referenced; the source now carries
  `make_warp_uniform` and `fma_f32x2_rn_noftz` only. Unused device functions produce no machine code, so the kernel SASS is
  unchanged (gate below).
