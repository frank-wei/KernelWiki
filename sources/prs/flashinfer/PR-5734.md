Public API, tensor shapes / dtypes / strides and the weight layout (`[N, K]` bf16, no load-time packing) are unchanged; every program still binds its tensor maps by value. Numerics are exact: the same fp32 accumulators and the same round-to-nearest bf16 conversion, so `out` is bit-identical to the #5721 programs on every row.
