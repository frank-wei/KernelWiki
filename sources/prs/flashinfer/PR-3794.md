## 📌 Description

Adds sliding window attention (left and right bounds) and attention sink support to the CuTe-DSL GQA decode backend, for both the non-paged and paged kernel paths. Also introduces a new `AttentionMask` abstraction that makes masking configurations JIT-composable.

- **Attention sinks**: removes the `NotImplementedError` guard in `decode.py` and `batch_decode.py`; the `sinks` tensor is now passed through to the cute-dsl kernel for both paged and non-paged decode.
- **Sliding window (left + right)**: removes the sliding-window `NotImplementedError` guard; `window_left` is wired through to the kernel. A new `window_right` parameter is added to `BatchDecodeWithPagedKVCacheWrapper.plan` (keyword-only, defaults to `0`; `cute-dsl` backend only) to support right-boundary masking.
  - set `window_left=-1, window_right=-1` for dense mask
  - set `window_left=-1, window_right=0` for causal mask
  - set `window_left>=0, window_right>=0` for sliding window
- **`AttentionMask` ABC **: new JIT composable masking API in `fusion/mask.py` that allows users to define their own custom masking configurations (supports gqa decode only for now)
