## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR speeds up the Cake fused manifold hyper-connection (mHC) kernel (`flashinfer.experimental.deepgemm_mega_mhc`, public API `flashinfer.mega_mhc.prepare_mega_mhc`). It is one persistent kernel that fuses the mHC residual-stream mixing of DeepSeek V4.1 Flash at hidden size 5120. That covers the FP8-normalized comb/post/pre mixing GEMV work, a 4 x 4 Sinkhorn normalization (20 iterations) of the mixing matrix, the residual update, and the BF16 / FP8 outputs with their scale factors. The exported family has 4 routes: col and extra layouts, each in plain and shifted form. The token range is split into 4 split-count classes chosen at generation time: 40 splits for T <= 192, 27 for 193 <= T <= 320, 20 for 321 <= T <= 448 and 16 for T >= 449. That gives one compiled program per route and split class, and one source per program serves both architectures. This PR delivers the 40- and 27-split programs (T <= 320). In these programs the Mix role now runs the 4 x 4 Sinkhorn chain on two lanes, with in-register row sums and one xor-1 shuffle per iteration.
