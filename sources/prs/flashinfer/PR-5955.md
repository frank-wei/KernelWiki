## What changed

The experimental Mega mHC kernel (`flashinfer.mega_mhc.prepare_mega_mhc`, backend under `flashinfer/experimental/deepgemm_mega_mhc/`) is regenerated through its export adapter. The public signature is unchanged. Device code: every regenerated program compiles to the same SASS as the source it replaces on both architectures (table below); the only intended change is on the host side (one source per program instead of 24 per-architecture copies, the split count as a compile-time definition, a lean loader without the catalog).
