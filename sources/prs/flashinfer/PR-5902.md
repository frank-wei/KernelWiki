## Description

Avoid wave quantization in fused multi-token KDA decode and repeated RMSNorm
reduction work on tiles that preserve its float32 addition grouping.

### Dispatch rule

Select `(R, KQ, bpm, NCH, SPLIT) = (2, 16, 2, 2, 1)` by default on
B200, B300, GB300, and SM107 for T in {5, 8} when the unsplit sequence-head
grid spans more than one wave and fewer than two waves at one CTA per SM.
Two CTAs per SM fit the grid into one wave; `bpm=2` measured slightly faster
than `bpm=3`.

B200/B300 one-wave selection accepts output differences up to 3 BF16 ULP in
some H12/T5 shapes. State and checkpoints differ by 1 BF16 ULP in one
H12/T5/N15 shape on each of these two products; conv state is exact.
The tested B200/B300 FP32-state controls are exact in all buffers.
GB300 and SM107 one-wave numerics are detailed below.

### Single-pass RMSNorm

`(R, KQ, NCH, SPLIT) == (2, 16, 2, 1)`. This covers the long wide tile and
the one-wave tile, for every supported head count, token count reaching these
tiles, and BF16 or FP32 recurrent state. The rule has no device, shape, or
