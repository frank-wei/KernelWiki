## What

`csrc/fused_moe/cake_deepseek_fused_routing/cake_deepseek_fused_routing_kernels.cu` carried four physical
schedules times nine score/bias dtype pairs as 36 separate kernels (8,300 lines). Only two kernel bodies exist:

- `grouped` vs `grouped_k8g4` differ in two `#pragma unroll` literals;
- `single128` vs `single384` differ in the thread count and the shared-memory offsets derived from it;
- the dtype pairs differ in the pointer types and the element casts.

The file is now two kernel templates, `kernel_cake_deepseek_routing_grouped<ScoreT, BiasT, kGroupRankUnroll,
kRouteUnroll>` and `kernel_cake_deepseek_routing_single<ScoreT, BiasT, kThreads>`, with one explicit instantiation
per original kernel (480 lines, generated by the Cake exporter). The launch header is one `launch<ScoreT, BiasT>`
template with the same routing rules (E=256/G=8/topk_group=4/topk=8 -> unroll 4/8; other grouped -> 1/1; single
group -> 128 or 384 threads) and launch configuration.
