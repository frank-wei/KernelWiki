## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`QkvNormRopeExchangeOverlap` combines the QKV projection, per-head QK RMSNorm and RoPE with the Ulysses QKV all-to-all exchange in one kernel (BF16 activations and weights, fp32 accumulation). Its producer kernel, which writes the exchanged rows, has four builds: the shipped build, `ow256` (operand load width 256), `bulk_ow256` (bulk row store plus operand load width 256) and `bulk` (bulk row store alone, at the shipped operand load width 128). Each build exists as bn128 / bn256 and single / two-CTA pair programs, plus two fold programs per pair build. The default build depends on architecture and world size:

- `ow256` on SM100 (B200) four-rank and on SM103 (B300) four- and eight-rank
- `bulk_ow256` on SM100 eight-rank
- the shipped build on SM90 (H100) at every world size and on SM107 (Rubin) two- and four-rank

This PR makes the bulk-row-store build (`bulk`) the default for SM107 four-rank plans and adds three SM107 producer programs (a bn256 pair program and two folds). SM107 two-rank plans keep the shipped build, SM90 / SM100 / SM103 programs and defaults are unchanged, and `FLASHINFER_QKV_EXCHANGE_PRODUCER_VARIANT` still selects any build explicitly.
