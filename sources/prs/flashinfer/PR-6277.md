## 📌 Description

@humansand

Small token batches previously used N64/N128 tiles. Add N32 W4A16 MegaMoE paths and autotune candidates, plus model presets for reproducing small-shape workloads.

- **N32 implementation:** FC1 executes one 32-token epilogue half; FC2 uses the corresponding compact accumulator load, conversion, transpose and store. M128 uses one-CTA MMA and M256 uses two-CTA MMA, both with K256 and cluster `(2,1,1)`.
- **Autotuning:** four tiles, `((128,32,256), (256,32,256), (256,64,256), (256,128,256))`, × group hints 512/1024 × epilogue/dispatch return modes give **16 default tactics**. M128 is limited to N32; larger tiles remain available for dense workloads.
- **Contracts:** retain the existing activation math, bit-exact reference, scheduler, two weight-decode warp groups, weight layout and fused deterministic combine. N64/N128 retain their existing epilogue paths.
- **Benchmark support:** add the presets below while preserving the `deepseek-v3` default, and normalize fixed JSON tactic tuples. Reported measurements use `--precomputed-routing` to exclude routing preparation from timing.

| Added preset | Hidden D | Intermediate E | Experts N | Top-K | Activation |
