## 📌 Description

This PR makes three changes to trtllm-gen paged decode, one per commit. Commit 3 extends commit 1 to multi-token (spec-decode) queries.

### 1. `perf(trtllm-gen decode)`: clamp >16 KV splits to the CGA reduction limit

`computeCtaAndClusterConfig` sets the KV split count to `min(maxSplits, SMs / (batch × headsKv × …))`. KV splits are reduced in one of two ways:

- **`CgaSmemReduction`:** the split CTAs form one cluster and reduce through distributed shared memory. A cluster holds at most 16 CTAs.
- **`GmemReduction`:** the fallback. It reduces through global memory with an atomic counter.

When there are few (batch × headKv) CTAs and the KV is long, the SM-filling split goes past 16, and the launch ends up on the GMEM path. Batch-1 decode with 8 KV heads at KV ≥ 9216, or headKv = 1 models up to batch 8, are typical cases. More SMs push more shapes past 16. On a 212-SM part, `min(32, 212 / 8) = 26`.
