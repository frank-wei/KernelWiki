## Summary

Adds `flashinfer.cake_sampling`: a fused top-k → top-p → sampling pipeline for Blackwell (SM100 B200/GB200, SM103 B300/GB300), measured and tuned on B200 and B300, that implements the semantics of `top_k_top_p_sampling_from_probs(filter_apply_order="top_k_first")` in two kernels per call:

1. **Cluster radix top-k** (`radix_topk`): one thread-block cluster per row runs a three-pass radix select (11/11/10 bits of the float32 key) with 2048-bucket shared-memory histograms reduced across the cluster through distributed shared memory (`ld.shared::cluster.v4`), then writes a `[batch, 1024]` slab of exact top-k (value, index) pairs. Ties at the k boundary resolve toward the lower vocabulary index (ballot ranks + one block scan, no atomics), so the top-k set is exactly the first k entries of `lexsort(-prob, index)`.
