## What changed

Both generated families behind `flashinfer.MiniMaxH3Nvfp4PreAttention` and `flashinfer.MiniMaxH3QkvQuantizePack`
are regenerated through the Cake generated-program export so that every program is delivered once:

* `csrc/cake_minimax_h3_qkv_quantize_pack/`: one kernel source + one host binding per output format (`nvfp4`,
  `mxfp8`), 4 files / 658 lines (was 32 files / 7344 lines in `sm_100a/` + `sm_103a/`). The token count `M` and the
  derived strides are launch parameters; the destination partition count `P` and `HEADS_PER_DESTINATION = 56 / P` are
  compile-line definitions of the route (`-DP=.. -DHEADS_PER_DESTINATION=..`), and the source is compiled with the exact
  flag set of the device it runs on. Generated SASS per `(target, P, format)` instantiation is unchanged.
* `csrc/cake_minimax_h3_nvfp4_pre_attention/`: three programs, 6 files / 4871 lines (was 8 files / 7903 lines): the
  norm + AdaLN + NVFP4 quantize stage is one source shared by SM100 and SM103; the fused NVFP4 QKV GEMM + Q/K norm +
  RoPE + destination pack is one schedule per target (SM100: eight epilogue warps; SM103: sixteen epilogue warps,
  K=96 block-scaled MMA). Tensor maps
