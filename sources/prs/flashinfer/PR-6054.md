## Summary

Extends the Cake backend of `flashinfer.comm.all_gather_matmul` (`backend="cake"`, SM100a / SM103a) to the operands a tensor-parallel engine actually holds, so a sequence-parallel column-parallel linear can call it without reshaping or copying its parameter:

* **K-major weights.** The engine's `[N, K]` parameter is accepted through its transposed view (`w.t()`, strides `(1, K)`) with no copy; the backend reads the layout from the strides and selects a K-major TMA descriptor variant of the main kernel. The contiguous `[K, N]` layout keeps its ratified route.
* **Any local row count M.** The 128-row tile over the local input is masked in the epilogue (tail ranks such as `M = 125`, odd counts such as `1025`), with TMA out-of-bounds zero fill over the local tail; outputs are written for exactly `M` rows.
* **Any `N % 256 == 0`.** The Llama-3.1-70B TP8 projections (`qkv` N = 1280, `gate_up` N = 7168) and the TP4 counterparts (2560 / 14336) are admitted alongside the ratified 2048.
