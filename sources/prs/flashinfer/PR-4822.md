## Summary

Extends the Blackwell all-gather matmul implementation added in #4722 to tensor-parallel world size 8 while preserving the existing TP2/TP4 paths.

- Adds eight-rank barrier and main-kernel routes.
- Supports the TP8 BF16/FP16 `N=2048` path.
- Supports the prepared packed-QKV TP8 route with local `N=1280`.
- Preserves fail-closed dispatch, reusable prepared launchers, and fresh-output semantics.
