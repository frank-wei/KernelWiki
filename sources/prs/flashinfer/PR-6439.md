## Summary

Part of the generated-kernel progress tracker #4254 (training-kernel tracker #4642). Follow-up to #6053 (the `cake_mok_bf16`
MoE-training package on main): four performance changes (a fifth commit is formatting and doc wording only); no existing signature changes — the public API only grows by optional parameters with defaults (`create_mok_bf16_workspace(precision, imbalance_comm_sms, imbalance_threshold)`; `MoKConfig.imbalance_comm_sms` / `imbalance_threshold`), the helpers `resolve_imbalance_comm_sms`, `count_routed_load` and `select_comm_split`, the constants `IMBALANCE_COMM_SMS`, `IMBALANCE_THRESHOLD` and `MOK_PRECISIONS`, and the `CAKE_MOK_COMM_SPLIT_LOG` switch; the new default `imbalance_comm_sms="auto"` enables the 24 / 28 split on B200 BF16 only above the threshold. Supersedes #6240 (closed): its two performance changes (the imbalance-aware communication split and the re-exported backward kernels) are re-based here onto the #6053 package layout; the feature content of #6240 (context-only recompute, GLM-5.3-Flash layouts, clamped SwiGLU, native MXFP8 routed experts) is already on main through #6053 and is not part of this PR.
