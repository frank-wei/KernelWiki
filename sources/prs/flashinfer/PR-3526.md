## 📌 Description

`SharedStorageQKVO` unconditionally reserved 1-element placeholder arrays for the NVFP4
scale-factor buffers (`k_sf_smem` / `v_sf_smem`) and the FP8 "repack" buffer
(`kv_smem_repack`) even for KV dtypes that never touch them. After `alignas(16)` each
placeholder occupies 16 B, inflating `sizeof(SharedStorageQKVO)` by 48 B (FP16) / 32 B (FP8).

For `HEAD_DIM 256` the q/k/v union already fills the entire 64 KiB opt-in shared memory budget
(`cudaDevAttrMaxSharedMemoryPerBlockOptin`) on Turing/Volta (SM75/SM70). The extra padding
pushes the struct past 65536 B, so
`cudaFuncSetAttribute(kernel, cudaFuncAttributeMaxDynamicSharedMemorySize, ...)` is rejected
with `cudaErrorInvalidValue` ("invalid argument") and the prefill kernel never launches. This
is a regression for `head_dim 256` on these arches (e.g. observed via vLLM
`BatchPrefillWithPagedKVCache` on an RTX 2080 Ti).
