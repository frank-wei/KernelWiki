## Summary

Regenerates the Cake-generated `backend="cake"` Kimi-K3 MLA FP8 paged attention route (#5552; r52 programs in #5602) for the **r54 kernel** on SM100 (B200) and SM103 (B300 / GB300). The host side is unchanged from #5602 (same planner, grids and kernel arguments); this PR moves only the generated programs of both architectures, every file written by the exporter from the same producer tree, and the two architectures' exports agree byte-for-byte (`csrc` and the registry).

What r54 changes against the r52 programs (`698a96197`):

- **The redundant `p_full` mbarrier is removed from the wide two-CTA kernel.** Since r52 the softmax / correction warps arrive `o_ready` (tile parity, 4 warps x 2 CTAs, cluster arrive to CTA 0) right after the P store's `fence.proxy.async` at the same site where they arrived `p_full`, and the MMA warp waited both barriers at the same point before PV(t) and before the drain; `p_full` therefore carried no ordering of its own. PV(t) is now gated
