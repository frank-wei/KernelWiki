## 📌 Description

The FA2 attention kernels masked logits with a finite sentinel (`math::inf = 5e4`). Because the online-softmax running maximum is tracked over the **raw** QK dot product, a valid logit below `-5e4` could never raise the initialized maximum: every probability underflowed to zero and valid rows returned zero output with a sentinel LSE (#4267, #4450).

Replacing the sentinel with IEEE `-inf` is necessary but not sufficient. The online-softmax updates evaluate `exp2(m_prev - m)` and `exp2(s - m)`; a row whose every logit is masked computes `(-inf) - (-inf) = NaN`, which reaches the output and LSE because the existing final `(m != -inf) ? rcp(d) : 0` guard cannot recover from `NaN * 0`. Three surfaces hit this (#4451, #4452, plus multi-token split-KV decode):

- fully masked rows of a bottom-right aligned causal prefill (`qo_len > kv_len`),
- a kv-warp slice that owns no valid column (one-key ragged rows),
- an empty split-KV chunk merged in `state_t::merge`/`normalize`.
