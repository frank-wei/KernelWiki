## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This is a regenerated export of the Cake all-gather matmul backend. On SM103a (B300), it routes two bf16 K-major gate/up shapes with 512 padded rows to `cg2s2`, a spill-split variant of the CTA-pair twin, and adds the two programs for them. It also replaces the positional CTA-pair flag of the host ABI with a form code. SM100a (B200) routes and programs are unchanged.

This PR builds on the previous PR of this series (SM103a 16-CTA push and world-size-2 CTA-pair points). That PR builds on the SM100a CTA-pair points PR. Neither of the two is merged yet. The branch `cake-agmm-sm103a-spill-split-pairs-push-rows` was created from the previous PR's branch `cake-agmm-sm103a-push-rows-ws2-pairs`, and the PR targets `main` so that CI runs. Until the earlier PRs merge, the GitHub diff also contains their commits. This PR's own change consists of:

- the spill-point tables in the loader;
- the form code in the host ABI;
- the two `cg2s2` programs;
- the regenerated host sequences;
- the tests.

Please merge it after the previous PR.
