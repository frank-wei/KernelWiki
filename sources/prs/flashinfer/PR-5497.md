## 📌 Description

Forward `enable_pdl` from `_moe_core_impl` to `moe_sort` in the CuTeDSL fused-MoE path.

Previously, `_moe_core_impl` forwarded the setting to the GEMMs but omitted it from the routing call. Consequently, `moe_sort` used its default `enable_pdl=False`, even when PDL was enabled by the caller.

The production change is one line:

```diff
         tile_tokens_dim=tile_size,
+        enable_pdl=enable_pdl,
         **moe_sort_kwargs,
```

This activates the existing routing PDL path when requested, allowing routing to overlap with a preceding PDL-capable producer such as `moeA2ASanitizeExpertIdsKernel`. Explicit `enable_pdl=False` remains supported.
