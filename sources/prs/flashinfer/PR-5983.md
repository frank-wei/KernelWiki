feat(cake_dsv4): SM120/SM121 DeepSeek-V4.1 mixed-cache sparse-MLA decode (528 B FP8 SWA + 288 B FP4 compressed, BF16 Q)

## Summary

Adds a Cake-generated decode kernel family for the DeepSeek-V4.1 **mixed cache** on SM120 (RTX PRO 6000 Blackwell, RTX 5090) and SM121 (GB10), reachable through the existing public surface:

```python
trtllm_batch_decode_sparse_mla_dsv4(..., backend="cake", kv_cache_format="fp8_dsv41_fp4_ca")
SparseMLASm120Wrapper(backend="cake", kv_scale_format="ue8m0_g32", extra_kv_fp4=True, compute_precision="bf16")
```

The kernels read the two caches in place: the 528 B/token FP8 SWA main cache (512 E4M3 + 16 UE8M0 group-32 footer scales) and the 288 B/token V4.1 FP4 compressed cache (512 E2M1 dims incl. RoPE, 256 B payload + 32 B E4M3 group-16 footer scales). Q stays BF16 and QK is computed in BF16 (`mma.sync m16n8k16`) with exact on-chip dequantization (E4M3 x 2^e and E2M1 x E4M3 are exact in BF16); P and V are BF16, accumulation / softmax / merge are fp32
<!-- upstream-excerpt-end -->
