## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR adds `flashinfer.experimental.cake_kda_train`: forward, first-order backward and checkpoint replay (backward without saved activations) for packed variable-length KDA (Kimi Delta Attention) chunked training in the GLM-5.3-Flash geometry. That geometry uses head dimension 128 for q, k, v and the gate, chunk length 64, a zero initial state per document, 1 to 64 heads per call and one packed batch described by `cu_seqlens`. This operator has a single Cake variant (BF16 q, k, v, out, dq, dk, dv and dbeta; FP32 gate g, dg and recurrent state; packed `[1, S, H, 128]` layout), and this PR delivers it with both save modes: `light` (the default, measured below) and `tape` (keeps the state tape for a faster backward). No previous Cake version of this kernel is shipped, so the baseline is the Triton `chunk_kda` from FLA 0.6.0 (commit ce50999e), with the same L2 normalization, gate pre-activation and sigmoid(beta) applied outside both implementations.
