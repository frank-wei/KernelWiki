## MiniMax-H3 full MLP block operator (BF16 / MXFP8 / NVFP4, SM100 / SM103) — #4532 candidate 6

Adds `flashinfer.diffusion_ops.minimax_h3_mlp{,_mxfp8,_nvfp4}`: the complete MiniMax-H3 MLP block
(RMSNorm + AdaLN modulation → FC1 (5376 → 2×14336) + SwiGLU → FC2 (14336 → 5376) → gate × o + residual)
as three Cake (Weave IR) kernels generated for `sm_100a` and `sm_103a`:

1. norm + AdaLN (+ the variant's activation quantization: MXFP8 E4M3 + UE8M0 block scales, NVFP4 E2M1 + UE4M3 block scales);
2. FC1 + SwiGLU, 2-CTA `tcgen05` GEMM with TMEM accumulators and a CLC tile scheduler, whose epilogue writes the **FC2-ready
   operand** (BF16 `y`, or the quantized `y` + scales the FC2 GEMM consumes directly);
3. FC2 with the gate × o + residual epilogue, launched with programmatic dependent launch behind FC1 and a tail-wave split-K
   over consecutive CLC units for the small-M rows.

Companion to #5491 / #5506 (`minimax_h3_fc1_swiglu`, candidate 5): the FC1 kernels and the norm arithmetic are shared;
this operator removes the FC2 round trip through a library GEMM and the separate quantization pass of `y`.

### Correctness

* Out-projection operator rules: `atol = rtol = 1e-2` against the FP3
