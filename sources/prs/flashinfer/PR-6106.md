## 📌 Description

Unify MLA functional and planned execution behind backend-owned implementations, and add `backend="autotune"` to `BatchMLAPagedAttentionWrapper`.

- TRTLLM-GEN, CuTe DSL and XQA share preparation and execution between functional and wrapper entrypoints. Backend classes also implement the tuning interface, removing separate runner implementations.
- Wrapper autotuning benchmarks eligible TRTLLM-GEN, CuTe DSL, XQA, CUTLASS, FA2/FA3 and opt-in cuTile candidates for the planned workload. The first uncached run requires `with flashinfer.autotune(True):`; subsequent calls retain the selected backend and tactic until replan, while forwarding current tensors and scalar options. CUDA graph capture requires warmup and preserves its buffer contract.
- Preserve profiling input layout and aliasing, isolate candidate output buffers, and fix the FA3 MLA KV descriptor advance for CKV128/256.
- Consolidate regressions into the existing MLA suites and document the shared backend architecture.
