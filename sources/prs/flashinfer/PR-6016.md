## Description

Round 5 of the deterministic multi-LoRA BGMV MoE backend (`csrc/cake_bgmv_moe`, SM90/SM100/SM103), following #5727 / #5850 / #5989. Same exact numerics as the shipped kernels (FP32 products and accumulation, one final rounding, fixed reduction order, no output atomics, bitwise-reproducible replays); the shrink outputs are bitwise identical to the round-4 kernels and the FP32 accumulator differs from an FP64 pair-loop reference by no more than the round-4 kernels on every row (8 seeds x 137 rows: 0 better / 1096 ties / 0 worse).

- **Pair-grouped exact pipeline for large token counts** (`group_build -> shrink_grouped -> expand_grouped -> combine`, `plan.variant == "generic_grouped"`): routes are grouped by their unique `(LoRA, expert)` pair so each pair's A/B rows are streamed once per 16-route tile instead of once per route; the per-token combine sums the route partials in ascending pair order (deterministic).
