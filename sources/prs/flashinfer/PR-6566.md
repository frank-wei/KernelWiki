## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This is a regenerated export of the Cake all-gather matmul backend. It changes which calls run the CTA-pair main kernel on SM103a. No existing kernel program changes, and SM100a is unchanged.

This PR builds on #6501 (SM103a SM push route band and CTA-pair main kernel), which is not merged yet. It targets `main` so that CI can run. Until #6501 merges, the diff also contains #6501's commit (`c8917fee`); only the last commit (`d8e69c67`) belongs to this PR: the region-table change and the new world-size-8 pair twin. Please merge it after #6501.

The change has two parts:

1. **Region table with column ranges.** Each entry in the loader's CTA-pair region table now has a minimum N as well as a maximum N. A class can also list several rectangles. With these two changes, the table can select single measured shapes.
2. **Two more shapes on the CTA-pair main kernel.** Two gate/up projection shapes at M=512 per rank (TP4 and TP8; bf16, K-major, K=8192) now run the CTA-pair twin. They run 5.2–6.9 % faster. The TP8 shape needs the world-size-8 bf16 K-major twin, which this PR adds to the delivered kernel set.
