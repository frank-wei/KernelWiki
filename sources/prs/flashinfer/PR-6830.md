## Summary

The Cake-generated Kimi-K3 vision tower package lives in `flashinfer/experimental/kimi_k3_vision_tower/`. It serves `flashinfer.kimi_k3_vision.{kimi_k3_vision_tower, prepare_kimi_k3_vision_tower}` with `backend="cake"` on SM100 and SM103, and it is JIT only with no AOT entry. The exported package has three kinds of duplication: five attention forms are exported twice (once per architecture), each program has its own host binding, and the registry is a 1,664-line literal. This PR has three commits. The first folds the SM100 attention copies into their SM103 twins. The second compacts the registry to one row per program. The third replaces the 76 host bindings with one shared launcher.
