# Three kernel modes

All three modes share the wide_vec kernel family (gdn_wide_vec_kernel for T>=2; gdn_wide_vec_kernel_t1 for T=1; small-batch ILP=4 path for B*HV < 128). The mode is selected at the Python wrapper layer via the disable_output, disable_state_update, and recovery_steps / accepted_steps flags. JIT cache keys differ across modes so each is compiled as its own specialization.

1. Recovery kernel  (disable_output=True, disable_state_update=False) Advance state through T tokens without per-token output. Used in the spec-decode reject branch where the verified prefix needs its state folded in but the speculated decode outputs are discarded. Supports per-request K via accepted_steps[i] (early-exit per CTA at accepted_steps[i]+1 iters).

2. Output-only / stateless decode  (disable_output=False, disable_state_update=True) Emit T per-token outputs, discard final state. Used in the spec-decode speculate branch where the kernel produces draft outputs but the candidate state is thrown away.
