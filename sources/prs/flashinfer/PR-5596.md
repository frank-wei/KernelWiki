## Summary

Adds `backend="cake_cute"` to `VariableBlockSparseAttentionWrapper`: the fifteen Hopper (SM90) variable block-sparse attention kernels of `backend="cake"` (persistent pair/split kernel, small-selection KMAX {1,3,4,6}, split-KV KMAX {1,3,4,6}, cluster/DSM-merge {2x4, 3x3, 3x6, 4x2, 4x4, 6x2}) rendered as **CuTe DSL** Python modules, driven by the **same planner and plan rows** as the CUDA route. The kernels are structural reproductions: same warp roles, pipeline stages, mbarrier inventory, TMA descriptors, WGMMA schedule, distributed-shared-memory merge and epilogue (side-by-side table below). No new optimisations; PR 5470's `vsa_sm90_blk64` route is untouched.
