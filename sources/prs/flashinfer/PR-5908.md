## What changes

`csrc/fused_moe/warp_decode` shrinks from 191 files / 224,774 lines to 52 files / 72,845 lines without changing a single
compiled kernel.

- **Never-compiled sources removed.** The 66 per-module and 55 per-sequence `*_binding.cu` files (97,836 lines) were never part
  of the JIT spec; `cake_warp_decode_inventory.json` (35,171 lines) existed only to hash-check them at import. The JIT module now
  lists its device translation units per exact target directly (`flashinfer/jit/cake_fused_moe_warp_decode.py`); per-source
  compile flags are unchanged (fast math on every kernel except the SiTU static FC1 kernel). The legacy sm_103a fallback source
  and the `HAS_SILU` build flag are gone: the SiLU kernels are always part of the source list.
- **Identical kernels shared.** 17 of the 34 sm_103a kernels are byte-identical to an sm_100a kernel apart from their hash id
