## Summary
Fifth performance round of the Cake Mamba2 SSD combined prefill (`flashinfer.mamba.SSDCombined(backend="cake")` and its Cake-only functional wrapper `flashinfer.mamba.ssd_combined_fwd`), SM100 (B200) and SM103 (GB300). Exact arithmetic is preserved: every kernel change is a schedule / data-movement / issue-order change that is bitwise identical to the previous release on the 9-shape bitwise set (partial chunks, D per head and per head x dim, packed varlen, three state dtypes), the 3 multi-work-item shapes and the 5 sub-chunk shapes on both archs; no FTZ / rounding / accumulation-order change; the two host rules below are calibrated from measurements only.

- **Exact scan — epilogue ring (six regenerated device sources `exact_<state>_<mode>`)**: the epilogue warps store each 128-row output stage as four per-warp 32-row TMA slabs with per-warp bulk-group waits (the `out_map` TMA box shrinks from 128 to 32 rows); the output stage runs through a four-slot ring whose z-gate loads for the next group are issued inside the current group's body, ahead of that group's arithmetic and stores; the D row is staged in shared memory once per work item; the next work item's initial state
