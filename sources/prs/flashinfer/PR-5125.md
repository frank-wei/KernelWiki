# [CuTeDSL] Shared-load inline-asm helpers omit effects, allowing stale-load reuse

`ld_shared_v2_u32` and `ld_shared_v4_u32` read shared memory, but both emit
`llvm.inline_asm` with `has_side_effects=False`, register-only inputs, and no
memory clobber. I can demonstrate elimination of a required second read using
the actual FlashInfer helpers with NVIDIA's public CuTeDSL bindings.

This report concerns the helpers' compiler-visible contract. It does not claim
that NVIDIA's normal CuTeDSL JIT currently fails the full FlashInfer test, or
that LLVM is violating the contract it receives.
