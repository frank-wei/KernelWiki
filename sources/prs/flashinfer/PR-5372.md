## 📌 Description

Relaxes the alignment constraints of the SM90 CuTe-DSL BF16/FP16 fused MoE from whole GEMM tiles to 16-byte rows, which are now:

| dimension | rule (before) | rule (after) | reason |
|---|---|---|---|
| `hidden` | `hidden % 64 == 0` | `hidden % 8 == 0` | 16-byte rows for GEMM1's gather and GEMM2's row scatter |
| `I`, gated activations | `I % 32 == 0` | `I % 32 == 0` (unchanged) | 32-column up/gate interleave of `w1` |
| `I`, ReLU² | `I % 64 == 0` | `I % 8 == 0` | 16-byte C rows for GEMM1's TMA store |

## 🔍 Related Issues

Follow-up to #4878 (SM90 CuTe-DSL MoE backend).
