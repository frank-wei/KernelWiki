## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
> Developed by the **CAKE team**, the kernels in this PR **outperform** the relevant **SOTA baselines at the time of merge** on the **vast majority of performance benchmark shapes**, matching them otherwise.

This PR removes duplicated sources from the Cake-generated `flashinfer/experimental/cake_mok_bf16` package. The package holds MoK BF16/MXFP8 MoE kernels for SM100a, SM103a and SM107a. The PR has one commit per step, five commits in this order: share the fused bindings between sm_100a and sm_107a, share the 8 BF16 fused kernels across all three targets, use one launcher TU per launcher shape, compact `sources.json` to one record per role, and drop the uncalled `specs_for_arch` helper. Together the commits delete 60 duplicate source files (146,415 lines), add 5 generic launchers (498 lines) and shrink `sources.json` from 12,218 to 2,058 lines. Each per-commit diff below is measured against the commit before it, and the five diffs add up to +3,285 / −158,993 lines. Each commit's section below keeps the verification for that step.
