## Summary

The Cake-generated Mamba kernels behind `flashinfer.mamba` include several things that can go:

- device sources that no route can select
- a host launcher template that duplicates another one
- a selective-state-update kernel that is a copy of another kernel except for one define
- some dead host code

This PR removes them in four commits. It covers two parts:

- **SSD combined scan:** the generated device sources and host templates in `csrc/cake_mamba_ssd_combined/`. The loader is `flashinfer/mamba/cake_ssd_combined.py`, which uses its `_PROGRAMS` table.
- **Selective state update STP programs:** `csrc/cake_selective_state_update/`, with the registry in `flashinfer/jit/mamba/cake_selective_state_update.py`.

What changes:

- Nine unreachable SSD `_noring` device sources are deleted, along with their ten `_PROGRAMS` entries. The program count drops from 66 to 56.
- The exactpre programs now render the fused host launcher, so the precomputed host template is delete
<!-- upstream-excerpt-end -->
