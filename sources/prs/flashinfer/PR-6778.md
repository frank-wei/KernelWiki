## 📌 Description

The Cake DSA sparse-attention training backward (`flashinfer/experimental/cake_dsa_train`, the four backward programs `cake_dsa_h64_train_{726ceb6d,76061910,d6a7bc0b,e29d165e}…_kernel.cu`) loads its `.16x256b` TMEM fragments (S, dP, dQ, dQr, dKV, dKR) with `tcgen05.ld` at lane 0 or 16 from every warp of a warpgroup:

```cpp
asm volatile("tcgen05.ld.sync.aligned.16x256b.x8.b32 ..." : ... : "r"(tmem_tmem + 192));
```

PTX ISA, tcgen05 "Access restrictions": "A lane of the Tensor Memory can be accessed by a single warp in the warpgroup". Warp 0 of a warpgroup may access lanes 0-31, warp 1 lanes 32-63, warp 2 lanes 64-95 and warp 3 lanes 96-127. Warps 1-3 therefore address another warp's lanes. On SM100/SM103 the kernels compute the right result today, because the hardware serves the warp's own quarter. All 20 loads of each program now add the warp's lane base, so each warp names the lanes it reads:

```cpp
const int tmem_lane_base = (tid & 96) << 16;   // (warp % 4) * 32 in the lane field
asm volatile("tcgen05.ld.sync.aligned.16x256b.x8.b32 ..." : ... : "r"(tmem_tmem + tmem_lane_base + 192));
```
