## 📌 Description

`layernorm_quant` is the only norm quant routine still running on the first-generation CUDA kernel only; `rmsnorm_quant` and `fused_add_rmsnorm_quant` already default to CuTe-DSL kernels. This PR ports `layernorm_quant` to CuTe-DSL and wires it as the default backend, with the CUDA kernel kept as the `FLASHINFER_USE_CUDA_NORM` fallback.

The new `LayerNormQuantKernel` derives from `RMSNormQuantKernel` (multi-row tiles, cluster reduction, cp.async staging, vectorized fp8 stores for both e4m3 and e5m2), with three deltas:

- LayerNorm needs two reductions (mean, then variance). The cluster path reuses a single mbarrier by waiting on phase 0 and then phase 1, with a cluster barrier in between; `cluster_reduce_multirow` and `row_reduce_sum_multirow` gain an optional `phase` parameter (additive, existing callers unchanged).
- gamma/beta are float32 while the input tile is fp16/bf16, so they are loaded through a dedicated tiled copy whose value mode is split into 128-bit pieces, keeping the fragment flat order aligned with the input fragment.
