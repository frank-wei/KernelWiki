## 📌 Description

Follow-up to #6163, which landed the public `concat_mla_kv_quant_fp8` API (the fused MLA context K/V pack with saturating FP8 cast) backed by generated Cake programs. That PR grew out of this one and replaced the hand-written kernel this PR originally carried. This PR now adds that hand-written kernel back as a **second backend** and routes between the two by head count, so each shape gets the faster implementation:

```python
key, value = flashinfer.concat_mla_kv_quant_fp8(kv_nope, k_pe, key=None, value=None, *, nope_dim=128, backend="auto")
```
