## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
> Developed by the **CAKE team**, the kernels in this PR **outperform** the relevant **SOTA baselines at the time of merge** on the **vast majority of performance benchmark shapes**, matching them otherwise.

This PR deletes 42 of the 111 stage-1 kernels in the Cake-generated `csrc/cake_sampling` sources, together with their manifest rows and `kernel_symbols` entries (126 → 84 entries). The host dispatch never selects any of these kernels. The PR has two commits, one per step. The first deletes 34 kernels that need a launch-flag combination the host never produces for that variant. The second deletes 8 more that pass the launch-flag logic but that the stage-1 ranking never puts first. Host policy and dispatch are unchanged, the 15 stage-2/3 rows are untouched, every kept kernel body is byte-identical to `main`, and the two commits remove 277,331 and 88,426 lines of generated source. Each commit's section below keeps the verification for that step.
