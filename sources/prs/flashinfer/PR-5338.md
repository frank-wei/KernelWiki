## 📌 Description

### What this PR changes

Syncs the `sm90_fp8_fp8_bf16_pull_cutedsl` kernel tree with the kernel team's latest Hopper FP8 drop and wires the new knobs through the shim / backend (three commits on top of `main`):

1. **Tail-split pair tasks, per-bucket `group_hint`, FC2 16-byte stores** (kernel tree + shim):
  - `tail_split_pairs`: an expert whose token count is an odd number of CTA tiles used to leave the second CTA of its tail cluster block idle; the scheduler now turns that block into pair tasks (both CTAs compute the single valid token tile against adjacent weight tiles, weights loaded through a second non-multicast TMA atom).  Legal only with a 2-CTA token cluster (swap-AB cga (1,2,1) / non-swap cga (2,1,1)); the dispatch-driven token-back expects `ceil(W/2)` fc2_done publishes per split tail.
  - `group_hint` (scheduler group size) becomes a per-bucket entry of the heuristic table (264 on per_tensor 512-8192, blockwise 512-2048 / 8192); FC2 epilogue writes 16-byte stores on the non-swap and swap-AB local paths.
  - heuristic table retuned: per_tensor 1024-32768 -> swap-AB ping-pong M128N128 cga(1,2,1) with tail split
