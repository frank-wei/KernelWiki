## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`grouped_mxfp8_quantize` quantizes a 2-D activation to MXFP8 with per-group E8M0 scales. Cake has two variants of it: bfloat16 input and float16 input. This PR delivers both, on sm_100a and sm_103a. The baseline is the previous Cake version of the same kernel: the loader shipped at FlashInfer main 23f3e8f6. Each variant was timed on one shape. For BF16 the speedup is 0.980 on GB200 (sm_100a) and 0.975 on GB300 (sm_103a). For F16 it is 0.980 on GB200 and 0.991 on GB300. Values below 1.0 are slowdowns. The BF16 shape comes from the owner's shape list. That list has no timed F16 shape, so the F16 row uses the kernel test's benchmark shape.

### BF16 on sm_100a (GB200)

NVIDIA GB200 (sm_100a), CUDA 13.4, driver 595.84.01. previous = shipped Cake loader at FlashInfer 23f3e8f63b66; new = this PR's export; median GPU time (CUPTI, cold L2), 3 groups × 128 iterations; speedup = previous / new.

| shape | previous (µs) | new (µs) | speedup |
|---|---:|---:|---:|
| B=2 M=256 K=4096 (T=512) | 3.872 | 3.952 | 0.980 |
