## 📌 Description

Add native TRTLLM Gen SwiGLU StepFun support to the flat and unified MoE APIs for BF16, FP8 per tensor, MXFP8, and NVFP4:

```text
StepFun(up, gate, L) = clamp(up, -L, L) * min(silu(gate), L)
```

The default physical limit is 7. Per-expert limits support mixed routed/shared expert caps, with typed FP8 preparation converting physical limits into accumulator units. Includes native validation, DA and per-token NVFP4 forwarding, trace references, end-to-end numerical tests, and documentation.

Step trace references restore native layouts before evaluating the activation: BF16 BlockMajorK, FC1 gate/up interleave and FC1/FC2 row permutations, and MXFP8/NVFP4 128x4 weight-scale swizzles. NVFP4 bias rows are restored as well.
