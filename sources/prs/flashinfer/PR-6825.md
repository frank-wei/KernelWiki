## 📌 Description

Adds a caller-owned workspace to the trtllm-gen fused-MoE APIs, the trtllm-gen counterpart of `cutlass_fused_moe_workspace_size` / `workspace_buffer=` (used by vllm-project/vllm#60570).

`trtllm_fused_moe_workspace_size` is implemented by adding a `query_workspace_size` mode to each trtllm-gen moe call. It will not execute the runner, but record the tensors allocated before the runner call.

Test result:

Tested on B300, bf16 routed, 16384 tokens, H=7168, I=2048, 256 experts, top-8, on B300, autotuning peak allocation drops to 896.8 MiB from 3,579.9 MiB (−2,683.1 MiB).
