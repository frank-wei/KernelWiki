## 📌 Description

Refactor Frost’s host logic to follow the standard MoELayer backend registration and dispatch path. Replace per-call candidate discovery with shared eligibility checks and winner caching. Consolidate common host code, cache compiler metadata and prepared execution state, reuse compatible weight views, and preserve per-call launch state.

Warm eager CPU overhead drops by approximately 90% across BF16, MXFP8, NVFP4, and MXFP8 × MXFP4 on the 76 paired cases where both versions select Frost.

| Recipe | Before | After | Reduction |
|---|---:|---:|---:|
| BF16 | 400\.94 | 36\.49 | 90\.90% |
| MXFP8 | 572\.53 | 55\.67 | 90\.28% |
| NVFP4 | 591\.05 | 54\.46 | 90\.79% |
| MXFP8/MXFP4 | 1159\.02 | 99\.02 | 91\.46% |
