## 📌 Description

Stacked on #6537 (merge that first); the diff against #6537's head is this round's change.

#6537 turned on two host-side shape gates by default on SM100 and SM103. This PR does three things:

* It picks the producer build and the plan's group scaling of `flashinfer.comm.QkvNormRopeExchangeOverlap` per (architecture, world size), using the settings that measured faster on each.
* On SM90 it rebuilds the bn128 producer with a six-stage TMA ring.
* On SM90 it turns on a third shape gate, `reserved_sms_large_m`.

Below, W is the world size and M is the number of token rows each rank projects (batch × local sequence length). K is the hidden size.

Defaults per (architecture, world size):

| Architecture | W | Producer build | `group_m_scale` | `reserved_sms_large_m` |
