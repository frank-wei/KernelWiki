## 📌 Description

Extends the per-expert SwiGLU-OAI parameters (`gemm1_alpha` / `gemm1_beta` /
`gemm1_clamp_limit`) from `Fp8QuantizationType.MxFp8` to
`Fp8QuantizationType.DeepSeekFp8` (fp8 blockwise with fp32 block scales).

DeepSeekFp8 was previously rejected outright: that path has no fused FC1 epilogue and
runs a separate activation kernel, which would have silently dropped the values. This
PR teaches that kernel the OAI epilogue:

    x_glu    = clamp(x_glu, max=limit)
    x_linear = clamp(x_linear, -limit, limit)
    out      = x_glu * sigmoid(alpha * x_glu) * (x_linear + beta)

The interesting part is **resolving the per-expert entry**. On the fused path the cubin
inherently knows which expert a tile belongs to (it is the batched-GEMM batch index),
whereas the standalone activation kernel only has a permuted token index. This uses the
invariant that permuted tokens are grouped per expert and padded to `tileTokensDim`, so
`ctaIdxXyToBatchIdx[permutedIdx / tileTokensDim]` recovers the local expert — the same
index the fused path receives. That is the sole reason `activation::Data` gains the
`ctaIdxXyToBatchIdx` / `tileTokensDim` fields.
