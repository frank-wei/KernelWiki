## 📌 Description

Co-authors: @jychen21 @AichenF

Submitted by: @GnohzZ.

Adds `sm120_mxfp4_mxfp8_bf16_cake` through `MoEEpLayer`: a Cake-generated SM120 MegaMoE backend
(MXFP8 activations, MXFP4 routed weights, BF16 output) whose expert-parallel traffic goes **over RDMA
with NCCL GPU-initiated networking (GIN), issued from inside one persistent kernel**.

- **EP over RDMA from inside the kernel (NCCL GIN).** Dispatch, FC1 + SwiGLU + FP8 requantization,
  FC2, the expert-result return and the weighted combine run in one cooperative persistent kernel.
  Payloads between EP ranks are NCCL Device API GIN puts with signals, issued by the kernel itself on
  NCCL symmetric windows (NCCL 2.30.7) — no separate dispatch / combine kernels. The same
  kernel runs multi-host EP (EP16 over two hosts validated) and single-host pairs that cross PCIe
  sockets (EP8 below). The existing SM120 MegaMoE backend (#4632) moves data through NVSHMEM peer
  pointers, i.e. within one host.
- **LSA, a by-product of the same transport design.** The transport is chosen per EP-rank pair:
