## 📌 Description

The NVFP4 AlphaMoE kernels (`csrc/alphamoe_nvfp4_sm100.cu`, `alphamoe_nvfp4_c386_up.cu`, `alphamoe_nvfp4_c388_up.cu`) load their epilogue accumulators with `tcgen05.ld` at

```cpp
int down_addr = taddr + (unsigned int)(physical_feature << 16) + ...;   // physical_feature = consumer_warp * 32 + lane
```

a different TMEM lane in every thread. PTX requires one address per warp for `tcgen05.ld` ("All the threads in the warp must specify the same value of taddr [...] Otherwise, the behavior is undefined"). ptxas moves the operand into a uniform register, which takes one lane's value, so the kernels compute the right result today, but only by accident of that lowering. The 66 sites now pass the warp's lane base, the value lane 0 already passed:

```cpp
int down_addr = taddr + (unsigned int)((consumer_warp * 32) << 16) + ...;
```
