## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
> Developed by the **CAKE team**, the kernels in this PR **outperform** the relevant **SOTA baselines at the time of merge** on the **vast majority of performance benchmark shapes**, matching them otherwise.

Adds three generated program families to the Cake Kimi-K3 NVFP4 SiTU experts (`cutlass_fused_moe(..., activation_type=ActivationType.Situ, tp_size=8, backend="cake")`) for the small token counts on SM100 (B200) and SM103 (B300), each shipped for both architectures:

- **Fused quantization + router (M = 8, 16).** The input quantization CTA body is fused into the single-CTA router. One launch of grid `(M + 1, 1, 1)` (block 0 routes, blocks 1..M quantize) replaces the separate quantization and router launches, so the `(arch, n8_feature)` route runs `quant_route, fc1, fc2, finalize` -- four kernels instead of five.
- **Epilogue-triggered FC1 (M = 1).** A tile-N8 FC1 program that signals its dependent launch from the epilogue replaces the previous FC1 program on the `(arch, m1)` route; the route keeps its four kernels.
