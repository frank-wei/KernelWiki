Closes #5787

Host/binding-level cleanup of `csrc/cake_bgmv_moe`, `flashinfer/fused_moe/bgmv_moe.py` and the family tests.
Device code is unchanged: every compiled kernel (36 JIT modules: 12 specialized + 24 generic bundles for
sm90a/sm100a/sm103a) has the same SASS before and after this change, and the prepared plans produce bitwise
identical outputs.

What changed

- The twelve generated bundles include `<cstdint>` instead of declaring their own fixed-width typedefs and
  unused tensor-map structs, so both bindings drop the `#define`/`#undef` renaming around the body include.
- Both bindings check the compiled compute capability once in `configure()` (module load) instead of
  re-querying two device attributes on every launch; the Python side already routes each device to the
  module compiled for it.
