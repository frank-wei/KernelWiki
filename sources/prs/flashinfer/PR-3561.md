## 📌 Description

Adds `flashinfer.fused_moe.hash_topk`, the DSv4 hash-based MoE expert routing kernel. DSv4-Pro hash-MoE layers select experts from a precomputed token-to-expert table `tid2eid` instead of running a dynamic top-k, so routing is an O(1) table lookup followed by a `sqrt(softplus(.))` score normalization. One warp processes one token.

Ported from SGLang's `deepseek_v4/hash_topk.cuh`. The Python signature matches `sglang.jit_kernel.deepseek_v4.hash_topk` so it works as a drop-in replacement.

### API

```python
from flashinfer.fused_moe import hash_topk

topk_weights, topk_ids = hash_topk(
    router_logits,                 # [num_tokens, num_routed_experts] float32
    input_ids,                     # [num_tokens] int64
    tid2eid,                       # [vocab, topk] int32
    num_fused_shared_experts=0,    # 0 or 1
    routed_scaling_factor=1.0,
    launch_with_pdl=True,
)
```

The routed weight for a selected expert is `sqrt(softplus(router_logits[token, expert])) / sum_over_routed`. When `num_fused_shared_experts == 1`, a shared-expert slot is appended with id `num_routed_experts` and weight `1 / routed_scaling_factor`.

### Implementation Notes

* SM-portable
