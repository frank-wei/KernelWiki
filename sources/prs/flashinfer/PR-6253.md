## 📌 Description

Adds support for exporting un-finalized MoE output from the CUTEDSL MegaMoe kernels on SM100. With `do_finalize=False`, EP communication still completes inside the kernel, but the top-k cross-expert reduction is skipped and per-route BF16 rows are handed back to the caller for finalization (e.g. custom reduce, shared-expert fusion).

- Add `compute_unfinalized()`
- Add `--no-do-finalize` to offline tuning.
  - Currently incompatible with enable_in_kernel_fc2_reduce and auto knobs (requires fixed/offline-tuned knobs).
  - Currently only supports w4a4, w4a16, and bf16.
- Save `live-tokens` to autotuning cache. Now flashinfer will query with combined key `max-tokens` and `live-tokens`.
