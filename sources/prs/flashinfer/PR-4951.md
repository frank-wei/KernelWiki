## Summary

- add generated SM120 kernels for prequantized Sage block-sparse attention
- add a manifest-driven JIT loader for six exported specializations
- expose the implementation through `bsa_attn_sm120_blk64_sage_fwd(..., backend="cake")`
- keep output storage and TMA descriptor workspace caller-owned
