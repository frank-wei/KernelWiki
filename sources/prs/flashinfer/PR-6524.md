## Summary

Regenerates the native FP4 GEMM family `flashinfer.experimental.deepgemm_fp4_gemm` (public API `flashinfer.fp4_gemm.prepare_fp4_gemm`) for SM100a (B200) and
SM103a (GB300) at FlashInfer `22d60b5bb`. One exact schedule change reaches the native FP4 GEMM programs in this update. The normal BN160 program (`normal_bm128_bn160_s7`; cohort row model-fp4gemm-l2-m512, five epilogue passes) now pipelines its epilogue across passes: each store pass issues one `tcgen05.ld` batch for the next pass while the current pass converts and stores (one-pass lookahead), instead of loading, converting and storing pass by pass. The change is program-scoped (switched on for the BN160 program only in its source module); the helpers are in the sources for the other multi-pass programs but switched off there, and every other native FP4 GEMM program -- the seven others, including the two single-pass programs (swap-AB BM16 and normal BN16) -- renders byte-identical to the previous delivery on both architectures. In the paired A/B against the previous delivery the row reads 3.31 % faster on B200 (7.108 to 6.880 us; floor 1.24 %) and 2.47 % faster on GB300 (6.788 to 6.624 us; floor 1.06 %), beyond it
