## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This is a regenerated export of the Cake all-gather matmul backend. It changes the SM103a (B300) push launch for one world-size-4 row point and adds SM103a CTA-pair points for four world-size-2 shapes. No kernel program changes, and SM100a (B200) routes and programs are unchanged.

This PR builds on the previous PR of this series (SM100a CTA-pair points). That PR builds on the SM103a gate/up PR and the SM103a route-band PR. None of the three is merged yet. The branch was created from the previous PR's branch `cake-agmm-sm100a-cg2-points`, and the PR targets `main` so that CI runs. Until the earlier PRs merge, the GitHub diff also contains their commits. This PR's own change consists of the SM103a launch-row table, the three SM103a region points with their two pair twins, and the regenerated host launch sources and tests. Please merge it after the previous PR.

The change has two parts:

1. **SM103a push launch rows.** A new per-architecture table, `PUSH_LAUNCH_ROWS_BY_ARCH`, sets the push launch for listed (world size, padded rows) points. SM103a has one entry: at world size 4 with 512 padded rows, a call launches 16 push CTAs per peer instead of 8, using the wide push program. SM1
