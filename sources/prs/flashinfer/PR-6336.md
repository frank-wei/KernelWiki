## 📌 Description

Expand PrimsTS BF16 MoE autotuning with BatchN tileN=192 and two-CTA BatchM candidates for prefill. BatchM consumes existing block-shuffled weights and cluster-granularity routing metadata directly.

The `prims_ts_bf16_moe` and `prims_ts_bf16_routed_moe` interfaces remain unchanged. Autotuning selects compatible FC1/FC2 pairs.

### Changes

- Add N192 routing support and BatchM candidates with two accumulator stages or one stage with maximum TMEM overlap.
- Match operand orientation, weight layout and routing geometry across FC1/FC2; invalidate cached tactic selections.
- Zero-fill routed TMA padding and align wide scale-factor descriptors with their load coordinates.
- Keep persistent output staging separate from operand buffers, protect scratch reuse, and drain outstanding TMA stores before epilogue completion.
- Extend standalone BatchM kernels with NVFP4 output and FP8 maximum-overlap support, including output scales and reference checks.

### Performance
