## 📌 Description

Add NVFP4 and MXFP8 (E4M3/E5M2) support to `MoEEpLayer` on Rubin (SM107),
with BF16 combine and output. In-kernel reduction is off by default because
it uses nondeterministic atomics.

The kernels come from CuTe DSL MegaMoE `1667b47a`
([export details](https://github.com/akaashrp/flashinfer/blob/sm107-megamoe/flashinfer/moe_ep/kernel_src/sm107/next_cutedsl_megamoe/VENDOR.md)).
The adapter handles Rubin's weight and scale layouts, clears combine slots
for masked routes, and returns a separate output tensor by default so a later
call cannot overwrite a previous result.

## 🔍 Related Issues

Based on #4601. The SM100 package move was merged separately in
[#5371](https://github.com/flashinfer-ai/flashinfer/pull/5371).
