## Summary

Stacked on #6190 (merge that first; this PR's own change is its top commit). Same SM100 / SM103 DeepSeek-V4
NVFP4 sparse-MLA decode kernels and the same host path as #6190; one generated helper changes (the shared device header's QMUL4
helper, `cake_dsv4_qmul4_portable` -> `cake_dsv4_qmul4`, so the six NVFP4 kernel units are rewritten at their call sites -- a
one-token rename; diff vs #6190: 10 files, +673/-650) and one requirement is added:

- **Hardware QMUL4.** The NVFP4 cache dequant multiply (E2M1 value x E4M3 scale -> E4M3, one rounding) in the shared device
  header `csrc/cake_dsv4/common/cake_dsv4_nvfp4_device_common.cuh` is now the PTX ISA 9.4 packed multiply
  `mul.rn.e4m3x4.e2m1x4.e4m3x4.satfinite` (one `QMUL4` SASS instruction per four values plus a `PRMT` scale-byte broadcast)
