## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`cake_all_gather_matmul` all-gathers each rank's row-sharded activation and multiplies it by a contiguous `[N, K]` weight. Cake ships it in bf16 and fp16, K-major and N-major weights, world sizes 2, 4 and 8, two main-tile widths and two transport routes (copy engine, SM push). This PR delivers one SM103a (B300) variant: world-size-8 calls with 1024 padded rows on the SM-push route launch the push kernel with 16 CTAs per peer instead of 8, so one push launch grows from 56 to 112 CTAs. It adds no program and changes none, and the GEMM math is unchanged. The table compares it with the previous Cake version of this kernel, the K-slice readiness programs of #6742, whose branch this one is built on.

| Shape per rank, M × N (world size 8, K = 8192) | Node | Previous version (µs) | This PR (µs) | Speedup |
|---|---|---:|---:|---:|
| 1024 × 1280, bf16, K-major weights (Llama-3.1-70B TP8 QKV) | node 1 | 324.8 | 317.1 | 1.012 |
| 1024 × 1280, bf16, K-major weights (Llama-3.1-70B TP8 QKV) | node 2 | 314.5 | 311.2 | 1.034 |
