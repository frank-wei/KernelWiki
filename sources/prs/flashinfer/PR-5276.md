## 📌 Description

Add locality-domain execution support to the Rubin SM107 CuTe DSL W4A4 fused-MoE path.

The caller can provide one weight shard and one long-lived green-context stream per locality domain, together with the per-domain SM count. FlashInfer then:

- runs FC1 concurrently across the two domains, with each domain producing a disjoint half of the intermediate output;
- runs FC2 concurrently across the two domains, with each domain producing a disjoint half of the hidden output;
- optionally overlaps the fused-finalize output memset on a separate stream;
- sizes each persistent grid using the per-domain SM count;
- gives localized and full-width runners distinct autotuning cache keys;
- optionally autotunes both runners and dispatches the faster path for each profiled shape;

The localized path is intentionally restricted to the configuration implemented and validated here: Rubin SM107, W4A4, exactly two equal-width shards, fused finalize, and no per-token activation scales. Unsupported combinations fail explicitly
