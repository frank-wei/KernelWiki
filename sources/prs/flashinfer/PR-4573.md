## Description

Add an explicit `backend="cake"` option to
`flashinfer.mla.trtllm_batch_decode_sparse_mla_dsv4` for SM100 and SM103. The backend
handles the validated BF16 and FP8 DeepSeek V4 sparse-MLA cases through architecture-specific generated device variants and compiled dispatch programs,
separate TVM-FFI bindings, and FlashInfer's JIT.

Each variant carries its compilation and argument contract. Python owns
immutable TMA descriptor storage across caller-workspace replacement; generated
bindings perform no device allocation. Compiled programs retain the original
stage order and route selection while linking separately compiled kernel
libraries, preserving each kernel's optimization flags. The existing API retains its normal
input validation and default backend selection.
