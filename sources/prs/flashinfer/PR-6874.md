## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
The `cake_causal_conv1d_train` kernel, a packed width-4 depthwise causal conv fused with SiLU, has one data-type variant (BF16 in/out with FP32 math) and a forward and a backward program per architecture. This PR adds a second backward program for that variant. The host selects it by channel count C (C >= 512 on sm_100a and sm_103a, C >= 1024 on sm_107a); below those thresholds the previous backward programs are still used, and the forward is unchanged. Against the previous Cake version of this backward (the programs shipped in #6844), the geomean speedup (previous / this PR) across all 14 shapes is 1.0569 on GB300, 1.0765 on B200 and 1.0511 on R200. On the shapes the host routes to the new program, the per-shape speedup ranges from 1.0403 to 1.0991 on GB300 (12 shapes, geomean 1.0667), from 1.0702 to 1.1226 on B200 (12 shapes, geomean 1.0898) and from 1.0694 to 1.2581 on R200 (4 shapes, geomean 1.1908).

**Backward latency, NVIDIA GB300 (sm_103a), CUDA 13.4**
