## Summary

Regenerates the SM100a / SM103a MiniMax-H3 fused RMSNorm + AdaLN + FC1 + SwiGLU sources from
the updated generator: the MXFP8 and NVFP4 GEMM cores now run 256-column output tiles per CTA pair
(128 gate + 128 up weight rows per CTA, one 256-column TMEM accumulator, eight-warp early-release
epilogue) and fetch their block-scale tiles as 128-byte TMA rows instead of 16-byte rows.  The
BF16 operator and the three norm + quantize kernels are unchanged.  Numerics are bit-identical to
the merged #5491 operators (paired kernel-only runs report 0 output mismatches; the quantized
activation stays bit-exact vs `nvfp4_quantize` / `mxfp8_quantize`).

Follow-up to #5491 (tracker #4254).
