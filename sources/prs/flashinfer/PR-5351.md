## 📌 Description

Optimize existing PrimTS QToken-KvBlock-Sparse-Attention on Blackwell. The plan/run lifecycle, supported shapes, KV-cache layouts, and standalone metadata outputs are preserved.

### Query grouping API

QToken planning, workspace sizing, and eager attention use keyword-only `group_size=1` instead of the ambiguous `seq_len_q`/`max_seq_len_q` grouping names. One means no grouping; pass larger G explicitly. Fixed Q `[B,Nq,G,Hq,D]` must match G; packed Q `[total_q,Hq,D]` uses request-safe `qo_indptr` and allows shorter final groups. The recommendation helper's `seq_len_q` still means the actual request length. Generic FMHA sequence-length APIs are unchanged.

### Optimization techniques

- Donate idle-warpgroups’ registers to full-row softmax within the CTA register budget.
- Stage full D256 FP8 heads and rebalance K/V buffer depths to reduce pipeline overhead.
- Use compile-time page-index access to avoid register-array spills.
- Use head-aware flat locators and rank-2 TensorMaps for eligible compact caches, without repacking K/V.
