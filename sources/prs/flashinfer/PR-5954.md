## Summary

Closes #5806. The experimental balanced GQA decode package is regenerated from its Cake producer so that each program ships once instead of once per architecture.

- **Arch-neutral programs.** The three programs (row tile for `q_len == 1`, packed 32-row and 64-row multi-token programs) each ship one kernel and one binding source. The only architecture-dependent line (the shared-memory base address) sits under `#if __CUDA_ARCH__ == 1000`; the per-architecture copies differed in nothing else.
- **Shared headers.** `cake_balanced_gqa_decode_device_common.cuh` (device helper preamble) and `cake_balanced_gqa_decode_host_common.cuh` (tvm-ffi argument checks, descriptor encoders) replace the preambles repeated in every source.
- **Registry.** `cake_jit.py` builds its JIT specs from a three-record `PROGRAMS` table plus a `KINDS` map (`row` / `mtp32` / `mtp64`) instead of six copies of the 20-entry argument plan; the JIT spec names are unchanged (`<program>_<arch>`).
- **Host.** `cake_backend.py` resolves the program by kind and caches the device SM count and architecture per device index. `prepare_balanced_batch_decode_with_kv_cache` keeps validating and carving the caller-owne
