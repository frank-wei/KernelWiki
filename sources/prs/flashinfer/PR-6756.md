## Summary

This PR removes duplication and dead code from the experimental Cake-generated Kimi-K3 attention-residual family (`flashinfer/experimental/cake_kimi_k3_attn_res/`). It deletes 16 duplicate kernels, and their records now build from kept sources with `-D` flags. The 91 per-record TVM-FFI bindings become three launch bindings, and `MODULES` becomes program rows over three argument plans. Unreachable planner code is removed, and wheels now ship the generated sources. `csrc/` goes from 182 to 78 `.cu` files. With `--no-renames`, the diff is 129 files, +1,393 / -43,542 (GitHub's rename view: 126 files, +1,022 / -43,171). Every record keeps its name, JIT module name, kernel symbol, host-shim namespace, `arches` and argument plan. `KERNELS` is byte-identical, and program selection, launch arguments and results are the same for every input.
