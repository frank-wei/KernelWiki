## 📌 Description

<!-- What does this PR do? Briefly describe the changes and why they’re needed. -->

### Summary
Adds two gated activations to the b12x NVFP4 fused-MoE kernels so for currently not supported models:
- **`gelu_tanh`** (gated GeGLU, tanh-approx GELU) — for Gemma-4.
  - Addresses #3683
- **`swigluoai_uninterleave`** (gated SwiGLU-OAI: `gate*sigmoid(α*gate)*(up+β)` with optional clamp; configurable `swiglu_alpha/beta/limit`, default 1.702/1.0/None) — for MiniMax-M3.
  - Addresses #3732

Also adds transparent zero-padding for **non-128-aligned `intermediate_size`** (e.g. Gemma-4's 704): the dispatch pads weights + scale factors up to the gate/up tile width. Currently not supported as discussed in #3683

No public API or behavior changes for existing `silu`/`relu2` paths.
