## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Removes the torch.utils.cpp_extension.load-based C++/CUDA CUTLASS blk64 kernel (bindings.cpp, mainloop/epilogue headers, instantiations) and replaces it with a native CuTe-DSL implementation, following the same vendor-kernel + thin-adapter pattern already used by the blk128 backend. Adds kv_splits and Sage-FP8 quantization test coverage for the new backend, and fixes a uniform-block-count indexing bug in the Sage-FP8 dispatch path (sparse.py) surfaced by the new tests.
