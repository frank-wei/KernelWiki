## Summary

This PR removes duplication and dead code from the Cake-generated programs behind the prepared KDA prefill API (`flashinfer.prepare_bf16_kda_prefill`, `prepare_tf32_kda_prefill`, `KDAPrefillPlanCache`) on SM100 / SM103. That is 51 BF16 and 34 TF32 modules. The 85 checked-in TVM-FFI bindings are now rendered from one template. 32 fused-M128 BF16 kernel clones fold onto 8 flag-keyed bodies. Raise-only launch branches and duplicated host code are removed. The BF16 planner now sends requests that had no exported body to exported ones. `csrc/` goes from 170 `.cu` files to 61 `_kernel.cu` files and no checked-in bindings. 53 kernel files are byte-identical to base, and the 8 fold bodies are the only modified kernel files. With `--no-renames`, the diff is 132 files, +3,781 / -130,296.
