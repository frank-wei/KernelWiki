## Summary

Each module in the three Cake-generated RoPE append / KV-pack families compiled its own copy of the kernel and of the TVM-FFI binding, for a total of 54 `.cu` files. The three families are bf16 fused QK RoPE append (8 stages, 20 modules), fp8 fused QK RoPE append (3 modules) and the fp8 KV-pack quantizer `concat_mla_kv_quant_fp8` ("kvq", 4 head-group programs x SM100/SM103). After this PR each family has one kernel source and one binding (6 `.cu`). Every module keeps its kernel symbol (`-DCAKE_KERNEL_SYMBOL`), JIT module name and host-shim namespace, so all libraries can still be loaded into one process. The manifests shrink from 4,558 to 434 lines and from 714 to 196 lines. The diff touches 74 files, +3,423 / -26,626 with rename detection off (GitHub pairs the new shared sources with deleted copies and shows 68 files, +1,262 / -24,465).
