## Problem

`top_k_renorm_probs` returns bitwise-different results on repeated calls with bitwise-identical input. On GB300 (192x131072 fp32, k=50): 19/19 repeated invocations differed, max_abs_diff ~3e-8.

This matters for replicated execution: tensor-parallel LLM serving runs sampling/spec-decode verify redundantly on every TP rank with identical inputs, and per-invocation nondeterminism makes ranks compute rank-divergent `target_probs`.
