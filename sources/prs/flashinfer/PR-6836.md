## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
The experimental `cake_dsa_train` backend (`flashinfer.dsa_sparse_attention.dsa_sparse_attention[_varlen]`) has native 64-query-head DSA sparse-attention training kernels: forward, backward, backward aux and index preparation. They use bf16 inputs/outputs and fp32 statistics and accumulation, and support dense and packed/varlen rows. The kernels have two variants, by positional encoding. The RoPE variant has 512 latent + 64 rope query/key dimensions (the GLM-5.2 geometry). This PR delivers the NoPE variant, which has 512 latent dimensions only and no rope block (the GLM-5.3-Flash geometry). It includes the variant's own generated programs for sm_100a, sm_103a and sm_107a, the autograd entry, the packed/varlen entry with device-side index conversion, and the planner/validation code. The tables below give the NoPE speedup over the shipped Cake RoPE kernels with zero rope inputs. That baseline computes the NoPE result exactly.
