## 📌 Description

Optimize the existing SM12x fused FP4 MoE backends, particularly workloads whose intermediate dimension is not a multiple of 128. The changes reduce padded weight storage, routing overhead, unnecessary data movement, and synchronization while preserving supported fallback paths.

### What changed

- **Static:** use true-extent up/gate/down weight views and source block scales where supported; prefetch weights during routing; merge eligible intermediate slices to reduce partial-output traffic; restore routing state in finalize; and make the M32 tile geometry and warpgroup register handoff consistent.
- **Dynamic:** parallelize the expert-tile prefix scan, skip invalid tail MMA and eligible empty stages, avoid the last Q1 staging round trip, specialize route-scale indexing, and select A16/A32/A64/A128 transfers from the valid row count. Use source FC2 scales and an L2 eviction policy for streamed weights.
