> Give the dense EFC kernel the same callback-based reduction interface as the
> block-scaled kernel. The wrapper materializes source, combine, finalize, and
> consumer functions, while the vendored kernel owns fragment traversal,
> synchronization, cross-thread combination, and output storage.
>
> The generated epilogue owns pointwise and fragment-local reduction semantics.
> Physical reduction geometry uses generated combine and finalize callbacks;
> the reduction primitive identifies the operation and does not select a
> runtime algorithm.
>
> Remove the dense reduction descriptor parser and hardcoded affine and boolean
> consumer arithmetic so both vendored kernels use the same callback contract.
