Human-authored context: Extend inline asm hop for multiple-return.

> AI-generated summary from Codex, reviewed by the author:
>
> Allow `inline_asm_elementwise` to accept a tuple of output dtypes and
> return multiple tensors from one assembly invocation. Inductor represents
> each result independently while Triton codegen shares the underlying
> invocation through kernel CSE. Mixed output dtypes and `pack > 1` are
> supported, while eager Jiterator execution remains single-output.
>
