* __->__ #184377

Route CUDA Inductor random lowering through rand4x/randn4x helpers so pointwise random kernels consume all Philox outputs instead of discarding three lanes. Add generated-code and helper-order tests for the vectorized path.

This preserves the random distribution, but changes the exact CUDA Inductor random sequence for a given seed because the four Philox lanes are now consumed instead of discarding three.
