Migrates the NVGEMM backend off the internal-alpha `cutlass_api` package onto
the official `cutlass.operators` API (ships with nvidia-cutlass-dsl 4.6.0). The
NVFP4 performance features and the zero-copy swap_ab optimization that were
originally bundled here are split into the following commit (#189805); this
commit is the mechanical migration plus one change entangled with the migrated
wrapper rewrite.

Review order:

1. Migration (mechanical, most files): `cutlass_api` -> `cutlass.operators`.
   Renames: get_kernels->get_operators, Kernel->Operator, KernelMetadata->
   OperatorMetadata (.kernel_name->.operator_name, .kernel_class->
   .operator_class, .min_cc->.designed_for_min_cc), DenseTensorAttributes->
   DenseTensorConstraints, ScaledTensorAttributes->ScaledOperandConstraints
   (.base->.quantized), arguments.ScaledTensor->ScaledOperand, library.ScaleMode/
   ScaleSwizzleMode->top-level, utils split into utils.{tensor,device,common,
