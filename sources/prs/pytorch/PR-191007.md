## Summary

Triton removed the block-pointer frontend API (`tl.make_block_ptr` / `tl.advance`) in [triton-lang/triton#10833](https://github.com/triton-lang/triton/pull/10833) (merged 2026-07-15). On any post-removal Triton, emitting `tl.make_block_ptr` now raises at compile time:

```
triton.compiler.errors.CompilationError: ...
    block_ptr0 = tl.make_block_ptr(in_ptr0, shape=[512, ks0], ...)
                 ^
Block pointers have been removed in favor of the tensor descriptor API
```

(That last line is Triton's *own* error text — the tensor-descriptor API is the replacement **Triton** suggests. This PR does **not** auto-migrate block pointers to tensor descriptors: when the block-pointer API is gone, Inductor simply stops emitting block pointers and falls back to its default masked-indexing path — or, where independently eligible, the existing tensor-descriptor/TMA path — as described below.)
