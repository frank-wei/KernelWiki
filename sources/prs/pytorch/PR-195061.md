Human Notes:

Inner tree optimization time! It was correct, now make it fast (or less slow).
After this set of optimizations we're close to parity with unordered reductions,
but not quite there. I believe this is as close as we can get - the only remaining
change is the butterfly reduction across lanes in a warp, and for fixed ordering
we must have them. Sad face.

Codex:

Stage coalesced global loads in shared-memory tiles so each lane can fold a
contiguous run and finish with one butterfly. This removes repeated lane
butterflies without changing the inner-tree DAG.

The implementation uses one buffer and refills it only after folding,
avoiding the large-M write-after-read race and limiting shared-memory
occupancy. Staging is restricted to aligned, single-batch mid-band plans;
ragged and multi-batch plans retain the register fold. Bitwise tests cover
staged identity padding, and routing tests ensure the optimization actually
runs.
