## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Used codex to find some TensorIterators that should have been using const_input instead of non const method inputs. Prevents a COW of the Tensor input. I asked Codex to only look apply the fixes to high confidence inputs. Codex read the kernels and then decided which values are inputs. Note this is safe even when something is an input and an output as the output call will trigger the COW.
