## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Stack from [ghstack](https://github.com/ezyang/ghstack/tree/0.15.0) (oldest at bottom):
* #184927
* __->__ #184926

Registers a fp32, last-dim, contiguous topk override at aten::topk /
topk.values for K in {64, 128, 256, 512, 1024}. Fused radix-select +
bitonic sort, one CTA per row, single launch.

Two specialisations selected at compile time by a ``deterministic``
constexpr keyed off torch.use_deterministic_algorithms: a faster
atomic-gather + ord-only sort path (default; non-deterministic on
threshold-bin ties), and a prefix-sum gather + lex (ord, -idx) sort
path that's bit-exact to aten.

On B200 across the full 88-case sweep (5 K values x 4 M classes x N in
[2K, 512K], filtered by the cond):

  default kernel: 3.00x geomean over aten (range 1.63x-4.02x)
  deterministic:  2.55x geomean over aten (range 1.35x-3.66x)

Test plan:

    python test/python_native/test_topk_cutedsl.py
