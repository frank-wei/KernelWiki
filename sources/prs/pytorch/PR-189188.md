Basically allowing reading form scalars (global scale) Agent notes below;


Add a fourth captured-epilogue-arg kind "scalar" beside tile/row/col for
[1, 1] read-only tensors. This unlocks native float8 tensorwise quant
epilogues, e.g. (acc * s).to(torch.float8_e4m3fn) with a captured
per-tensor scale, which the lowering previously rejected.

The lowering and runtime classify [1, 1] args as scalar before the
row/col checks so M == 1 / N == 1 problems stay unambiguous, and scalars
are orientation-invariant under swap_ab. Vendored patch 0010 adds the
kernel-side scalar load: a smem-free CapturedScalarLoad / ScalarTupleLoad
epi op pair whose per-tile Float32 value broadcasts through TensorSSA
arithmetic in the epilogue. Kinds remain a static wrapper/runtime ABI and
QuACK compile-key input; scalar dtypes join the row/col/tile dtype tuples
in the compile key.
