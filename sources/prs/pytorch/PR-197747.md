## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Notable new features compared with 0.13b:

* New `flyc` backend: FlyDSL SDPA fp16/bf16 kernels for gfx950 and gfx1201, at
  parity with the Triton kernels and substantially faster on most head
  dimensions
  + See [AOTriton 0.14.2b Release Notes](https://github.com/ROCm/aotriton/releases/tag/0.14.2b)
    for measured performance improvments
* **API BREAKING, ABI STABLE** `VarlenBits` replaces the `VarlenType` enum
  + Q and K now choose their sequence addressing independently, along three
    axes: tensor shape, how lengths are given, and how offsets are given
  + 0.14b library keep working with applications built for 0.13b; only
    the source-level params struct changed
* Triton bumped to 3.8.0; tuning databases re-tuned for gfx950 and gfx1100
* ROCM 10 (HIP 7.16) support is added to the package list

Bug Fixes:

* `bwd_kernel_fuse` used `Out`'s strides for `dO`
* Causal masking wrote `+inf` LSE out of bounds
* Attention bias was not cast to fp32 before scaling with `ln(2)`
* `attn_fwd` persistent dynamic mode early exits on certain mask pattern
* Runtime: device is taken from the stream, and several entry points no
  longer assume GIL being hold.
