# Summary

This pr does a few things
1. It lets us load broadcastable tensors and consume in epilogue functions:

```Py
scale = torch.randn(M,1)
  def epilogue_fn(acc):
      return (acc.float() * scale).relu()
```

we support multiple loads

2.) Fixed the semantics for when we load from boolean tensors for example:
```Py
mask
def epilogue_fn(acc):
    acc_float = acc.float()
    return torch.where(mask, acc_float, -acc_float)
```

The fix for the second is a lil gross but basically it undos the to `to_acc_dtype` path backed into the quack epilogue and now update codegen to produce;

```py
@cute.jit
def flex_gemm_epilogue_804510af4df0d2df(acc, aux0):
    tmp0 = aux0.to(cutlass.Boolean)
    tmp1 = acc.to(cutlass.Float32)
    tmp2 = cute.TensorSSA(-tmp1, tmp1.shape, tmp1.dtype)
    tmp3 = cute.where(tmp0, tmp1, tmp2)
    return tmp3
```
