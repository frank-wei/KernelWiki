## Human Note

At a high level we are now allowing chunking + reductions along the n axis. So this is two forms of reductions;
1 is the chunked or interleave pairing and the other is the reduction along the N axis follwing this up. Below we have 2 for the first and then 32 for the second or a total of 64 elements. We needed so mechanize to enforce we have 64 acc values in regsisters and we do the reductions only in registers for now. This is explicitly about reductions that need to broadcast back to the final output such, and for that case we need to have the finalized reduction value ready for broadcast before we can write the final output.

Example now supported
```Py

 import torch
 import torch.nn.functional as F
 from torch._higher_order_ops import flex_gemm

     amax = groups.abs().amax(-1, keepdim=True)
     scale = amax.clam
