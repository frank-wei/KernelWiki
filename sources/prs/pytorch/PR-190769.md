## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Stack from [ghstack](https://github.com/ezyang/ghstack/tree/0.15.0) (oldest at bottom):
* #192830
* __->__ #190769

Enable 2-CTA for Blackwell MetaWS max-autotune GEMM (`tl.dot(..., two_ctas=True)`, `ctas_per_cga=(2, 1, 1)`). The current generated MetaWS path only admits the validated TMA epilogue-store protocol; this does not constrain non-WS 2CTA kernels. Keep the persistent-loop stride cluster-aligned when the physical SM count is odd, and make B-tile swizzle eligibility depend on element size.

The paired-CTA TMA output path depends on the one-copy output-ring correctness contract in fb-triton #3543.
