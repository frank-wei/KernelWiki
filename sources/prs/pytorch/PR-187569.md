## Summary

`torch._scaled_mm` row-wise scaling already supports fp32 output on the cuBLAS path. However, the CUTLASS `f8f8bf16_rowwise` fallback still rejected fp32 output. This fallback is used in cases such as sm89, CUDA < 12.9, and Blackwell with row-wise scale tensors.

This PR enables fp32 output for the CUTLASS row-wise fallback in the no-bias case.

The no-bias output dtype was previously hardcoded to bf16. The no-bias dispatch now selects `DtypeOutput` from `out.dtype()`:

* `float`
* `cutlass::half_t`
* `cutlass::bfloat16_t`

This enables fp32 output and also makes fp16 no-bias output dtype-correct on the CUTLASS path. The bias branches are unchanged.

## Changes

* Relax the CUTLASS row-wise output-dtype gates to allow fp32 output:

  * the classic `_scaled_mm` entry
  * `_scaled_rowwise_rowwise`
  * `RowwiseScaledMM.cu::check_inputs`
* Bind `DtypeOutput` from `out.dtype()` in the no-bias branch of `dispatch_fp8_rowwise_kernel_on_bias_dtype`.
