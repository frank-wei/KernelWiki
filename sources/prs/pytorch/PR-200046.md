## Summary (human written only)

This PR removes the standalone `gradInput.zero_()` operation from CUDA MaxPool2d backward by explicitly writing zero for nonmatching indices in the channels-last single-window path, allowing both contiguous and channels-last kernels to initialize every input gradient while preserving existing accumulation and dtype handling. Validation on an H100 with CUDA 12.8 passed all 105 selected CUDA tests, including 96 new regression combinations using NaN-prefilled output buffers and an independent CPU autograd reference, along with scoped lint and `git diff --check`. Profiling reduced GPU activities per backward call from two—device Memset plus the backward kernel—to one backward kernel; matched repeated measurements across six float32 layout/shape cases showed approximately 16%–28% lower latency, limited to small smoke benchmarks on a shared H100.
