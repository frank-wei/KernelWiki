# cuDNN varlen causal GQA paged-KV support

## Summary

The attention semantics needed by issue #195603 are supported by cuDNN 9.24 on GB200 without
changing FA4. The implementation now routes eligible `varlen_attn` and `varlen_attn_out` calls to
cuDNN for:

- causal attention with `seqused_k` and `block_table`;
- grouped-query attention (`Hq=16`, `Hkv=4` in the reported case);
- SM100 forward with head dimension 256; and
- `max_q <= 128`.
