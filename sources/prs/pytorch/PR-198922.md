## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Fix a race condition in the CUTLASS memory-efficient attention forward kernel,
reported by turboderp in https://github.com/facebookresearch/xformers/issues/1392
as nondeterministic NaNs with head_dim >= 256 on Ampere, Ada and Blackwell
consumer hardware, hitting roughly a third of runs on an RTX 3090. This is the
same fix @danthe3rd made in xformers in 2023, "[cutlassF] fix race condition":
https://github.com/facebookresearch/xformers/commit/55a4798d99c350eca9d225a14003f226775e5f76
This copy of the kernel never picked it up.

## History and how this happened

The kernel was vendored from xformers in #86157 (Oct 2022), nine months before
the upstream fix landed (July 2023). None of the syncs after that picked the fix
up: it is absent from #100583, #103704, #112267 and #127090 alike.

The commented-out call site sitting in the tree today came from somewhere else
entirely. #123571 (Apr 2024) backported the sliding-window feature, copying that
region of `kernel_forward.h` across from an upstream source that was by then
post-fix. The region happened to contain one line of the race fix. That line
