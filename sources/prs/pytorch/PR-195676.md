## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`ApplyOp1`/`kernelPointwiseApply1` are only reachable through `CUDA_tensor_apply1`, which no longer exists (the header stops at `CUDA_tensor_apply2`).

The `NOTE [ CUDA_tensor_applyN helpers ]` comment above stays; it still describes the surviving `apply2` templates.

Test plan:

```
python setup.py develop
python test/test_torch.py -k test_scatter
python test/test_distributions.py -k Poisson
```

The two surviving callers of this header (`Distributions.cu`, `DistributionTemplates.h`) both go through `CUDA_tensor_apply2`, so building the CUDA extension is the check that nothing referenced the deleted templates.

This change was authored with the assistance of an AI coding agent and reviewed before submission.
