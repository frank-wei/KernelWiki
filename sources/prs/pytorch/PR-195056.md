Human Notes:

Optimization for tall-and-narrow reductions - large M, small N. Potentially use TMA
for these cases where that has been measured to be faster.

Codex:

Add a one-thread-per-row configuration for tall, narrow reductions, avoiding
the idle lanes imposed by a full-warp row mapping. For wider narrow rows, TMA
stages whole rows into shared memory and rotates reads to avoid bank
conflicts.

The measured row-count and chunk gates retain direct loads where they are
faster. TMA additionally requires SM90+, fp32, a power-of-two row length, and
a lane stride at the measured direct-load cliff. The shared body validates
those requirements even when callers force the option.
