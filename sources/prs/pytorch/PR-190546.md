[CUDA 13.4](https://docs.nvidia.com/cuda/developer-preview/13.4/cuda-toolkit-release-notes/index.html) adds support for the NVIDIA Rubin Architecture (compute capability 10.7).

10.7 will only support 32 resident warps per SM / 1024 threads, while previous compute capabilities with HBM memory supported 64 warps / 2048 threads. For thread-based kernels such as the vectorized elementwise kernel, the amount of in-flight memory requests per SM decreases by a factor of 2x without any change.

This change adds a third specialization of the vectorized element-wise kernel, which is only used for SM 10.7, only with vector size 8, and only if the footprint is large enough, to allow higher block-level parallelism for small footprints. This specialization is only compiled for the SM 10.x family: there is no SM 10.7 specific compilation pass.

This change targets 128 bytes per thread to load inputs while the default typically uses 8 elements per thread: 16 bytes with half precision and 32 bytes with single precision for a single input and 32 / 64 bytes respectively for two inputs.
