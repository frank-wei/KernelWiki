## Agent Report
### What this covers
Same-dtype CUDA copies whose innermost dim is contiguous in both tensors but which are not contiguous overall. Before this change they ran the generic elementwise copy, which decodes a full N-D index for every element. Examples:

- **Permutes that keep the last dim**, 2D to N-D: `x.permute(0, 2, 1, 3).contiguous()` (attention `[B,S,H,D] -> [B,H,S,D]`) in both directions, 5D shared-inner permutes, broadcast outer dims (`expand(...).contiguous()`).
- **Writes into padded or pitched buffers**: `buf[:, :w] = src`, `CopySlices`.
- **Reads out of padded buffers**: `padded[:, :w].contiguous()`, pad/slice backward.

The new path moves each row as opaque 16-byte chunks, so the offset is computed once per chunk instead of once per element. It applies when the row bytes, both base addresses and every outer stride are 16-byte multiples; other layouts keep the generic kernel.
