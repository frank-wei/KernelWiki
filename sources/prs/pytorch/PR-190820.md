Enables more general block scaled matmul

> This adds the low-level support needed for an SM100 block-scaled matrix
> multiplication to perform small reductions while it is producing the matrix
> result. Block-scaled matrix multiplication includes operations such as FP4
> scaled matrix multiply, where scales are applied to blocks of input values.
>
> The kernel can group neighboring output rows or columns, combine partial
> results across the threads working on the tile, write a smaller reduction
> result, and optionally use that result when producing the main matrix output.
> This commit adds the machinery inside the vendored kernel; later commits wire
> it into Inductor's selection and scheduling paths.
>
