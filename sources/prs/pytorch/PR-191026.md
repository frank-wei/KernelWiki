Recognize terminal flex_gemm::to_blocked transforms on compressed local-reduction outputs and store directly into the padded cuBLAS 128x4 scale layout. Keep layout policy and CuTeDSL construction in PyTorch while exposing a generic cache-keyed output-layout callback boundary in vendored QuACK.

Allocate aligned carriers without initialization, zero-fill padded or symbolic carriers, predicate stores with logical GEMM bounds, and filter GEMM tiles that do not compose with both blocked-layout atoms. Select ordinary or transposed callbacks from the existing swap_ab config without adding duplicate runtime state.

Add eager-layout parity, raw/MXFP8/NVFP4, padding, dynamic-shape, tuned multitile, swap_ab, rejection, cache-key, and F.scaled_mm SWIZZLE_32_4_4 integration coverage.
