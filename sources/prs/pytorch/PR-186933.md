## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Fixes #185610

`triton_helpers.minimum` uses `a < b` which treats `-0.0 == +0.0`, causing `minimum(-0.0, +0.0)` to return `+0.0` instead of `-0.0`.

Use `tl.minimum` with `tl.PropagateNan.ALL` uniformly (already used for HIP) which follows IEEE 754 signed zero semantics.
