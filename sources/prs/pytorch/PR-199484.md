## Summary (human written only)

This PR fixes the ROCm path of `coalesceValuesKernel` described in #199483. In #158281, feature tile offset relied on `nsegments` instead of blockDim.x, so dense sizes wider than 256 (on CDNA) were never written. This  PR restores the same offset logic as in CUDA, cleans-up unused arguments and adds regression test.
