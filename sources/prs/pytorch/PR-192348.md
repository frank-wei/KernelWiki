## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Stack from [ghstack](https://github.com/ezyang/ghstack/tree/0.14.0) (oldest at bottom):
* __->__ #192348

Bool tensors are rejected by sub/neg, unary plus, cov, trapezoid, hardtanh and relu with a plain RuntimeError. Switch these native checks and their refs to NotImplementedError, the right type for a dtype that is simply not implemented.

Change expected exception type to `NotImplementedError` in `test_sub_typing` and skip it under dynamo, that treats any NotImplementedError as dynamo bug, but here it's genuine not-implemented exception (test_dtypes are skipped for the same reason)
