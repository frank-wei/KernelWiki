Stack from [ghstack](https://github.com/ezyang/ghstack/tree/0.15.0) (oldest at bottom):
* __->__ #185988

FlexAttention backward expects captured score_mod gradients to be represented as writable buffers that the backward template can atomic-add into. Indexed captured tensors already go through zeros_and_scatter, which allocates that backing grad buffer, but an unindexed captured scalar requiring grad is produced by the joint graph as an unnamed scalar ComputedBuffer. process_joint_outputs then tried to look up a buffer by name and failed with assert buf.name is not None.

Wrap unnamed scalar captured-grad contributions in a scalar Scatter buffer before processing joint outputs, matching the accumulation model used for indexed captures. The Triton scatter path also needs to handle empty-dimensional scatter indices: empty contiguous index sums now produce a SymPy zero, and literal scalar indices are materialized as tl.full tensors before broadcast_to. I considered special-casing the assertion site, but that would still leave the template without a writable grad destination.

Fixes #145208
