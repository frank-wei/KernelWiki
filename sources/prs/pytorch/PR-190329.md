Our MAGMA deprecation effort lost some steam as we hit an operation where the cuSOLVER/cuBLAS dispatch could not compete with MAGMA -- the LU factorization with a partial pivoting. The LU factorization performance is quite critical, as it serves as a backbone for the linear solver with unstructured systems, along with some other quite useful operations like det/logdet, etc.

This PR implements a MAGMA-like kernel to unblock us before cuSOLVER/cuBLAS teams resolve the issue on their end.

The kernel performance plots are available here (H100, A100, GB200, L40S): https://github.com/nikitaved/custom_lu_batched_kernel_bench/tree/main/benchmarks/plots.
These are tested against MAGMA 2.10.0 (CIs install 2.6.1, and there the LU kernel is up to 50% slower).
The repository also contains correctness check scripts (thank you, Claude) for a wide range of shapes/matrix structures and conditioning of the systems -- these are on-par with MAGMA (I am seeing MAGMA failures though, with the expanded correctness test suite -- investigating).
