Human Notes:

Perf tuning.

Codex:

> Tune the RMSNorm backward persistent grid by normalized width, element size,
> and row count. For more than 32 partial rows, use the shared reduction with work
> distributed across rows within and between warps; retain the original geometry
> for smaller partials.
>
> Weight-only calls also compute an unused input gradient. Decline unprofitable
> cases to ATen before allocating native buffers, using measured thresholds.
> Review the launch policy and reduction together, then the eligibility guard and
> dispatch-boundary tests. Keep representative persistent-grid and gradient cases
> while removing the measured redundant test combinations.
>
> Performance
> -----------
> Measured on NVIDIA B200 with CUDA 13.2 on 2026-10-05 after rebasing onto
> 70c29184487f. Native AOT is disabled. The 12-case benchmark explicitly selects
> the JIT or ATen route. Times are microseconds: eager latency is the warmed
> Timer median (at least 0.2 seconds per case); GPU latency sums median kernel
> durations over 40 calls in a separate profile
