Stack from [ghstack](https://github.com/ezyang/ghstack/tree/0.18.0) (oldest at bottom):
* #196599
* __->__ #196598

Human notes:

Remove static-`N` dependence in the kernels - move to dynamic/rungs as necessary.

Codex:

Replace exact-N radix compilation with runtime N and bounded work rungs. Scalar tails use a fixed maximum of four iterations, small vector regimes use a fixed maximum vector count, and deterministic K=512 retains its measured fixed-work rung. The register kernel uses runtime code branches for the K=16 N=64-1024 ladder while keeping occupancy outliers exact.

The alternatives were materially slower: a fully runtime deterministic tail loop regressed K=1024 by 11-20%, and capacity-padding register ladders regressed by up to 3.5x. The selected bounded-work approach stays close to exact specialization:

| Approach | Latency delta vs exact-N |
| --- | ---: |
| Register branch ladder, N=64-1024 | 0% to +9.3% |
| Fixed max scalar tail | 0% to +5.5% |
| Fully runtime scalar tail, deterministic K=1024 | +11% to +20% |
| Fixed max vector count for small N | +0.8% to +4.9% |
