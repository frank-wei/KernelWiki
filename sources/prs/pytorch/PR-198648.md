<!-- upstream-excerpt-start -->
For merge on Monday, Sept. 28th.

We are performing an upstreaming to materialize the contents of `third_party/kineto` into `pytorch/pytorch` instead of registering Kineto as a submodule. Please see https://github.com/pytorch/kineto/issues/1478 for rationale on this move.

Because the files are materializing in place, there should be minimal impact as no dependencies need to change.
