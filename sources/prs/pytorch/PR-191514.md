prepares dense kernel for direct cutedsl codegen (instead of EVT)

> This updates the vendored dense matrix-multiply kernel so it can run the
> post-processing function generated directly by Inductor. It maps captured
> tensors such as biases into the layout expected by the kernel, exposes the
> operations used by the generated function, and stores each requested output.
>
> The older metadata format remains supported in this commit so the kernel
> change can land separately from the scheduler change that starts using the
> direct path.
>
> ## Example
>
> The direct epilogue represents a computation such as:
>
> ```python
> def fn(a, b, bias):
>     return torch.relu((a @ b) + bias)
> ```
>

> dense kernel's broadcast layout, evaluates the addition and ReLU, and stores
