## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Add CuteDSL op overrides for common math intrinsics (`rsqrt`, `exp2`, `log2`, `log10`, `tan`, `acos`, `asin`, `atan`, `atan2`, `floor`) and `logical_xor`. These were missing from `CuteDSLOpOverrides`, meaning CuteDSL templates would fall through to decomposed fallbacks or fail for ops without decompositions. All map directly to `cute.math.*` intrinsics.
