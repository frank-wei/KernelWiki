## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`BiasType` is never referenced in the body of `f8f8bf16_grouped_gemm_impl_sm90`,
and both of its values produce the same `Gemm` type, so the tile-size dispatch
tree and every CUTLASS alias below it were instantiated twice for no device-side
difference. It has been unused since #148531, and `GroupedBlas.cpp:534` rejects
bias outright.

The public `bias` argument and its "Bias not supported yet" check are untouched.

Authored with an AI assistant.
