Use Triton's PropagateNan.ALL operations in the shared min/max helpers. The default reduction path uses relaxed signed-zero selection, allowing SM80+ to replace compare/select sequences with native instructions while preserving NaN propagation.

Provide an opt-in strict_signed_zero path that retains the previous compare/select behavior for signed-zero ties. Apply it to regular, unrolled, and online-softmax reductions. Add direct elementwise and reduction coverage for NaNs, infinities, and signed zero, and run the existing arg-reduction reuse test in strict mode where it asserts exact zero signs.

Local B200 performance:

Measured the isolated two-file delta from this PR on top of the scalar online-softmax Phase B tree (`0e40fb08157`).

Method: 4x NVIDIA B200, 4 workers/GPU, fresh caches, coordinate descent disabled, exact shape-aligned A/B. The head completed 4,977/4,977 corpus points with zero failures in 961.7s; supplemental model/Opacus points produced 5,127 exactly matched kernel-shape pairs.
