Stack from [ghstack](https://github.com/ezyang/ghstack/tree/0.15.0) (oldest at bottom):
* #194414
* #194126
* __->__ #193857

Adds host-side TMA support for the B200 GEMM template in Inductor. This PR uses a new `{{tma_descriptor()}}` Jinja hook to create TMA descriptors, either on the host (via registers in `host_tma_descriptor_args`) or on device (by emitting `tl.make_tensor_descriptor` within the Triton kernel). The host-side TMA descriptors are passed into the kernel with the `tensordesc<>` signature.
