## Human Note

Prior to the rebase on epimod we had inductor own tuning (via a patch in quack). In the base pr we let quack own autotning and it by default it is much slower than inductor. This switches us back. But one thing we gave up (intentionally) is the verification of configs and let epi-mod(quack) handle this.  We keep the handiling there. We dropped our patch for autotuning and now we are adding back a modified version for the new api.


This pr adds a way to pass in a representative of the problem ModProblem and not need to allocate tensors -> `legal_mod_configs`. We dropped the owned config list and this pr adds it back to heruistics.
We now use this to create the usual multi lowering choices with different configs that have been verified `legal`. This drops tuning time down to 1/10 the time.
