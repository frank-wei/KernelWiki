## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Fix the same race condition in the CUTLASS memory-efficient attention backward
kernel that #198922 fixed in the forward kernel, as suggested in review there.
Unlike the forward fix, this is not a port: neither xformers nor CUTLASS example
41 has ever drained in `kernel_backward.h`. This one also reaches ordinary
shapes: head_dim 128 is affected, whereas the forward race needs head_dim >= 256.

## Details

Every sm80+ GEMM in the backward (Q * K^T, dO * V^T, and the dV, dQ, dK
from-shared-memory GEMMs) ends its mainloop on
`cp_async_wait<kNumStagesConcurrentLoad - 1>()`, leaving the last `cp.async`
group in flight. For the from-shared-memory GEMMs, and for Q * K^T and dO * V^T
whenever `set_zero_outside_bounds(!skipBoundsChecks)` is set, those copies are
`cp_async_zfill`, which writes zeros even when predicated off. The following
code then writes into shared memory that aliases the pending copies' target
before anything waits on them.
