Human Notes:

Previously all datapaths use runtime trip counts, which allows a single kernel to
service all N values without recompile. We will be adding in fixed-ordering (inner-tree)
reductions which instead will require compile-time trip counts. This functionality is
added as an optional thing when required.

Codex:

Add an opt-in reduction order whose addition DAG depends only on N and
reproduces the existing ATen inner-tree sum/prod bits. Static fragments,
streaming carries, ascending lane butterflies, and N-specific launch plans
preserve that DAG while reusing the shared load, projection, and store body.
This fixed order is the stack's basis for eager/Inductor bitwise parity.

The default rolled folds remain runtime-shaped and continue sharing kernels
by vector class. The fixed order compiles per N, covers all reference plan
shapes, and rejects explicit requests it cannot honor rather than silently
using another order. Golden hashes and differential tests pin all plan
shapes, four dtypes, sum/prod, signed zero, batch indep
