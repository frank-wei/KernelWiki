Extend NVGEMM epilogue fusion to scaled GEMM by adding an EFC variant of the
vendored block-scaled kernel. The variant materializes Inductor's generated
pointwise function as the kernel's existing elementwise epilogue callback and
casts its result back to the declared output type before storing. Runtime
argument reuse now also redirects and clears scaled epilogue tensors.

Derive EFC operators only after the narrowed scaled manifest has applied dtype,
architecture, shape, and support filtering. This retains all 96 original NVFP4
candidates, adds the 60 compatible EFC variants, and avoids enumerating another
6,600 metadata configurations on the cold path. By-name runtime reconstruction
uses the same narrowed path instead of falling back to the full 300K manifest.

The scheduler continues to reject grouped GEMM, mutation, broadcasting, and
reductions. Those require richer epilogue contracts than this elementwise
callback and will be added separately.
