Summary:
# Context
Similar to [#195542](https://github.com/pytorch/pytorch/pull/195542).

The remaining hot copy conversions are int32 -> int64, bool -> int64 and bool -> float64.

# This PR
* Specialize kernels for int32 -> int64, bool -> int64 and bool -> float64
* Created util to clean up surrounding code a little

Test Plan:
# Automated
Added tests.

# Benchmarks

Sources in D121853326. Profiler kernel time, means of 200 interleaved iterations; control = base, test = this diff; A/A within +/-0.5% from 16M elements (MI300X: +/-1.3% from 268M, rounds pooled ungated).

Speedups everywhere except A100 and H100 96GB from 8M elements, where some pairs run up to 4% slower, but the benefits easily outweigh that.
