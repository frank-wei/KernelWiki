# Human Note
So in the forward we support `contraction` which is what is needed for most mlp these days where you fuse the gate and up projection togeterh and then combine. This means your output woudl have been Mx2n but via `grouped reduction` we reutrn MxN. There is a very natural symmetry in the backward where you would have a grad of MxN and need to return the Mx2N result for subsequent matmuls or (expansion). This PR is enabling the later;
