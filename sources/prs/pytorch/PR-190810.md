> Fuse same-CTA grouped sum, mean, product, minimum, and maximum reductions into NVGEMM epilogues. Represent reduction geometry, expressions, outputs, and mean finalizers explicitly so the scheduler can validate supported groups and preserve fallback when a reduction requires communication outside the selected tile.
>
> Add backend-neutral GEMM epilogue data structures and loop-IR expression analysis. Thread the resulting reduction contract through scheduling, rendering, benchmarking, and the block-scaled CuTeDSL provider while preserving the primary GEMM output alongside compressed auxiliary outputs.
