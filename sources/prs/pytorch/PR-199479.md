## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Remove two local Tensor variables in `batch_norm_stats_cuda_template`
(`dummy_mean_`/`dummy_var_`) that are declared but never used, fixing a
clang-tidy `bugprone-unused-local-non-trivial-variable` hit.

No explicit `.clang-tidy` entry is added for this check: it is already
covered by the existing `bugprone-*` wildcard once clang-tidy is new enough
(per review feedback).

`NaiveDilatedConvolution.cu` was dropped from this PR: the `output_`/
`grad_input_` locals flagged there are actually used a few lines below their
declaration (passed to `slow_conv_dilated_all_cuda_template`), so removing
them does not compile; those were false-positive hits from the original pass.

No behavior change is intended.

This PR was authored with an AI assistant (Claude Code).
