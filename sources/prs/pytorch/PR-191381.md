### Agent note

`CuteDSLTemplate.generate` logged every candidate render to the `output_code` artifact, but
`CuteDSLTemplateKernel.render` returns a `PartialRender` whose hooks are not yet finalized, so the
artifact never actually contained generated code. On a compiled FlexGEMM (relu epilogue plus a CODA
rmsnorm/GEMM pair, 58 candidates, fresh Inductor cache) that is 211 dumps and 422 lines.

Dropping the line leaves `cutedsl_template` with only candidate-generation failure diagnostics, which
belong under `TORCH_LOGS=+inductor` alongside the rest of template selection rather than in an artifact
that means "the wrapper I am about to run", so the module moves to the ordinary module logger.
`kernel_code` already reports the generated kernel.
