Agent note
Local-reduction outputs previously inherited the reducer's logical matrix layout. Callers that
needed the transposed result could return a transpose view, but could not request contiguous
transposed storage without an external copy. For CODA RMSNorm backward this left the fused dW
values correct but returned the wrong physical layout.

storage transform. Analysis owns the transpose/clone nodes, lowering allocates canonical
