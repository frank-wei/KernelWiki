### Summar
Previously we were restricted to intra warp reductions or intra subtile for n=1. This PR lets us reduce up to tile-M or tile-N in chunks. For axis = 1 we accumulate partials in registers, for axis = 0 (m) we accumulate in shared memory so much of the work was setting up the smem allocation and coordinating the invoking of the different initializations and combine funcs.

Example

```Py

  m = 128
  n = 128
  group = 64

  def epilogue_fn(acc):
      x = acc.float().view(-1, group, n)
      return acc.relu(), x.sum(1) + x.amax(1)

  def fn(a, b):
      return flex_gemm(
          torch.mm,
          (a, b),
          epilogue_fn,
          kernel_options={"backend": "QUACK"},
      )

```
