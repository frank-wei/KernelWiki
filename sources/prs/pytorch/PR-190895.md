Build-side tooling for embedding AOT-compiled DSL kernels into aten.

Naming note: "native AOT" here means ahead-of-time compiled DSL
kernels embedded in the native (aten) library -- it is unrelated to
AOTInductor/AOTAutograd (whole-graph capture); this machinery embeds
individual eager kernels behind aten ops. The namespace is
torch._native (the DSL override stack) + "aot".

An op opts in with torch/_native/ops/<op>/aot.py (stdlib-only at module
scope; single declaration or a family via declarations()), exporting
the grid, the Python coverage projection (covered_axes), and the
C++-emitting functions (cpp_dispatch_prelude / cpp_dispatch /
cpp_launch, optional cpp_helpers / cpp_covers). decl.py is the
contract and validating loader.

toolchains.py: per-DSL export + launcher codegen behind a uniform
launch_<prefix>(tensors..., scalars..., stream) contract; this commit
carries the base class and CuteDslToolchain (export_to_c). read_only
tensor args go through const_data_ptr (COW-safe).
