## Vectorized 2D scatter_reduce/index_reduce min/max fast paths

### Summary

Add optimized CUDA fast paths for 2D `scatter_reduce_` and `index_reduce_`with `amin`/`amax` on `dim=0`.

The fast path applies when `self` and `src` are contiguous, rows are sufficiently aligned, and `scatter_reduce_` receives an index expanded from a 1D row index. Eligible `index_reduce_` calls are delegated to the equivalent scatter path, including `include_self=False` after its existing identity initialization.

On sm_90+ with CUDA 12.8+, the implementation uses bulk asynchronous global-to-shared loads, double-buffered shared memory, and vectorized global `red.*` min/max instructions for FP16/BF16.

On sm_80 - sm_89, the implementation uses 16-byte `cp.async` loads with warp-per-row scheduling. FP16 and BF16 use packed two-element 32-bit CAS reductions, including an early exit when neither element changes. Float and double continue to use the existing generic min/max implementation.

ROCm is excluded from these paths. Reductions other than `amin` and `amax` are unchanged.
