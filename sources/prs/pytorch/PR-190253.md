This PR introduces new stateless RNG APIs for generating integers / raw bits:
* `randint(key, *shape, low=0, high=None, dtype=torch.int32)`
* `randint_(key, result, *, low=0, high=None)`
* `bits(key, *shape, dtype=torch.int32)`
* `bits_(key, result)`

`randint()` / `randint_()` can produce bounded or full-range random integers. `bits()` / `bits_()` are convenience wrappers for full-range generation of the given dtype.

Supported dtypes: all signed and unsigned integral types **except `torch.bool`**:
* `torch.int8` / `torch.uint8`
* `torch.int16` / `torch.uint16`
* `torch.int32` / `torch.uint32`
* `torch.int64` / `torch.uint64`

All 32-bit or smaller dtypes come from sampling 32 bits of randomness and downcasting as necessary. For 64-bit dtypes,
64 bits of randomness is sampled per output value.

from torch.func import _random as r
