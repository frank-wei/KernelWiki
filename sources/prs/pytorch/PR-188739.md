### Agent
Add FlexGEMM epilogue lowering for the MX E8M0 and NVFP4 E4M3 scale
custom ops used by float8 quantization.

MX scales lower natively over TensorSSA values by extracting and clamping
Float32 exponent bits while preserving E8M0 zero, saturation, infinity,
and NaN encodings. Store-only local reductions encode the compact reduced
value before broadcasting it to QuACK's compressed-output store shape;
fragment-sized scales can also remain available to later quantization
operations. Larger physical reductions use the equivalent generated
scalar finalizer. Explicit max_power arguments are static integer inputs.
