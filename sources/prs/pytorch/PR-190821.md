> This connects PyTorch Inductor to the vendored dense and block-scaled matrix
> multiplication kernels that can perform extra work before storing their
> outputs. It gives both kernels one shared description of grouped reductions,
> validates whether a requested group size and direction are supported, builds
> the kernel arguments and output buffers, and includes those choices in the
> compilation cache key.
>
> Unsupported shapes or operations are rejected before launch so Inductor can
> use another implementation. Keeping this contract shared prevents the dense
> and block-scaled paths from interpreting the same post-processing differently.
>
