# Summary

Before we did not enable the `tuned` flag that is passed through kernel_options and also supported in quack. Now we do :)

This uses as much infra from the existing parallel compile but still some quack specifics. TLDR is we compile in parallel and using fake-tensors produced in the sub procs and we store the kernels to disk as object files. During tuning we just load from disk. We do some vendor edits to allow for the quack cache dir to be embed with inductors and follow similar semantics.

As well I also did some small tuning on b200 (only dev we currently support) and baked in a better set of defaults for shapes at sizes while making sure it works with dynamic shapes.
