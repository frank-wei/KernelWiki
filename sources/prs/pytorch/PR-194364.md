## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This completes the migration from `cutlass_api` to `nvidia-cutlass-operators` and reenables NVGEMM in B200 smoke CI.

More specifically this
- drops <0.2.0 support
- updates NVGEMM code gen and tests
- rejects symbolic shapes before CUTLASS Operators selection
- supports eligible epilogues of pointwise, grouped reduction, and sum/div mean
- defers unsupported reduction layouts and composite gen'ed reductions to the existing unfused path
- expands direct dense NVGEMM coverage to Hopper
