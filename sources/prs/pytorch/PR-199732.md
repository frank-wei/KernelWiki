<!-- upstream-excerpt-start -->
Stack from [ghstack](https://github.com/ezyang/ghstack/tree/0.15.0) (oldest at bottom):
* __->__ #199732

> AI-assisted change prepared with Claude Code. It was split out of #199430 so it can land on main independently.
>
> On CUDA, `split_with_sizes_copy` crashed the process when its input had no elements (since #117203). The fast path's launch size math computed zero chunks per block and then divided by it, so any call with an empty input that took the fast path crashed. The CUDA fast path now returns early for empty inputs, since there is nothing to copy.
>
> Test Plan: the new empty cases in `test_split_with_sizes_copy_out`, including all-empty splits, crash the process without the fix (found when the fix was written for #199430) and pass with it. The test runs on CUDA when a GPU is available. The local build predates main, so the test ran on an older main (ff18741848a) whose build includes this kernel change; `TensorShape.cu` is unchanged on main since then.
> ```bash
> python test/test_torch.py -k test_split_with_sizes_copy_out
> ```
