## Summary
- make auto split-K selection treat zero launch grids as `split_k = 1`
- keep AMD matmul tile widths positive for `N == 0`
- preserve the existing allocation/return path for empty outputs
- avoid reading gather indices for `K == 0`, when no activation rows contribute
- expand the zero-size `test_op` sweep across plain/ragged/batched modes, explicit and automatic split-K, and zero batch size

## Validation
- H100 direct repro: `M == 0`, `N == 0`, and `K == 0` produce the expected shapes and zero-reduction values
- GB200 complete zero-size pytest slice: `352 passed, 560 skipped`
- GB200 plain `K == 0` pytest slice: `32 passed, 64 skipped`
- `origin/main` with the PR sweep cases: `M == 0`, `N == 0`, and zero batch fail with `ZeroDivisionError`
