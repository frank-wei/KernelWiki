<!-- upstream-excerpt-start -->
PR description written by Codex

Expose FPSan embedding as gl.fpsan.embed/unembed and provide triton_kernels.fpsan tensor helpers for arbitrary-strided GPU tensors. The kernels compile in normal mode and support signed or unsigned payloads, multiple devices, FP64, FP32, FP16, BF16, and all four real FP8 formats.

Validation: triton_kernels tensor suite (144 passed); combined Gluon frontend/FPSan suites (561 passed, 146 skipped, 1 xfailed); exact normal-mode payload oracle across all eight float formats on a non-current GPU.
