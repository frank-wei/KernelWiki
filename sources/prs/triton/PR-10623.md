## Summary

Call `torch.nn.functional.pad` directly for empty MX layout inputs across Hopper, Blackwell, CDNA4, and GFX1250, while retaining the separate empty-launch guard for Blackwell's ragged Triton kernel.

[PyTorch #161639](https://github.com/pytorch/pytorch/pull/161639) allows zero-sized `constant_pad_nd` outputs starting in [PyTorch 2.10.0](https://github.com/pytorch/pytorch/releases/tag/v2.10.0); 2.9.1 still rejects the same case.

## Testing

- 124 existing CPU/meta zero-size layout roundtrip cases with PyTorch 2.10.0
