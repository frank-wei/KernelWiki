## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Expose optional `disable_lsr` for top-k forward and `maxnreg`/`sched4reg` through the reduction optimization flags. These allow callers to tune the existing compiler controls without modifying kernel arithmetic. Unset options are omitted from launches, preserving the current defaults and avoiding CUDA-specific options on other backends.

Based on current main, including #11478. Pre-commit checks and eight manual CPU checks passed for default configuration, option forwarding, scoped overrides, and autograd argument counts. Those CPU checks use mocked GPU dispatch; GPU correctness and performance tests have not been rerun for this PR.
<!-- upstream-excerpt-end -->
