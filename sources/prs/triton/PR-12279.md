## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Rename the gfx1250 ISA family and related symbols to CDNA5:
- `ISAFamily::GFX1250` -> `ISAFamily::CDNA5`, `isGFX1250()` -> `isCDNA5()`
- `is_hip_gfx1250` -> `is_hip_cdna5`
- `GFX1250MXScaleLayout` -> `CDNA5MXScaleLayout`, `GFX1250_SCALE` -> `CDNA5_SCALE`
- gfx1250-suffixed test files, FileCheck prefixes and comments

The gfx1250-strict variant keeps its name (`isGFX1250Strict`,
`skip_if_gfx1250_strict_wmma`), as do concrete target arch strings.
<!-- upstream-excerpt-end -->
