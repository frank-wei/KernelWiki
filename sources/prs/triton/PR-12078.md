## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
It turns out that despite ptx having 16 bit atomic instructions, these are actually emulated in ptxas.

This changes the locking to use native 32-bit atomic instructions, giving a 1.4x speedup in a matmul benchmark running under gsan.
