## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Disable implicit floating-point fusion by default. Kernels can opt in with
enable_fp_fusion=True, or applications can restore the previous default
with TRITON_DEFAULT_FP_FUSION=1.

Set TRITON_FORCE_DISABLE_FP_FUSION=1 before starting the process to
override both settings. Explicit tl.fma operations remain fused.

Preserve fusion-dependent arithmetic with explicit FMAs and targeted
kernel opt-ins. Enable fusion for the Hopper MXFP4 test because a ptxas
bug causes it to fail with fusion disabled.
<!-- upstream-excerpt-end -->
