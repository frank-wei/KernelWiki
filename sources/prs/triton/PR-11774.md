## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This adds a special "write-once" gsan allocation. The rules here are that they can be written exactly once, and read many times after being written.

This means we only need to track for read-after-write violations, so we can simplify the shadow cell to a single scalar write clock which is 1/6th of the size of a normal shadow cell. This allows us to track byte-granularity while actually using less shadow memory than 4-byte granularity normal allocations.

Also, this allows for a completely wait-free shadow memory access pattern. This means we don't serialize accesses to those address.
<!-- upstream-excerpt-end -->
