## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Activation scales when the tile is not a clean multiple of the block size can load garbage. However, on the consumer side masking prevents the compiler from keeping scales in smem->tmem, killing perf. We fix this on the producer side by writing zeros into the padded space, which we know is correct because the blackwell scales layout interleaves the blocks, so the padding is interleaved inside the allocation.
<!-- upstream-excerpt-end -->
