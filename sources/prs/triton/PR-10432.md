## Summary
- avoid `torch.nn.functional.pad` for empty Hopper, CDNA4, and GFX1250 MX storage while preserving the padded extents used by the existing view paths
- make Hopper MXFP4 value unswizzling repack from the configured MX axis
- avoid launching Blackwell ragged activation-scale unpadding for empty storage
- add CPU and meta zero-sized roundtrip coverage for Hopper, Blackwell, CDNA4, and GFX1250 layouts

## Root cause
`torch.nn.functional.pad` rejects valid empty tensors when an unpadded dimension remains zero. The AMD scale transforms also used inferred reshape dimensions that are ambiguous for zero-element tensors, and GFX1250 scale alignment divided by a zero-width dimension. Separately, Hopper value unswizzling always assumed the packed source axis was `-2`, and Blackwell ragged activation-scale unswizzling attempted an unnecessary kernel launch for empty storage.

## Testing

- direct CPU/meta cross-layout zero-sized and representative non-empty roundtrip matrix across Hopper, Blackwell, CDNA4, and GFX1250 layouts
