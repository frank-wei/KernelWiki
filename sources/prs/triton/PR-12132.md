## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
CUDA 13.3 and 13.4 ptxas can increase the register usage of non-persistent Hopper MXFP4 matmuls enough to halve block residency. The launch heuristic already budgets shared memory for 16 resident warps, but only persistent kernels received the matching register constraint.

Apply the register budget to regular Hopper MXFP4 kernels when that occupancy is feasible. Account for the accumulator footprint, available grid waves, and the extra BF16 shared-memory tile used by scaled-input lowering. Leave register allocation unconstrained when those resources prevent the target, and preserve existing tile selection, pipeline depths, and persistent-kernel behavior.

This replaces the single BF16 tile special case with a resource-based policy; it does not change the Triton compiler, CUDA version, or numerical operations. Regression tests check real compiled resources and numerical results for four/eight-warp kernels, large accumulators, small grids, and scaled inputs.
