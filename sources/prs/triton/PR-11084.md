## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
PR description written by Codex

Expose native Blackwell packed arithmetic through `add2`, `sub2`, `mul2`, `fma2`, `min2`, and `max2`, with inferred or explicit result types and normal tensor broadcasting. Rubin reuses the two-lane APIs and adds `add4`, `sub4`, `mul4`, and `fma4` for mixed FP8 and packed FP4. The shared arithmetic dispatcher remains private.

Replace `float2` and handwritten packed-float assembly in attention and MoE. A named `_combine_add2` reducer uses existing Gluon layouts; the compact C++ binding constructs the operation and only infers FP4 result layouts when necessary. No payload bitcasts or unrelated language-core/compiler-frontend changes are included.

Focused regression coverage preserves mixed-precision and FP4 signatures, scalar broadcasting, multi-CTA and warp-specialized reductions, diagnostics, and direct packed register chains without redundant test matrices. Validated with 283 compiler lit tests (2 unsupported), 336 Gluon frontend tests (32 skipped), 116 Triton frontend/compiler tests, and 22 GB300 packed-operation tests (2 skipped).
