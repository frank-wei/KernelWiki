## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
PR description written by Codex

NVIDIA CI repeatedly compiled expensive Triton kernels during GPU tests and amplified contention with runner-specific pytest pools.

Capture explicitly marked tests in one FakeTensor-only pytest session backed by a globally deduplicated, dynamically balanced compiler pool. Scoped launch/specialization hooks and reusable warmup-aware testing helpers preserve ordinary test behavior, randomness, pointer alignment, instrumentation, and compiler options. Require every warmed specialization to be consumed and every marked runtime compilation to hit its warmed cache entry.

Replace runner-specific Make recipes with a Python suite runner and thin Make targets. Dynamically distribute Gluon and replenishing ConSan workers across any requested GPU count, overlap compatible suites, then run memory-intensive examples with bounded per-GPU concurrency. Keep machine GPU counts and compiler-worker budgets in the workflow; remove fixed GPU lanes, duration tables, pytest-split, shell process management, and test monkeypatches.
