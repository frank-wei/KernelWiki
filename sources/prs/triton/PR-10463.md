## Summary

- return empty matmul outputs before selecting kernel optimization flags
- allocate empty outputs without split-K scratchpads
- support zero-axis direct-scale MX reference upcasts
- expand existing matmul and MX casting sweeps for swizzled zero-row, zero-column, and zero-batch cases

## Root cause

Empty operands are not TMA-compliant, while non-strided MX layouts require persistent TMA during optimization selection. The existing empty-output return happened after flag selection, so valid empty results failed despite requiring no kernel.

## Testing

- H100 and GB200 custom-layout zero-row and zero-column matmul sweeps
- GB200 all-swizzled zero-batch matmul sweep
- H100 and GB200 full `test_mxfp.py`
- H100 and GB200 `test_opt_flags_split_k.py`
