## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
GSan's `syncThreads` can execute within warp-specialized partitions, where only part of the CTA participates. Replace the implicitly aligned `bar.sync` with `barrier.sync` so these calls do not require convergence across the whole CTA.

Extend the existing warp-specialization test to check that GSan's inline assembly uses the unaligned form.

- All pre-commit hooks, Python syntax, and diff checks passed.
- GPU validation could not run: dependency setup on the Brix GB300 devbox failed because its package registry could not be resolved.
