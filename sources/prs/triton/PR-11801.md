## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Python 3.13 uses precise definition locations when `inspect` retrieves source. Triton's `specialize` and `aggregate` wrappers preserve the original file or class identity but keep a generated location. As a result, `inspect.getsource` can return only a signature fragment for a specialized function or raise `OSError: source code not available` for an aggregate class.

Preserve the original Python function and class definition locations. The adjusted JIT source-location fields stay as they are, and the class location is copied only when the original class provides it.
