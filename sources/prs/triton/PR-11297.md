## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR reduce GSan overhead for TMA operations by replacing per-element pointer/mask instrumentation with rectangular access descriptors.

We still keep a stack of input regions, but now each region represents a tile by its base pointer, row width, row stride, and row count. Gather/scatter operations use the same interface but with each row being its own rectangle.

## Performance
### Attention

For gluon-attention, we see a nice 7-29% speedup.

### Attention

| Head dim | CTAs | Main | This PR | Speedup |
|---:|---:|---:|---:|---:|
| 64 | 1 | 10.41 ms | 9.49 ms | **1.10×** |
| 64 | 2 | 12.70 ms | 11.83 ms | **1.07×** |
| 128 | 1 | 24.80 ms | 19.29 ms | **1.29×** |
| 128 | 2 | 20.20 ms | 16.76 ms | **1.21×** |

### MoE
For MoE, apparently the HBM swizzling was interfering with the pointer access coalescing before and we're actually seeing a massive speedup from this change.

| Batch size | Main | This PR | Speedup |
|---:|---:|---:|---:|
| 128 | 125.15 ms | 33.10 ms | **3.78×** |
| 256 | 135.35 ms | 36.19 ms | **3.74×** |
| 512 | 182.02 ms | 48.32 ms | **3.77×** |
| 1024 | 228.43 ms | 61.16 ms | **3.73×** |
