## Modifications

1. Adopt this kernel to JIT, to support GLM-5 hidden size (6144)
2. Support SM120, by decreasing the number of stages to fit the SM120 shared memory (99 KB) vs 228 KB on Hopper/Blackwell (since this kernel uses mma.sync for latency instead of tensor core, it's fully compatible)
3. Rewrite this kernel in cute-dsl. Currently, it's perf is better on SM120, but not on SM100. Maybe migrate it later/on future archs if necessary.

DSL vs the original CUDA changes on SM120:
1. Instead of ldsm_x4, use _ldmatrix_x2
2. Eliminate the register spill to GMEM issue (`max_number_threads=[256], min_blocks_per_mp=1`) by capping the launch bounds on SM120, when tileN is 8
3. Instead of try_wait, simply use mbarrier_wait.
