## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
## Summary

- Centralize diffusion quality-gated fusion selection and shared model residual/modulation fallbacks.
- Reuse `jit_kernel` launcher utilities in recent CUDA kernels and shared bit-exact numerical primitives in Triton kernels.
- Move generic native BF16 RMSNorm out of the Z-Image-specific module and tighten shape, dtype, device, and compile guards across recent diffusion fast paths.
- Remove dead registrations, duplicated model helpers, and redundant tests while expanding precision and `torch.compile` coverage.

## Why

Recent diffusion performance work added several kernels and model integrations in parallel. That left duplicated launch plumbing, repeated numerical helpers, model-local fallback logic, and a few overly narrow or dead components. Besides making maintenance harder, those copies could drift in supported shapes, fallback behavior, or precision contracts.

This cleanup keeps one implementation for each shared concern and makes backend selection explicit. Lossless paths continue to require reference-equivalent or bit-exact behavior; non-bit-exact fusions remain gated to high-quality mode.

## Impact

- No intended model-output, accuracy, or precision change.
