## Motivation

Reduce MoE launch and memory-traffic overhead by fusing `silu_and_mul` and `per_token_group_quant_fp8`. The fused Triton kernel computes the gated activation, derives per-token-group FP8 scales, and writes the FP8 down-projection input in one pass.

> The no-flag auto-dispatch update is in [xieminghe1/sglang#1](https://github.com/xieminghe1/sglang/pull/1). The original PR head has **Allow edits from maintainers** disabled, so it must be merged by the fork owner before this PR updates.

## Changes

- Add `fused_silu_mul_quant_fp8` and its H200 benchmark.
- Feed the fused FP8 tensor and generated activation scales directly into the down MoE GEMM.
- Preserve the DeepSeek-V4 `swiglu_limit` clamp inside the fused kernel.
- Automatically dispatch to the fusion from the Triton MoE path. No environment variable or new server argument is introduced.
- Add standalone kernel coverage, dispatch-condition coverage, and an end-to-end fused-vs-fallback MoE comparison.
