## Motivation

DeepSeek V4 with DP attention currently cannot use breakable piecewise CUDA graph for mixed/extend batches. This leaves the prefill/mixed path on eager kernel launches and can cause large host-side gaps under high concurrency. This PR adds the DeepSeek V4 and DP-attention plumbing required to make breakable piecewise CUDA graph capture/replay work for DSV4 mixed chunk workloads.

Co-authored by: @Oasis-Git

## Modifications

- Add a graph-break wrapper for DeepSeek V4 attention so the DP-attention backend can run inside BCG/PCG replay while writing into a static output buffer.
- Add `input_embeds` forwarding and hybrid-SWA buffer dtype handling in `BreakableCudaGraphRunner`.
- Add DP-wide guards for piecewise replay so all active DP ranks enter the same replay path, and sparse/tail DP batches fall back to eager instead of hanging.
- Make DP MLP-sync propagate whether every DP rank is eligible for piecewise CUDA graph replay.
- Skip TBO-only split-index work when TBO is disabled, which is needed for `enable_mixed_chunk` mixed batches.
- Accept both raw `int8` and `fp8_e4m3` DeepGEMM dispatch-buffer views in the DSV4 MegaMoE pre-dispatch matcher.
