## Summary

Fuse the packed single-stream Q/K copies, RMSNorm and interleaved RoPE in FLUX.2 Klein Base4B on Hopper. The native profile identifies this remaining split chain after the existing AdaLN and SwiGLU fusions.

On **1× H200**, native eager **1024×1024 / 50 steps / BF16 / lossless**, the two fixed full-request-warmed ABBA groups reduce worker E2E by **2.53–2.60%** and client E2E including PNG saving by **2.43–3.41%**. Every valid lossless PNG is byte-identical. Initial one-step-warmup groups, including slower candidate observations, remain reported below.

## Modifications

- Add a Triton kernel that reads strided Q/K directly from the packed QKV/MLP projection and writes contiguous normalized/rotated Q/K. Adjacent V/MLP values are untouched.
- Preserve the native tiled RMSNorm reduction and its BF16 output rounding, followed by FlashInfer's interleaved RoPE cosine-FMA ordering. Explicit sign-bit negation preserves negative zero.
- Keep rotary pairs in registers: the initial gather implementation used 90 registers/thread; the NCU-driven pair layout uses 34, with no spills.
