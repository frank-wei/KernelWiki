## Motivation

The Kimi-K3 KDA MTP verify kernel (`fused_kda_decode_mtp_dspark`) spends much of its time on precompute dependencies and state synchronization. Rebalancing that work cuts kernel latency by up to 1.37× on B300, and outputs stay bitwise identical.

## Modifications

All changes are in `python/sglang/kernels/ops/attention/kda_decode_mtp.py`:

- Keep convolution weights in producer registers, removing their shared-memory staging and the initial CTA barrier.
- Reorder independent convolution/gate work and prefetch output-normalization inputs using spare producer capacity.
- Use warp-level synchronization for warp-local state transfers, and overlap resident-state loads with precompute while keeping the cross-warp barriers.
- Public wrapper, launch dispatch, persistent AOT cache, ReplaySSM, padding, output normalization and caller-owned output buffers are unchanged.
