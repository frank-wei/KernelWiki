## Motivation

1. **The MLA output / q / kv projection w8a8-block FP8 GEMM uses the Triton kernel.** `apply_w8a8_block_fp8_linear` selects `triton_gemm_a8w8_blockscale` for the MLA projection shapes (they are in the hard-coded `use_aiter_triton_gemm_w8a8_tuned_gfx950` list). On gfx950 + HIP≥7.2 the CK bpreshuffle kernel (`gemm_a8w8_blockscale_bpreshuffle`, which aiter dispatches to the `ck_tile QuantGemm`) is faster for these shapes.

2. **The attention-output inverse RoPE falls back to a per-token strided kernel on HIP.** `fused_rope_inplace(o[..., -rd:], ...)` uses a single fused CUDA kernel on NVIDIA but on HIP falls back to `apply_rotary_emb_triton`, which launches one program per token and does strided (`2i` / `2i+1`) interleaved loads. Used batches tokens and coalesced contiguous loads.
