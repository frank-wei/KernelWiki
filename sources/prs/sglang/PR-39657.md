## Summary
- Add a Hopper variant of the block-FP8 Triton matmul, `_w8a8_block_fp8_matmul_hopper`, with two tuning knobs read from the per-shape config: `SWAP_AB` transposes the MMA so the weight tile occupies the M dimension for tiny M, and `SPLIT_K` splits the K loop over a second grid axis into fp32 partials that `_reduce_block_fp8_split_k` sums.
- `w8a8_block_fp8_matmul_triton` selects the Hopper kernel only on sm90 and only when the chosen config entry carries one of those keys; every other config keeps the existing kernel selection, grid and output buffer.
- Seven H200 tuning files for `fp8_w8a8` with `block_shape=[32, 32]` (N,K in {1152,5120}, {1792,5120}, {25600,6144}, {4096,1280}, {5120,2048}, {5120,576}, {8192,1280}). Their `"1"` entries use `SWAP_AB` and `SPLIT_K` in {1, 2, 4, 8, 16}; the `"2"` entries are plain, so M >= 2 runs the existing kernel and bs=1 rows differ from bs>=2 rows by the fp32 accumulation order (one bf16 rounding step at most).

## Changes to existing kernels
- None. Configs without the two keys, including all existing `[128, 128]` H200 files, take exactly the previous path.
