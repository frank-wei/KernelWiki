## Summary
- Add `--enable-mamba-cache-stochastic-rounding` and `--mamba-cache-philox-rounds` as general Mamba cache options.
- Validate unsupported stochastic-rounding configurations early with actionable errors: FP16 SSM cache is required, CUDA is required, Triton SR requires SM100-family Blackwell, and FlashInfer SR requires FlashInfer Mamba availability.
- Thread SR through both selective-state-update backends:
  - Triton passes SR enablement and Philox rounds into the SGLang Triton kernel.
  - FlashInfer creates a CUDA random seed only when SR is enabled and passes `rand_seed` plus Philox rounds.
- Port the Triton stochastic FP16 state write path with `cvt.rs.f16x2.f32`, while keeping the existing cast path for non-SR writes.
