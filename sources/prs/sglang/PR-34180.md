## Summary
- Centralize bit-exact first-sight `torch.equal` verify/disable behind `BitExactFusionGate` for FLUX / GLM / Sana / Ernie fused-norm sites (stops another per-model `_DISABLED/_VERIFIED` copy after #34126).
- Deduplicate shared helpers: Flux/Flux2/Qwen `_get_qkv_projections`, transformer lazy-load for denoising/Hunyuan3D, and route Z-Image RMSNorm wrappers through `fused_gate_rmsnorm`.
- Drop unused package-level `get_kernel` wrappers; keep registry entries for namespace discovery (including `sparse_linear_attn_fwd`).
- Rename generic native NSS symbols off the Qwen-only prefix; move `PRECISION_TO_TYPE` to a leaf `precision_types` module; refresh skill docs for `native_bf16_rmsnorm` / `BitExactFusionGate`.

## Why
Post-#34085 / #34126 parallel fast-path work left duplicated verify scaffolding, model-local helpers, dead package wrappers, and stale Qwen/Z-Image naming in code and skills. This cleanup keeps one implementation for each shared concern without changing numerical contracts.

## Impact
- No intended model-output, accuracy, or precision change.
- Bit-exact paths still self-verify on first sight and permanently fall back on mismatch.
- Unsupported shapes/dtypes/dev
