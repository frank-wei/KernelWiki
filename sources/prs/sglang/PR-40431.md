## Motivation

The legacy FP4 indexer replays a capacity-sized CUDA Graph grid even when the live context is short. Masking K loads and final logits still leaves dequantization, dot products, weighting, and reduction running on fully invisible tiles. In a measured shape with 1,048,896 output columns and at most 8,704 visible positions, more than 99% of columns are invisible.

This change skips the arithmetic for completely invisible tiles and writes `-inf` directly to valid output addresses.

## Modifications

- Add a CTA-uniform branch after loading the current device-side `n_vis`. Partially visible tiles retain the original arithmetic, BF16 rounding points, and masks.
- Express existing caller guarantees to Triton: zero-width inputs return before launch, and contiguous queries have a 128-element head stride when `H > 1`. Exclude singleton heads from the stride assumption.
- Preserve the function signature, output shape, cache layout, launch grid, and call sites. Each graph replay reads the current device length; no new feature flags are introduced.
