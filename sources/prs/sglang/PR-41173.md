## Motivation

QSA graph replay launches separate layout builders and prepares each draft step's lengths independently. Generate compatible row/layout metadata together and build all draft steps in one launch.

## Modifications

Apply step offsets in the kernel, cache compatible graph arguments, and retain the existing fallback when step layouts cannot be grouped.

This PR is independently based on `main`. QSA KV preparation is tracked separately in #40972.
