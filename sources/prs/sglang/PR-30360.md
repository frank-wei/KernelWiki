## Motivation

Add native serving support for MiniCPM-SALA checkpoints, which interleave MiniCPM sparse softmax-attention layers with constant-decay Lightning linear-attention layers.

The implementation integrates the model with SGLang's existing attention, linear-attention, CUDA graph, and memory-pool infrastructure. It also replaces the serving-time dependency on the original out-of-tree block-table extension with SGLang JIT kernels.

## Modifications

- Add `MiniCPMHybridConfig` and register both `MiniCPMForCausalLM` and `MiniCPMSALAForCausalLM`.
  - Normalize mixer aliases and repeat mixer patterns to the configured layer count.
  - Parse both flattened and legacy nested sparse-attention configuration.
  - Describe Lightning state using the existing `Mamba2CacheParams` and linear-attention model registry.
- Extend the MiniCPM model with SALA mixer support.
  - Add Lightning QKV projection, optional Q/K normalization, RoPE
