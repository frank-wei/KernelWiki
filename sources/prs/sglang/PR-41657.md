## Motivation

The Q RoPE store before FlashMLA used a Triton kernel (`q_rope_store`) that only covered some shapes; the rest went through a separate copy plus in-place RoPE. The JIT Q norm+RoPE kernel already does the same work and can skip the norm.

## Modifications

- `main_norm_rope.cuh`: the Q kernel gains a `kApplyNorm` switch; `fused_q_norm_rope(q, q_out, eps=None, ...)` applies RoPE only while copying Q into the (padded) output.
- `MQALayer._compute_q_b` calls `fused_q_norm_rope` for every CUDA call with a `q_out` buffer, replacing the shape-gated `q_rope_store` path.
- `q_rope_store.py` is removed.
- Under ROCm the kernel rounds the sine product before the cosine fma, the gfx950 batched-RoPE order that the Triton kernel reproduced, so `test_dsv4_q_rope_store.py` keeps its AMD CI registration and now tests `fused_q_norm_rope` (bitwise against `fused_rope_inplace`, on CUDA and on gfx950).
