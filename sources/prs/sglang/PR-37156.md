## Summary

This PR implements the Qwen-Image FP8 norm + activation-quantization fusion
described in [Agentic Kernels in Production](https://www.baseten.co/blog/agentic-kernels-in-production/)
for SGLang's native diffusion backend on Blackwell.

The new JIT CUDA paths fuse:

- LayerNorm + AdaLN scale/shift + static E4M3 quantization for the image/text
  attention inputs; and
- gated residual add + LayerNorm + AdaLN scale/shift + static E4M3
  quantization for the image/text MLP inputs.

Each kernel returns both the original BF16 modulation output and its
prequantized FP8 representation. The ModelOpt FP8 projections consume the FP8
tensor directly, while the BF16 tensor remains live through the corresponding
projection to preserve the original allocation/lifetime semantics. On the
official checkpoint this enables 240/240 block paths.

The fast path is deliberately narrow: CUDA Blackwell+, BF16 batch-1 contiguous
tensors, hidden size 3072, affine-free LayerNorm, finite positive scalar FP32
ModelOpt input scales, no indexed modulation, no zero-condition-timestep path,
and no breakable CUDA graph. Separate Q/K/V projections must have identical
input scales; packed QKV from #37123 uses
