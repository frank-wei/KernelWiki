## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Add the plan KV-canary JIT CUDA kernel, the top consumer of the write/verify
kernels.

The plan op (python/sglang/jit_kernel/kv_canary/plan/: api.py, entries_kernel.py,
offsets_kernel.py, utils.py) computes per-request canary write/verify plans and
launches the canary_plan_entries.cuh kernel; it consumes VerifyPlan and
WritePlan from the verify and write kernels. plan_ref.py is its Python reference.
Includes the paired header csrc/kv_canary/canary_plan_entries.cuh.

The plan tests (incl. the cross-kernel pipeline e2e and differential oracle) and
benchmarks travel with this commit.
