## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`_online_combine_kernel` picks the next draft token as the min candidate index among tied maxima. If a step-logits row is degenerate (e.g. all `-inf`, so no `rescaled == best` comparison is true), `cand` stays all-`_IDX_SENTINEL` (2147483647) and that sentinel is written as a token id, which then asserts out-of-range in the downstream embedding `index_select`.

Guard by clamping an all-sentinel row to token 0 so a valid id is always emitted; a degenerate draft is harmless (rejected at verify). Defense-in-depth, independent of any upstream cause of the degenerate row.
