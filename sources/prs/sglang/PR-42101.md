## Motivation

MiMo's input local audio transformer runs six attention layers with only four tokens and head dimension 16. cuDNN SDPA takes about 1.915 ms per layer at the observed 300-second audio shape on H200. A specialized Triton kernel reduces this to 43.25 µs while closely matching the tested cuDNN arithmetic.

## Modifications

- Add a one-warp kernel processing four batch/head pairs per program, with runtime group count to avoid recompilation for every audio length.
- Keep QK, exponential sums and accumulation in FP32. Round unnormalized exponential weights to the input dtype before PV, then normalize the weighted sum, matching the tested cuDNN path.
- Select the implementation once when building MiMo's input local transformer: Hopper, head dimension 16, and group size 1–4 use the specialized adapter; other configurations use SDPA. The adapter keeps only the runtime precision, mask, position-bias, dropout and attention-weight choices. Q/K/V shape, device, dtype consistency and stride checks live in the kernel host entry point.
