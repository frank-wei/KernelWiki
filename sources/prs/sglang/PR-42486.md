## Motivation

Make the default recurrent Q/K normalization explicitly compute a reciprocal norm and then multiply, keeping reciprocal formation and vector scaling as separate source operations.

## Modifications

- Compute `1 / sqrt(sum(x*x) + epsilon)` once for each Q/K vector in the default KDA and GDN path, then multiply by it. The CuTe decode-parity branch continues to use `rsqrt` and shares the final multiplication.
- Add bitwise output/state coverage against separately normalized inputs for both recurrences at head dimensions 32, 64, and 128. Exact sums of squares keep the test independent of the standalone normalizer's reduction layout.

## Accuracy Tests
