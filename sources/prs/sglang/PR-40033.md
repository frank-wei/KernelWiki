## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Routes the EAGLE tree, greedy verify, ngram reconstruction, and target-only sampling kernels through `sglang.kernels.ops.speculative` (JIT) on CUDA and ROCm, with the device kernels shared as headers so the MUSA AOT build keeps using the same source. No functional change: every device kernel is byte-identical to main modulo whitespace.
