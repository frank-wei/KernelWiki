## What this does

Extends `--enable-unified-memory` to **MLA-hybrid-Mamba** models (Kimi-Linear), on the Triton attention backend.

Unified memory replaces the two static pools — a full-KV pool and a Mamba/linear-attention state pool, split once at startup by `--mamba-full-memory-ratio` and never rebalanced — with a single shared buffer that two `MultiEndedAllocator`s grow into from opposite ends. The pain it removes is one side idling while the other retracts or OOMs. The MHA-hybrid version already landed upstream; this adds the MLA-hybrid case.

## Design: dense views

The MLA layers have uniform entries (`kv_lora_rank + qk_rope_head_dim` = 576 wide for Kimi-Linear), and the page-major envelope is already a legal dense paged pool — so no new physical layout is needed, only index renumbering:

- each layer gets a contiguous view into the envelope starting at byte `l · page_size · E` (`build_dense_mla_views`)
- dense loc `φ(t) = (t // ps) · (ps · L) + t % ps`, layer-independent
- three coordinate systems: **virtual** (what upper layers persist) → **physical** (internal to compaction) → **dense** (handed to the kernel per forward)
