## Motivation

Qwen-Image's ModelOpt FP8/NVFP4 path materializes output-projection bias before the attention and feed-forward residual updates. In a GB300 profile, the denoiser launched 673 BF16 add kernels per profiled step; 224 of those launches disappear when the four per-block output biases are consumed by the following residual operation.

This implements the Qwen-Image bias-absorption optimization described in [Agentic Kernels in Production](https://www.baseten.co/blog/agentic-kernels-in-production/).

## What changed

- defer attention and FFN output bias for ModelOpt FP8/NVFP4 with the existing `skip_bias_add` contract;
- extend the hidden-3072 JIT norm kernel with `bias + gated residual + LayerNorm + scale/shift`;
- add a JIT `bias + gate * output + residual` kernel for the final block residual;
- use native BF16 `__hfma` so the residual can break BF16 midpoint ties exactly like the production `MulAdd` kernel;
- keep Nunchaku, non-ModelOpt, unsupported shape/device/dtype, and torch.compile/BCG paths on their existing implementation.

The eager fast path is deliberately narrow: CUDA SM 10.3, BF16, batch 1, hidden size 3072, contiguous/aligned tensors, and row-broadcast bias
