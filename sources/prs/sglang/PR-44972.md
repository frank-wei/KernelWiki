## Motivation

Uniform draft writes first gathered a write window and then translated FULL/SWA locations in separate operations. Precomputed write locations also bypassed the normal per-space cache in KVLocPlan.

## Modifications

Virtual table lengths are runtime bounds, invalid IDs use safe sink addresses, and FULL/SWA bounds are checked independently. A GPU test covers table-size changes, sink IDs and JIT-cache reuse.

- Fuse uniform write-window gathering with FULL/SWA physical-location translation.
- Have DSPARK consume the fused write plan.
- Route precomputed locations through KVLocPlan's existing per-space cache so repeated callers share the same contract.
- Cover static/unified locations, draft disposition, and kernel exports.
