## Summary

The Kimi-K2.x EAGLE3 spec-decode path ran two NCCL all-gathers on the hot path:
the draft `fc` projection gather and the vocab-parallel LM-head logits gather
(hit by both draft sampling and target verify). This PR shards the `fc` weight
and replaces **both** NCCL all-gathers with a single symmetric-memory multimem
all-gather path, matching the tokenspeed approach.

What it does:

1. **Shard `fc` column-wise across TP** (`ColumnParallelLinear`): `fc` projects
   the concatenated aux hidden states (`21504 -> 7168` for K2.5) and is the
   largest draft weight (~300 MB bf16); replicated, every rank re-read it each
   draft step. Sharding makes each rank read only its `1/TP` slice. Correct
   because the fc input is TP-replicated for EAGLE3 (`attn_tp_input_scattered`
   disabled), so a hidden-dim gather reconstructs the output exactly.
