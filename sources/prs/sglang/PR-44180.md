## Motivation

Serialized INT8 MiniMax-H3 checkpoints keep their AdaLN shift/scale/gate tables in FP32. `_modulate_scale_shift` and `_modulate_gate` only had BF16 kernels, so these checkpoints fell back to eager `index_select` + multiply + add + cast. That is about 100 gate calls and 1 scale/shift call per forward, each making several full-size passes.

## Modifications

- Add `indexed_scale_shift_fp32_`, `indexed_gate_fp32` and `indexed_gate_fp32_` next to the BF16 kernels in `kernels/ops/diffusion/modulate/indexed_modulation_triton.py`, export them from the diffusion facade, and document them in the kernels README.
- They keep eager torch's rounding: the product goes through `mul_rn_f32` so the following add cannot contract into an FMA, and the result rounds to BF16 once at the store.
- `minimax_h3.py` dispatches to the FP32 kernels by table dtype. It also requires unit column stride on the tables before taking any kernel path, because the kernels index columns contiguously. The eager fallback is unchanged.
