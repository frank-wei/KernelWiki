## Summary

- Extend the existing SANA convolution post-processing kernels to NCHW and to an already-biased GLU input; use them in SANA-WM's spatial FFN.
- Traverse streaming's exclusive backward GDN recurrence directly in reverse frame order, removing full-video flip/shift/cat intermediates. Preserve the forward recurrence and carried state.
- Verify each supported signature against the original implementation before enabling the path; fall back on mismatch, JIT failure, gradients, compilation, or unverified graph capture.
- Add convolution rounding, streaming state, changed-input graph replay, and fallback tests.

## H200 results

Setup: **1x H200**, PyTorch `2.11.0+cu130`, native `SanaWMTwoStagePipeline`, 1280x704, 49 requested frames, 16 fps, seed 42. Prompt: `a camera moving forward and turning left`; input: the SANA-WM cat image, camera actions `w-16,wl-16,l-16`. Bidirectional uses 20 main denoise steps and guidance 4.5; streaming uses its native preset with `--streaming --refiner-chunked`.

Each quality mode uses fresh processes in **A-B-B-A** order on the same GPU, with request warmup and output saving. E2E is the SGLang perf dump's `total_duration_ms`, not process startup
