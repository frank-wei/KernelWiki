## Motivation

`kimi_k2_moe_fused_gate` is currently hard-coded for 384-expert routing (Kimi K2). MiMo V2 Flash uses the same DeepSeek-style `noaux_tc` routing with `num_expert_group=1` but has 256 experts. This PR extends the fast-path kernel to cover both 256 and 384 expert configurations from a single code path, so MiMo V2 Flash can take the same optimized fused gate as Kimi K2 instead of falling back to the slower generic biased grouped topk. Alongside the templating, the kernel itself receives several micro-optimizations on the existing 384-expert path.

## Modifications

### `sgl-kernel/csrc/moe/kimi_k2_moe_fused_gate.cu`

**Multi-config support**

- Refactor kernel-side constants into `template <int N> struct GateConfig` so `VPT`, `WARPS_PER_TOKEN_SMALL`, `THREADS_PER_BLOCK_SMALL`, `VEC_PER_LANE`, etc. all derive from `NUM_EXPERTS = N` at compile time.
- Templated `kimi_k2_moe_fused_gate_kernel_small_token<N>` and `kimi_k2_moe_fused_gate_kernel<N>` on `N`; the kernel body is identical for 256 and 384.
- Host launcher dispatches via `switch (num_experts) { case 256 / case 384 / default }`. Unsupported sizes hit `TORCH_CHECK(false, ...)` with a clear message instead of silentl
