# kernels: wave64 histogram-select for the MiniMax-M3 decode top-k

The MiniMax-M3 decode block top-k (`minimax_decode_topk` / `minimax_decode_topk_page_table`) picks the `topk` highest-scoring KV blocks per (head, batch) row with one CTA per row. This PR adds a wave64 histogram-select implementation of that selection for ROCm, and raises `TopKTrait::kMaxNumBlocks` from 4096 to 16384. The ROCm path packs `(score, ~block_id)` into a `u64` total order, runs one coarse histogram round (256 bins for rows up to 1024, else 2048), refines with 11-bit rounds while more than 128 candidates remain, and finishes with a wave-0 bitonic sort over the survivors; bins above the threshold bin are emitted immediately, bins below die, and the threshold bin survives to the next round, so the row is still read from global memory exactly once. The block-id kernel's ascending-order emit now uses a single 64-lane ballot instead of two width-32 shuffle reductions, and `TopKTrait` becomes `TopKTraitImpl<kNumThreads>` so the ROCm launchers can select a 1024-thread instantiation when `max_seqblock > 1024` (CUDA still instantiates only the 512-thread trait).
