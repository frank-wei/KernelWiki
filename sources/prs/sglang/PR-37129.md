## Summary

This PR implements the Qwen-Image NVFP4 `resnorm_quant` optimization described
in [Agentic Kernels in Production](https://www.baseten.co/blog/agentic-kernels-in-production/).
For the image and text FFN branches, one Blackwell JIT kernel now performs:

- `residual_out = residual + gate * (attention_output + output_bias)`;
- FP32-accumulated LayerNorm and BF16 scale/shift modulation;
- direct E2M1 activation packing; and
- direct 128x4-swizzled E4M3 scale writes for the following ModelOpt FP4 FC1.

This removes the large BF16 modulation intermediate and the following
`flashinfer.fp4_quantize` launch. The conversion uses the same
FlashInfer/TensorRT-LLM helper as the production quantizer, so packed values,
scales, and residual output are byte-exact.
