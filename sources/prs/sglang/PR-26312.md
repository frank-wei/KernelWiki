## Motivation

Add classic reject sampling (RS) in Eagle speculative decoding.

The current pipeline of Eagle speculative decoding employ greedy sampling in both predicting draft tokens and target verification.

Use classic reject sampling means to use actual draft prob distribution for sampling draft tokens and for acceptance criterion.

Experimental results show using classic rs can largely improve accept length across various tasks.

## Modifications

We change how tokens are drafted: from argmax to sample on draft distribution. And we provide a reject sample triton kernel to update accept criterion from `p` to `min(1, p\q)`.
