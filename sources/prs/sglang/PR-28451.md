## Motivation

To address https://github.com/sgl-project/sglang/issues/28511.

The GDN (Gated DeltaNet) decode kernel reads the full recurrent state `S [HV, V, K]` from HBM **and writes it back every decode step**. On the H20‑3e this packed decode is **70–79% memory-bandwidth-bound at batch ≥ 64** — the per-step state read+write traffic dominates.

ReplaySSM (Dao AI Lab, https://dao-lab.ai/blog/2026/replayssm/) removes the per-step state write: keep a small per-slot ring buffer of the last `L` steps' `(d, k, g)`, read the output via the history route, and flush the full state only every `L` steps. Per-step state traffic drops from read+write ( ~`8dn` ) to read-only ( ~`4dn` ) → roughly halved.
