## Modifications

- Split `MiniMaxSparseKVPool` into a logical-size dense pool for layers 0–2 and a mapped HiSparse main pool for sparse layers 3–59. The K-only index pool remains GPU-resident and uses the enlarged logical address space.
- Add `HiSparseMHAMainPool` and a layer-first MHA host-pool specialization that transfers separate K and V buffers.
- Add a native block-index MHA swap-in wrapper to the current `kernels/ops/kvcache` JIT path. The CUDA kernel accepts `[batch, topk_blocks]`, resolves token positions in registers, masks the invalid tail of a partial final block, and emits the flattened token-slot table expected by sparse attention.
- Keep cache residency and LRU replacement token-granular, swap missing K/V entries into the GPU working set, and pass fixed-address `hisparse_slots` directly to decode attention for CUDA graph replay. This removes the Python block-to-token tensor expansion and clamp.
