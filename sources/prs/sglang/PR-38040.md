## Motivation

DiT inference is dominated by a few large GEMMs, and BF16 weights dominate memory (Qwen-Image's
DiT is 38 GiB). The existing online INT8 option, `kitchen_int8`, needs an external package and is
slower than BF16 on Hopper and Blackwell.

This PR adds `--quantization convrot_int8_customkernel`: online W8A8 INT8 with no calibration data,
no extra package and no special checkpoint. Following ConvRot ([arXiv:2512.03673](https://arxiv.org/abs/2512.03673)),
a group-wise Hadamard rotation (the regular Hadamard, a Kronecker power of a 4x4 block whose rows
all sum to one) is applied before INT8 quantization so that per-row activation and per-channel
weight scales stay accurate despite channel outliers and non-zero group means. Rotation, quantization, INT8 GEMM
and dequantization run as one fused sgl-kernel op per linear.

The method is model-agnostic. On Qwen-Image, Qwen-Image-Edit, Flux it is 1.13x to 1.61x faster (based on setup and model) than BF16, halves the DiT weights, and is about 2x faster than current `kitchen_int8` at the same memory.
