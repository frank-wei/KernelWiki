## Summary

Reduce HunyuanVideo eager overhead with three scoped paths:

- a lossless Triton kernel that applies image RoPE while packing image/text Q, K and V into contiguous attention inputs
- a `quality=high` strided QK RMSNorm path that avoids input contiguous copies
- the existing quality-gated fused linear+GELU epilogue for the Hunyuan MLP

The QKV/RoPE pack uses per-signature first-use bit-exact verification. The numerically relaxed RMSNorm and GELU paths are mounted only for `quality=high`. The cleanup keeps mounting all-or-nothing when the public FlashInfer CuTe QK RMSNorm entry point is unavailable, so no partial quality configuration leaks into the model.
