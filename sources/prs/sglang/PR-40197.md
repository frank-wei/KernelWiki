## Motivation

Several kernel integrations carry copies of the same TMA builders, warp primitives, alignment code and compiler policy. Fixes then need to be repeated across implementations, while unused fallback/cache helpers obscure the active paths. Consolidate these implementations and remove unused private code without changing the kernel algorithms or dispatch thresholds.

## Modifications

- Share the chunk and recurrent/output-state TMA descriptor builders across the six Blackwell GDN/KDA CuTe kernels. Keep their distinct state layouts, tile sizes, stages and swizzles.
- Reuse DSA's existing split-K reduction and split heuristics in sparse decode. DSV4's different architecture-specific heuristic stays separate.
- Reuse native LoRA token indexing and large-expert alignment in the experimental paths; update the Marlin runner's import to the canonical implementation.
- Use existing `warp`, `bits` and PDL helpers in packed KDA, MoE alignment and Inkling. Centralize the identical activation/SiTU fast-math policy while preserving the HIP/Blackwell precision rules.
- Remove unused DSV4 compression fallback, KDA repack caches, DSA reference dequantizer, MiMo ffprobe helper and NPU s
