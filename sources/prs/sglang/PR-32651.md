## Summary

- remove the disconnected Z-Image CuTe `norm_tanh_mul_add` kernel and its unused runtime wrappers after Z-Image moved to the bf16-preserving Triton native-norm path

- aggressively remove verified zero-reference runtime helpers, config classes, encoder code, duplicate platform code, and stale diffusion environment settings
- add CuTe dispatch regression coverage and direct Z-Image Triton norm parity/fallback tests
- synchronize all checked-in diffusion skills with the current component-accuracy layout, kernel/test paths, Z-Image fast path, and current nightly benchmark cases
