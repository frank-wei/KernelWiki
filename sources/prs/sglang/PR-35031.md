## Motivation

Move `causal_conv1d_fwd` / `causal_conv1d_update` off the prebuilt `sgl_kernel` wheel and onto the JIT kernel infra, keeping the in-place contract, the exported ops, and bit-level numerics. Both sit on the prefill/decode path of every short-conv hybrid model — LFM2 / LFM2-MoE, Mamba2, GDN.

## Modifications

- Device kernels move into `kernels/jit/csrc/mamba/causal_conv1d.cuh` unchanged; only the host launchers switch to the tvm-ffi `TensorView` API. Strides stay `uint32_t` elements, as in the AOT `ConvParamsBase`.
- The JIT build matches the wheel's arch split — `-use_fast_math` on SM 9.0, precise math elsewhere, per `load_utils.py`'s `compute_capability == 90` — so the SiLU epilogue emits the same bits. Math mode is part of the build key.
- CUDA serving goes through the JIT registry behind a `torch.compile`-compatible custom op; everything else keeps Triton. The AOT ops stay exported for external users and for the differential test.
