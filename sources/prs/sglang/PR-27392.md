## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Powered by [KDA-Pilot](https://github.com/mit-han-lab/kernel-design-agents), we propose a B200 native CUDA fast path for the Qwen-Image norm/scale/shift hot loop.

## Motivation

Qwen-Image native SGLang diffusion spends a measurable part of denoise time in the norm/scale/shift hot loop. This PR keeps the scope small and adds a B200 native CUDA fast path only for the Qwen-Image shape/layout that hits this bottleneck.

## Modifications

- Add a small native CUDA implementation for the two Qwen-Image norm-scale-shift call patterns.
- Keep the existing public JIT Python APIs and fallback behavior unchanged.
- Dispatch to the native path by default only when the Qwen-Image BF16, contiguous/aligned, Blackwell-or-newer conditions match; unsupported shapes continue to use the existing CuTe-DSL implementation.
- Leave `python/sglang/jit_kernel/tests/diffusion/test_fused_norm_scale_shift.py` unchanged from main.
- The earlier qknorm-rope experiment is not part of this PR.
