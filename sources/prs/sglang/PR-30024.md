## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
ROCm HiCache L2-L1 (host-device) load-back perf work: gets the JIT staged write-back kernel working on ROCm, widens the MLA gather copy to 128-bit, and fixes block_quota to honor SGLANG_HICACHE_BLOCK_QUOTA at runtime.

- Widen MLA gather to 128-bit. 128-bit streaming load/store when aligned. +32% at block_quota=8, +36% for D2D on MI355X.
- Fix block_quota env override. Was resolved once at import, so the env var had no effect at runtime. Now resolved per call. Cuts layer_first per-layer gather ~17.9ms -> 2.5ms at 128k prefix.
- Tune default block_quota. HIP default 2 -> 16 (CUDA unchanged). ~27.6% lower prefill_forward, ~21% lower E2E TTFT in a 1P1D A/B on Kimi-K2.6.

Test plan

- [x] JIT staged write-back builds/loads on gfx942 and gfx950
- [x] page_first + kernel no longer crashes on first prefill on ROCm
- [x] SGLANG_HICACHE_BLOCK_QUOTA honored per-request
- [x] Re-run 1P1D load_back A/B (Kimi-K2.6) to confirm deltas hold post-rebase
