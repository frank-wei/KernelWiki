## Summary

Fuse ERNIE-Image Q/K RMSNorm with its full-width rotate-half RoPE cache.

The generic JIT QKNorm+RoPE kernel gains an explicit full-width NeoX cache mode. It remains orthogonal to the Cosmos pack-KV path: full-width caches are rejected for pack-KV, while existing cache layouts retain their behavior.

ERNIE hoists a concatenated full-width cos/sin cache, preserves exact BF16 rounding, and verifies the fused result against the existing split RMSNorm + RoPE path on first use. The cleanup also covers two fallback correctness details:

- the generic API infers the logical half-width RoPE dimension when callers omit `rope_dim` for a full-width cache
- if the first kernel attempt partially mutates Q/K and raises, the reference fallback runs from pristine clones
