## Motivation

Add an optimized SM120 FP8 skinny GEMM for small-token ModelOpt FP8 linear projections.

The SM12x integration now exposes one adaptive `try_sm120_fp8_linear` facade. It selects the existing streaming GEMV for supported M=1 shapes, the KDA CUTLASS GEMM for qualified M>=2 shapes and the oversized M=1 projection, then returns `None` to the existing ModelOpt fallback when neither implementation applies. Unsupported devices, shapes, layouts, dtypes, scales, and bias configurations therefore keep their existing behavior without environment-variable switches.

## Modifications

- Add the CUTLASS SM120 FP8 skinny GEMM as a lightweight JIT CUDA kernel.
- Register the unified `gemm.sm120_fp8_linear` entry under `KernelBackend.KDA`.
- Centralize SM12x capability, shape, layout, runtime dependency, quantization, and provider selection in one lazy facade.
- Keep the existing streaming GEMV first for supported M=1 shapes; use KDA for qualified M>=2 shapes and the M=1 `(K, N) = (5120, 34816)` projection that exceeds the GEMV range.
- Reduce `ModelOptFp8LinearMethod` to one `self.use_sm120_fp8` flag and one facade call.
