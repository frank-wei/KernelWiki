## Motivation

Fuse combine + RMSNorm for 9–96-row speculative verification batches, which currently launch two kernels.

## Modifications

- Extend the existing kernel dispatch and model guard to 96 rows, using 4/2/1 column partitions.
- Preserve large-prefill and MXFP8 paths; add a registered boundary test.

## Accuracy Tests

**60 fresh GPU comparisons passed** against unfused combine + RMSNorm on GB300, PyTorch 2.13/CUDA 13, Triton 3.7.1. Measured `c65ae3b`; its kernel/test are byte-identical to this PR's `ae64e93` head.

Reference: `RMSNorm.forward_cuda(hc_combine(x, pre, 4, x.dtype))`, width 5120, four streams, epsilon 1e-6. Six comparisons per row count: seeds 0/1/2 × contiguous/stride-2 rows, with BF16 inputs/outputs and BF16/FP32 combine weights. All passed `rtol=2**-7, atol=1e-3`.
