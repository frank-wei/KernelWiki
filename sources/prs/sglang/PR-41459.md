## Motivation and changes

Speed up LTX-2.3's QK RMSNorm + split RoPE on H200 using the **KDA + Codex CLI + Kimi K3** candidate. The SM90 implementation combines Q and K into one launch for the measured workloads and uses aligned BF16 vector loads/stores with specialized 64/128 head dimensions. It preserves the original reduction order, intermediate BF16 rounding, public API, custom-op/fake interface and Hopper quality gate.

The change is limited to `ltx2_qknorm_split_rope`: one SM90 CUDA header, its JIT dispatch, and regression tests. Unaligned pointers, odd RoPE strides and other supported head dimensions retain scalar handling; Q and K select their paths independently, including empty sides. Other architectures continue to use the original header.

Baseline: `0bc074db83286449b96198eb340dacdf89041650`. Candidate: `8b4fed70dfec11e1d4483527903cb2ecdf54251b`. The final CUDA preparation only changes comments, formatting and include ordering relative to the timed overlay; the Python dispatch is byte-identical.
