## Summary

This is **Part B of [#28511](https://github.com/sgl-project/sglang/issues/28511)** (porting [ReplaySSM](https://dao-lab.ai/blog/2026/replayssm/), Dao AI Lab 2026). It replaces the GDN (Gated DeltaNet) speculative-decode **target-verify** path — which today writes a full `[V, K]` recurrent state to `intermediate_ssm` for **every draft token** so a rejected draft can roll back — with a per-slot **circular ring** plus a frozen checkpoint. The verify output for the whole draft window is reconstructed *output-only* via the chunked delta-rule `(I + A)^{-1}` UT-transform, the committed state is advanced by a **closed-loop exact fold** (a bitwise clone of the recurrent update, replayed from raw ring inputs at flush), and rejected-draft rollback becomes a cursor move.

**Major update vs the earlier revision of this PR:** the long-output degeneration documented below is **fixed in-PR** by the closed-loop exact fold, and the fold's former throughput cost is recovered by tf32 output dots + activation-dtype rings + flush amortization. The shipped design measures **accuracy parity, throughput parity, and −11.5 GB speculative scratch per GPU (TP1)** vs the recurrent baseline.

Opt-in
