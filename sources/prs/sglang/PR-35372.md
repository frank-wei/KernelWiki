## Motivation

`mega_moe_pre_dispatch` assigns one thread to each 8-element input chunk, so a single CUDA block can only cover hidden dimensions up to 8192. Wider shapes are rejected before launch.

## Modifications

- Cap the block size at the CUDA 1024-thread limit and process wider rows in strided chunks.
- Recompute quantization-group indices for each chunk while preserving the UE8M0 scale layout.
- Keep a separate single-chunk kernel specialization so existing shapes retain the same instruction path.
- Reject wide shapes whose tail would split a warp-level reduction.

## Accuracy Tests

- Verified bitwise FP8 output and UE8M0 scale bytes against a reference implementation for hidden dimensions 3584, 5632, 8192, 12288, and 16384.
- Verified exact top-k copies and idle-slot padding.
- Verified that hidden dimension 8320 fails with the expected full-warp alignment error.
- JIT-compiled the ported CUDA header successfully.

## Speed Tests and Profiling

- The single-chunk specialization produces the same SASS instruction stream as the previous kernel.
- CUDA-event microbenchmarks showed no measurable regression for shapes that already fit in one chunk.
