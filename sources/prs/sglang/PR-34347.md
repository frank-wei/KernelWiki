## Motivation

The diffusion fused QKNorm+RoPE kernel is expected to preserve the split BF16/FP16 rounding boundary: both RoPE products round to the activation dtype before the final add or subtract. On SM120, nvcc may contract the packed local expression, so the fused result differs from the split reference for a small number of BF16 values and fails the exact-rounding regression test.

## Modifications

- Add SM120-only helpers that issue explicit round-to-nearest BF16/FP16 PTX multiply and add/subtract instructions.
- Use the helpers in both NeoX and interleaved rotary layouts.
- Preserve the existing C++ arithmetic byte-for-byte for pre-SM120 targets.

## Accuracy Tests

- RTX 5090 final exact-rounding regression: `1 passed, 1250 deselected`.
- RTX 5090 candidate diffusion suite: the SM120 QKNorm+RoPE failure is fixed.
- H100 full QKNorm+RoPE suite: `1251 passed`.
