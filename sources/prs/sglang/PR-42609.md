## Motivation

Anima applies split-half RoPE separately to Q and K, materializing negation, concatenation, FP32 casts, and arithmetic intermediates. The eager chain launches 16 GPU kernels per paired Q/K call.

## Modifications

- Replace this chain with one paired Triton kernel, mounted after the unchanged Q/K RMSNorm.
- Preserve separate FP32 multiplication and addition boundaries with `enable_fp_fusion=False`, then cast once to the output dtype.
- Retain eager fallback for unsupported inputs, gradient-enabled execution, and `torch.compile`.
- Verify each new signature with `BitExactFusionGate`; disable fusion on mismatch or kernel failure.

## Accuracy Tests

- **50 numerical cases passed**, covering FP16/BF16, multiple batch sizes, sequence lengths, head counts, signed zero, and finite extremes.
- **17 existing Anima tests passed**.
- Fallback, gradient parity, first-use/warmed CUDA graph capture, and compiled-eager comparison checks passed.
- All eight generated outputs, including separate profiling runs, have identical PNG and decoded-pixel hashes.
- Pre-commit passed. No new persistent unit tests were added.
