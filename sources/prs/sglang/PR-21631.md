## Motivation

Among the known issues, #20611 #19737 #18785 #14363 FA3 and the hicache kernel can cause illegal memory access (IMA), which mainly occurs between D2H transfer and FA3 forward. Due to stability requirements, deployments are currently restricted to using the `--hicache-io-backend direct` configuration; however, the performance of the `direct` backend currently lags behind that of the `kernel` backend. Meanwhile, in storage stores like Mooncake Store, Page-first layout is essential due to the need for zero copy.
This pull request attempts to use a combination of layout refactoring and `cudaMemcpyBatchAsync` during the D2H transfer process (layer_first[device] -> page_first[buffer&device] -> page_first[host]). This can bypass the IMA issue caused by FA3 and the hicache kernel.
