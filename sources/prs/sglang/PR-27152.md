## Motivation

1. `enable_deepseek_v4_fp4_indexer` never assigned on `self` in `DeepseekV4HipRadixBackend.__init__`, causing `AttributeError` on access.
2. `0xFFFFFFFFu` in `fused_norm_rope_indexer_fp4` is a 32-bit `unsigned int`, but ROCm's `__shfl_xor_sync` requires a 64-bit mask — causing a static assertion compile error on gfx950.

## Modifications

Fix three bugs in the DeepSeek V4 FP4 indexer path:

1. Assign `self.enable_deepseek_v4_fp4_indexer` from `server_args` in `__init__`.
2. Replace `0xFFFFFFFFu` with `kFullMask` (64-bit).
