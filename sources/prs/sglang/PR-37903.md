## Motivation

Add [OpenVDN/vdn-minimax-h3](https://huggingface.co/OpenVDN/vdn-minimax-h3) (VDN-H3): MiniMax-H3 with hybrid attention (chunked window softmax + a Video Delta linear branch), 8-NFE DMD2 distill, t2va only, with the `hybrid_window_attn_h3` backend it was trained for.

8x B200, 1344x768 at 24 fps with audio, 14.375 s (345 frames, ~104k packed rows), `num_inference_steps: 9` (8 DiT forwards), seed 1000, Ulysses 8, eager, warmup at the served clip shape:

| Config | s/NFE | Denoise (8 forwards) | Request after warmup | Peak HBM |
| --- | ---: | ---: | ---: | ---: |
| OpenVDN published (fp8, 5+3 branch-parallel Ulysses) | 1.40 | 11.2 s | - | - |
| SGLang default (online `mxfp8`) | **0.93** | **7.45 s** | **9.3 s** | 77.7 GB/GPU |
