## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Stacks on #43620.

- `MarkovSampleStep` adds a step's bias to the base logits, rounds the sum to the head's step dtype, and picks one token per row: the argmax at temperature 0, a Gumbel-max sample otherwise. Triton and torch implementations.
- The noise is Philox4x32-10 computed in the kernel, keyed by the server seed and countered by (global token id, row, step, a per-block offset). It needs no noise tensor, does not touch the torch generator, and every TP rank draws the same values from the same inputs.
- TP-sharded vocab: without kept logits each rank reduces its shard to one (value, index) pair per block and only those pairs are all-gathered; with kept logits the step logits are gathered once and every rank picks from the full vocab. Either way a step takes one collective.
- A greedy-only variant (no temperature read, no noise code) compiles when no row samples.
- Replaces `sharded_greedy.py`; the DeepSeek-V4.1 greedy graph tail now calls the op.
- Tests: Triton against the torch reference, the greedy-only variant against the mixed one, NaN and inf, ties across blocks, strided rows, the tempered-softmax distribution, noise keying, and sharded against full vocab in both gather
