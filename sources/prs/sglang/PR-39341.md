## Summary

GLM-5.3-Flash does not start on ROCm. The server dies on the first forward with

```text
NotImplementedError: kpool indexer is only supported on CUDA
```

The k-pool indexer computes the scores that decide which tokens sparse attention looks at. It needs two pieces that exist only on NVIDIA — a tilelang kernel whose own selector returns `False` off CUDA, and DeepGEMM, which has no ROCm build. With neither available there is nothing left to call, so it raises instead of falling back.

This gives ROCm those two pieces by calling AITER, and fixes the one thing that has to move with them: the memory layout of the cache AITER reads.

| What | Change |
| --- | --- |
| decode scores | AITER's paged kernel instead of tilelang/DeepGEMM |
| prefill scores | AITER's Triton kernel instead of DeepGEMM |
| the cache both use | AITER expects it written in 16x16 tiles, not row by row, so the five kernels that touch it now share one offset helper |
| very long prompts | AITER's prefill kernel miscompiles once its output passes 2 GiB and kills every rank; the work is split to stay under it ([ROCm/aiter#5114](https://github.com/ROCm/aiter/issues/5114), @Arist12) |
