## Motivation

Qwen-Image-Edit's Hopper profile contains repeated QK normalization/RoPE and joint-QKV concatenations in the DiT, plus 96 separate SDPA window calls per window-attention layer in the vision encoder. Reuse the existing Qwen QKV epilogue on Hopper and process packed vision windows through PyTorch's public varlen attention API.

On one H200 with main's PyTorch 2.13 dependencies, lossless eager engine E2E falls from **32.8171 s to 32.3141 s (1.533%)**. All saved before/after images are byte-identical within each quality mode. This is a modest combined full-model gain; the much larger microbenchmark ratios do not represent E2E speedups.

## Modifications

- Enable the existing BF16, batch-one, head-dimension-128 QKV epilogue for eligible unquantized SM90 Qwen attention. Support independent image/text token strides; retain mask, shard/padding, layout and alignment fallbacks and the existing environment opt-out.
- Vectorize adjacent RoPE-cache loads and paired V-head copies, and move Q/K/V dispatch into the grid's second dimension. Explicit `fmaf`/`fmul` preserves the original RoPE contraction and intermediate rounding. Odd head counts retain a smaller final copy.
