With this PR, K3 can use the AITER prefill kernel, but must disable FP8 kernel, which does not support 12 heads.
Two changes to the server cmd (full cmd in the description above)
- `export SGLANG_AITER_FP8_PREFILL_ATTN=0`
- `--prefill-attention-backend aiter`

## Motivation

<!-- Describe the purpose and goals of this pull request. -->

The triton `extend_attention_fwd` is much slower than the aiter kernel for MLA prefill.
- Triton kernel: `extend_attention_fwd()` in `python/sglang/kernels/ops/attention/extend_attention.py`
- AITER kernel: `_fmha_fwd_bf16_opus_fwd` in `aiter/ops/mha.py`, calling `gqa_d192_v128_kernel` kernel

K3 at TP8 gives 12 heads per GPU, so the existing `concat_and_cast_mha_k_kernel` hits arange's range must be a power of 2. The new kernel handles this by padding the head axis.
