## Motivation

<!-- Describe the purpose and goals of this pull request. -->

This patch is 3/N of the original https://github.com/sgl-project/sglang/pull/32796 to enable dcp support for aiter backend. This part focus on enabling aiter asm for kimi k3 target verify.

Under DCP, the KV cache is sharded round-robin by global position. Gluon cannot apply a mask on global positions, so DCP target verify runs two passes: one over the committed prefix and one over the verify window, then it merges the two results. The asm cp round-robin kernel masks on global positions, so one pass covers both.

This patch routes DCP target verify onto that kernel. It also replaces the scalar `_MLA_ASM_PS_MAX_QLEN` ceiling with two predicates, because the bound is not one number: it moves with the head count and with the query dtype. Those predicates decide the Gluon fallback without DCP as well, so this patch changes the TP path too.
