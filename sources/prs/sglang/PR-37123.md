## Summary

This PR optimizes the Qwen-Image ModelOpt attention projection pipeline on
Blackwell in two precision-specific ways:

- **FP8:** merge each image/text Q/K/V triplet into one packed projection,
  preserving every checkpoint shard's original FP8 weight and scale through
  CUTLASS channelwise scaling. The packed BF16 result is split into zero-copy
  strided Q/K/V views.
- **NVFP4 and FP8:** one JIT CUDA epilogue performs per-head Q/K RMSNorm,
  interleaved RoPE, V copy, and joint `[text, image]` Q/K/V output packing.

For FP8 this changes six projection GEMMs and six activation-quantization calls
per block invocation into two packed GEMMs and two quantization calls, then
feeds their views directly to the epilogue without contiguous copies.

The first FP8 prototype requantized all three checkpoint weight shards to their
largest scale. It was fast but failed the quality gate (SSIM 0.883575, LPIPS
0.075531), so that implementation was rejected. The final implementation uses
CUTLASS's existing per-output-channel scale support and is pixel-exact against
main after 50 denoise steps.
