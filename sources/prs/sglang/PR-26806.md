## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Add the KV-canary write JIT CUDA kernel: write.py (WritePlan and
launch_canary_write_kernel) and its paired header csrc/kv_canary/canary_write.cuh,
plus the Python reference write_ref.py. The write kernel stamps canary slots into
the KV cache; it builds on shared types from the verify kernel and the canary
constants.

The write/verify hand+fuzz tests and shared fixtures/invariants and benchmark travel with this commit.
