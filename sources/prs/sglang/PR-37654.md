> Draft for public review. The K2 Horizon model repositories remain private until release, so please do not merge this PR before the release gate is cleared.

## Motivation

Add native SGLang serving support for the IFM K2 Horizon family without checkpoint-provided Python code.

## Modifications

- Add native xLLM/K2 Horizon dense, MoE, and MoVA model support.
- Add K2 Horizon reasoning and tool-call parsers with template detection.
- Support non-ambiguous reasoning terminators selected per request from `reasoning_effort`.
- Preserve reasoning state through Chat Completions, Responses API forwarding, and disaggregated handoff/rebootstrap.
- Add model, parser, grammar, routing, weight-mapping, Responses API, and disaggregation tests.
- Fail during model initialization for unsupported TBO, EPLB/expert remapping, quantized weights, and non-BF16 execution.

The generic serving-core extension is multi-terminator reasoning support. It adds optional, backward-compatible request fields and matching/accounting so one server can handle K2 requests whose reasoning effort selects different end markers. Existing single-terminator parsers keep their existing path.
