## Motivation

The Qwen-Image 2.1 VAE decode of a 1024x1024 image takes 186 ms on one SM120 GPU. Its decoder (dims 1152/1152/1152/576/288/144, five up blocks that run three residual blocks at their own resolution and then upsample) spends that time on cuDNN convs, but also on work that is pure data movement: cuDNN's NCHW/NHWC transposes around every conv (25 ms), aten's channel RMSNorm chain (fp32 copy + reduce + four pointwise passes + SiLU), a separate bias-add pass after every conv (46 launches, 10 ms) and nearest-2x upsampling that quadruples the pixels before a 3x3 conv.

This PR removes that overhead in two tiers, following the existing VAE fast-path conventions (`VaeFastPathGate` for quality-gated paths, `BitExactFusionGate` first-sight verification for default-on paths):

- **default (`quality=lossless`)**: bit-exact fusions only; the output PNG is unchanged;
