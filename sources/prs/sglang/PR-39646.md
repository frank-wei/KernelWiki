## Summary
- Extract standalone DeepSeek V4.1 kernels and Python wrappers from #38798 as the first layer of a linear PR stack.
- Add small BF16 GEMMs and WO-A projections, Engram hash/gather/gate operations, decode scheduling metadata, candidate selection helpers, Q RoPE/store, FP32 RMSNorm, HC mixing/MXFP8 epilogues, and row-wise argmax.
- Keep model dispatch, scheduler/cache ownership, and runtime integration in #38798. Existing Top-k implementation changes are isolated in #39648.

## Scope and verification
- 23 kernel/wrapper/helper files: +2,459 / -19; all byte-identical to the source snapshot `01d34d7b404451bce7f7b35e306de6fab395024d`.
- Carry seven complete existing test files unchanged and the existing standalone HC/MXFP8 parity cases; leave model-dispatch cases in the remaining PR. The extracted parity function is AST-identical.
- Existing Python functions are AST-identical to the base; `tiny_gemm` is equivalent after the declared helper relocation and namespace/name substitutions.
- Total: 33 files, +3,494 / -19.
- All applicable pre-commit checks passed. All eight extracted test files passed on one GB300; the decode-metadata suite skipped 66 shapes where FlashMLA does not
