## Motivation

  MHATokenToKVPool.set_kv_buffer_prefix_valid commits accepted-prefix KV rows after DFLASH verification. With --kv-cache-dtype fp8_e4m3 and checkpoint KV scales, the existing path performs:

  1. In-place scale division for K
  2. In-place scale division for V
  3. K cast to FP8
  4. V cast to FP8
  5. Triton byte-copy/scatter

  This is five GPU kernel launches per layer and introduces full HBM round-trips for the intermediate scaled tensors. Without explicit scales, the path still requires two casts plus the scatter kernel.

  This PR fuses source-dtype scaling, FP8 conversion, and prefix-valid scatter into one Triton kernel.

  ## Modifications

  - Added set_kv_buffer_prefix_valid_tiled_fp8 in cache_move.py.
      - Preserves the existing (batch, row, tile) structure, commit_lens early exit, and loc_2d indirection.
      - Uses element-based offsets and strides rather than byte-based addressing.
      - Receives typed source and FP8 destination pointers.
      - Divides in FP32 registers, rounds back to the source dtype to reproduce eager div_ semantics, then casts directly to the destination FP8 type.
