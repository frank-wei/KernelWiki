## Motivation

SWA segment frees currently launch separate Torch operations to look up peer pages and clear FULL-to-SWA mappings. Fuse that metadata work into one Triton kernel to reduce per-free scheduler dispatch overhead.

## Modifications

- Preserve page ownership, deferred frees, and the per-request SWA-ring early return. CPU/NPU keep the Torch reference path.
- Retain the peer-mapped invariant and debug validation, and avoid specializing on the page count or representative-pointer alignment.
- Add kernel/allocator regressions and include the current `test/registered/kernel/` taxonomy in the kernel CI path filter.

## Accuracy Tests

- Fresh focused CUDA suite with `SGLANG_IS_IN_CI=true` and `SGLANG_ENABLE_ASYNC_ASSERT=true`: **139 tests and 244 subtests passed** at `750ba1d20`.
- The deliberate-invalid-input debug test now scopes invariant signaling OFF only around its invalid free, avoiding a fatal device assertion before Python validation. Allocator debug checks and the separate STRICT contract tests remain enabled. This follow-up changes tests only.
- CUDA memory checking: **zero errors**.
- Additional CUDA ring/debug/grouping matrix: **8/8 cases passed**, checking mappin
