## Motivation

Triton compiles one variant of a kernel per class of each integer argument it specializes: divisible by 16, equal to 1, or neither. Sequence lengths and row counts change with the resolution, the prompt and the input image, so a request whose sizes fall into a class the server's warmup did not hit compiles kernels on the spot.

Qwen-Image-Edit shows it on the nightly's first request. The server warmup conditions on a square image, giving 8192 tokens; the nightly's 1024×704 input gives a count not divisible by 16. With a cold Triton cache (a fresh machine or container), that first request spent 1.95 s in its first denoising step against 0.34 s for later steps. The Triton cache shows what compiled during that request: the select-0/1 LayerNorm modulation kernel, its residual variant and the LayerNorm-modulate kernel, each a second variant whose TTIR signature differs from the warmup's only in `seq_len` and `stride_i_b` losing `tt.divisibility = 16`.
