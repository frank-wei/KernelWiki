## Summary

Bring Nemotron 3.5 Super MTP serving optimizations for SM120 into SGLang: small-M NVFP4 MoE execution, SM120 GEMV, FlashInfer host planning, and hybrid prefill CUDA graphs.

## Scope

- Native SM120 NVFP4 MoE for 1–4 token rows on Nemotron's expert shape, dispatched from the FlashInfer CUTLASS runner when FlashInfer's fused finalize is enabled. Unsupported shapes and quantization recipes keep the stock runner.
- Opt-in reversible pair-major FC2 weight layout for serial verify (`SGLANG_SM120_NVFP4_PHASE_LAYOUT`). Nemotron owns the layout, and the runner reaches it through an optional `prepare_for_forward` hook. Weight updates reuse the existing derived-cache guard, and weight export is rejected while the layout is enabled.
- The BF16 and FP8 GEMV kernels gain PDL and SM120-tuned launch shapes. `--bf16-gemm-backend gemv` is accepted on SM12x.
- An opt-in M=2–16 Triton router inside the existing fused-gate operator (`SGLANG_SM120_MTP_ROUTER_TOP22`), with unchanged device arithmetic.
- Opt-in FlashInfer host planning for EAGLE draft and verify (`SGLANG_FLASHINFER_DRAFT_HOST_INDPTR`, `SGLANG_FLASHINFER_VERIFY_HOST_PLAN`).
