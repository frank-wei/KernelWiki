## Motivation

Enable decoder SWA bounded replay by default for supported standalone CUDA DeepSeek-V4.1 configurations, while preserving an explicit full-prefill opt-out. In our paired accuracy runs, AIME 2026 without an explicit output cap was identical (469/480 each); DeepSWE differed by one solved task and MMMU-Pro by five correct responses. These are finite, stochastic accuracy measurements, not proof of numerical equivalence or a universal speedup.

## Modifications

- Enable decoder replay by default on CUDA DSv4.1 unless `disable_decoder_bounded_replay` is set for eager/breakable prefill, with the existing DP-attention compatibility checks. Keep PD, context parallelism, encoder replay, other platforms, and incompatible configurations out of automatic enablement.
- Preserve explicit `--enable-decoder-swa-bounded-replay`; add `--disable-decoder-bounded-replay` to retain full prefill, including prompt-logprob support. Bounded replay remains numerically different from full prefill and does not support prompt logprobs.
- Include the candidate-table capacity fix needed for speculative verification beyond the 1,048,576-token boundary. Select the existing 1
