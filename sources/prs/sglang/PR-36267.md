## Motivation

Qwen3.5 GDN prefill materializes QKV/Z/B/A projection slices early, then performs separate Q/K/V layout copies before FlashInfer prefill. These data-movement kernels are material at long cached-prefix prefill sizes.

## Modifications

- Keep QKV, Z, B, and A as strided projection views for CUDA non-speculative extend.
- Teach gated RMSNorm to consume the 3D strided Z view directly.
- Reuse already-contiguous Q/K/V from the CUDA fused split; materialize only strided inputs before the existing L2Norm kernels for FlashInfer prefill.
- Preserve the input dtype in the fused prepare path and restrict the projection-view fast path to CUDA.
- Add focused BF16/FP16 tests for projection views, QKV preparation, dtype preservation, strided gated norm, and the production fused-split-to-FlashInfer chain.
