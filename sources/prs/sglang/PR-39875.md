## Motivation
<!-- Describe the purpose and goals of this pull request. -->
#39652 (`13d593b6cf`) breaks the JIT build. It added the V4.1 row quantizers behind`#ifndef USE_ROCM` in `kv_layout.cuh`,
branch that a V4 instantiation discards, but a discarded branch is still parsed and the
name does not depend on the template parameters, so lookup runs on it whatever the layout
being compiled, and every ROCm build of those headers fails:
```
fused_norm_rope_v2.cuh:507:18: error: no member named 'v41' in namespace 'sglang::deepseek_v4'
```
#37810 (`a813224e78`) breaks target-verify metadata. It added the `req_pool_indices_repeated` parameter to `_attach_unified_kv_prefill_meta` and updated one of its two call sites. The other one, in `make_forward_metadata_from_raw_verify`, is left one positional argument short, so `num_tokens` never binds and the call raises `TypeError`.
