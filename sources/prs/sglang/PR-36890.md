## Motivation

`--enable-unified-memory` asserted `dcp_size == 1`, so the unified memory pool
and decode context parallelism could not be used together. This enables the
combination for Kimi-Linear (MLA hybrid Mamba).

The two features each rewrite the KV location space, and they had never been
composed:

- DCP hands out a **widened** virtual id space — `dcp_size` logical ids share
  one stored row, and a rank owns the ids with `loc % dcp_size == dcp_rank`.
- The unified pool adds its own transform on top, virtual -> physical -> dense
  (`translate_kv_loc_dense`, the page-major envelope's dense per-layer views).

## Modifications

The composition rule is that **every DCP index kernel already collapses
`loc // dcp_size` when it builds an index** (`create_triton_kv_indices_for_dcp_triton`,
`update_kv_lens_and_indices`, `filter_dcp_local_kv_indices`, and the
`dcp_local_prefix_kv_indices` slice). So `translate_kv_loc*` keeps speaking the
collapsed id space, and only the allocation surface widens.
