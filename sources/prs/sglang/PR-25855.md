## Motivation

`paged_mqa_metadata.cuh` (introduced in #23882) is currently a single-block
kernel whose Phase 3 has lane 0 of each warp serially advancing `q` across
the per-batch prefix array — `O(bs)` dependent smem loads on one SM with the
other 131 SMs idle. For `bs ≥ 1024` the kernel costs 60–2000 µs.

This PR rewrites it as a batch-size-adaptive 3-path dispatch (tiny / small /
multi-block), replacing Phase 3 with `num_sm + 1` parallel `upper_bound`s
(O(log bs) per thread) and fanning out Phase 1 across SMs for large `bs`.

**Result on H200 (sm_90, num_sm=132): GeoMean 45.3× over `bs ∈ [128, 32768]`,
peak 297× at `bs = 32768`, byte-equal correctness preserved.**
