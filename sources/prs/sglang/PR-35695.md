## Summary

- add a paired BF16 JIT CUDA kernel for SANA-Video interleaved Q/K RoPE
- preserve the eager fp64 arithmetic and fp64 -> fp32 -> bf16 conversion order for bit-exact output
- guard the fast path with first-sight bit-exact verification and a permanent eager fallback
- register and document the kernel, with CUDA correctness coverage and a representative benchmark

## H200 results

Model: `Efficient-Large-Model/SANA-Video_2B_480p_diffusers`, eager mode, 832x480x17, 12 denoise steps, guidance 6, seed 42.

- paired RoPE microbenchmark: 1.4422 ms eager -> 0.1192 ms JIT (12.1x)
- denoise latency: 0.239-0.245 s/step -> 0.212-0.213 s/step (~11% faster)
- end-to-end median: 3.8675 s -> 3.5492 s (~8.2% faster)
- generated video SHA256 remained exactly `0c1846a9e56c82b285d3b8c7813c81e392c87c04071ac5c517bf09d1f1d6a4ae`
- ptxas: 27 registers, 0 spill stores, 0 spill loads, 0 barriers
