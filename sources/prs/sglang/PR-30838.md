## Motivation

Rework the JIT kernel dtype trait system, warp reduction primitives, host-side check utilities, and the Python build layer. Highlights: type-driven reductions with a single-instruction `redux.sync` fast path, hipcc-proof dispatch, stream-style zero-overhead host checks, a `utils/` package split, and arch-specific (`sm_XXa`) JIT targets.

## C++ headers

- **`DTypeTrait<T>`** (renamed from `dtype_trait`): per-field registration macros (`#undef`'d at end of header), specializations for integral types, fp32/fp16/bf16 scalar + packed x2/x4, fp8; metadata (`unpacked_t`/`kVecSize`, `kFloatMax`, `kZeroBits`); `abs/max/min` for fp16/bf16, native `add = __hadd2` for packed half2/bf16x2 on CUDA (packed SUM compiles to one `HFMA2`).
