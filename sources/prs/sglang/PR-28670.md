## Summary

Adds `kpool_topk_transform` as a lightweight sglang JIT kernel. It selects the top-k pooled groups from a `[B, num_groups]` score tensor at pool granularity, expands each selected group to `pool_size` token indices, and optionally remaps those indices through a page table or a ragged offset. An optional `seq_lens` enables tail append.

The pool-level radix top-k core was previously shipped as an AOT `sgl-kernel` op (`fast_kpool_topk_transform_fused`). It is re-implemented here as a JIT kernel so the indexer stays on the sglang JIT path without requiring a sgl-kernel rebuild.
