## Motivation

FLUX.3 FP8 linear layers currently use separate PyTorch operations for row padding, FP32 conversion, rowwise absmax reduction, scaling, clamping, and FP8 conversion. This introduces intermediate allocations and multiple kernel launches for each activation quantization.

This PR fuses these operations and row padding into a single Triton kernel, reducing quantization kernel launches from `8` to `1` and eliminating intermediate activation buffers while preserving the existing quantization semantics.

## Modifications

- Add a Triton rowwise E4M3 quantization kernel with fused zero-row padding.
- Preserve the existing scale calculation and minimum scale of `1e-12`.
- Use IEEE-rounded division and direct FP32-to-E4M3 PTX conversion to avoid intermediate FP16 double rounding on SM89.
- Register and export the kernel through the diffusion kernel facade.
