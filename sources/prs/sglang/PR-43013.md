## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
**This reduces CPU/host overhead when running TML Inkling architecture models at low-latency.**

## Motivation

Short-convolution prefix-cache tracking computes each checkpoint window with several eager Torch operations. Even on the prefill CUDA-graph path, the metadata refresh launches those operations before replaying the model graph.

## Modifications

Replace the NVIDIA CUDA tracking-index calculation with one Triton launch into the existing output buffer. Preserve signed floor division for negative offsets, token-buffer clamping, zeroed padding, and absent prefix lengths during graph capture. Keep the existing Torch path for other devices, as well as current draft-decoding guards and physical checkpoint-slot handling.

Register the operator lazily under `sglang.kernels.ops.mamba` and add a CUDA CI parity test.
