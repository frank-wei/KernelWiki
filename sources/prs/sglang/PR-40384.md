## Motivation

LongCat's single-stream DiT blocks materialize BF16 tanh GELU and then concatenate it with attention output. The native Edit-Turbo profile shows 20 such sites per denoising step. A fused kernel removes the intermediate store/reload and one launch per site while preserving the eager BF16 result.

Edit-Turbo also lacks BCG registration. Simply registering it does not work for a non-square edit: the synthetic square input changes the warmup output grid and VL prefix, so the real request misses the captured signature. This patch makes the existing model-owned synthetic warmup hook preserve the explicitly requested aspect ratio and enables BCG for Edit-Turbo.

On **one H200**, the combined patch reduces native saved-image request E2E in two A–B–B–A groups: **worker 2.46% / 2.65%, client including PNG save 2.89% / 2.62%**. Baseline is original eager; candidate uses the fused kernel, corrected warmup and actual BCG. All valid lossless outputs are byte-identical.
