## Motivation

LingBot Video (MoE 30B-A3B) applies a per-token gated residual and an adaLN modulation chain at every DiT block:

- `x = x + (gate * update).to(x.dtype)` with a per-token `gate [B, S, 1]`
- `(rmsnorm(x) * (1 + scale) + shift).to(dtype)` with per-token `scale`/`shift` that are non-contiguous `[B, S, 6D]` chunk views

On a single B300 the extra-high profile shows a large elementwise/copy ladder around these chains. Neither was fused: the existing bit-exact `residual_gate_add` had no per-token gate mode, and the bit-exact `rmsnorm_scale_shift_bitexact` is ERNIE-specific (it replicates one platform's exact RMSNorm reduction order, which does not match LingBot's custom FP32 RMSNorm).

## Modifications

- **`residual_gate_add` per-token gate mode (JIT CUDA).** Add a third gate mode (`kPerToken`): one scalar per row, broadcast along the hidden dim. Full and row-broadcast modes are unchanged (backward-compatible).
