## Summary

- extend the shared diffusion `residual_gate_add` JIT op to the mixed layout used by SANA-Video: a transposed-dense `[B, tokens, hidden]` residual/output, contiguous update, and `[1, 1, hidden]` gate
- use a 32x32 padded shared-memory tile so update reads and residual/output traffic stay coalesced without inserting a full `.contiguous()` copy
- preserve the residual stride and keep all unsupported dtype/layout/device cases on the existing eager fallback
- add production/edge-shape, storage-offset, fullgraph, and CUDA Graph tests; update the registered benchmark and diffusion fast-path documentation

## Motivation

On an NVIDIA H100 80GB profile of native SGLang SANA-Video (832x480x17, 8 steps), the two gated residual sites per transformer block did not reach the existing contiguous-only fusion:

```text

update shape/stride:   [1, 7800, 2240] / (17472000, 2240, 1)
gate shape:            [1, 1, 2240]
```
