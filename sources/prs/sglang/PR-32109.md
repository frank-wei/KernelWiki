## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Extend the per-request early-exit pattern from #31981 to the remaining kernels whose grid or inner loop spans the full captured width: DSA decode / target-verify metadata, FA3 decode metadata, TRTLLM MHA graph metadata, extend attention (regular and unified), the DSA indexer K+S gather, and the sparse prefill index transform.

<details>
<summary>Appendix: microbenchmark results (kernel x setting, main vs this PR, n=10)</summary>

Methodology: 10 interleaved A/B process pairs (main / PR alternating); each sample is one Triton `do_bench` (100ms warmup + 1000ms measurement); values are mean +- std over the 10 runs; verdicts use a paired t-test (n=10, two-sided 5%). `SKIP` = most blocks are past the per-request live length, the early exit fires; `NOSKIP` = every block is live, the exit never fires (worst case, pure guard overhead). "n.s." = not statistically significant.
