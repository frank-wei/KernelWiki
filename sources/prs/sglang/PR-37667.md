## Motivation

Add native SGLang serving support for UNO, a diffusion-augmented LLM. UNO uses two model pathways:

- The `diffusion pathway` combines the autoregressive (AR) weights with diffusion weights implemented as LoRA adapters.
- The `AR pathway` uses only the base AR weights.

The diffusion pathway drafts a block of tokens in parallel, and the AR pathway verifies those proposals against the base model's autoregressive distribution.

UNO is **lossless** like speculative decoding; however, it does not employ a separate draft model.

Each decoding cycle performs two target-model forward passes:

1. A diffusion-pathway forward pass that produces the first output token and a block of draft proposals.
2. An AR-pathway forward pass that verifies the proposals.

The integration supports two UNO sampling modes. The diffusion pathway constructs marginal distributions for a block of `B` tokens:

1. `Linear sampler:` Samples each token independently from its marginal distribution. This mode is designed to maximize system throughput and uses `B` as its primary hyperparameter.
