## Motivation

The MiniMax-H3 DiT spends most of its time in full attention over a 37.7k-token
video latent, and that share grows with resolution and duration. This PR adds
`--attention-backend subblock_sparse_attn`: a cheap estimator runs before attention and
picks, per (head, query block), which 64-token key blocks are worth attending,
and FlashInfer's `bsa_attn_blk64_fwd` does the sparse attention. Nothing is
trained and no weights change. **1.14x** on DiT denoise at the default budget,
**1.22x** with the FlashInfer patch below.

The design question is the estimator. The usual proxy score for a 64x64 block is
`mean(Q_block) · mean(K_block)`, which averages away exactly the variation that
decides which keys a query wants. This one cuts each block into sub-blocks —
`n_k` on the key side, `n_q` on the query side — scores every sub-block pair and
combines them with a log-sum-exp:

```
score(i, j) = log Σ_{a<n_q, b<n_k} exp( mean(Q_{i,a}) · mean(K_{j,b}) · scale )
```
