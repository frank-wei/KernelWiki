## Summary

This PR fuses the FLUX.2 single-stream output sequence

```text
torch.cat([attention_bf16, swiglu_bf16]) -> FlashInfer NVFP4 quantize -> to_out GEMM
```

into one SM103 JIT kernel that reads both BF16 branches and writes the concatenated E2M1 values and 128x4-swizzled E4M3 scales directly. A standalone ModelOpt helper feeds the packed activations and scales directly to the existing FP4 `to_out` GEMM; this PR has no dependency on #37096.

This removes one 24,576-wide BF16 materialization and one full-width quantization read in each of the 48 single-stream blocks. Unsupported shapes, TP > 1, non-SM103 devices, compile/capture, alternate FP4 modes, or missing layout guarantees retain the existing path.

> [!NOTE]
> This PR is now based directly on current `main` and contains no #37096 commits. The benchmark below was originally collected with #37096 present in both baseline and candidate, so the reported delta still isolates only the token-cat fusion.
