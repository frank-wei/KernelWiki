## Summary

This PR implements the remaining FLUX.2 ModelOpt FP8 producer/packing optimizations from [Agentic Kernels in Production](https://www.baseten.co/blog/agentic-kernels-in-production/):

- fuse bit-exact LayerNorm + adaLN modulation + static FP8 quantization for all 80 eligible double/single-block producer paths;
- merge image/text QKV checkpoint shards into two channelwise-CUTLASS FP8 GEMMs per double block while preserving every shard's original FP8 bytes and scale;
- fuse double-block QK RMSNorm + RoPE + text/image joint QKV packing into one Blackwell JIT kernel that consumes the packed GEMM views directly;
- fuse single-block `[attention | MLP]` concatenation with static FP8 quantization, avoiding the full-width BF16 intermediate.

The three runtime changes share the packed checkpoint and prequantized-activation interface. The isolated norm producer measured only **-0.565%** e2e, and norm + merged QKV/epilogue measured **-0.768%**; I kept them together with token-cat + quant rather than opening sub-threshold performance PRs. The complete path reaches **-3.20% e2e / -3.25% denoise**.
