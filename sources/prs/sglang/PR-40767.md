# Summary

A PDL secondary can inherit a preceding GEMM's large shared-memory partition and lose L1 capacity. Add an opt-in L1 preference to the shared kernel launcher that searches for the smallest shared-memory carveout retaining the kernel's default occupancy.

The preference is memoized per kernel and device and can be configured at module load or lazily through `LaunchKernel`. Existing upstream kernels retain their default policy; this exposes the reusable API for callers that need it. ROCm retains its occupancy query without setting a CUDA attribute. Memoized callers must use fixed block dimensions and dynamic shared-memory size for each kernel/device pair.

Beyond the port, add a CUDA regression test covering occupancy preservation, default-policy launches, raw-stream and device-based launches, repeated calls, exact output equality, and isolation from unused GPUs; document the memoization preconditions.
