## Motivation

Detect corrupted KV transfers before decode generates tokens. Add an optional Adler-32 integrity check for prefill/decode disaggregation, disabled by default.

## Modifications

- Add GPU checksum kernels for contiguous regions and indexed KV/state pages. Prefill sends the checksum with the final chunk; decode verifies it before batching and retains it across retraction.
- Add `--disaggregation-enable-kv-checksum` to the disaggregation argument group. Enable it on both prefill and decode engines with matching KV layouts; it adds an optional metadata buffer.
- Abort a mismatching request and increment the transfer-failure counter. Raise in CI instead, and skip health-check requests.
- Register CUDA tests for reference parity, corruption detection, optional metadata layouts, health checks, and failure-counter behavior. Update an existing handoff test fixture for the disabled default.
