## Motivation

Add support for Baidu Unlimited-OCR. Closes #29115.

## Modifications

- New model, config, and multimodal processor for Unlimited-OCR (vision encoder/projector reuse DeepSeek-OCR, language model reuses DeepSeek MoE).
- Prefill-aware sliding window attention in the FlashAttention backend: each decode step attends over the protected prefill range plus the recent window via a per-request page table, in both the normal and CUDA-graph decode paths.
- All-SWA cache path: a pure-SWA radix cache, a single-pool token allocator, and a per-request evict floor that protects the prompt/image tokens, wired through the shared memory and scheduler code that assumed a full-attention pool exists.
- Registered the config (AutoConfig, no trust_remote_code), processor, and chat template, and added an `images_config` request field to select the image mode (tiny/small/base/gundam).
- Added the model to the fused MoE config tuner.

## Usage

Launch the server:

```
python3 -m sglang.launch_server --model-path baidu/Unlimited-OCR --attention-backend fa3 --page-size 1
```

CUDA graph and the overlap scheduler are on by default and account for the throughput below, so no extra flags are neede
