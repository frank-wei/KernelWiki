Supersedes #31358 — rebased on the latest `main`.

## Motivation

Add serving support for the **Inkling** model family — a hybrid-attention Mixture-of-Experts architecture that interleaves sliding-window and full softmax attention with Mamba2 linear-attention layers, an NVFP4-quantized MoE, optional vision/audio multimodal towers, and native multi-token-prediction (MTP) speculative decoding.

## Modifications

- **Model**: `InklingForConditionalGeneration` and its multimodal / MTP-draft variants, registered in the model and architecture maps.
- **Hybrid SWA + Mamba KV cache**: routes Inkling through the hybrid sliding-window / full-attention KV pool and the Mamba2 state cache, with per-layer window and cache sizing. Uses the unified radix tree and extra-buffer Mamba strategy, applied automatically via architecture defaults.
- **MoE**: NVFP4 MoE served through the FlashInfer TRT-LLM routed runner.
- **Multimodal**: optional vision and audio towers with dedicated Inkling image/audio processors; the towers are built only when `--enable-multimodal` is set.
