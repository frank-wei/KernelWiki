## Motivation

Add native Qwen-Image 2.1 text-to-image generation and editing, including multiple reference images and RGBA input/output. SGLang owns the model components and preserves the checkpoint's Transformers 4.57.3 conditioning semantics.

## Modifications

- Add the DiT, RGBA VAE, Qwen3-VL conditioning, model registration, and CLI/server integration.
- Align conditioning and VAE normalization with [Diffusers #14804](https://github.com/huggingface/diffusers/pull/14804): training image markers, white alpha compositing for vision only, empty-prompt handling, pre-final-norm text features, and FP32 VAE normalization.
- Integrate request-scoped prefix caching, Cache-DiT, breakable CUDA graphs, TP/Ulysses/Ring/CFG parallelism, encoder sharding, VAE parallel decoding, component/layerwise offload, and adapter mapping.
- Add complex RoPE, Q/K normalization, and scale-only LayerNorm fusions with first-call equality checks and native fallbacks. Detect the running CUDA build's complex multiplication FMA order for Hopper and Blackwell.
