# [Feature] Add SSD-backed Expert Pack inference for DeepSeek-V4-Flash and Kimi-K3

## Summary

This PR adds an opt-in SSD-backed inference path for **DeepSeek-V4-Flash** and **Kimi-K3**. It allows these MoE models to run when their complete weights are larger than GPU VRAM and host RAM combined.

Routed expert weights are stored on SSD and loaded only when selected by the router. The implementation uses:

- an expert-major **Expert Pack** layout for efficient random access;
- direct I/O into aligned pinned host buffers;
- asynchronous host-to-device transfers; and
- a byte-budgeted LFU/LRU GPU cache for frequently used experts.

The runtime does not prune, merge, skip, replace, or re-quantize experts, and does not reduce Expert Top-K. The default `auto`, `safetensors`, and `gguf` loading paths remain unchanged; SSD execution is enabled only through the explicit `expert_pack` path.

## Supported Scope

`ExpertPackModelLoader` is selected only with `--load-format expert_pack`. Official checkpoints loaded through the standard `auto` or `safetensors` paths never enter this loader.

The currently validated DeepSeek input is the single-file MXFP4 GGUF used by `frob/deepseek-v4-flash-073
