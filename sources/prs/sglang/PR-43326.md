## Motivation

Under `--enable-unified-memory` a speculative draft's KV lives inside the target's pages (a fused draft), but only a draft whose layers are all full-attention can fuse: it goes into the full-attention sub-pool. An MTP head with sliding-window layers (MiMo-V2-Flash) or with recurrent state (Inkling's per-depth conv-chain head) declines, and for a hybrid sliding-window or Mamba-hybrid target, main then refuses to boot ("needs the draft's KV fused into the target's pages, but this draft cannot fuse"). So neither model can run NEXTN with `--enable-unified-memory`.
