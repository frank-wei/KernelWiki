## Motivation

Helios applies the same transposed RoPE chain to already-normalized Q and K in
every self-attention block. At the production `[8640, 40, 128]` BF16 shape,
the eager reshape/chunk/mul/add/stack path takes about 1.62 ms per Q/K pair and
accounts for thousands of launches in a short denoise profile.

## Modifications

- Add a lightweight JIT CUDA kernel that applies Helios' transposed RoPE to Q
  and K together, in place. Explicit FP32 round-to-nearest operations preserve
  the eager multiply and add/subtract boundaries before casting back to
  FP16/BF16.
- Dispatch it from `HeliosSelfAttention` only for compatible CUDA dtype, shape,
  layout, device, and pair alignment. Tensor-parallel RMSNorm and unsupported
  inputs keep the existing eager path.
- Register the lazy diffusion-kernel export and add unit, compile, import, and
  production-shape benchmark coverage.
- Document the fast-path contract in the diffusion kernel README and profiling
  skill reference.
