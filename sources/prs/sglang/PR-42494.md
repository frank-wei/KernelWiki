## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
ROCm Llama startup fails during graph capture because #41282 keeps the RoPE cache in FP32 while the fallback kernel assumes the query dtype. Let the kernel read FP32 caches and round cos/sin to the query dtype before the existing arithmetic. This preserves the FP32 cache used by QSA without converting the whole cache on every forward.

The diffusion fixes defer quantization imports to break the linear-layer import cycle, enable the existing MiniMax H3 denoising path on HIP, pass the existing HF credential to dual-GPU tests, and install ffmpeg/ffprobe for H3 media validation.

The existing ROCm RoPE test now runs even with AITER enabled, checks FP32-cache outputs against the same-dtype kernel bit for bit, and runs in Stage A so it catches this failure before the longer suites. Correctness, performance and startup thresholds are unchanged.
