## TODOs:
This PR aims to address the very obvious issues. There are still the following items:
1. Ensure the right kernels
- When using the default command, it uses Flashinfer FA2 attention for full attention, instead we should use mamba `extra_buffer` and `trtllm_mha` for that command (always). For example, we'd use:
```
python3 -m sglang.launch_server \
  --model-path nvidia/NVIDIA-Nemotron-3-Super-120B-A12B-BF16 \
  --trust-remote-code \
  --attention-backend trtllm_mha \
  --max-mamba-cache-size 256 \
  --mem-fraction-static 0.8 \
  --mamba-scheduler-strategy extra_buffer \
  --tp 4 \
  --ep 4 \
  --mamba-backend flashinfer
```
2. Kernel perf
- For Mamba SSU, Flashinfer provides a kernel for this (`--mamba-backend flashinfer`) It's faster in all scenarios, but does not support topk > 1 in spec decode.
