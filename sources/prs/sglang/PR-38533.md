## Summary

Preserve eager BF16 rounding in the opt-in Hopper LTX QKNorm + split-RoPE kernel. The existing high-quality path from #38396 keeps the normalized value and cosine product in FP32; on the tested LTX-2.3 TI2V workload this produces visible frame differences and audio drift. This patch restores those two BF16 boundaries while retaining the fused launch.

A compile-time specialization selects the Hopper arithmetic. The existing SM90 quality gate and SM100 FP32 specialization remain unchanged. Recorded H200 validation covered exact Q/K equality at production shapes and changed-input CUDA graph replay.

**Comparison scope:** this is a numerical-correctness fix. The E2E table compares the rounded fusion with a matched **unfused** reference, demonstrating the useful fusion benefit after fixing rounding. It is **not** a measured speedup over current main's approximate Hopper fusion. All five device microbenchmarks are slower with fusion; that result is included below.
