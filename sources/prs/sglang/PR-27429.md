## Summary
- move Mamba state tracking Triton code into the existing Mamba Triton helper module
- move TRTLLM MLA draft pad/unpad kernels into `attention/triton_ops/pad.py`
- move DeepSeek MHA chunked-prefix KV index construction into `attention/triton_ops/kv_indices.py`
- move the DeepSeek V4 RMS normalize Triton helper into `models/triton_ops/deepseek_v4.py` while preserving the old `deepseek_v4.rms_normalize_triton` import path

## Motivation
PR #26000 centralized several utility Triton kernels out of large backend/helper files. This follows the same organization rule for a few remaining inline kernels in backend/model/mixin files without changing launch semantics.

## Validation
- `python3 -m ruff check` on all touched files
- `python3 -m compileall -q` on all touched files
- `git diff --check`
- `PYTHONPATH=python python3` import smoke for the moved Triton helper modules

Note: full local imports of `trtllm_mla_backend` / `deepseek_v4` are still blocked by the macOS environment's older local `transformers` package (`PreTrainedConfig` import), so the validation kept to syntax, lint, and direct helper-module imports.
