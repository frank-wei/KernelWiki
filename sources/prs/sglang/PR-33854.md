## Motivation

PR #33734 shipped the bit-exact residual-gate half of the ERNIE-Image adaLN block and explicitly **dropped** the other two fusions from closed PR #30170 — the CuTe-DSL `fused_norm_scale_shift` / `fused_scale_residual_norm_scale_shift` kernels — because they are *not* bit-exact: they compute `norm(x)*(1+scale)+shift` in one fp32 pass, and re-validating them behind a `quality=high` gate perturbed the 50-step trajectory to same-seed full-image **PSNR 18.83 dB / SSIM 0.797** vs lossless, far below the PSNR>25 bar.

This PR is **not** a re-enable of those kernels. It reimplements both fusions as Triton kernels that are **numerically re-engineered to be rounding-faithful to the eager chain, step for step**, so they are bit-exact (`torch.equal`, full-image md5-identical) and can be wired on the default lossless path with no quality gate — the same standard #33734 used.

Per 1024x1024 image the block executes `norm+modulate` 2 sites x 36 blocks x 2 CFG x 50 steps = 7,200 times; eager spends 4-5 kernels per site (`sgl_kernel.rmsnorm`, `1+scale`, `mul`, `add`, plus `residual_gate_add_cuda` at the second site), all bandwidth-bound on (1, 4216, 4096) bf16 activations.
