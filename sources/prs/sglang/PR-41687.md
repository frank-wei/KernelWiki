## Motivation

This extends the ROCm cooperative DSA indexer top-k (`dsa_topk_coop.cuh`) to MI455 (gfx1250).
gfx942 and gfx950 keep the same wave size and compile to the same device code (see below).

The kernel's wave-level steps are sized with `kWaveSize = 64`, which matches the wave64 CDNA
targets:
- the wave prefix sum (`__shfl_up(v, o, kWaveSize)`);
- the per-wave scratch (`BlockSize / kWaveSize` slots);
- the lane and wave indexing used by the block scans and histograms.

gfx1250 runs 32-lane waves (`warpSize == 32`; ROCm clang 23 (MI455 toolchain) rejects `-mwavefrontsize64` for
gfx1250: `option '+wavefrontsize64' cannot be specified on this target`). Measured on MI455 with GLM-5.2-MXFP4 (`index_topk` = 2048):
- rows no longer than `topk` select every element and are correct;
- rows longer than `topk` get wrong or out-of-range indices, which show up as memory faults in
  `coop_topk_kernel` on an 8K-token prefill, and in the sparse MLA decode kernel that reads the
  indices on GSM8K once contexts pass 2048.

Builds on the cooperative top-k kernel from #37591.

## Modifications

- Select `kWaveSize` by arch family, the same way as `deepseek_v4_topk.cu` (#41020):
