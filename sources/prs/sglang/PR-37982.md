## Motivation
Inspired by the combination of block-sparse attention and Sage FP8 compute in [FlashInfer's SM100 backend](https://github.com/flashinfer-ai/flashinfer/pull/4612), this PR adds optional SageAttention2 compute to MiniMax-H3's SubBlock sparse attention backend on SM90.


The new mode is opt-in. BF16 remains the default, and Sage compute currently targets SM90.

## Modifications

- Add `compute_mode="sage_fp8"` with online INT8-QK / FP8-PV computation and BF16 inputs and outputs. Model weights remain unchanged.
- Adapt SubBlock routing to the native SM90 kernel's Q64 × K128 block layout.
- Preserve the existing BF16 Q64 × K64 defaults on SM90, SM100, and SM120.
- Check GPU capability and the optional SpargeAttention dependency at server startup.
- Add regression tests and documentation.

Enable Sage compute with:

```bash
--attention-backend subblock_sparse_attn \
--attention-backend-config '{"compute_mode":"sage_fp8"}'
```
