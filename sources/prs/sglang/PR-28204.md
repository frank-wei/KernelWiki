## Motivation

Video/image VAEs with causal Conv3d feature caches currently build the conv input with a separate temporal `torch.cat` and spatial `F.pad` when a cached temporal context is present. This shows up in decode-heavy Wan paths as small but repeatable overhead, and the same input-preparation pattern is also used by Qwen Image VAE.

This PR keeps the optimization narrow: it only fuses cached temporal concat plus constant spatial padding for guarded contiguous 5D NCDHW tensors. It does not change parallel decode policy, performance baselines, tiled decode behavior, or the previous halo-buffer experiment.

Wan models are offline generation models, but their VAE decode still uses feature-cache chunking by default for multi-frame video. In that path, each latent temporal slice is decoded separately and later slices consume cached causal-conv boundary features from earlier slices, so this fused path is exercised by normal Wan video decode.

## Changes
