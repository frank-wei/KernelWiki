## Motivation

Restore CI paths broken by recent main-branch interface migrations. Scheduler/MLX profiler fixtures still provide ranks through `ps`, the Q8KV8 prefill fixture lacks `swa_kv_pool`, and ROCm speculative tree launches are rejected by a CUDA-only tensor device check.

These failures are present on main `567d5925fe`, independently of #39957. The rank consumers changed in #40071, the KV-pool access changed in #38792, and the tree wrappers moved to JIT in #40033.

## Modifications

- Use scoped `get_parallel().override(...)` in the idle-counter and MLX profiler tests, including the PP size/depth configuration.
- Give the Q8KV8 test pool the `swa_kv_pool.page_size` interface used by the backend.
- Use the existing platform-dependent `kDLGPU` in all three speculative tree entry points. It resolves to CUDA for CUDA builds and ROCm for HIP builds, while retaining the same-device checks for the remaining tensors.

Four existing files changed; existing assertions and kernel computation are unchanged. No new test files or CI skips.
