## Motivation

- Fuse GLM-5.3-Flash KDA projections with quantization-aware routing and weight-loading support.
- Fuse beta activation into the gate/cumsum kernel and avoid redundant compilation for dynamic token counts.
- Reuse CPU token counts and precompute prefill state-tracking metadata to reduce device-to-host synchronization.

## Performance

Tested on 8× H100 GPUs with TP8/EP8 and EAGLE speculative decoding.

Median throughput across three paired runs, normalized to the pre-PR baseline:

| Workload | Before PR | After PR |
|---|---:|---:|
| 1K input / 512 output, concurrency 1 | 100% | 103.14% |
| 1K input / 512 output, concurrency 8 | 100% | 103.28% |
| 1K input / 512 output, concurrency 32 | 100% | 104.99% |
| 8K input / 128 output, concurrency 8 | 100% | 111.00% |

Results were measured before the latest main rebase. Concurrency 32 includes one slower run; warm-prefix throughput decreased in all three runs.
