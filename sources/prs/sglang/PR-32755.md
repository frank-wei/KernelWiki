Optimize fused_q_indexer_rope_hadamard_quant scheduling: 8 warps/block
  (256 threads) + lane-0-only weights_out write. The math path (RoPE /
  128-pt Hadamard / fp8 quant) is unchanged, so output is bitwise-identical

  -DQ_BLOCK_SIZE / -DQ_MIN_BLOCKS_PER_SM.
