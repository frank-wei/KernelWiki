## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`dflash_accept_bonus.py` and `dflash_prepare_block.py` each held one Triton kernel + its wrapper plus a byte-identical copy of `_pick_num_warps` and `_is_row_major_contiguous_2d`. Merge both into a single `triton_ops/dflash.py` (matching the `eagle.py` / `multi_layer_eagle.py` by-algo file naming), collapsing the duplicated helpers to one copy. The only importer (`dflash_worker_v2`) is repointed to the merged module. Behavior-preserving: the kernel and wrapper bodies are moved byte-identically.
