## Motivation

The nightly `test_glm52_fp8.py` perf test crashed with an illegal memory access on all three variants ([run](https://github.com/sgl-project/sglang/actions/runs/28986113304/job/86015497076)). The CUDA coredump shows the faulting kernel is **FA3 sparse decode** (`FlashAttnFwdSm90`, bs=1 decode right after an 8192-token prefill), and the faulting `LDGSTS` address is exactly `kv_pool_base - 1152B` (= one 576-elem bf16 DSA KV row) — i.e. FA3 dereferenced **KV slot index `-1`**.
