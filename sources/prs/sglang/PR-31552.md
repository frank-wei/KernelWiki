## Summary

- specialize Marlin MoE kernels for expert-parallel and bias launch paths at JIT compile time, removing per-block branches from the hot loop
- choose large-M Marlin launch configs using register/shared-memory occupancy and available problem parallelism instead of accepting the first valid config
- cover both bias/no-bias, small/large-M non-EP paths with a numerical reference test

The scheduling and specialization changes are kept together because the ablation below shows a material interaction: either change alone is small, while the combined kernel consistently improves Kimi-K2.7 prefill.

## Performance

NVIDIA H200 x8, TP8, `moonshotai/Kimi-K2.7-Code`, BF16 activation + MXFP4 Marlin MoE. SGLang BCG prefill was enabled (`--cuda-graph-backend-prefill breakable`) with the same server flags before and after. Each request used four seeded random JPEGs, the radix cache was flushed before every request, and results below are medians after three full-shape warmup rounds.
