## Summary
- Add the DeepSeek-V4.1 sparse-indexer kernels that sit beside Top-k v2: a bf16 small-row top-k, the two-level indexer's block-max keys and sorted block table, and a cluster-occupancy probe.
- Rework Top-k v2's edge handling and cluster dispatch (details below); the existing suite still passes and two new regression cases pin the fixed `-inf` tie behaviour.

## New kernels
- `topk_bf16_small` (`topk_transform_bf16_small`): bf16 top-k for rows of at most 16384 scores, two radix passes over the raw bf16 bytes, fused with the page-table transform; adapted from DeepSelect's init-window select.
- `block_amax` (`amax8_varlen`): level-one keys of the two-level indexer, the max of each 8-score block with the row's newest block forced to `+inf`.
- `candidate_block_table` (`sort_candidate_blocks`): counting sort of a row's selected blocks over a bitmap plus the page transform, in place.
- `jit/utils/occupancy.py` (`get_max_active_clusters`): asks `cudaOccupancyMaxActiveClusters` how many clusters of a given width fit at a given occupancy; sizes the Top-k v2 persistent pool at JIT time.
