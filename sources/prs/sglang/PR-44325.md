## Motivation

Add native text-to-image inference for `OpenMOSS-Team/MOSS-Image-Base`, including the latest DiT weights and small FLUX.2 decoder. Load its Diffusers component export through SGLang's standard component loaders and run the model through the native diffusion runtime.

## Modifications

- Register `OpenMOSS-Team/MOSS-Image-Base` and `OpenMOSS-Team/MOSS-Image-SFT` identifiers. End-to-end checkpoint evidence below covers Base only; SFT is name registration only until its weights are updated and validated.
- Expose `uncond_skip_layers` and `slg_*` through model-owned sampling fields and the existing Images API whitelist. DiT `skip_layers` is an internal forward argument.
- Register the pipeline, DiT, Qwen3.5 text encoder, training V2 nearest-grid Euler scheduler and sampling configuration. Keep flow shift 5, BF16 DiT/text encoder and FP32 VAE.
