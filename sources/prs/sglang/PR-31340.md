## Summary
- Select the Triton E4M3 FP8 dtype by CUDA architecture so A100/SM80 uses `tl.float8e4b15` instead of unsupported `tl.float8e4nv`.
- Store FP8 quantized outputs through `uint8` views after bitcasting FP8 values, preserving the one-byte FP8 payload while avoiding unsupported FP8 pointer dtypes on A100.
- Keep the ModelOpt FP8 linear path wired to the existing Marlin fallback for pre-Hopper GPUs, with `envs.SGLANG_FORCE_FP8_MARLIN` as the manual override.
