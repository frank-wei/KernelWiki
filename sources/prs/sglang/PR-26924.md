## Motivation

Add fused Triton kernels for Qwen3.5 (397B-A17B) to reduce kernel launch overhead and memory allocations in the attention output gate and MoE shared expert paths.

Target model config: `hidden_size=4096, num_attention_heads=32, head_dim=256, attn_output_gate=true`

## Modifications

1. **`fused_sigmoid_mul`** — fused `attn_output * sigmoid(gate)` kernel in `layers/elementwise.py`
   - Supports inplace write-back, strided 3D gate (avoids `.contiguous()` copy from `torch.chunk`)
   - Used in every attention layer's output gate path
2. **`fused_gate_sigmoid_mul_add`** — fused `final += sigmoid(hidden @ gate_weight) * shared_output` kernel
   - Used in MoE shared expert gate path
3. **Overlap mamba verify update with draft extend** via side stream in `eagle_worker_v2.py`

## Unit Tests

All tests passed on B200:

- `test_fused_gate_sigmoid_mul_add`: **91 passed**
- `test_fused_sigmoid_mul`: **201 passed** (flat, 3D, strided gate, Qwen3.5 MoE target config)
