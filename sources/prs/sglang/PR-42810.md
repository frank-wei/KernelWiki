## Motivation

Models with a clamped SwiGLU-OAI MLP (e.g. MiniMax-M3's dense and shared experts) that feed an MXFP8 down projection currently run the activation and `flashinfer.mxfp8_quantize` as two separate kernels. The existing diffusion `_silu_mul_mxfp8_kernel` already writes FlashInfer's 128x4 swizzled E8M0 scales, so this PR adds a SwiGLU-OAI branch to it.

## Modifications

- `_silu_mul_mxfp8_kernel` takes `ALPHA` / `LIMIT` as constexpr. `ALPHA=None` keeps the SiLU path unchanged. Otherwise it computes `clamp(gate, max=limit) * sigmoid(alpha * gate) * (clamp(up, ±limit) + 1)` in the op order Inductor emits for `swiglu_no_interleaved_with_alpha_and_limit`, rounding to bf16 once.
- New `swiglu_oai_mxfp8(hidden, alpha, limit)`, registered as `quantization.swiglu_oai_mxfp8`.
- Move `mxfp8_swizzled_triton.py` from `kernels/ops/diffusion/quantization/` to `kernels/ops/quantization/`, since the quantizer and SwiGLU producers are not diffusion-specific.
