## Motivation

<!-- Describe the purpose and goals of this pull request. -->

Add a unified-KV attention backend for DeepSeek-V4 on amd code path, porting [ATOM's sparse attention kernels](https://github.com/ROCm/ATOM/tree/main/atom/model_ops/v4_kernels), which has great perf. It is gated by `SGLANG_HACK_FLASHMLA_BACKEND=unified_kv_triton`; when disabled, the default path is unchanged.
