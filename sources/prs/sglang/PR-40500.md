## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Avoid per-token Mooncake copies from #40045 when prefill draft KV rows are wider than decode rows. Pack head slices with the existing gather kernel, then transfer contiguous ranges; drain transfers before buffer reuse.

B200/NVLink, Kimi Linear + dummy DSpark, TP1 → TP2/DCP2, BF16 draft KV, OSL=1, two runs per variant. Same payload; packing included. Mean TTFT (main → PR):

| Prompt / prefill cache | Concurrency 1 | Concurrency 4 |
|---|---:|---:|
| 32K / cold | 1.20 → 0.58 s | 3.54 → 1.87 s |
| 90K / 83K | 2.90 → 0.21 s | 9.36 → 0.70 s |
| 170K / 164K | 5.48 → 0.28 s | 17.68 → 0.92 s |

170K draft microbenchmark: 1.71M → 13.3K descriptors per peer. Adds 320 MiB of bounded pack capacity for Mooncake in this setup; NIXL allocation is unchanged. Reverse-width mismatch retains fallback.

Validation: byte-exact transfer/kernel tests; GSM8K **90.5% (362/400)** with Kimi + dummy DSpark, TP2/PP2 → TP4/DCP4 on eight GB300s across two nodes using Mooncake RDMA (single rail). Speculative-verify smoke passes. The GSM8K topology change is uncommitted.
