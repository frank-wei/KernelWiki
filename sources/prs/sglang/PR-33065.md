## Motivation

FlashMLA returns natural-log softmax LSE, while the MLA DCP merge paths currently treat all decode LSE as base-2. As a result, FlashMLA + DCP computes incorrect cross-rank softmax weights and attention output.

For partition functions `Z = [2, 8]` and a second-shard local output of `10`, the correct contribution is `8`. Interpreting `[ln(2), ln(8)]` with `exp2` produces `7.2330317` instead.

Fixes #33064.

## Modifications

- Make the AG/RS Triton correction kernel select `exp/log` or `exp2/log2` through a compile-time LSE-base flag.
- Propagate that flag through `cp_lse_ag_out_rs_mla`.
- Select natural-log LSE for the `flashmla` attention backend in both MLA DCP communication paths:
  - all-gather LSE + reduce-scatter output;
  - A2A/FlashInfer-A2A LSE reduction.
- Keep base-2 as the default, so FlashInfer MLA behavior is unchanged.
- Add a GPU regression for the exact natural-log weighting error and a routing test for backend selection.
