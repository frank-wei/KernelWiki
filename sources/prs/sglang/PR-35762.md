## Motivation

DCP assigns KV ownership round-robin **per token** (`owned_offsets = arange(rank, num_kv_tokens, dcp_size)`), so on a DCP1 -> DCP-N PD transfer the source indices are strided and `group_concurrent_contiguous` cannot merge them: the relayout emits **one RDMA descriptor per token per layer** (`tokens x layers` per chunk). The transfer becomes descriptor-bound rather than bandwidth-bound.

## Modifications

- **Pack cyclic DCP rows:** Added a raw-pointer Triton gather and common packing path that turns strided MLA source rows into contiguous blocks, reducing transfer descriptors from one per owned token per layer to destination-contiguous runs.
