### Modifications

- Add an opt-in DeepSeek V4 FP4 indexer path with `--enable-deepseek-v4-fp4-indexer`.
- Keep the default DeepSeek V4 indexer path unchanged.
- Add FP4 indexer cache layout, FP4 Q/K quantization helpers, fused KV store path, and registered kernel tests.
