## Motivation

Add staged write-back support for the `page_unified` KV cache layout, building on the unified storage layout discussed in #33651 and the GPU staging approach introduced in #21631.

The destination layouts are:

- **MHA:** `(page, head_group, layer, 2, page_size, head_in_group, dim)`, where K=0 and V=1.
- **MLA:** `(page, layer, page_size, dim)`, storing one compressed KV tensor per layer.

## Changes

- Add `hicache_page_unified_relayout_kernel` to gather per-layer GPU KV data into contiguous staging pages using 16-byte vectorized loads and stores.
- Support MHA and MLA through compile-time specialization. MLA has no head-group, separate K/V, or head axes.
- Reuse the existing whole-page D2H copy helpers after GPU relayout.
- Support transfers larger than the caller-provided staging buffer by processing chunks on the current CUDA stream.
- Add MHA and MLA Python entry points and correctness tests in existing files.

This PR implements the write-back primitives and tests. Host-pool integration and load-back support are outside its scope.
