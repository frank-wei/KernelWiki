## Motivation

Fixes #41494: GLM-5.3-Flash (DSA with `index_kpool=4`) loses the NIAH needle at 16K when prefixes are shared. Supersedes #41645.

A pooled index key covers 4 consecutive tokens, i.e. 4 physical KV pages of 64. Before this PR the radix tree page was 64, so a prefix hit could end inside a pooled-key group. The resuming request then wrote its pooled keys into the group-head page owned by another request's cached prefix, and later readers of that prefix saw the wrong keys.

## Modifications

- **Logical page = 64 × `index_kpool` (256)** for the allocator, radix tree, PD and HiCache. KV kernels and the DSA backend's `real_page_size` keep 64-token physical pages. Logical page `L` owns physical pages `4L .. 4L+3`.
- **Index page id = logical page id.** Each index page holds 64 pooled keys (`slots_per_page`). Pooled key `j` of a request lives at index slot `req_to_token[r, 4j] // 4`, and the index page table is `page_table_64[:, ::4] // 4`. Every group-head lookup in the k-pool kernels and planners now divides by `POOL_SIZE`.
