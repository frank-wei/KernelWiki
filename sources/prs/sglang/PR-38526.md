## Summary

This PR adds native SGLang support for [`inclusionAI/Ling-3.0-flash-VL`](https://huggingface.co/inclusionAI/Ling-3.0-flash-VL), including text, image, and video serving through the OpenAI-compatible API. It supports the official [BF16](https://huggingface.co/inclusionAI/Ling-3.0-flash-VL), [FP8](https://huggingface.co/inclusionAI/Ling-3.0-flash-VL-fp8), [INT4](https://huggingface.co/inclusionAI/Ling-3.0-flash-VL-int4), and [FP4](https://huggingface.co/inclusionAI/Ling-3.0-flash-VL-fp4) checkpoints.

Ling-3.0-flash-VL is a roughly 125B-parameter, 5.1B-active hybrid MoE VLM. Its 42-layer language backbone interleaves KDA and MLA attention and uses 512 routed experts with 8 selected per token. The public checkpoint uses one sigmoid router with correction bias per MoE layer. A 27-layer vision encoder and external two-layer `linear_proj` connect image and video features to the language model; the checkpoint has no deepstack tensors and disables the vision merger projection. Position encoding uses centered Bailing mRoPE with sections `[8, 12, 12]`.

The companion cookbook and deployment recipes are in [#38434](https://github.com/sgl-project/sglang/pull/38434).
