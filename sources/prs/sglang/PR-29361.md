## Motivation

Add a native CUDA JIT fast path for the LTX-2.3 residual-gate update pattern from KDA-Pilot task `b200_diffusion_residual_gate_add__multi_shape` / [BBuf/KDA-Pilot#134](https://github.com/BBuf/KDA-Pilot/pull/134).

The hot pattern is equivalent to:

```python
hidden_states = hidden_states + update * gate
```

for contiguous `[B, L, D]` tensors with either a full gate or a broadcast gate shaped `[B, 1, D]`. The LTX-2.3 HQ two-stage path hits large broadcast rows such as `[1, 32640, 4096]` and full-gate rows such as `[1, 8160, 4096]` across the DiT residual, attention, and MLP updates.

## Modifications

- Add `diffusion_residual_gate_add` lightweight JIT CUDA kernel.
- Mark KDA-developed CUDA csrc files with the MIT HAN Lab Kernel Design Agents provenance comment.
- Register it as an eager SGLang custom op with a fake impl so direct `torch.compile` tracing sees an opaque op instead of tracing JIT/module loading.
- Support both full gates and row-broadcast gates, including the large LTX-2.3 HQ broadcast shape with a row-tiled CUDA path.
- Wire LTX2 transformer residual-gate updates to try CUDA by default, then fall back to the existing Triton `fuse_scale_shift_kernel` i
