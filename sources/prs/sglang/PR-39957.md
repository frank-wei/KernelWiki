## Motivation

On small DeepSeek-V4.1 TP4 batches, inverse RoPE, WO-A projection, and MXFP8 quantization require separate kernel launches. This PR fuses the sequence to reduce launch and intermediate-memory overhead.

## Changes

- Add the SM100/SM103 fused inverse-RoPE + WO-A kernel, with BF16 or FlashInfer-swizzled MXFP8 output, for up to 32 token rows and the supported `(groups, rank, K) = (2, 1024, 4096)` shape.
- Dispatch it for eligible DSV4.1 layers; preserve main's model-type gating, NPU WO-A path, and the existing fallback for other shapes/backends.
- Add the JIT CUDA-driver link support and mbarrier helper required by the kernel.
- Keep 18 focused correctness cases in `test/registered/kernels/`: BF16/MXFP8 output, padded inputs, token-count boundaries, scale padding, and int32/int64 positions. Validate scales in bulk and update the WO-A imports in existing tests.
