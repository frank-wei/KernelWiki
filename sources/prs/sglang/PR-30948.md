## Motivation

The TP-local embedding path currently emits separate mask pointwise kernels, `F.embedding`/`indexSelectSmallIndex`, and a masked fill for every draft forward.

This is part 2 of 3 extracted from #30388.

## Changes

- Add a fused Triton vocab-parallel embedding kernel for the standard unquantized path.
- Gather in-shard rows and directly write zero rows for out-of-shard token IDs.
- Clamp invalid lanes to row zero before forming the weight pointer.
- Restrict the fast path to TP > 1, contiguous CUDA int32/int64 token IDs, supported CUDA weights, and `UnquantizedEmbeddingMethod`.
- Preserve the existing CPU, NPU, TP1, quantized/custom-method, and unsupported-layout fallbacks.
- Add focused kernel tests and a benchmark, including exact int64 minimum/maximum token IDs.

## Impact

This collapses the repeated TP embedding mask, gather, and fill sequence into one kernel.
