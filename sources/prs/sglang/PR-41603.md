## Motivation

Extend the existing opt-in TRT-LLM sparse MLA backend to DeepSeek-V4.1. The default attention backend is unchanged. Enable with `--dsv4-attn-backend trtllm --cuda-graph-backend-prefill disabled`.

## Modifications

- Add uniform FP8 compressed-cache writes for V4.1's ratio-1/2 layers.
- Support indexed ratio-1/2 metadata, empty compressed histories, and DSpark's noncausal SWA draft blocks.
- Use native query-head counts, fuse RoPE with FP8 Q conversion, and combine sparse-index copying and length preparation into one kernel.
- Reject V4.1 TRT-LLM prefill CUDA graphs and SWA bounded replay for now. Existing context-parallelism/online-compression restrictions remain.

## Accuracy Tests

Local tests before the cluster outage, using real DeepSeek-V4.1-Flash weights on 4×GB300, TP4/EP4, and FlashInfer 0.6.18.post1:

- 24 fused Q/metadata checks matched their unfused references exactly.
- Attention reference checks covered prefill, decode, verification, short contexts, and DSpark. Relative RMSE against FP32 attention was below 2.6%; tested decode/verify CUDA-graph outputs matched eager outputs exactly.
- 30/30 arithmetic/retrieval checks passed, including approximately 128
