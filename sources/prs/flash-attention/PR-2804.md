## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Two coupled changes to the hdim-64 SM100 backward that together remove every compute-wide barrier from its main loop. Gradients are bit-identical to the current kernel under `deterministic=True`; every other shape and architecture is untouched.

**Results** (B200, bf16, 64k tokens per call, 32 query heads, sustained-load medians, shipped default vs current main):

| shape | mode | before, TFLOP/s | after, TFLOP/s | speed-up |
|---|---|--:|--:|--:|
| b2 s32k h32:32 | dense | 731 | 841 | 1.150x |
| b2 s32k h32:32 | causal | 705 | 808 | 1.147x |
| b4 s16k h32:8 | dense | 840 | 903 | 1.075x |
| b4 s16k h32:8 | causal | 750 | 842 | 1.123x |
| b8 s8k h32:32 fp16 | dense | 692 | 782 | 1.131x |
| b4 s16k h32:32 | dense, deterministic | 709 | 774 | 1.091x |
| b4 s16k h32:32 | causal, deterministic | 664 | 725 | 1.093x |

Every measured hdim-64 shape improves by 6-15%, and the gain grows with sequence length. A 124-configuration sweep (seqlen 512 to 32k, MHA/GQA/MQA, dense, causal, local, varlen, bf16/fp16, deterministic and not) gives a geometric-mean speed-up of **1.129x non-deterministic** (worst cell 1.023x) and **1.050x deterministic** (worst cell 0.995x). hdim 128 is unchanged.
