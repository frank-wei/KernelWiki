## Summary

  The dedicated SM100 hd256 2CTA forward kernel (`BlackwellFusedMultiHeadAttentionForward`) hardcoded contiguous strides for its q/k/v/o CUTE layouts, silently scrambling memory accesses for any caller passing a non-contiguous tensor — most notably the `(B, H, S, D).transpose(1, 2)` pattern used by HuggingFace attention layers. PR #2666 worked around this by forcing `q.contiguous() / k.contiguous() / v.contiguous()` in the dispatcher.

  This PR fixes the kernel itself so it reads the *actual* input strides, then removes the `.contiguous()` workaround. It also lifts the `_as_bshkrd_tensor` / `_as_shhb_tensor` helpers (already used by the hd256 backward) into a shared module.
