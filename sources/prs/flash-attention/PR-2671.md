## Summary

Fix three FA4 CuTe frontend issues reported on SM120/SM121 paths:

- cast optional `window_size_left/right` to `cutlass.Int32` for `cute.compile` while keeping runtime TVM FFI calls unchanged (#2653)
- initialize `dQ_single_wg` in the SM120 backward configuration before it is included in the compile key (#2650)
- preserve the original `softmax_scale` in the SM80/SM120 backward kernel when `score_mod is None`; `compute_softmax_scale_log2` intentionally returns `None` for the adjusted score-mod scale in that case (#2651)

## Validation

- `git diff --check`
- `PYTHONPYCACHEPREFIX=/private/tmp/flash-attn-pycache /usr/bin/python3 -m py_compile flash_attn/cute/interface.py flash_attn/cute/flash_bwd.py`
- static source assertions for the compile-time Int32 conversion, SM120 `dQ_single_wg` initialization, and backward `softmax_scale` preservation

I could not run the CuTe/CUDA runtime tests on this machine because `cutlass`, `cuda`, and `quack` are not installed locally.
