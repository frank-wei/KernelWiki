## Purpose
Some all-to-all backends use `-1` in the `topk_ids` to indicate that a token is routed to a non-local expert (e.g. see [DeepEP elastic dispatch logic](https://github.com/deepseek-ai/DeepEP/blob/main/deep_ep/include/deep_ep/impls/dispatch_copy_epilogue.cuh#L106-L109)), but currently the `moe_align_block_size` kernel does not handle `-1` values.

For example this logic will attempt to read `expert_map[-1];`
