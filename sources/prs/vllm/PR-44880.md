## Purpose

Add MTP (Multi-Token Prediction) speculative decoding support for Bailing MoE hybrid models, and enhance the linear attention backend to support speculative decode with CUDAGraph.

**Key changes:**

- **New `BailingMoeV25MTPModel`**: Add the draft model implementation for Bailing MoE V2.5 MTP speculative decoding (`bailing_moe_mtp.py`), including `BailingMoeV25MultiTokenPredictor` with shared embedding/lm_head support and MoE expert weight loading.
- **Speculative config**: Register `bailing_hybrid_mtp` model type and auto-detect Bailing architectures to override `model_type` and `architectures` for MTP draft model construction.
- **Model registry**: Register `BailingMoeV25MTPModel` in `_SPECULATIVE_DECODING_MODELS`.
- **Model arch config convertor**: Add `BailingHybridMTPModelArchConfigConvertor` to provide correct `num_hidden_layers` for MTP layers.
- **Linear attention backend**: Enhance `LinearAttentionMetadataBuilder` to support speculative decode by splitting decode/prefill state indices, handling multi-token draft indices (`num_accepted_tokens`, `query_start_loc_d`), and CUDAGraph capture with spec decode awareness.
