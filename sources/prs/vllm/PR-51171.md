## Purpose

Speculative decoding on ROCm cannot reach FULL cudagraphs, for two independent
reasons. This fixes both. Measured on Kimi-K3 with a DSpark draft, TP8 on MI355X.

**The reported support level.** A DSpark draft group serves its whole
`1 + num_speculative_tokens` block through the decode path, but
`TritonMLAMetadataBuilder` reports `UNIFORM_SINGLE_TOKEN_DECODE` from a class
constant, and the engine takes the minimum over attention groups -- so that one
group downgrades the *whole engine* off FULL. `forward_mqa` flattens the block
with `repeat_interleave` on a Python int and performs no device->host sync, so
the group does satisfy `UNIFORM_BATCH`. `triton_mla.py` now reports that where
the KV cache group is marked `non_causal_multi_token_decode`. Note the predicate
is group scoped, not draft scoped, so a causal target sharing a draft's group is
lifted too; `__init__` two lines below already uses it to raise
`reorder_batch_threshold`, and the docstring records the scope.
