## Purpose

Add support for speculative decoding with `mamba_cache_mode=align` when Mamba conv state uses DS layout (`[num_blocks, dim, state_len]`).

  For DS layout and accepted-token offset > 0, the conv-state tail is strided and cannot use the existing contiguous memcpy path. This PR adds a DS-tail copy spec and a Triton copy kernel for:

  ```text
  dst[:, : state_len - offset] = src[:, offset:]
  ```

  The kernel keeps pointer offset arithmetic in int64 to avoid overflow for large Mamba cache tensors.
