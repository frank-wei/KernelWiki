## Overview

Fixes #61114. Give block verification fresh acceptance and draft random draws when an uncommitted position is revisited in a later round.

## Claims

- Removes the cross-round sampling bias for deterministic and probabilistic drafts in Model Runner V2.
- Preserves seeded repeat, request-order and batch-splitting behavior in both verification modes. Standard probabilistic token sequences change, but their target distribution is retained.
- Uses a shared step-seed helper without new forwarding parameters, round-position tensors, scheduler state, host synchronization or sampling kernel launches.
- Covers ordinary draft sampling, the shared DFlash2/LiLiCorr candidate walk, DSpark and ordinary watermark fallback.

## Validation

Real V2 generation with one-layer, context-independent Llama target/draft models, TP=1, float32, two speculative tokens and 10,000 requests per configuration:

| Draft | Verification | Expected P(third token = 0) | Before | After |

| Deterministic | standard | 0.5000 | 0.5039 | 0.5039 |
| Deterministic | block | 0.5000 | 0.4171 | 0.4989 |
| Probabilistic | standard | 0.3000 | 0.3083 | 0.3055 |
