## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Models with multiple KV cache groups of different dimensions (e.g. GLM-5.2 which has MLA + DSA indexer attention) produce different page sizes per group. `KVBlockZeroer` previously asserted a single uniform page size, crashing during initialization.

Group segments by page size and launch the Triton zeroing kernel once per group. The kernel is unchanged.

I vibe coded this to fix #49696, but it's unclear if GLM needs this as it is neither Mamba nor non-uniform KV dtype model so it doesn't have the NaN/Inf reinterpret_cast hazard.
<!-- upstream-excerpt-end -->
