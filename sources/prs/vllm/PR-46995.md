## Purpose

Adds support for [DSpark](https://huggingface.co/deepseek-ai/DeepSeek-V4-Pro-DSpark) speculative decoding, using both DeepSeek-V4 DSpark models as well as [DeepSeek-trained Qwen3-DSpark](https://huggingface.co/deepseek-ai/dspark_qwen3_8b_block7) models.

## Design

DSpark uses non-causal sliding-window attention. To implement this, instead of manually reimplementing the MLA attention, we instead utilize the existing SparseMLA backends with an expanded topk size, in which the queries all include _each other_ in their topk indices, independent of causality. This implements exactly-correct attention with respect to causality (see test_dspark_noncausal_sparse_mla.py) while also minimizing changes to the KV cache utilities and allowing reuse of existing, efficient sparse attention kernels.

For CUDA Graphs, we capture the full DFlash backbone and autoregressive sampling loop in a single graph. This decreases host and kernel launch overhead.

## Testing

I ran GSM8k at high concurrency, with and without prefix caching (and num_fewshot high enough to trigger prefix cache hits), and got good scores with DSV4-Pro + DSpark.

I ran multiple categories of SPEED-Bench at BS32 + BS8
