## Description

This PR migrates sequence-layout and decode-context-parallel JIT kernels used by the DSv4 attention path to the shared warmup contract.

## What Changed

- Migrated sequence packing/unpacking and attention CP-output correction kernels.
- Migrated DCP index-correction and candidate-processing CuTeDSL kernels.
- Moved specialization ownership next to each runtime kernel.
- Added compile-only CuTeDSL paths using fake tensor descriptors.
- Replaced representative runtime inputs with kernel-owned traced dispatch spaces.
- Added dispatch-equivalence tests for the migrated kernels.
