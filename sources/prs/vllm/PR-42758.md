## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR enables perf_token_group_quant kernels for ROCm, and since those kernels are defined by the compilation target _C_stable_libtorch, so this PR also enables this target.

-  modify per_token_group_quant kernels to make them support rocm (warp size 64 and 32).
- change GroupReduceMax device function to ensure it works on 64 warp size.
- change `hipify.py` to handle cmake issue when hipifyinng cu to hip.
- change all compilation passes to have the new kernels on rocm.
<!-- upstream-excerpt-end -->
