## Overview

On ROCm, the Qwen4Exp QSA indexer now runs the fused pre-indexer kernel instead of the unfused Gemma RMSNorm / MRoPE / compress / cache-write chain. The kernel is an AMD-path copy of NVIDIA's (`amd/ops/qsa_pre_indexer.py`), as review asked; NVIDIA files are untouched. Follow-up: #59732 ports #57097's main-attention fusion onto this copy.

## Claims

- One launch per QSA layer per step for the indexer prepare, replacing 37 (−20% kernel launches per decode step at 8k/1024 c4, TP2).
- MI355X TP2 `amd/Qwen3.8-Flash-Next-Quark-MXFP4`: +3.1% to +9.3% output throughput, largest at 8k/1024 c4; TTFT flat (decode-only change).
- No accuracy change: GSM8K 0.9636 → 0.9689 (MI355X).
- NVIDIA unchanged: no NVIDIA file in the diff.
