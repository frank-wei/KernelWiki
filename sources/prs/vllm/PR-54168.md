## Summary

This PR reduces the SM100 Kimi-K3 latent-MoE decode tail latency for low token counts while preserving the existing operator structure. Deferred BF16 top-16 finalization, routed AllReduce, RMSNorm, and shared-expert ReduceScatter remain fused in one CuTe DSL collective kernel; the following rank-sharded up-projection and Lamport consumer are made cheaper and are launched earlier with PDL.

The production path remains valid for `M <= 16` (and the existing larger capacities). The most aggressive static SIMT up-projection is deliberately limited to `M <= 5`; measurements show that the dynamic WGMMA path wins again from `M=6` onward.

## Optimization details
