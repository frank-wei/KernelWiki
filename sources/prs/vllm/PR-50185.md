## Purpose
A few small improvements to reduce the latency of the attention residual kernel:
- Use vectorized loads when populating `q_cache`
- Treat `B` and `N` as compile-time constants
- Set `NC = 3` for low batch size path
- Unroll the main loop over `num_chunks`

## Test Plan

```
pytest -v tests/models/kimi_k3/test_attn_res.py
```
