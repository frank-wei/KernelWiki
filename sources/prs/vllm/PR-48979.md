## Purpose
This PR modifies the `VLLM_MOE_SKIP_PADDING` logic introduced by https://github.com/vllm-project/vllm/pull/46428/, removing the separate call to `torch.where` and instead passing the `is_padding` mask into the topk kernel. The topk kernel then reads from `is_padding` to determine whether to set any given `topk_ids` entry to `-1`.
