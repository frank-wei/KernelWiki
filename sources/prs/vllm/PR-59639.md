## Purpose

Fixes the intermittent `test_engram` failure in `(MI355) Miscellaneous Kernels` ([AMD CI build 13954](https://buildkite.com/vllm/amd-ci/builds/13954#01a0f6b2-7be7-4b87-9033-677cce28c6dd)).

Branching on `SORTED` at runtime in `_engram_lookup_kernel` (#59327) intermittently crashes Triton 3.8's `RemoveLayoutConversions` pass (`PassManager::run failed`). The crash can hit any lookup, including unsorted ones. The root cause is dangling `rematMapping` keys, fixed upstream by [triton-lang/triton#10706](https://github.com/triton-lang/triton/pull/10706). That fix is not in Triton `release/3.8.x`.

This PR makes `SORTED` a constexpr on Triton 3.8, so the branch is resolved at compile time. The check should be removed once Triton ships [triton-lang/triton#10706](https://github.com/triton-lang/triton/pull/10706).
