## Motivation

Add native vLLM support for the complete Dots3 NOTE model, including:

- Text generation
- Image understanding
- Audio understanding
- Native video processing with interleaved visual and audio inputs
- FP8 MoE inference
- MTP speculative decoding
- OpenAI-compatible tool calling

Dots3 NOTE uses one unified Hugging Face model type and architecture:

- `model_type`: `dots3_note`
- `architectures`: `Dots3NoteForCausalLM`

The same architecture can serve the complete multimodal model or run only its language model through vLLM's existing `--language-model-only` option.

Dots3 NOTE's DSA layer is structurally related to DeepSeek-V3.2, but it cannot directly reuse the complete DeepSeek implementation because it combines:

- Full-attention MLA layers with DSA indexing
- Dense sliding-window MLA layers with different attention geometry
- Different attention gates for full-attention and SWA layers
- Different latent KV widths across attention layer groups
- A tail-RoPE DSA index-key checkpoint layout
- An SWA-shaped MTP layer
- A MoE vision encoder and an audio encoder
- Native video preprocessing that interleaves timestamped image and audio embeddings
