## Description

This PR migrates the DSv4 MHC TileLang path to the shared JIT warmup contract.

## What Changed

- Migrated pre-fusion, post-fusion, fused MHC, head-fusion, and prenorm GEMM TileLang kernels.
- Moved TileLang specialization heuristics into kernel-owned `dispatch(...)` methods.
- Defined warmup search spaces through AST ranges, coupled inputs, and predicates.
- Added a shared TileLang compile-only helper using fake tensor descriptors.
- Kept TileLang and DeepGEMM dispatch concerns separate.
- Preserved the existing TileLang kernel bodies and runtime selection behavior.
- Added tests comparing migrated dispatch keys with the original heuristics.
