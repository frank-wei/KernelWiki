## Purpose
This is a PR for the proposal defined in this [RFC #53916](https://github.com/vllm-project/vllm/issues/53916) for implementing text watermarking in vLLM. Refer to that RFC for all design decisions, justifications and empirical results.

We implement:
- a new watermarking sampler using the Gumbel-max algorithm
- a new detection primitive for this sampler
- a stable PRF to be used for keyed generation
- a per-request `watermarking=false` opt-out while keeping the algorithm and key engine-level
- an example endpoint for detection

## Test Plan
See "Implementation plan" section of [RFC #53916](https://github.com/vllm-project/vllm/issues/53916)
We test inference performance, as well as quality of generation, using standard tools and evaluations.
