## Summary

This PR follows the Kimi Linear KDA prefill optimization direction validated by
SGLang in https://github.com/sgl-project/sglang/pull/23038. That PR showed that
the KDA chunk prefill path benefits from moving the raw gate producer closer to
the chunk consumer and fusing gate activation with chunk-local cumulative gate
construction.

For vLLM, this PR fuses raw gate activation, chunk-local cumsum, and natural-log
to log2 scaling into one Triton kernel. This removes the separate gate producer,
chunk cumsum, and `RCP_LN2` multiply launches from the KDA prefill path.

The chunk path keeps the FLA-style `RCP_LN2 + exp2` convention, so the natural
KDA recurrence is preserved as `exp(x) == exp2(x / ln(2))`. The recurrent/decode
path still uses the existing natural-base gate path.

This also wires the fused chunk path to reuse prepared `chunk_indices` through
the KDA prefill subgraph. Compared with SGLang's PR, that part is expected to
contribute less in vLLM because vLLM already precomputes and caches GDN/FLA
chunk metadata in `GDNAttentionMetadata`. The main gap addressed here is
therefore the gate + cumsum + `RCP_LN2` fusion.
