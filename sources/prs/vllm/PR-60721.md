## Overview

Tidy `csrc/`: merge one-macro/one-function headers, rename the misnamed `attention/` dtype directory, move stragglers next to the extension that builds them, delete unreferenced code, and flatten `csrc/libtorch_stable/` back into `csrc/` now that nearly every GPU kernel is stable-ABI. No functional change intended.

Not a duplicate: the only open PR touching this area is #38134 (WIP, removes the KV cache dtype enum), which has a different goal and predates the `libtorch_stable/` layout.

## Claims

- `csrc/` is now `core/` (shared by every extension), `cpu/` and `rocm/` (legacy-ABI code), and everything else is the stable-ABI CUDA/HIP tree. `libtorch_stable/` is gone; extension names (`_C_stable_libtorch`, `_moe_C_stable_libtorch`) are unchanged.
- Every quoted `#include` resolves to the same file before and after the flatten (scripted over all 250 sources).
- The built CUDA extensions register the same 160 op schemas as `main`.
- Every `csrc/` path in the CI `source_file_dependencies` filters exists again. 68 entries had been left naming paths that moved under `libtorch_stable/`.
