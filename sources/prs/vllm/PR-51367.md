## Purpose

Replace the Gumbel sampler's Philox-based uniform generation with a manual Murmur3 x86_32 mixing path keyed by request seed, token position, and vocabulary offset. The goal is to preserve the target sampling distribution while improving RNG resolution and avoiding backend-specific math paths.

Related RFC: #54143.

This is not a duplicate of #47524. That PR keeps Philox and combines more of its output bits to improve uniform resolution; this PR evaluates a different RNG and a backend-independent logarithm path. The existing Philox helpers remain available for rejection sampling.

## Implementation

- Generate fp32 uniforms from the full 32-bit Murmur3 result through two exact 16-bit integer-to-float conversions, avoiding backend-dependent uint32-to-float behavior.
- Generate centered fp64 uniforms from 53 random bits and explicitly keep both endpoints open after fp64 rounding.
- Use a stable degree-8 approximation for `log1p(-u)` in the fp32 winning tail instead of a backend-specific libdevice call.
