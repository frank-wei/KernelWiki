## Purpose
While moving kernels to use the libtorch stable abi and moving them into the csrc/libtorch_stable directory, we noticed a lot of the header files were being left behind. This PR is to fix that by moving header that are 'stable' (~~i.e. no dependency on libtorch at all or only use stable headers~~ i.e. header files only used by stable kernels) into the libtorch_stable directory ~~and changing the references to these headers in csrc/ explicitly to stable_libtorch/xxx/yyy to be more explicit~~.
