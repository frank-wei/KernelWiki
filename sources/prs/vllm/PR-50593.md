## Purpose

The AMD Kimi-K3 decoder previously executed several memory-bound operations around AttnRes as separate kernels:

1. Update the accumulated prefix residual.
2. Write the updated prefix into block-residual storage.
3. Run the AttnRes weighted residual aggregation.
4. Apply the input RMSNorm.
5. Add the self-attention output to the prefix.
6. Run the MLP AttnRes aggregation.
7. Apply the post-attention RMSNorm.

These operations repeatedly read and write full hidden-state tensors and introduce additional kernel-launch overhead. This overhead is especially significant during decode, where each request processes only a small number of tokens while executing 69 KDA layers per generated token.

This PR extends the existing AMD AttnRes Triton kernel so it can optionally fuse:

- Prefix residual updates.
- Attention-output delta addition.
- Block-residual writes.
- AttnRes weighted aggregation.
- Input RMSNorm.
- Post-attention RMSNorm.
- The zero-block fast path.
