## Purpose

Add sequence parallelism (SP) to Qwen4Exp / Qwen3.8-Flash-Next to reduce replicated GR and PLE computation and support sequence-parallel MoE.

- Enable GR/PLE SP with `--enable-hc-sp` while retaining tensor-parallel MoE.
- Automatically enable model SP with the existing sequence-parallel MoE configuration (`TP>1`, `DP>1`, EP enabled, and a supported all-to-all backend).

SP currently requires PP=1 and MoE layers. External LoRA adapters on SP-sharded GR/PLE projections are not supported.

## Test Plan

```bash
python -m pytest -q tests/models/qwen4_exp/test_config.py \
  tests/models/qwen4_exp/test_ple.py tests/models/qwen4_exp/test_tpsp.py
```

## Test Results

- Regression tests: **92 passed**, including two-GPU GR/PLE SP and four-GPU MoE SP tests.
- Ruff and `git diff --check`: passed.

### Accuracy

Models: `Qwen/Qwen3.8-Flash-Next` and its `-FP8` variant. MTP=3, PP=1, prefix caching disabled. Same prompts and generation settings within each pair: seed=1236, temperature=0.7, top_p=0.8, top_k=20, max_tokens=32768, thinking enabled.

Selected results, **SP off → on**. GSM8K: 1,319 questions; GPQA Diamond: 198 questions. Original evaluation scores are retained.
