## Purpose

`mm_input_norm` is a memory-bandwidth-bound operator: one multiply-add per
element, so runtime is dominated by DRAM traffic. This PR adds a Triton
fusion kernel that performs the whole per-channel affine transform in a
single pass, replacing the eager path that materialized an fp32 intermediate.

The Triton fused kernel is **significantly faster** than the eager,
`BatchNorm1d`, and `torch.compile` baselines on the same workload, because it
reads the input once and writes the output once — no intermediate DRAM
round-trip.
