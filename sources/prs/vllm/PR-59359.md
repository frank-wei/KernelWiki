## Purpose

Add sampling-mask replay for fixed-boundary speculative decoding in Model Runner V2, on top of the compact sampling-mask representation.

The implementation preserves the ordinary single-token fast path and exact packed-mask fallback, and returns one processed-target support set for each emitted accepted, recovered, or bonus token. Output D2H is scheduled before postprocessing and the next proposal.

## Supported configuration and boundaries

The merged implementation does **not** restrict replay to `method="mtp"` or standard rejection sampling. Configuration tests accept MTP, EAGLE/EAGLE3, dFlash, dSpark and draft_model, and accept standard, block and synthetic rejection configurations. Configuration acceptance is not a claim that every combination has GPU E2E coverage.

Replay requires Model Runner V2, fixed verification boundaries (adaptive verification disabled), `logprobs_mode="processed_logprobs"`, no diffusion model and no custom logits processors. NGRAM GPU replay validation is not established by the test results below.
