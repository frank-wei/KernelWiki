## Purpose

Skip padded work in block-FP8 `DeepGemmExperts` on SM90 and SM100-family GPUs. Both grouped GEMMs use DeepGEMM's prefix-sum scheduler, and fused SiLU/SwiGLU activation quantization consumes the same live expert endpoints. This avoids visiting unused padded GEMM tiles and quantizing the full allocated workspace when only a fraction contains live rows.

The shared permutation helper produces expert endpoints for both architectures. SM100 dispatch uses packed UE8M0 activation scales; SM90 dispatch uses the column-major FP32 activation-scale path, including plain and power-of-two-rounded scales. The dispatch remains limited to block-FP8 weights and supported fused gated activations. `mk_alignment_scope` and DeepGEMM's default `ensure_zero_padding=True` remain in place. Other paths keep their existing behavior.
