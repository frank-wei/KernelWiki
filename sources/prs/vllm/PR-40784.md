## Summary

Tune wvSplitK skinny GEMM kernel for gfx1151.

## Kernel benchmarks

**bf16 `wvSplitK` kernel benchmark on Strix Halo (gfx1151, 20 CUs):**

- `N=1` average: **+18.7%** bandwidth improvement
- `N=2` average: **+19.8%**
- `N=3` average: **+15.2%**
- `N=4` average: **+13.0%**

**fp16 `wvSplitK` kernel benchmark:**

- `N=1` average: **+6.1%** bandwidth improvement

## End-to-end benchmark

AMD Strix Halo (gfx1151, LPDDR5X-8000 128 GB), `input-len=128`, `output-len=128`, `num-prompts=5`, Median TPOT (ms):

| Model                           | Baseline | This PR | Change                          |
| ------------------------------- | -------: | ------: | ------------------------------- |
| `Qwen/Qwen2.5-0.5B-Instruct`    |     5.18 |    5.18 | 0.0%                            |
| `Qwen/Qwen3-4B`                 |    37.32 |   36.85 | **-1.3%**  |
| `Qwen/Qwen3-8B`                 |    77.16 |   70.09 | **-9.2%**                       |
| `google/gemma-3-4b-it`          |    38.82 |   36.63 | **-5.6%**                       |

The 0.5B model shows no measurable change. Larger models that are decode-bound on the skinny GEMM kernels see significant TPOT improvements.
