## Purpose

Fixes #55350.

Kimi-K3's low-token-count TP8 KDA projection-overlap path fails during CUDA
graph profiling on H100/SM90a. Two independent incompatibilities are involved:

1. the skinny N/K kernels unconditionally emit PTX `fma.f32.bf16`, which
   requires SM100 or newer and fails libNVVM compilation for `sm_90a`; and
2. FlashInfer's `cute-dsl` QKVG backend rejects SM90 during backend validation.

PR #55108 avoids the failure by disabling KDA projection overlap on Hopper.
This PR keeps the overlap structure enabled while selecting architecture-safe
operations.

## Implementation

- **SM100 and newer:** retain the existing mixed-precision BF16 FMA path.
- **SM90:** convert BF16 operands to FP32 and use FP32 FMA in the skinny N/K
  kernels.
- **SM100 and SM103 QKVG:** retain FlashInfer `cute-dsl` with PDL.
- **Other capabilities, including SM90:** use `torch.mm` for QKVG while keeping
  the concurrent F_A/beta and F_B projection branch.

The architecture check follows the PTX ISA requirement that
`fma.f32.{f16/bf16}` requires `sm_100` or higher. SM100 and SM103 behavior is
otherwise unchanged.
