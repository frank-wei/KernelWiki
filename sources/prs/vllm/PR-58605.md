## Purpose

Remove redundant integer-alignment specializations for `BATCH_SIZE` in the Triton top-k/top-p kernel and `ROUND` in the split top-p step kernel. Both retain Triton's value-1 specialization. Pointer/row-stride alignment, sampling modes, split counts, and warmup input enumeration remain unchanged.

This reduces the measured sampler warmup plan from **120 to 92 compile keys** without changing corresponding generated instructions. It is independent of #58582's parallel compilation. Unlike #45601's runtime warmup-coverage changes and fully dynamic `BATCH_SIZE`, this only removes duplicate alignment variants, preserves `BATCH_SIZE=1`, and also reduces `ROUND` variants. Open-PR searches found no equivalent alignment-only change.
