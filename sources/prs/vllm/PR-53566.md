## Description

This PR migrates the DSv4 NVIDIA CuTeDSL attention and sparse-attention kernels to the shared warmup contract.

## What Changed

- Migrated indexer-Q and dequantize-and-gather CuTeDSL kernels.
- Migrated the sparse-attention compression kernel family.
- Defined kernel-owned compile keys and AST-traced warmup spaces.
- Added compile-only CuTeDSL paths using fake tensor descriptors.
- Preserved the existing kernel bodies, runtime dispatch, and specialization behavior.
- Added tests comparing dispatch results with the pre-migration specialization logic.
