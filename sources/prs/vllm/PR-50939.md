# Summary
The block verification path does not currently guard against -1 placeholder draft token ids, which can be used as padding. This PR simply ensures that these draft tokens are rejected, and that they don't cause OOB for block verification. This was already handled for standard/greedy rejection sampling here: https://github.com/vllm-project/vllm/pull/46533.
