## Description

This PR migrates DSv4 common attention preparation, cache, indexer, and sparse-attention kernels to the shared warmup contract.

## What Changed

- Migrated fused Q/K normalization and MTP input normalization.
- Migrated cache compression, inverse-RoPE quantization, and partial-state kernels.
- Migrated common Triton indexer and sparse-attention kernels.
- Defined kernel-owned compile keys and AST-traced warmup spaces.
- Added compile-only paths without dummy kernel launches.
- Added tests comparing dispatch results with pre-migration specialization logic.
