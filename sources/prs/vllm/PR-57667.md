## Purpose

Mixed prefill batches can pass an offset view of the candidate expansion's `end` buffer after warmup used an aligned pointer. Triton specializes on that alignment and JIT-compiles another kernel during serving.

Disable alignment specialization for `end_ptr`: each program stores one scalar, so alignment does not enable vectorized stores. Extend the existing reference tests to cover both aligned and offset output buffers, including strided outputs and untouched padding. Candidate selection, ordering and bounds are unchanged.

Extracted from #57643 at the author's request; the fix and tests are removed from that PR. This targets `main` independently of the all-reduce/mHC changes. Open-PR searches for `end_ptr`, sparse candidate alignment and sparse-indexer warmup found no other PR addressing this specialization; #57206 changes prefill selector dispatch instead.
