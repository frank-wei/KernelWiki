## Purpose

Mamba prefix caching currently splits a prefill at the last block boundary

Let's use a 8k input as an example

Before

```bash
Model forward (7680 tokens) ->
FlashKDA(7680 tokens) ->
save checkpoint ->
Model forward (320 tokens) ->
FlashKDA(320 tokens)
```

Now

```bash
Model forward (8000 tokens) ->
FlashKDA(7680) ->
save checkpoint ->
FlashKDA(320)
```

This PR helps us avoid a second full-model pass through attention, MoE, routing, and TP collectives.
