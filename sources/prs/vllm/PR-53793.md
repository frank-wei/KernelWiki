## Purpose

Fuse BF16 ReLU2 with static per-tensor FP8 activation quantization for
compatible Nemotron-H MLP down-projections. The Triton producer preserves the
observable BF16 rounding boundary and returns a `QuantizedActivation` through
the generic `maybe_fused_act_quant` interface, allowing the consumer to use its
checkpoint input scale without quantizing twice.

This implements the activation-quantization work tracked by #43501, integrates
with the manual-fusion interface from #51415, and uses the consumer contract
from #44260. It supersedes closed draft #53791, which was an environment-gated,
model-local prototype. No other open PR found in the duplicate-work search
implements this ReLU2-to-static-FP8 producer/consumer path.

The final dispatch is capability-driven:

- Nemotron-H MLPs call `maybe_fused_act_quant` unconditionally; unsupported
  inputs fall back to the existing ReLU2 path.
- The producer is registered only on CUDA SM90+ for consumers advertising
  `kFp8StaticTensorSym`.
- Its support predicate requires a contiguous BF16 CUDA input and a scalar
  FP32 `input_scale` on the same device.
