## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`ops.swap_blocks_batch` crashes with `cuMemcpyBatchAsync failed at index 0 with error 1`
(`CUDA_ERROR_INVALID_VALUE`) on the legacy default stream — `cuMemcpyBatchAsync` rejects it
(handle `0` / `CU_STREAM_LEGACY`); per-thread-default and real streams are fine.

Reproduced on H100 / CUDA 13.0 (driver 580.105.08): the legacy default stream triggers the
error and a non-default stream succeeds through the same op.

Fixes #46345
