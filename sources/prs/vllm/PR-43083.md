## Test Plan

Evals and E2E benchmarks with the generated tuned configs.

Generate configs for Nemotron-3-Super (will also be used by Nemotron-3-Nano):

```bash
python3 -m benchmarks.kernels.benchmark_selective_state_update \
--ngroups 8 \
--headdim 64 \
--dstate 128 \
--nheads 8 16 32 64 128 256 \
--mamba-ssm-cache-dtype float32 \
--compare --validate --save-configs
```
