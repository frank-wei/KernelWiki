## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Adds `LongcatFlashNgramForCausalLM`, the n-gram-embedding variant of LongCat-Flash, as a Model-Runner-V2 model. The n-gram input layer's per-request token history is isolated in a `ModelState` (rather than threaded through the shared runner, as the abandoned #33611 attempt did), and the n-gram id hashing runs in a small CUDA kernel adapted from SGLang. The model auto-selects the V2 runner and a no-compile + FULL-cudagraph config, so it deploys from a bare `vllm serve` with no extra flags. This also fixes a latent MLA-scale double-bake in the shared `longcat_flash` weight loader.

Validated on `meituan-longcat/LongCat-Flash-Lite` (bf16, TP4): GSM8K 5-shot ~84% with 0% invalid across eager and cudagraph (incl. chunked prefill); MTP works. Not a duplicate — #46623 is LongCat-Next (a different multimodal model) and #33611 was abandoned. Developed with AI assistance.
