## Summary

- load four packed sparse-MLA mask words with one aligned 128-bit load
- retain four-word padding in mask row views so vector loads remain aligned
- preserve the reserved key-offset word instead of slicing it out of returned mask views

## Performance

Kernel-only FA4 benchmarks on an NVIDIA B200, using BF16, 8 heads, QK head dimension 192, value head dimension 128, `num_splits=1`, and an all-ones mask:

| Q x KV | Unmasked baseline | 32-bit mask | Overhead | 128-bit mask | Overhead |
| --- | ---: | ---: | ---: | ---: | ---: |
| 256 x 2,048 | 0.0339 ms | 0.0530 ms | +56.2% | 0.0410 ms | +21.1% |
| 1,024 x 8,192 | 0.1049 ms | 0.1956 ms | +86.4% | 0.1439 ms | +37.2% |
| 4,096 x 32,768 | 0.5595 ms | 0.8597 ms | +53.7% | 0.6592 ms | +17.8% |

An arbitrary packed-mask comparison between the old 32-bit callback and the new 128-bit callback produced exactly matching outputs.
