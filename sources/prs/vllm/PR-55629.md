## Purpose

DeepEncoder relative attention currently expands decomposed height and width
terms into a dense `[B, heads, HW, HW]` bias before SDPA. Its 64x64 global
attention therefore materializes a 384 MiB BF16 temporary.

This PR adds a dedicated Triton forward kernel that evaluates both relative
terms while streaming key/value tiles through online softmax:

```text
before: rel_h + rel_w -> dense 4D bias -> SDPA
after:  compact rel_h/rel_w -> fused Triton attention
```

The Triton path is limited to the production DeepEncoder global-attention
configuration on CUDA: FP16/BF16 with head dimension 64. Window attention,
CPU, unsupported dtypes, and unsupported head dimensions retain the existing
SDPA path. The implementation does not use FlexAttention or `torch.compile`.
