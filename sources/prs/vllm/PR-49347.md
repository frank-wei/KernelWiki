## Purpose

This PR adds online MXFP4 linear/MOE quantization support.

This lets users pass `--quantization mxfp4` (or `--quantization online --quantization-config '{"linear": "mxfp4", "moe": "mxfp4"}'`) on an unquantized (bf16/fp16) model directly.

This PR also implements a Triton fallback path (`downcast_to_mxfp` in `mxfp4_utils.py`) for MXFP4 dynamic quantization, and a single `mxfp4_quantize` functions that gathers XPU/AITER/triton fallback.
