## Overview

Follow-up to #58997. Removes what was left of `mamba_cache_mode="all"` and deprecates `--mamba-cache-mode`, which no longer has any effect.

## Changes

- **KV cache manager:** `MambaManager` asserts that prefix caching runs only with `mamba_cache_mode="align"`. A `"none"` group under a caching manager used to silently run all-mode dense caching. Production never pairs them: `MambaModelConfig` ties `"align"` to prefix caching on and `"none"` to off.
- **CLI:** deprecated `--mamba-cache-mode`. `MambaModelConfig` already overwrote any user value (`"align"` iff prefix caching is on), so the flag is now ignored with a warning and will be removed in v0.33.0. ReplaySSM/RecoverSSM errors, config docstrings, docs, CI configs and e2e tests now refer to prefix caching instead of the flag.
- **Kernels:** dropped the APC per-block state inputs from Triton `causal_conv1d_fn` / `causal_conv1d_update`. No caller used them, and the non-APC path is unchanged. XPU is untouched.
