## Summary

Fix two independent release-v2 wheel-build failures:

- Pin CUDA 12's `nvidia-nccl-cu12` to NCCL 2.30.7 in both the DeepEP wheel-build stage and final runtime image stage.
- Guard Kimi K3's BF16 conversion paths for CUDA host and pre-Ampere compilation, and reject BF16 Kimi fused-MLA launches below SM80 rather than silently skipping work.

## Root causes

DeepEP `d4f41e4e93` uses NCCL GIN APIs that require NCCL >= 2.30.4. The prior CUDA-version guard only activated the 2.30.7 `UV_OVERRIDE` for CUDA 13+, so CUDA 12.9 release jobs resolved Torch's older NCCL and failed with missing `ncclGinRequest_t` and `ginTrafficClass` symbols.

The Kimi K3 merge added direct `_typeConvert<BFloat16>` member access without the existing pre-Ampere compile guard. CUDA 13's x86 wheel build also compiles SM75 and a host pass, where that specialization is intentionally unavailable, causing compilation to fail before packaging.

## Duplicate-work check

No open PR was found for the CUDA 12.9 DeepEP/NCCL compatibility fix. The Kimi K3 implementation PR #50000 does not modify the failed fused MLA kernel; no open PR was found for this CUDA compile repair.
