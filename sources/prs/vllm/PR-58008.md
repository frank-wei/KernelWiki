## Purpose

The existing kernel is implemented in pytorch and leads to **18** elementwise kernel launched per forward. We replace it with a single triton kernel.

**Perf: -5% ITL, +3-5% out tok/s**

## What it does

GLM-5.3-Flash's indexer selects `topk + kpool_tail` tokens, where the tail size is <kpool=4 and depends on the number of tokens in the request. AITER expects a fixed topk value independent of request length. Hence we use `fit_kpool_indices_to_aiter` to select the a fixed topk tokens from history and tail respectively, and disregard any extras.

The kernel prioritizes selecting the tokens from the tail, and then selects the highest prio tokens from the history, until topk tokens are chosen.
