## What's New

Three commits: engram DP sharding (from #56230) plus two engram
embedding I/O improvements for DeepSeek V4.1:

**0. DP sharding for engram tables (previously #56230).** Engram tables
are sharded across a node-local engram DP (EDP) group instead of being
fully replicated per DP rank; per-step all_gathers trade tokens for
heads so each rank can serve its local shard. Set
`--engram-config.enable_engram_dp_sharding false` to retain TP-only tables
(default: true). This is independent of `embedding_across_dp`; explicitly
enabled DP shared memory still uses a node-local group. Qwen4Exp keeps using
its existing ETP group and does not create an extra EDP group. Row-wise
sharding for configurations with too few hash heads remains a TODO.
