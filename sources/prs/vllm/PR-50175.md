## Description

This PR migrates generic MLA metadata and indexing kernels to the shared JIT warmup contract.

## What Changed

- Migrated sparse-MLA metadata and index-conversion kernels.
- Migrated prefill chunk metadata and top-k/SWA combination kernels.
- Added shared compile-only CuTeDSL support using fake tensor descriptors.
- Replaced external representative-shape loops with kernel-owned traced dispatch spaces.
- Registered only the warmup providers selected by the active backend.
- Added dispatch-equivalence and warmup infrastructure tests.
