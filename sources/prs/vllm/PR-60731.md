## Overview

This PR ports the DeepSeek-V4.1-Flash mono decode kernels of #60397 to gfx942 (MI300X and MI325X). A standard decoder layer then runs as 2 kernels instead of 32. The path is opt-in with `--monokernel`, as on gfx950.

The PR was rebased onto `main` after #61082 as one commit. The commits after it merge `main` and answer the second review (see Details). gfx942 now runs the same layers whole as gfx950, with the switch of #61082 (see Details). The latest commits take the PR out of shared code, as RFC #60904 asks, and merge `main` with #62131 (see Details). The AgentX and GSM8K comparisons below are from 67206b7 and the commits before it, when the switch was `VLLM_ROCM_MONO_DECODE=1`. The checks of the latest commits are at the end of Validation.

## Claims

MI325X, TP4, DSpark with 5 drafts. Each AgentX run is 3,600 s and is scored with InferenceX's own result code.

- AgentX at concurrency 1, against `main`: interactivity P50 goes from **216.85 to 503.53 tokens/s/user** (2.32×), P90 from **182.25 to 411.26** (2.26×), and total throughput per GPU from 4,024 to 6,546 tokens/s (1.63×).
