## Summary

#51674 added fused GDN MTP verification for `HV/H=8`. An audit of public Qwen
GDN configs found production ratios `1/2/3/4/8`, from Qwen3.5 0.8B/2B through
Qwen3.6 27B/35B and Qwen3.8 2.4T.

This PR:

- makes the value-head ratio a compile-time kernel parameter and dispatches
  exact ratios `1/2/3/4/8`;
- enables the same ratios in the Qwen GDN guard, with an exact-divisibility
  check;
- preserves the six original ratio-8 cases and adds focused production-ratio
  and unsupported-ratio coverage.

There is no operator ABI or build-system change. An open-PR search found no
other implementation for these ratios.
