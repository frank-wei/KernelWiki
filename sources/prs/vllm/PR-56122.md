## Dual-key Gumbel-max
### Purpose
Text watermarking in vLLM (see https://github.com/vllm-project/vllm/pull/54053) currently is not compatible with speculative decoding. This PR proposes multiple changes to resolve this:

- `"allow_target_only_watermarking": true` allows the use of speculative decoding with watermarking, but will not watermark accepted draft tokens: this will dilute the watermarking signal in proportion to the share of output tokens that are accepted drafts
- `dual_key_gumbel` algorithm is a variation of the Gumbel-max algorithm, where we use different keys to watermark our generations: this allows for watermarking of draft tokens, and also for improved diversity of outputs when using watermarking

Dual-key watermarking allows to support speculative decoding by using algorithm 6 of [SynthID-Text's supplementary material](https://media.springernature.com/original/springer-static/esm/art%3A10.1
