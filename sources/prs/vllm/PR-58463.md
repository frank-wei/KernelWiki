## Context
https://github.com/vllm-project/vllm/pull/46849 added the infrastructure to fuse last N-1 draft steps into a single cudagraph for models with attention backends that support it. Currently DeepSeek V4 satisfies the conditions to enable this, when using MTP > 1.

## This PR
It turns out we can remove the first attention metadata build before drafting the last N-1 speculative tokens in a fused loop. In this PR, I make the necessary changes to `DeepseekSparseSWAMetadataBuilder.update_draft_decode_metadata` and refactor `AutoRegressiveSpeculator` so that the first draft metadata build can be safely skipped during FULL cudagraph replay.

With these changes, DSV4 + MTP no longer rebuilds metadata during proposal, resulting in a correctness-preserving removal of about 1ms of host work per decode step. No significant throughput improvement was observed from these changes.
