## Upstream PR description (verbatim excerpt)

### Two changes to the compressed-tensors W8A8 INT8 linear path.

1. Tensor-descriptor operand loads for `scaled_mm_kernel`
2. Enables that path on XPU at all.

### Per-kernel microbenchmark:

B70, int8 in / bf16 out, device self-time via torch.profiler: TD reduces self-time by 89-99% across M in {1, 64, 256} and K=N in {4096, 8192}, with max|plain - TD| = 0.0.

### Accuracy

gsm8k, 5-shot, n=200:

| | flexible-extract | strict-match |
| --- | --- | --- |
| TD off | 0.800 +/- 0.028 | 0.720 +/- 0.032 |
| TD on | 0.790 +/- 0.029 | 0.710 +/- 0.032 |

Both match the checkpoint's expected gsm8k range, which also confirms the new XPU dispatch path is numerically fine.

### Performance

1x Arc Pro B70, `neuralmagic/Meta-Llama-3.1-8B-Instruct-quantized.w8a8`, `--linear-backend triton --enforce-eager --no-enable-prefix-caching`, seed 42, `random` 1024-in/128-out. Only `VLLM_TRITON_USE_TD` differs between arms; 500/30/60 requests completed, 0 failed.

| | TD off | TD on | delta |
| --- | --- | --- | --- |
| saturation output tok/s | 32.93 | 78.93 | +139.7% |
| saturation median TTFT | 956.5 s | 402.6 s | -57.9% |
| saturation median TPOT | 3318 ms | 1406 ms | -57.6% |
| concurrency 1 median
