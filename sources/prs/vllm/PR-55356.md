## Purpose

Group fp8 mla cahche insertion

Before:

```bash
CUDA launch 1：layer 0
CUDA launch 2：layer 1
CUDA launch 3：layer 2
CUDA launch 4：layer 3
CUDA launch 5：layer 4
```

Now
```bash
One grouped kernel launch
  ├─ token 0, layer 0
  ├─ token 0, layer 1
  ├─ ...
  └─ ...
```

So basically combining 5 layers together, saving a lot of launch time
