## Overview



Fix out-of-bounds lookahead in adaptive block verification

## Claims

The original `_compute_local_residual_mass_kernel` uses the configured maximum number of speculative steps to determine whether it has reached the end. However, with adaptive verification enabled, the actual verification block may be shorter. For example, 5 steps may be configured, but only 3 steps are actually verified.
