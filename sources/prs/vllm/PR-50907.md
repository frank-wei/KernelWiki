## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
- Remove ROCm-wide Math SDPA forcing from Transformers multimodal execution and affected test conftests.
- Remove blanket skinny GEMM disable overrides while retaining independent backend and determinism settings.
- Make non-contiguous skinny GEMM activations contiguous and fall back safely for unsupported weight or bias layouts.
- Use default speech attention on MI250 while retaining supported AITER routing on CDNA3+ hardware.
- Keep embedding reference comparisons aligned with the server's per-request execution geometry.

This addresses [#37736](https://github.com/vllm-project/vllm/issues/37736), where stale ROCm Math SDPA forcing made the 32-image Gemma3 profiling forward OOM on MI250. With default SDPA selection, the same profile completes while preserving model behavior. Removing blanket skinny GEMM disables exposed a non-contiguous activation bug in the ROCm GEMM dispatcher, which is fixed by normalizing supported inputs and falling back for unsupported operand layouts. Broad multimodal and targeted ROCm validation passed, with unrelated model-access and optional-dependency failures classified separately.
<!-- upstream-excerpt-end -->
