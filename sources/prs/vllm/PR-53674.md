## Purpose

Fixes #53668.

The MiniMax-M3 ROCm fused SwiGLU + MXFP8 activation quantizer now derives its E8M0 block scale with the same E4M3 finite range and float32 tiny-value floor as the shared MXFP8 reference. This fixes mixed-magnitude blocks that otherwise underflow small activation values, and preserves the reference scale for empty blocks.

## Duplicate-work check

Searched open issues and PRs for `swiglu_oai_quantize_mxfp8`, `_swiglu_oai_quant_kernel`, `swiglu MXFP8`, and the block-scale formula. No open change addresses this fused MiniMax-M3 implementation. #53110 fixed the separate generic ROCm quantizer; this PR applies the same established behavior to the omitted fused kernel.
