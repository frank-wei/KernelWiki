## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR expands Humming quantization support and integrates a unified input processing kernel.

#### 1. Hadamard transforms for online quantization

Enable Hadamard transforms by setting `hadamard_block_size` in `VLLM_HUMMING_ONLINE_QUANT_CONFIG`.

#### 2. SM120/SM121 support

Add support for NVFP4, MXFP4, and MXFP8, including the non-public `float4e0m3` and `float8e3m4` data types, see https://github.com/vllm-project/humming/pull/41 .

#### 3. Additional input quantization modes

Support `static_per_tensor`, `static_tensor_dynamic_group`, and `dynamic_group_tensor`. The latter two primarily serve NVFP4 quantization.

#### 4. Checkpoint quantization and input schema fallback

Honor checkpoint input quantization settings and automatically fall back to a higher-precision input schema when the device does not support the configured activation quantization type.

To retain the original WNA16 behavior, set:

```bash
export VLLM_HUMMING_INPUT_QUANT_CONFIG='{"dtype":"bfloat16"}'
```

Input schemas explicitly specified through `VLLM_HUMMING_INPUT_QUANT_CONFIG` disable fallback by default. Unsupported configurations raise an error unless `"allow_fallback": true` is explicitly specified.
