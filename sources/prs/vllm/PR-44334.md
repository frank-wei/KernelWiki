## Purpose
Continues the libtorch stable ABI migration by moving several kernels out of legacy _C and into _C_stable_libtorch.

**Ops migrated**
- `get_cuda_view_from_cpu_tensor` — CPU pinned/UVA tensor → CUDA view; uses a version-guarded `deleter` supported for 2.11 and 2.10 fallback copies to device.
- `silu_and_mul_per_block_quant` — fused SiLU+Mul + per-block FP8/INT8 quant;
- Removed cuda_utils_kernels.cu and cutlass_extensions/common.cpp from VLLM_EXT_SRC (_C build) in CMakeLists.txt (they where built in both `_C` and `_C_stable_libtorch`) and moved them to the libtorch_stable directory.
- Moved cutlass_extensions/common.hpp to libtorch_stable. This required a lot of the header paths to be updated.


cc @janeyx99 @Harry-Chen


**Note:** because of the lack of support in torch 2.10 for the version-guarded `deleter` in `get_cuda_view_from_cpu_tensor`, there were many updates to the file `cuda_view.cu` causing GitHub to treat is as a deleted/created file instead of a moved file. To check the diffs, look at this commit: https://github.com/vllm-project/vllm/pull/44334/changes/3c7c0b33b17c6f332eeaec66615dd520e44bb7d5#diff-8990e80917fbfbd159c47896ec7e9eed8517b32ae6fe0e8fd6b9acec3583
