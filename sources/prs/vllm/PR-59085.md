## Purpose

This PR upstreams work from the patch set of the MiMo recipe we deploy — Diffbot's MiMo-V2.6-Flash-RL FP8KV/W4A8 recipe (Hugging Face: diffbot/MiMo-V2.6-Flash-RL-FP8KV-W4A8-2x-RTX-PRO-6000, built by Mike Tung): the idea and the original implementation belong to its authors, not to us. Their version of this change is the recipe's `triton_unified_attention_diffkv.py` patch — the same file #59054 links, which also carries an independent copy; we re-derived the diff against upstream main, wrote the tests, and ran the checks.

Fixes #59054.
