## Purpose

DFlash (and any speculative method that drafts many tokens) crashes the V1
engine at startup on the Model Runner V2 path:

```
RuntimeError: Triton Error [CUDA]: an illegal memory access was encountered
  ... vllm/v1/worker/gpu/warmup.py  worker_sample_tokens(None)
```

Minimal repro (current main, single H200):

```python
from vllm import LLM, SamplingParams
llm = LLM(
    model="Qwen/Qwen3-8B",
    speculative_config={"method": "dflash",
                        "model": "z-lab/Qwen3-8B-DFlash-b16",
                        "num_speculative_tokens": 15},
    max_model_len=2048, dtype="bfloat16",
)
llm.generate(["Hi"], SamplingParams(temperature=0, max_tokens=16))
```

**Root cause.** The MRV2 sampler and rejection-sampling Triton kernels address
the logits tensor with a per-row offset `row * vocab_size`, computed in **int32**
(`tl.program_id` and loaded indices are int32, so `int32 * int32 -> int32`).

for large `K` the element count `num_tokens * vocab_size` exceeds `2**31`
