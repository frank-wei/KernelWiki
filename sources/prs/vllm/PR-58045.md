## Purpose

Optimize the active ROCm Kimi-K3 `fused_recurrent_kda_fwd_kernel` for
low-concurrency speculative decoding on MI355X.

The shipped gated configuration uses `BV=32`, `num_warps=4`, and
`num_stages=2`. With Kimi-K3 TP8 (`H=12`, `V=128`) at concurrency 1, this
launches only 48 workgroups for a four-token verification step on a 256-CU
MI355X. This change increases grid parallelism and removes recurrent-loop
runtime work when speculative requests have a uniform query length.

## Changes

- Select narrower V tiles from the number of head-sequences (`H * N`):
  - at most 24: `BV=4`, one warp;
  - 25-96: `BV=8`, one warp;
  - larger multi-sequence grids retain the dynamic path.
- Specialize equal-length speculative batches with a constexpr sequence length.
  C=1 additionally avoids sequence/head division and `cu_seqlens` loads.
- Detect uniform speculative query lengths from existing CPU metadata. Ragged
  batches retain the original dynamic loop. Token-padded graph inputs are
  checked against the packed tensor size before specialization.
- Tune pipeline stages by sequence length: 2 for T=1, 4/8 for T<=3, 6 for
  T<=6, 10 for T<=10, and 12 for longer specialized loops.
- Hoist
