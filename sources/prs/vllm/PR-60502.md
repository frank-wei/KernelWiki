## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Triton main removed tl.make_block_ptr/tl.advance (triton-lang/triton#10833), breaking compilation of the FLA-vendored and KDA-derived kernels with 'Block pointers have been removed in favor of the tensor descriptor API' (pytorch/test-infra#9017).

Following upstream flash-linear-attention#1062, this replaces every block-pointer use with explicit pointer arithmetic plus masked tl.load/tl.store. Block pointers already lowered to plain vectorized loads (not TMA), so this is behavior- and performance-equivalent by construction and keeps all vLLM backends green, unlike a tensor-descriptor migration, which TMA constraints (16B base alignment, inner stride 1, no transposed blocks) rule out for several kernels here.

I should note that if every backend can conform to the TensorDescriptor API (which AMD + Nvidia both have example fallbacks for on hardware without TMA/TDM) then the TensorDescriptor API could be used here. However, I didn't add this because also I assume additional testing is needed to test such hardware migrations.

Note: This is drafted with AI assistance (muse code).
