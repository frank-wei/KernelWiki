## Purpose
For pure prefills, there is a threshold of sequence length below which a masked MHA pathway is faster than sparse MQA. The [DeepSeek V3.2 paper mentions](https://arxiv.org/abs/2512.02556) this:

> Note that for short-sequence prefilling, we specially implement a masked MHA mode to
simulate DSA, which can achieve higher efficiency under short-context conditions.

https://github.com/vllm-project/vllm/pull/47327 implemented a dense MHA shortcut for when `seq_len < topk`. This PR extends that optimization by implementing the masked MHA pathway.
