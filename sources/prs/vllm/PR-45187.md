## Purpose

Add `nvfp4_4over6` as an optional KV cache dtype for NVFP4 KV cache stores.

The existing `nvfp4` behavior is unchanged. Enable 4-over-6 scale search with:

```bash
vllm serve <model> --kv-cache-dtype nvfp4_4over6
```

For each 16-element NVFP4 group, `nvfp4_4over6` evaluates scales derived from
`max / 6` and `max / 4`, then stores the candidate with lower reconstruction
error. The physical cache layout and capacity remain NVFP4; the existing NVFP4
attention read path is reused.

## Test Plan

```bash
pytest -q tests/utils_/test_torch_utils.py -k nvfp4_4over6
pytest -q tests/kernels/attention/test_attention_selector.py -k nvfp4_4over6
pytest -q tests/kernels/attention/test_cache.py -k nvfp4_4over6
```

Qwen3-8B evaluations used TP=4 with CUDA graphs enabled on 4x B200 GPUs.

| KV cache | AIME25 | AIME infer time | AIME output tok/s | LCB pass@1 | LCB infer time | LCB output tok/s |
|---|---:|---:|---:|---:|---:|---:|
| BF16 | 66.67% | 1476.7s | 12.3k | 54.85% | 1450.3s | 13.2k |
| `nvfp4` | 64.12% | 977.6s | 20.0k | 52.42% | 937.8s | 21.0k |
| `nvfp4_4over6` | 64.71% | 974.6s | 19.4k | 53.74% | 981.4s | 20.1k |
