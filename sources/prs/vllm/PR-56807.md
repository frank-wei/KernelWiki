## Purpose

Extend generation-side watermark context deduplication to speculative decoding.

- Build target verification contexts from committed and proposed draft tokens.
- Detect repeated contexts in committed history and earlier positions of the same speculative block while respecting `deduplicate_contexts_max_history`.
- Use the ordinary draft proposal at repeated contexts before running the unchanged acceptance test.
- Use the ordinary draw from the existing residual or target distribution for repeated rejection-recovery and bonus contexts.
- Leave disabled and greedy requests on their existing paths.
- Fuse committed-history and speculative-local context checks to avoid launch-heavy PyTorch bookkeeping.
- Fuse ordinary and watermarked draft sampling into one vocabulary reduction while preserving the pre-temperature draft-logit cache.

This keeps the standard `min(1, q/p)` acceptance rule and does not force rejection at repeated contexts.
