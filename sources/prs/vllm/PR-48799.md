## Purpose

Adds the core vLLM model and frontend support for `thinkingmachines/Inkling`, including the public `thinkingmachines/Inkling-NVFP4` checkpoint.

This is the first independently mergeable slice of #48768. It keeps the model implementation under `vllm/models/inkling` and includes the tokenizer, renderer, reasoning/tool parsers, model registry entries, tests, and the Python-only FA4 dependency needed to serve it. The remaining umbrella work will be split into follow-up PRs after this lands.

This slice explicitly excludes:

- LoRA support
- MTP/speculative decoding
- piecewise CUDA graphs

`FULL_DECODE_ONLY` CUDA graph mode is supported.

The FA4 dependency is installed under `vllm.third_party.tml_fa4` to keep it isolated from the normal `flash_attn` package. It is pinned to [vllm-project/tml-fa4@13374f0c](https://github.com/vllm-project/tml-fa4/commit/13374f0c855acc1add1bf30444bd67aebbc24a8e), which provides the pre-Blackwell compile and execution argument lists. Inkling also forces `num_splits=1` on Hopper because split-KV is supported only on SM100+ in this FA4 path.
