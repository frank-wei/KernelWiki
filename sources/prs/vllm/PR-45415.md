## Purpose
This PR continues the libtorch stable ABI migration (see https://github.com/vllm-project/vllm/issues/26946) for vLLM and is the final `_C` library kernels to move to the `_C_stable_libtorch` library. The PR moves `csrc/quantization/activation_kernels.cu` to `csrc/libtorch_stable/quantization/activation_kernels.cu`, along with the `weak_ref_tensor` (defined in ops.h), `silu_and_mul_quant`, and `persistent_masked_m_silu_mul_quant` kernels.
