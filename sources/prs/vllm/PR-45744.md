## Purpose

Reland of #45680 after M3 is merged

Add support for FP8 sparse GQA on NVIDIA
- Q is not quantized, only KV is
- Update the fused QKNorm+RoPE+insert to support FP8 KV cache
- Prefill kernel: MSA for sm100, Triton otherwise
- Decode kernel: Triton

Note: `--attention-backend TRITON_ATTN` must be used since `FLASH_ATTN` doesn't support FP8 KV cache, and FlashInfer FP8 doesn't support page size 128

```
          vllm serve {model} --port {port}
          -tp 4 -ep
          --block-size 128
          --max-model-len 128000
          --compilation-config '{"custom_ops":["all"]}'
          --kv-cache-dtype fp8
          --attention-config '{"backend":"FLASHINFER","use_trtllm_attention":true}'
          --speculative-config '{"method":"eagle3","model":"Inferact/MiniMax-M3-EAGLE3","num_speculative_tokens":3,"attention_backend":"TRITON_ATTN"}'
```

Note: FlashInfer trtllm-gen does not support Eagle3 MHA, so we need to use triton for it
