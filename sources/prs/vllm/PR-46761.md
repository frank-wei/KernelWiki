# Context
Currently in `DFlashQwen3Model` during `precompute_and_store_context_kv` we invoke `rms_norm` for each layer in a loop, resulting in multiple kernel launches. This is done because rms_norm only supports broadcasting the single `[hidden_size]` weights to all rows of the input.

<img width="1861" height="388" alt="image" src="https://github.com/user-attachments/assets/4c5d3040-c990-4cd9-bb65-f5e66c598d7d" />


# This PR
Adds support to `rms_norm` for passing in a weight of shape `[num_rows, hidden_size]`, which enables applying a different weight row to each input row. Using this new feature, we can perform the rms norm at the beginning of `precompute_and_store_context_kv` using a single kernel launch. This improves the CPU time:

<img width="1754" height="380" alt="image" src="https://github.com/user-attachments/assets/1070f0f0-613d-41bd-b170-231c06c5ab94" />
