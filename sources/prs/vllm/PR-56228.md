Split out from #56214 — this PR includes **only** the changes under `vllm/models/`:

- Adds the new `vllm/models/deepseek_v4_1/` model definition package (nvidia, amd, and common code paths)
- Includes the associated modifications to `vllm/models/deepseek_v4/`

All other changes from #56214 (kernels, rust parser, config, tests, etc.) are intentionally excluded.

**Non-duplication:** This is not a competing implementation — it is a scoped subset of #56214 (same author group), split out so the model definitions can be reviewed independently.
