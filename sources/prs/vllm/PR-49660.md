## Purpose
Fixes #42860.

Several kernels in `csrc/libtorch_stable/activation_kernels.cu` calculate pointer offsets using expressions such as:
```cpp
blockIdx.x * d
blockIdx.x * 2 * d
```
Because `blockIdx.x` and `d` participate in 32-bit arithmetic, these expressions can wrap when processing sufficiently large numbers of tokens and hidden dimensions. The resulting incorrect pointer offsets may cause the kernels to access unintended memory.

This PR converts blockIdx.x to an int64_t value before performing the offset calculations:
```
const int64_t token_idx = blockIdx.x;
```

The change is applied to:
- act_and_mul_kernel
- act_and_mul_kernel_with_param
- activation_kernel

This preserves the existing behavior for normal workloads while ensuring that pointer offsets are calculated using 64-bit arithmetic for large workloads.

PR #44026 previously proposed a fix for the same issue. However, it currently has merge conflicts and is marked needs-rebase. This PR reapplies the fix on top of the latest main branch and serves as an updated replacement for #44026.
