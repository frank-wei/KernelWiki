## Purpose

Fixes #57653.

DeepSeek V4.1 fails to import when Triton is unavailable. `sparse_mqa_logits.py` calls `tl.constexpr` at import time, but vLLM's fallback sets it to `None`. This blocks model inspection and causes the MI250 processor tests to fail on main.

Make the placeholder's `constexpr` return its input. This allows modules to define constants without Triton. The real Triton implementation stays unchanged. The existing placeholder tests now cover integer and float values, so no model-specific test or guard is needed.

The error was [reported in #56254](https://github.com/vllm-project/vllm/pull/56254#issuecomment-5644796189). I found no other open PR for this fix.
