## Overview

**Upstream full-model evaluation pending.**

Fix RecoverSSM align-mode final-state indexing at exact Mamba block boundaries in both the KDA commit planner and V2 postprocessing. Fixes #59933.

## Claims

- At an exact boundary, commit and record the state for the block containing the last accepted token, rather than advancing to the next block.
- Retain the zero-length clamp and block-table upper bound; leave non-align behavior unchanged.
- Extend existing numeric-reference and mixed-batch CUDA tests to cover boundary neighbors, request remapping, and first/second exact boundaries.
