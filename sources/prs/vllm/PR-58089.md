## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
- Compute the finite reciprocal block scale in the fused MiniMax-M3 SwiGLU/MXFP8 kernel.
- Multiply by that reciprocal to avoid `0/0` when the byte-zero E8M0 divisor flushes to zero on CDNA, while preserving the encoded scale bytes.
- Reuse the existing mixed-magnitude/zero-block regression and the full AMD MiniMax kernel suite.

The MI355 parity run exposed NaNs in an all-zero activation block. Merged #53674 corrected the fused kernel’s scale formula but retained division by the decoded scale. The generic quantizer already uses reciprocal multiplication from merged #53110, and this change applies the same arithmetic to the fused path. Fresh searches and the related PR review found no open change covering this remaining fused-kernel defect.

AI assistance: OpenAI Codex assisted with diagnosis, implementation and validation.
