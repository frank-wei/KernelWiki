## Summary

### CuTe DSL skinny GEMM

- Add an optional compile-time `K` specialization to the existing CuTe DSL
  skinny GEMM.
- On the static-`K` path, use a compile-time K-tile loop and prefetch the first
  two B tiles before the PDL wait.
- Convert each loaded A/B register tile to FP32 once before FP32 accumulation.
- Keep the existing dynamic-`K` path used by Kimi-K3 unchanged.

### GLM-5.2 mapping

- Extend the existing GLM-5.2 decode selection to use CuTe DSL for the skinny
  cases while retaining DSV3 and the original linear fallback:
  - `qkv_a` and `q_b`: CuTe DSL for M=1-2, DSV3 for M=3-16, original linear
    otherwise.
  - MTP `eh`: CuTe DSL for M=1-3, original `nn.Linear` otherwise.
- Add the GLM-5.2 DSV3 specializations for `qkv_a` and `q_b`.
- Enable the mapping only for `glm_moe_dsa`, unquantized BF16, and exact SM103.
- Preserve the original projection modules, weights, and state-dict layout.

This does not duplicate another open PR. It builds on the Kimi-K3 CuTe DSL
infrastructure added to `main` by #50089 and extends it to GLM-5.2.
