## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Follow-up to #19217. Align CUTLASS MoE activation handling and shared kernel tests with the selected implementation. Preserve public activation IDs and apply SwiGLU clamp limits when either neutral alpha/beta parameter is omitted. Initialize capture-local defaults safely, including when the first forward is captured and an eager forward runs before replay.

Backend selection rejects unsupported activation, quantization, scaling, clamping, and LoRA combinations before execution. These capability checks also cover B12x NVFP4 prefill when it uses CUTLASS. Selection and execution share one prefill-routing predicate, and rejections identify the candidate and execution path. Communication auto-selection falls back to AllGather/ReduceScatter when all-to-all is unsupported; explicitly forced incompatible methods fail before strategy allocation. Keep construction validation as a backstop and release communication resources on validation failures.
