Bug: https://nvbugs/6545424

Qwen3.5 disabled its fused QK normalization, RoPE, and gate preprocessing while torch.compile was active because the Triton launcher was visible to Dynamo. The token-major gated RMSNorm path had the same issue, and compile functionalization introduced copies around raw Triton calls. These fallbacks increased piecewise CUDA graph TTFT for long-context serving.

Register the fused QKV preprocessing as a functional custom op with a fake implementation, while retaining a small schema adapter for optional MRoPE sections. Enable the fused path during compilation and expose output gating as a mutating custom op that updates the terminal attention buffer in place.

Register token-major gated RMSNorm as a functional custom op that allocates fresh output storage internally. Avoid allocating and writing the unused reciprocal-standard-deviation buffer in inference. Extend optional inplace metadata for compiled output operators so the remove-copy pass can safely reconnect mutated buffers.

Add coverage for eager and compiled fused QKV/gating, strided gates, BF16/FP16 and MRoPE cases, gated RMSNorm functional schemas and FP8 compilation, and remove-copy/inpl
