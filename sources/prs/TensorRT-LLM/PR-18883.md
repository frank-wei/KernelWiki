## Description

Four changes to the Qwen3.8-Flash-Next decode path. Three remove a kernel launch
from a per-layer seam; one drops the vendored copies of two FlashInfer GEMMs.

1. **QSA split-K merge + output gate** — the gate ran as a separate elementwise
   kernel after the merge; it now runs in the merge epilogue, after the
   log-sum-exp reduction. `Attention` passes `output_gate` to the sparse hook
   instead of gating its return value.
2. **Low-M BF16 GEMMs imported from FlashInfer** — `flashinfer-python==0.6.18`
   is already pinned and exports both kernels, and the vendored copies matched
   upstream. Net −1460 lines; a version bump is now a one-line change.
3. **Router gate and QSA index projection join the low-M race** — the gate was
   missed because its weight is a bare parameter, not a `Linear`; the index
   projection was excluded by a `use_custom_cublas_mm=True` whose NCCL-window
   branch is dead at `tp_size=1`. Both go through the existing AutoTuner race.
4. **Shared-expert finalize deferred to Hyper-Connection** — its sigmoid gate ran
   immediately before HC read the same rows, so one Triton kernel now finalizes,
   combines and normalizes.
