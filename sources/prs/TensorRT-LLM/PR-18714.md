# Features
Six model-agnostic hot-path optimizations, measured on Qwen3.8-Flash-Next shapes on B200/B300 and gated by derived runtime properties.

- Block-scale MoE: removes a 64-bit divide and uses aligned 8-byte packed I/O for FP8 activation (36% faster across intermediate sizes); dynamically sizes BF16 finalize blocks (up to 22% faster across Qwen3.8-Flash-Next, Nemotron-3-Nano/3.5-Lightning, and Qwen3.5-122B); removes a redundant expert-count-zeroing launch.
- Gated RMSNorm: enables PDL when the launch grid underutilizes SMs, improving the kernel by 16–24% below the cutoff.
- Decode host path: directly gathers prior-step tokens into the persistent input buffer and coalesces prompt/KV-length staging (~17 µs saved per forward).
- Sampler: writes end-ID and max-length finish reasons in one Triton program instead of ~10 elementwise kernels (3.8×; ~45 µs saved per step).
- Correctness: guards packed activation on dtype and pointer alignment; fixes a `hiddenDimPerBlock` default that could yield an all-zero MoE output.
