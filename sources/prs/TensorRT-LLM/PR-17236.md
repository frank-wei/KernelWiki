## Description

This PR combines the MiniMax-M3 MSA selector implementation with its context/prefill optimization. It introduces one CUDA selector and then specializes its hot CTX path in two ways:

1. **Fused block selection.** A CUDA custom op replaces separate PyTorch validity masking, forced-block handling, top-k selection, sorting, and padding operations. It returns ascending `int32` block IDs with `-1` padding.
2. **Optimized CTX selector and zero-copy K2Q handoff.** For eligible context workloads with at most 128 allocated candidate blocks, a warp-specialized kernel reduces selector execution time. In pure prefill, the selector can write the head-major layout consumed by K2Q directly, avoiding the intermediate selector output and layout-conversion copy. Larger or otherwise ineligible shapes retain the general selector path.

These are kept together because the CTX optimization directly specializes the selector introduced by this PR and shares its CUDA kernel, Torch custom op, Python registration/routing, and tests.
