## Description

Fuse MiniMax-H3's two AdaLN sites into one Triton kernel each: `norm1` becomes RMSNorm + per-token gathered modulation (`rmsnorm(x)·w·(1+scale[idx]) + shift[idx]`), and `norm2` becomes gated residual + RMSNorm + modulation (`x1 = x + gate[idx]·attn`, then the same modulation on `x1`, returning both). The modulation table is the AdaLN projection output viewed as `[n_t·3, 6·D]`, read in place through the per-token index; no per-token modulation tensors are materialized. The final `x1 + gate_mlp[idx]·ff` stays in the compiled graph.

Per block this replaces two RMSNorm launches and four pointwise kernels with one pass per site. Rounding follows the compiled region: `x1` is formed in FP32 and stored once in BF16 (the eager path rounds the product and the sum separately), the RMSNorm result is rounded to BF16 as the FlashInfer RMSNorm op does, and the modulation is FP32 math with one final rounding. Gated to BF16 and hidden sizes up to 6144; `MiniMaxH3AdaLayerNormModulation.table()` is the single definition of the modulation table's column order, shared by the eager and fused paths. No configuration or public API changes.
