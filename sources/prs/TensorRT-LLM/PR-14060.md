## Description
- Enable disaggregated serving (KV cache transfer) for hybrid mamba models when using CppMambaHybridCacheManager with the C++ transceiver (UCX/MPI), supporting block reuse / prefix caching across attention and mamba layers
- Implement CUDA kernels (rnnCacheSplitConcat.cu) for RNN state split/concat to handle TP-mismatch scenarios between context and generation instances
- Extend cacheFormatter.cpp to format and transfer recurrent states (SSM + conv) alongside KV cache blocks during disagg context-to-generation handoff
- Add _request_id_to_state_index mapping in CppMambaHybridCacheManager to support correct state index lookup when batch order is reordered after prepare_resources (disagg reorders by py_batch_idx)
- Store global (pre-TP-division) RNN model params in LinearAttentionMetadata for C++ side TP-mismatch split/concat logic
- Add validation: raise ValueError when CppMambaHybridCacheManager is used with NIXL backend (unsupported), guiding users to set transceiver_runtime='PYTHON'
- Add integration tests for hybrid mamba disagg serving with block reuse enabled
