## Summary

EAGLE3 one-model **dynamic tree** speculative decoding performance optimizations + correctness fixes.

## Changes

**Perf**
- Pack dynamic tree retrieve into single `[B,N,3]` tensor + optimize slot ID HtoD copies
- `_get_compact_packed_mask_view()` directly writes packed mask in compact 1D layout (eliminates `_repack_mask_padded_to_packed()` overhead)
- Buffer dtype `int64 → int32` for `draft_tokens_buffer` / `position_ids_buffer` / `history_draft_tokens_buffer` / step0 input buffers (eliminates per-layer `.to(int32)` kernels inside CUDA graph)
- Fast path in `compute_spec_dec_packed_mask()` for `num_blocks==1` (dt ≤ 32)
- `torch.compile` fused ops for EAGLE3 dynamic tree
- Extract `DynamicTreeSlotStorage` and optimize slot-indexed read path

**Correctness**
- Fix `position_offsets_stride` for dynamic tree multi-batch correctness
- Fix `position_offsets_query_len` and packed mask width for Hopper vs Blackwell
- Unify packed mask layout for Hopper and Blackwell via `cumSeqLensQ`
- Decouple `position_offsets` query length from buffer stride and fix Hopper mask width
- Fix target model packed mask layout and position_ids for Hopper dynamic tree
- CUDA-graph-safe 1D→2D resh
