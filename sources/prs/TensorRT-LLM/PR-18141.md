## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Compared with the earlier multi-block attention-sink implementation, the fix changes the ownership of the virtual sink token. Previously (#15739), every partial CTA excluded the sink and the last CTA added it only after merging the FP16 partial outputs. The new implementation assigns the sink to CTA0 before partial normalization and removes the final-merge insertion, preserving exactly-once sink accounting while avoiding the numerically sensitive normalize-quantize-rescale sequence. The single-block path and mathematical attention definition remain unchanged.

Additional synchronization fixes protect asynchronous shared-memory reuse and ensure that only the last CTA writes the final output.

On GB10, TOT main reproduced the regression with a 0.68 Eagle3 draft acceptance rate. The complete XQA race and CTA0 attention-sink fix achieved a stable 0.83 acceptance rate.
