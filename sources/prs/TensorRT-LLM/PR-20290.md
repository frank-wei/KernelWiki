## Description

Fix excessive overhead in deterministic GVR V2 top-K, especially at **K=1024 and K=2048**. Follow-up to #20100.

With clustered logits, a few warps receive most of the candidates. Their local buffers can overflow even when the shared buffer has enough total space, triggering an expensive scan of the whole row.

This fix:
- Recovers overflowing candidates in parallel using exact per-warp counts.
- Adds candidate-buffer headroom without changing sampling thresholds.
- Removes unused shared-memory allocations and adjusts buffer sizes to limit memory pressure.

## Measured improvement

At BS=512 and N≈131,000, added cost drops from **208–221 µs to 1.05–2.76 µs**.

Each row compares identical input tensors on the same B200, using **nsys + cold L2**. Overhead is relative to the default-path control in each run.
