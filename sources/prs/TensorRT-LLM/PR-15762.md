- Added a new CUDA fused Adaptive LayerNorm kernel (`fusedAdaptiveLayerNormKernel`) supporting:
  - plain LayerNorm (BF16 output),
  - affine LayerNorm,
  - AdaLN modulation (scale/shift),
  - optional NVFP4 quantization to an `Fp4QuantizedTensor`-style packed FP4 output plus FP4 scale-factor metadata.
- Added the kernel launcher/parameter plumbing via a new C++ header (`AdaptiveLayerNormParams`) and built the corresponding op source into the THOP library.
