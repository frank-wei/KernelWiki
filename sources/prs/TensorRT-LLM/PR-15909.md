## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Add an opt-in nvMatmulHeuristics (https://pypi.org/project/nvidia-matmul-heuristics/) path that ranks/prunes CuTe DSL NVFP4 dense GEMM tactics before the AutoTuner compiles and benchmarks them, cutting autotuner warmup time on SM100/SM103. Gated by TRTLLM_CUTEDSL_NVMMH_ENABLE (default off); the baseline tactic sweep is unchanged when disabled or when the library is unavailable.

Core integration:
- Add tensorrt_llm/_torch/cutedsl_matmul_heuristics.py adapter (optional import, no-op fallback returning the original tactics on any failure/empty result).
- Add TunableRunner.filter_tactics_with_heuristics hook, invoked in AutoTuner._profile_runners after get_valid_tactics, wired into the NVFP4 path.
- Pin nvidia-matmul-heuristics in requirements.txt.

Tactic ranking:
  - _rank_prune_tactics ranks the full get_valid_tactics sweep and, when tile/cluster is selected, keeps only the top-K (tile, cluster, swap) keys that already exist in the valid list, re-validating before emission — a strict subset that never introduces a candidate the kernel validator rejected.
  - TRTLLM_CUTEDSL_NVMMH_FIELDS selects the model-driven knobs (tile/cluster coupled, plus optional swizzle/cta_order annotations
<!-- upstream-excerpt-end -->
