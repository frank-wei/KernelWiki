## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Add the CUTEDSL_FC12 MoE backend driving the fused FC1+FC2 CuteDSL NVFP4 kernel (single persistent kernel; keeps the FC1->FC2 intermediate on-chip, removing the global round-trip and one launch). Changes:

- vendor the fused kernel + manual_mma_128dp helper under _torch/cute_dsl_kernels/rubin/moe (kernel source unmodified except an intra-package import)
- add the fused custom op trtllm::cute_dsl_nvfp4_fc12_fused_rubin and its TunableRunner in cute_dsl_custom_ops.py
- add CuteDslFc12FusedMoE backend (distinct autotuner key, 128-tile outer runner, EPLB support, non-uGPU) and register it via create_moe / moe_resolution / fused_moe __init__ / llm_args
