## Summary

This PR extends NVFP4 cold-page KV cache compression to the cache layout used by DeepSeek-V4 sparse Attention.

DeepSeek-V4 does not store one conventional K/V tensor per Attention layer. It maintains several cache components with different formats and purposes. This change compresses only the ordinary ratio-4 compressed sparse-attention (CSA) latent that benefits from NVFP4, while preserving the remaining components in their existing representation.

The active GPU cache and the DeepSeek-V4 Attention path are unchanged. NVFP4 conversion occurs only when KVCM V2 moves a Page from the GPU hot tier to the Host or Disk cold tier; onboarding restores the original BF16 or FP8 runtime layout before the Page is published back to the model.
