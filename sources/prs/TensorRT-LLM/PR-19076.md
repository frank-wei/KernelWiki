## Description

This PR updates the host-side dispatch for self-sampling GVR V2 top-K. It improves decode and prefill routing on B200/B300; the device kernel is unchanged.

The existing dispatch has four issues:

- `4K < n <= 8K` decode shapes miss faster register-resident plans;
- the large crossing-bin gate used by some register plans can make one difficult row stall the launch;
- small-row prefill can select an unsampled plan inside the range where sampling is faster;
- register-wave boundaries assume a fixed 148-SM device.

## Changes

- **Decode:** add register routes for `4K < n <= 8K`:
  - `b <= num_sms`: `BLK=1024`, `VPT=2`;
  - `num_sms < b <= 2 * num_sms`: `BLK=512`, `VPT=4`, `MINB=2`.
- **Crossing-bin gate:** use `QC = QUADC = 96` for all register plans.
- **Prefill:** for at most 148 rows, use the sampled `BLK=512` plan when `n_env` is above its sampling threshold plus 256 and no larger than 16K. `run_prefill`, `prefill_ready`, and `warmup_prefill` now share this rule.
