## Description

### MiniMax-M3 block selector: histogram top-k vs the warp-strided kernel

MiniMax-M3 scores KV in 128-token blocks and selects the top 16, so a row is
`ceil(context / 128)` blocks wide and there is one row per (query token, KV head)
per sparse layer. Rows up to 128 blocks (16K context) keep the existing
register-resident bitonic kernels and are unchanged by this MR; the tables start
where the dispatch actually changes.

B200, selector kernel alone under CUDA graph replay, 200 warmup / 1000 iterations,
microseconds per call per sparse layer. Both columns are live measurements from
the same session on the same GPU, the old one from a build of the pre-MR kernel.
