## Description

Upgrade the PyTorch stack from Torch 2.11.0/Triton 3.6.0 to Torch 2.12.0/Triton 3.7.0.

The NVIDIA PyTorch 26.05 DLFW image supplies Torch `2.12.0a0+5aff3928d8.nv26.05`. Therefore, the package requirement is `torch>=2.12.0a0,<=2.13.0a0`, while public PyTorch installation paths use Torch 2.12.0.

This PR migrates TensorRT-LLM to the Triton 3.7 APIs and re-vendors `triton_kernels` from `v3.7.0`.

### Triton API migration

- Replace `triton_kernels.matmul_ogs` with `triton_kernels.matmul`.
- Migrate renamed matmul arguments and precision configuration fields.
- Replace removed routing wrappers with `TritonRoutingData`, `RaggedTensorMetadata`, and plain gather/scatter tensors.
- Explicitly combine scattered GEMM2 expert outputs, masking invalid expert-parallel routing slots.
- Update MXFP4 layout handling and aligned quantization behavior.
- Preserve paired MXFP4 value/scale layouts on Hopper and the natural strided path on Blackwell.

### Dependency and CI updates

- Require Torch `>=2.12.0a0,<=2.13.0a0`, supporting the NVIDIA DLFW 26.05 Torch build.
- Pin Triton to `3.7.0`.
- Re-vendor `triton_kernels` from Triton `v3.7.0`.
- Update public installation paths to Torch
