# [TRTLLM-15400][perf] fuse per-token AdaLN for VisualGen Wan 2.2 5B

## Scope

This PR targets the shared D=3072 Wan 2.2 5B transformer:

- Standard `Wan2.2-TI2V-5B`, in both T2V and I2V modes.
- FastWan 2.2 5B, which reuses the same transformer architecture and changes only the denoising recipe.

It does **not** replace the Wan 2.2 A14B D=5120 path. A14B continues to use the existing in-tree fused AdaLN/LayerNorm implementation.

The new kernels require BF16 **AdaLN activations**, but they are not restricted to unquantized models. FP8, FP8 block-scale, and NVFP4 configurations still carry BF16 tensors through AdaLN and quantize at the downstream `Linear` boundary. The new AdaLN kernels therefore apply to those weight-quantized paths as long as the runtime tensors satisfy the BF16 and layout contract. They do not themselves emit FP8/FP4 activations or fuse the downstream activation-quantization step.
