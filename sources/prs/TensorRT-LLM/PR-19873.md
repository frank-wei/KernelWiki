## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Context FMHA can hang with the persistent tile scheduler in a tcgen05 TMEM-deallocation guardrail trap. Add `TRTLLM_GEN_FMHA_CONTEXT_STATIC_TILE_SCHEDULER=1` as an opt-in workaround. Kernel support checks and launches use the same scheduler selection; the default remains persistent. Selecting the static scheduler may affect performance.

This ports the FMHA portion of commit `29ccb16af0d1c66f5f7c6522457d51862224c875`. Its staging-buffer changes are superseded on main: the Python copy engine has been removed, and `StorageManager` sizes host staging to at least `max(kDefaultPageStagingBytes, kPageStagingDepth * maxColdPageBytes)`.

Validation: all applicable pre-commit checks and `git diff --check` pass. C++ build and FMHA GPU execution were not run for this port.
