## Description

This PR ports the PR-3 slice of the DeepSeek V4 post-`a7728aa` work onto the current GitHub `main` branch.

It focuses on DSv4 sparse attention execution and the tightly-coupled custom op/model defaults:

- Wires fused FP8 Q quantization and `quant_scale_qkv` through the TRT-LLM THOP attention path while preserving the newer `main` attention API shape.
- Adds/updates DSv4 QNorm, inverse-RoPE FP8 quantization, indexer Top-K, compressor, and FP8 quantization kernels/op bindings.
- Updates DSv4 sparse attention/model defaults, including FP4 indexer K-cache defaults and KV cache manager v2 default handling.
- Expands DSv4 sparse/custom-op/unit coverage and DSv4 Flash accuracy references.

Conflict handling was documented locally during branch preparation and is intentionally not included in this PR because `tmp/` contents should not be submitted.

The branch was prepared in a fresh worktree and has been rebased onto GitHub `main` at `e9016273e8e87ee4998425e14ab37ca4f5e59e11`.
