## Description

For dynamic NVFP4 quantization in fused GELU MLPs on Blackwell (SM100/SM103), the global activation scale is unknown when launching the up-projection producer. Previously, this required falling back to unfused execution or writing BF16 activations followed by a standalone requantization pass.

This change extends the fused GELU CuteDSL epilogue to support deferred dynamic scale finalization:

1. **Producer (`dense_blockscaled_gemm_act_fusion.py`)**
   - Emits scale-invariant packed Float4E2M1FN output normalized per 16-element block via `div_full_f32(6.0, gmax)` (PTX `div.full.f32`).
   - Writes raw FP32 block scales (`a / 6.0`) directly to global memory in contiguous row-major `[M, N // 16]` layout.
   - Adds `wrapper_deferred_fp4out` to `Sm100BlockScaledPersistentDenseGemmActFusionKernel`.
2. **Runner and custom op (`cute_dsl_custom_ops.py`, `custom_ops/__init__.py`)**
   - Implements `CuteDSLNVFP4GeluDeferredFP4OutBlackwellRunner`.
   - Registers `trtllm::cute_dsl_nvfp4_dense_gemm_gelu_deferred_fp4out_blackwell` with fake-tensor support preserving dynamic batch/token dimensions.
