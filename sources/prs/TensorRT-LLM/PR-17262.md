## Summary

Integrate the SM100 NVFP4 Conv3d kernel into the native Wan VAE and compose it with the existing parallel VAE path.

- Detect packed ModelOpt NVFP4 VAE checkpoints and replace eligible native Wan 3x3x3 Conv3d modules.
- Prequantize BF16 checkpoint weights once when NVFP4 VAE quantization is requested.
- Select dynamic FP4 Conv3d candidates by supported geometry and channel shape, not Wan block field names.
- Use calibrated static activation scales when available; otherwise use rank-local dynamic activation amax.
- Fuse RMSNorm + SiLU + FP4 quantization on the calibrated path, and fold bias/residual into the Conv epilogue.
- Autotune a bounded provider-supported 1CTA/2CTA CuTeDSL tactic space per exact Conv3d problem shape.
- Keep the provider-recommended 256x256, 2CTA, 2x1 cluster tactic as the eager fallback.
- Persist and merge tuning selections across ranks while keeping CUDA graph capture/replay free of profiling.
- Reuse a compatible compiled cubin across runtime C/output geometries using the final provider kernel implementation.
