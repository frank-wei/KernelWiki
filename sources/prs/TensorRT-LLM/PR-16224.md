## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
SM120 compiles out the trtllm-gen sparse-MLA path in the C++ attention op, so
DeepSeek-V4 and DSA models need a different FMHA implementation on SM120/SM121.
This PR launches FlashInfer's native SM120 sparse-MLA kernel while keeping the
public attention backend set to `TRTLLM`.

This revision is rebased onto `upstream/main` at `a146f66933`.

## Dependencies

- #16673 is merged and included in the current `upstream/main` base.
- `flashinfer-python==0.6.15` exposes
  `flashinfer.mla._sparse_mla_sm120._sparse_mla_sm120_paged_attention`.
- No longer depends on #16217.

## Design

- Adds `FlashInferSparseMlaFmha` to TRTLLM's multiple-FMHA registry, before the
  trtllm-gen and fallback implementations.
- The kernel is FlashInfer-native, not a trtllm-gen kernel, so it is a separate
  FMHA implementation rather than part of `FlashInferTrtllmGenFmha`.
- Uses `KvCacheConfig.dtype="fp8_ds_mla"` as the packed-cache contract:
  - DeepSeek-V4 uses 584-byte footer-scale tokens and
    `tokens_per_block=256`.
  - DSA uses 656-byte inline-scale tokens and `tokens_per_block=64`.
- Keeps TRTLLM ownership of metadata, sparse prediction, index conversion,

<!-- upstream-excerpt-end -->
