## Summary

  This PR adds two RoPE options to NVFP4 cold-page compression. Some models divide cached K vectors or compressed KV rows into position-encoded RoPE and non-position-encoded NoPE regions:

  - `skip_rope_quantization` (default: `False`): set to `True` to preserve supported target RoPE values at their original hot-cache precision (FP8 or BF16). NoPE and ordinary V vectors still use NVFP4.
  - `nvfp4_residual_dim` (default: `64`): for DeepSeek-V4 target RoPE, `64` selects 2FP4 and `0` selects single NVFP4, matching the native DeepSeek-V4 encoder's naming and supported widths. Other models and separate draft caches ignore this option. RoPE preservation takes precedence.

  Both fields belong to `ColdPageQuantizationCompressionConfig`.

  2FP4 is supported only for DeepSeek-V4 target compressed rows. Other models and separate draft caches ignore `nvfp4_residual_dim`; setting it to `64` does not enable 2FP4 for them.

  | Model / cache | Original-precision RoPE | 2FP4 RoPE | Default when cold-page compression is enabled |
  | --- | --- | --- | --- |
  | DeepSeek-V4 | Supported | Supported | NVFP4 NoPE / 2FP4 RoPE |
  | GLM-5 | Supported | Not supported | Single NVFP4 |
