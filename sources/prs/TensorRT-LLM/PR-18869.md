## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Make next_n a runtime kernel parameter and use the multi-warp reduction for every CR128 decode. Split HD512 BF16 work across four head CTAs and distribute complete chunks over grid.z.

## Performance

Setup: Rubin SM107, HCA CR128 / HD512, LBS32, BF16 `kv_score`/state/output, FP32 APE, CUDA 13.5 / Torch 2.13. The four affected baseline files are byte-identical to GitHub `main` at the time of this port. Results use 16 alternating paired A/B rounds; each case uses 200 warmups and the median of 2048 CUDA-event measurements. Speedup is baseline/candidate; brackets are paired bootstrap 95% CI.

### Distributed compression hits
