## Description

Ports the Kimi K3 attention-residual RMSNorm fusion and the KDA beta-cache alignment fix from the internal Rubin branch onto `main`.

**Attention-residual kernels** — `kimiK3AttnRes/attnResFwd.cu` gains a fused trailing RMSNorm and an optional fused residual add; new `attnResFwdPersistentFused.cu/.h` adds a persistent-grid fused add+RMSNorm. `thop/attnResOp.cpp` additively registers `attn_res_rmsnorm_fwd`, `attn_res_add_rmsnorm_fwd` and `attn_res_add_rmsnorm_persistent_fwd`. The existing `attn_res_fwd` schema is untouched.

**KDA beta-cache alignment** — CuTe requires every nested cache view to be 16-byte aligned. Six fp32 heads are 24 bytes, so an unpadded row leaves alternating per-draft views only 8-byte aligned. `_allocate_kda_beta_cache` pads the physical head stride to a multiple of 4 fp32 heads and slices the logical count back off, so the shape is unchanged and only the stride grows. Applied at both allocation sites.
