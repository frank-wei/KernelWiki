## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Composable exception-handling policies for CUDA STF: a policy is a first-class value that says what happens when code throws, installed over a block with `ON_THROW(policy) { body };`. This replaces ad hoc try/catch at STF's internal boundaries and gives users a vocabulary for the error path.

### The model

On a throw, the block boundary catches and calls the policy's hook, `(const std::exception*, source_location, callable&)`, passing the exception, the throw site, and the body itself (replayable). The hook's answer decides the fate of the whole expression:

| answer | meaning |
| --- | --- |
| `nullval` | die: the hook never returns |
| `std::ignore` | resume: default-construct the result |
| a value | substitute it as the result |
| *(throw)* | rethrow: "not mine", pass it on |

Any callable answering this way is a policy and composes as a peer. Two optional capabilities join by presence: `on_success` (type-preserving observer of the success path) and `on_enter` (an entry gate run before the attempt, outside the policy's own catch).
