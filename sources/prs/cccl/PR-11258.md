## Description

Adds a static helper `exec_place::locality_domains(int dev_id, locality_domain_sm_split split = locality_domain_sm_split::backfill)` to the cudax places layer.

**What.** It returns the grid of execution places over all locality domains of one device, i.e. the same grid `make_locality_domain_grid(dev_id, split)` builds. The member simply forwards to that free function.

**Why.** `exec_place::all_devices()` is the established spelling for "a grid over every device"; `exec_place::locality_domains(dev)` is the same idea one level down the hierarchy (every domain of one device), so user code reads consistently:

```cpp
auto devs    = exec_place::all_devices();          // one place per device
auto domains = exec_place::locality_domains(dev);  // one place per locality domain of `dev`
```

`make_locality_domain_grid` is kept unchanged: it remains the documented free-function mechanism (and the C API builds on it). The new member is single-device sugar over it, exactly like `all_devices()` is sugar over `n_devices`.
