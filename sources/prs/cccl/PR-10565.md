## Summary

This finishes the `cuda::experimental` side of Library Fundamentals TS v3 [scope guards](https://en.cppreference.com/w/cpp/experimental/scope_exit).

`scope_exit` has been in cudax since #5975, and #10559 / #10523 built STF `SCOPE` and related exception helpers around it — but the TS surface itself stayed incomplete: only `scope_exit` existed, its move constructor did not `release()` the source (contra the TS), and `scope_fail` / `scope_success` were missing. STF already documents `SCOPE(exit|fail|success)` against the TS trio; this PR makes the underlying `cuda::experimental` API match that contract.

- Rename `__utility/scope_exit.cuh` → `__utility/scope.cuh` (mirrors `<experimental/scope>`).
- Implement `scope_fail` and `scope_success` per TS v3 (uncaught-exception counters; host-only — they need `std::uncaught_exceptions()`).
- Fix `scope_exit` move to deactivate the moved-from guard.
- Add Catch2 coverage for exit / fail / success, `release()`, and move-release.
- Move STF-oriented helpers out of the TS header: `with_location` → `source_location.cuh`, `throw_proof` / `throw_defer` → `scope_guard.cuh`, so `cuda::experimental::scope_*` stays a clean TS surface.
- Als
