## Description

Follow-up to #9868.

This PR migrates cuCollections `static_map`'s host `retrieve_all` API into cudax `fixed_capacity_map`:

- Stream-first `retrieve_all` API returning the key and mapped-value output ends
- CUB `DeviceSelect::If` implementation using memory-resource-backed temporary storage
- Original cuCollections unit tests covering empty, populated, discard-output, and cleared maps across key/value, probing, cooperative-group, and bucket-size configurations
