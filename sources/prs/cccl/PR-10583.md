## Summary

`localized_array` placed its allocation blocks by **sampled majority vote** even when the mapping came from a structured `cute_partition_descriptor` — the partition was erased into an opaque `std::function<pos4(size_t)>` at the composite boundary, so every allocation paid `probes x nblocks` owner evaluations and reported approximate placement accuracy.

This PR divides the ownership layout by the placement-block layout instead, and makes **maximal same-owner block runs** the placement currency end to end (one physical allocation + one mapping per run):

* **`for_each_owner_byte_run`** — enumerates the constant-owner byte runs with **one `owner()` evaluation per run**, abortable mid-walk.
