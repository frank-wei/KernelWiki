## Description

Follow-up to #11095 and https://github.com/NVIDIA/cccl/pull/11095#discussion_r3933782605.

This PR replaces direct kernel launches in cuco and its existing tests with `cuda::launch`, as suggested by @Jacobfaib during the review. It also removes `noexcept` from potentially throwing operations so exceptions from CUDA calls and user-provided functors, policies, or sentinel types can propagate.

HLL now reserves dynamic shared memory on the function used by `cuda::launch` before querying occupancy, and checks the driver call with `_CCCL_TRY_DRIVER_API`.

- [x] New or existing tests cover these changes.
