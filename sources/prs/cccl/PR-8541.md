## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Add an example of processing large data in batches using CCCL Runtime APIs and offloading actual work to CUB.
First it scans through devices to find one with the most memory and it prints some stats about the device.
In order to make the batched processing with two streams believable the program will generate a few GBs of data that is supposed to look like space observation.
Then it allocates relevant buffers and runs image processing pipeline using CUB primitives. It has two stages with some CPU-side computation between the stages.
Finally it runs custom kernel that compresses the image for preview, otherwise the output file would be huge, and saves it to a file.

The example is supposed to be split into files showing different types of runtime APIs, file with device related APIs, file with memory allocation, file for the processing. The files ended up rather imbalanced in size and less self-contained than I hoped, but maybe that's ok.

The example requires 4GB+ of host side memory, I think it's reasonable on modern machines. On GPUs with large amount of memory the number of tiles will be small, but otherwise the CPU side consumption could be too large.
