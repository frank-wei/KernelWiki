## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
localized_array teardown unmaps VMM backing (cuMemUnmap / cuMemRelease / cuMemAddressFree): synchronous driver calls that no event can defer. The arrays cached by a nested context's composite_slice_cache were destroyed with the nested context at pop() -- while the body graph launched by the same pop() was still running on the support stream, which surfaced as cudaErrorIllegalAddress on any composite data place used inside a conditional graph scope (while_graph_scope / repeat_graph_scope).

The composite cache is a per-context member and does not ride the ctx_resource transfer (import_resources_from), so enroll it explicitly: _pop_epilogue() now hands the popped context's cache over to the parent, gating every imported entry on the body's completion events. Reuse by a parent-level task therefore waits for the nested graph that last used the allocation, and the final unmap happens once the parent has synchronized (the dangling-event registration in _pop_epilogue already guarantees the parent's fence waits on the body graph).

Adds linear_pool::import_from and composite_slice_cache::import_from, and a regression test (stackable/composite_conditional.cu) exercising a composite cute fie
