## Description

Closes #10562.

This PR promotes cuco's host/device xxHash and MurmurHash3 function objects to `cuda::hash` in `<cuda/functional>`. It moves the existing implementation, tests, documentation, and benchmark into libcu++, migrates every in-tree cuco use to `cuda::hash`, and removes the cuco hash API and implementation.

The hashing algorithms and hash values are unchanged. The migration otherwise preserves the cuco implementation, with only libc++ style and compiler-portability adjustments. It also corrects a pre-existing signature bug in the MurmurHash3-32 span overload: the 32-bit algorithm and implementation returned `uint32_t`, but the public overload was accidentally declared as `uint64_t`.
