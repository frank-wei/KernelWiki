## Description

**Part 2/4 of the split of #9892** — stacks on #10769 (structured partitions). Until #10769 merges, the Files view shows both; this PR's own delta is **8 files, +407/−5** (tip of #10769 → tip of this).

- **C API**: `stf_placement_evaluate` (native or callback mapper) and `stf_placement_evaluate_partition` (structured partition) — run the exact block-owner decision procedure of the allocation path and return `stf_placement_stats` (+ optional per-grid-position byte counts) **without allocating**.
- **Python**: `placement_evaluate()` / `placement_stats` — accepts a `cute_partition`, a `native_partition_fn`, or a Python callable; `accuracy` is the fraction of bytes local to their owner; the analytic pre-filter for choosing a spec before touching memory.
- **Tests**: mapper-form coverage, partition-vs-native equivalence, C-order callbacks, majority tie-breaking, misuse/error paths (C and Python).

**Replication note**: the replicated per-member reporting (`stats.replication_factor`, `resident_bytes`) moved to the replication PR at the top of the stack.
