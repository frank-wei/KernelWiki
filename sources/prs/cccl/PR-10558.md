## Description

Closes #9989.

This PR incorporates https://github.com/NVIDIA/cuCollections/pull/777 by migrating the HyperLogLog sketch and open-addressing counter readback paths from the legacy asynchronous memcpy call to `cuda::copy_bytes`.

For CUDA Toolkit 13.0 and newer, the copies use stream-ordered source access, avoiding driver-side locking in the legacy path. Older toolkits retain the existing `cudaMemcpyAsync` behavior. No public APIs or result values change.
