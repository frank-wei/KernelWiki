## Description

This PR skips redundant erased-key checks when a container's empty and erased sentinels match. It specializes scalar and cooperative `insert`, `insert_and_find`, and `insert_or_assign` paths while preserving handling of distinct erased keys.

This follows the duplicate-heavy insertion profiling for #11869 and the set migration in #11126. Public APIs and object layouts are unchanged.
