## Description

<!-- Every PR should have a corresponding issue that describes and motivates the work done in the PR -->
closes https://github.com/NVIDIA/cccl/issues/7556

This PR makes classic de-coupled lookback algorithm deterministic by waiting on previous base anchor tile's (tile idx multiple of 32) to populate inclusive prefix. This way all non-anchor (non multiple of 32) tiles always have same reduction tree, and also only popuplate only partial prefixes to tile-states. TL;DR: this a serialized 32 batched chain, which works on all the SM's where classic de-coupled lookback algorithm was already working.

#### Note
Initial experiments in PR [3e45d96](https://github.com/NVIDIA/cccl/pull/9098/commits/3e45d96df063117fe359ce6a08cf70860a7a9637) Implements run-to-run deterministic device scan by generating fixed-reduction tree by reduce tile-aggregates in chunks of 32.

The commit also experiments warpspeed on Hopper (SM90 - H100) by using global atomic flag replacing workstealing (SM100), and it performs better than de-coupled for large problem sizes.
