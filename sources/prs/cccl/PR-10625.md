## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
A replicated data place duplicates a logical data over the affine data places of an execution grid's members: one padded replica per place (stride = size rounded to the placement granularity), VA-contiguous so the instance exposes replica 0 and ordinary code paths see a normal device allocation.

Replication is a PLACEMENT property, not an access mode:
- copies INTO the place populate replica 0 and fan out to the others (stream: same-stream memcpys; graph: a chain of memcpy nodes whose tail carries the dependencies), and writes at the place are rejected at task creation -- so a valid replicated instance is synced by construction, with no new coherence state;
- each shard of a grid parallel_for reads its own replica: the dispatch rebases mdspan instances by place_index * stride (the stride helper is shared with the allocation path so the two cannot drift);
- mutation happens at any other place and invalidates the instance; the next replicated read re-broadcasts (ordinary MSI);
- allocations are recycled through the composite cache, so replicated instances inherit the stackable pop-time handover (#10609) and work inside conditional graph scopes.
