## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Preparation for enabling `clang-tidy`'s `bugprone-exception-escape` on STF. This PR carries only the C++ fixes that check surfaced; the build-system wiring that turns the check on will come separately.

## Exception escapes

* `dot`'s destructor called `finish()` unguarded. A trace we fail to write is not worth terminating over, so the failure is now reported to `stderr`.
* `localized_array`'s destructor unmapped and released memory through `cuda_try`, which throws. It now uses `cuda_safe_call`, which reports and aborts, and `places.cuh` pulls that name in.
* `meyers_singleton::instance()` was unconditionally `noexcept` while running the singleton's constructor. It is now `noexcept` exactly when that constructor is. The nested `__instance_of` template exists so the exception specification can name the type that is actually instantiated, which is what grants access to `_Tp`'s protected constructor.
* Three sites in `logical_data` and `stackable_ctx` leave state behind that no caller could recover from, so terminating is the intent. Those are documented and marked `NOLINTNEXTLINE`.
