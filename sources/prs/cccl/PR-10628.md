# Enable precompiled headers for `cuda.compute` HostJIT builds

Parsing the CUB / libcudacxx / Thrust header bundle dominates a HostJIT build.
The backend has always contained a precompiled-header cache, but it was off and
the Python layer never enabled it. This turns it on, making algorithm builds
**2.4–4.1× faster**.

Build-time only: no change to kernel codegen, launch behavior, algorithm
semantics, or any on-disk format.

## Results

| algorithm | PCH off | PCH on | speedup |
| --- | --- | --- | --- |
| reduce | 3138 ms | 770 ms | **4.08×** |
| scan | 3015 ms | 757 ms | **3.98×** |
| transform | 2767 ms | 922 ms | **3.00×** |
| merge_sort | 3106 ms | 1304 ms | **2.38×** |

sm_89, CTK 13.0, gcc13, one build per process, median of 3. Reproduce with
[`pch_bench.py`](https://gist.github.com/shwina/1906a0bcbe1e4d22d6f3d449d3952e76).
