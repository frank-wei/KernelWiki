## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
- Audited every data member (non-static and static — public, protected, private, including `detail` namespaces) across `thrust/thrust/**` for `snake_case` compliance per `docs/cccl/development/coding_guidelines.rst`, as a follow-up to #11598 which covered function names.
- Found a handful of internal violations:
  - `feistel_bijection::{R_bits,L_bits,R_mask,L_mask}` → `{r_bits,l_bits,r_mask,l_mask}` (`thrust/detail/random_bijection.h`)
  - `sm52`/`sm60::warpSize` → `warp_size` (`thrust/system/cuda/detail/core/util.h`)
  - `bucket_functor::BitMask` → `bit_mask` (`thrust/system/detail/sequential/stable_radix_sort.h`)
- Added `readability-identifier-naming.MemberCase` and `.ClassMemberCase` (both `lower_case`) to `thrust/.clang-tidy` to enforce this going forward. `ClassMemberCase` alone is enough to also cover `static const`/`constexpr` members, so a separate `ClassConstantCase` isn't needed.
