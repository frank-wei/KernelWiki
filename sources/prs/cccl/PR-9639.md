## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
The RFA path in CUB's reduction is very similar to the normal two-phase path. We could potentially even try to unify it, but that may be more controversial. In any case, the tuning values for the ordinary reduction make equally sense for the RFA reduction (it just uses less of the values), so this PR proposes to just reuse the same tuning policy for RFA than for the ordinary reduction.
