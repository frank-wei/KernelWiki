## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR removes the `__synchronizer_` member from the `group` type. It's similar to when we removed the `__mapping_` member. I didn't find a good use case for studying what is the synchronization mechanism of a group.

As a consequence, there should be less instantiations of the `group` type, because same synchronizer instances can be used for different synchronizer types.
<!-- upstream-excerpt-end -->
