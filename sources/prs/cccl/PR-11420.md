## Description

<!-- Every PR should have a corresponding issue that describes and motivates the work done in the PR -->

Enables `google-*` checks in `clang-tidy`. I have kept this as a single PR since it's very small and hopefully uncontroversial (but please REVIEW BY COMMIT). The only checks that needed fixes are

- `google-readability-namespace-comments`: mismatched (or missing) namespace comments `// namespace foo::bar::baz`
- `google-readability-braces-around-statements`:
```c++
while (cond) ;
->
while (cond) { }
```
- `google-default-arguments`: Putting default arguments on `virtual` functions is BAD. The default value will depend on the static type of the caller and may be surprising. We silence this check everywhere (because it's all public thrust) but we should enable it so that we don't add more of this in the future.
- `google-global-names-in-headers`: Forbids `using namespace foo` in global scope.
