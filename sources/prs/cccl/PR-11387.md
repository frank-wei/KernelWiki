## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR makes groups expose the `is_always_exhaustive()` and `is_always_contiguous()` properties as a `static constexpr` member function. I'd like these properties to be publicly available, so you can for example say that your algorithm doesn't support non-contiguous groups.

This approach is similar to `mdspan`, where the mapping's properties are also exposed as `static constexpr` member functions of `mdspan`.
<!-- upstream-excerpt-end -->
