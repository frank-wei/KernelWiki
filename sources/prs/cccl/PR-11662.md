## Description

The `transform_iterator`, `strided_range`, and `sparse_vector` examples initialize device vectors through repeated element assignments. Construct these six vectors directly from initializer lists so the examples demonstrate the simpler initialization style requested in #724 and avoid individual host-side writes through device references. The sparse input vectors are also `const` now that they are fully initialized at construction.

Refs #724. This is a scoped follow-up to the broader examples modernization work.
