## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR introduces a minimal logging mechanism, compiled-in by default (unless disabled by a macro), inactive by default, which can be turned on by an environment variable to log CUB kernel launches and API dispatches (with selected tunings). The main motivation is to allow logging the runtime behavior of a program using CCCL without recompiling. That includes dumping the tunings used.

I initially thought it should replace `_CubLog`, but decided against it, since it's a breaking change. But I believe we should replace it at some point. The PR is intentionally not a full fledged logging framework, since I want to get the basic design out soon so we can start gaining experience.

With this change, I can now run the transform unit test like so, without extra output:

```
$ ./bin/cub.test.device.transform.lid_0
Randomness seeded to: 844268483
...
```
and the same binary with output:
```
$ CCCL_EXPERIMENTAL_LOGGING=1 ./bin/cub.test.device.transform.lid_0
Randomness seeded to: 844268483
Dispatching DeviceTransform to compute capability 12.0 with tuning: transform_policy { .min_bytes_in_flight = 65536, .algorithm = Algorithm::prefetch, .prefetch = prefetch_policy { .threads_per_block = 2
<!-- upstream-excerpt-end -->
