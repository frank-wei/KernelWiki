## Description

Windows C Parallel v2 HostJIT-generated DLLs fail to link when CUB checks the reported PTX compute capability: the freestanding host has no implementation of the `__assert_fail` symbol used by `_CCCL_VERIFY`. The failure also occurs in unrelated PR CI, including [#11495's HostJIT job](https://github.com/NVIDIA/cccl/actions/runs/35375033659/job/105699366030). It is separate from the Windows wheel DLL-packaging issue addressed by #11495.

Provide the host assertion adapter in the existing freestanding `assert.h` stub and include it explicitly from the runtime wrapper. Clang's trap builtin keeps failed checks fatal without requiring a C runtime assertion symbol. Apply the adapter on Linux too, where the JIT library previously relied on the loading process to supply that symbol. The device adapter is unchanged. Extend the freestanding header test with a runtime-valued host verification so this symbol must link.

Keep Breathe below 5 in a separate commit to restore documentation builds. Version 5.0.0 introduced invalid generated C++ declarations; the same generated page passes with 4.36.0 and fails with 5.0.0. The full strict documentation build passes with 4.36.0.
