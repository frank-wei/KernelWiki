## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This is something I've had in my mind for quite some time. The interop we had up to this point was basically useless in my opinion - what's the point of creating for example `this_block` from CG's equivalent when you can just construct it directly yourself.

This PR introduces the `cudax::make_cg_equivalent_group(...)` function that takes a CG group and a hierarchy and constructs an equivalent CCCL group. I haven't implemented all of the versions yet, but I think it's sufficient for now.

This PR should also replace #11209.
<!-- upstream-excerpt-end -->
