## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Currently, we have several group types - `this_group`, `coalesced_group`, `virtual_group` and `group`. Me and @pciolkosz, we feel like `group` is too non-specific name and we'd rather have it describe the group requirements.

This PR renames the `group` type to `generic_group` (feel free to come up with a better name) and the `is_group` concept to just `group`, similarly to what standard ranges do.

This rename also solves a small problem that I had with the `group_view` because just from the name it seems that it's a view for the `group` type. After this change, it'll be a view for any type that satisfies the `group` concept.
<!-- upstream-excerpt-end -->
