## Description

`std::aligned_storage_t` is deprecated in C++23, which breaks the cudax build with `-DCCCL_ENABLE_WERROR=ON` (`-Werror,-Wdeprecated-declarations`):

```
cuda/experimental/__stf/utility/memory.cuh: error: 'aligned_storage_t' is deprecated [-Werror,-Wdeprecated-declarations]
```

Replace the two `std::aligned_storage_t` members of the `small_vector` storage union with `alignas` byte arrays. The only accesses to these members go through `reinterpret_cast` in `small_begin()` and `big()`, which behave identically for a byte array.
