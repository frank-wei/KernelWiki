## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Fuses random-number generation and distribution mapping into a single kernel, replacing the old two-pass approach (curand host API / `thrust::default_random_engine` into an intermediate float buffer, then a second kernel mapping values into the target type/range).

- `C2H_HAS_CURAND` path: uses the curand *device* API (`curand_init`/`curand_uniform` per index) instead of the host API.
- Fallback path: uses libcu++'s `cuda::std::philox4x32` instead of `thrust::default_random_engine`.
- Removes `generator_t`'s persistent distribution buffer and the `init_generator`/`cleanup_generator` lifecycle — generation is now a stateless, pure function of `(seed, index)`.

Also fixes two pre-existing correctness bugs found during review:
- Vector-type generation (`int2`, `float2`, etc.) was drawing one random value per *element* and reusing it across all fields, so components weren't independent. Now sampled per-field.
- `c2h::gen()` for `custom_type_t` ignored the `min`/`max` bounds passed by callers. Now respected.
