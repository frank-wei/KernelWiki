## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Renames the last two non-PascalCase buckets found in `cub/cub/` template parameters: leading-underscore names with the underscore stripped (`_Tp` -> `Tp`, `_UnsignedBits` -> `UnsignedBits`, etc.) and mid-underscore names with the underscore removed (`T_In` -> `TIn`, `Extents_In` -> `ExtentsIn`, etc.). This clears CUB's template-parameter naming survey down to 0 non-PascalCase names.

A few parameters needed a non-mechanical name instead of the literal stripped form to avoid shadowing an enclosing scope's identically-named type/member (`util_type.cuh`'s `KeyValuePair`, `kernel_histogram.cuh`'s nested `BinSelect` — nvcc hard-errors on shadowing a template parameter, unlike a same-named local/member). `agent_reduce_by_key.cuh`'s nested `GuardedInequalityWrapper` dropped its template parameter entirely, since it's only ever instantiated with the enclosing class's own `EqualityOpT`.

This PR was created by Claude.
<!-- upstream-excerpt-end -->
