## Overview

This PR introduces `cccl.c.parallel.v2`, a reimplementation of `cccl.c.parallel` with an identical C API, built on the host-JIT infrastructure that landed in #8437.

v1 and v2 ship side-by-side so we can iterate on v2 without disrupting downstream consumers. The eventual plan is to retire v1 once v2 reaches parity in CI coverage.

## Scope of changes

**New project: `c/parallel.v2/`** — mirrors the layout of `c/parallel/`:
- `include/cccl/c/*.h` — same public headers as v1, identical signatures. The only divergences are in the `build_result_t` structs (different internal bookkeeping fields — `jit_compiler*` instead of `CUlibrary`/`CUkernel`s, etc.).
- `src/*.cu` — Implementation of algorithms. Each one is a thin shell that invokes `CubCall` (described below) and then assigns the result into the `build_result_t`.
- `src/hostjit/` — the JIT infrastructure brought over from #8484.
- `src/util/build_utils.h` — shared utilities
- `test/freestanding/` — v2-specific JIT-infrastructure tests (compile path, header availability, etc.).
