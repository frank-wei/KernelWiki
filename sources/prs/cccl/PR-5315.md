## Description

Introduce Python bindings for CUDASTF as a new `cuda-stf` package (module
`cuda.stf._experimental`, Linux only). The bindings sit on top of the STF C
API (`c/experimental/stf`, already merged to main) and expose contexts,
logical data, tasks, execution/data places (including composite,
read-only **replicated**, and **locality-domain** placement), CUDA graph
utilities, and interop layers for Numba, PyTorch, Warp, and cuda.compute.

**Scope note for reviewers:** the C API itself is not in this diff (it
landed separately) — the only C-layer change here is a small extension
(~105 lines): the replicated-placement entry points
(`stf_data_place_replicated`/`_deferred`/`_is_replicated`) and the
locality-domain shim over the #10658 factories (#10658 is merged to main;
its Python bindings were developed as #10703 and have been folded into
this PR) plus the reshape entry points. The execution-grid reshape
bindings originally split out as #9899 are folded in as well (their C++
machinery is already in main), together with the C-order public-shape
contract they assume: python-facing shapes are C order (dimension 0
outermost), converted to the native dimension-0-fastest ABI in one
