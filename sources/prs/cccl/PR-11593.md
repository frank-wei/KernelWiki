## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`configure_async_kernel` (the async-copy/ublkcp dispatch path of `cub::DeviceTransform`) picks items-per-thread at runtime. There was previously no visibility into what values this picked or why. This PR adds a log line for that.

Example output (`babelstream.ublkcp` benchmark, `mul`, `int8_t`, RTX 5090, `CCCL_EXPERIMENTAL_LOGGING=1`), showing items-per-thread scale up with problem size until the target is reached:

```
Elements=2^16: picked 1 items per thread, achieving 1536 bytes in flight (target: 49152), reduced from 32 to spread load evenly
Elements=2^20: picked 5 items per thread, achieving 7680 bytes in flight (target: 49152), reduced from 32 to spread load evenly
Elements=2^24: picked 32 items per thread, achieving 49152 bytes in flight (target: 49152)
Elements=2^28: picked 32 items per thread, achieving 49152 bytes in flight (target: 49152)
```
