## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
@gevtushenko has found that the current RLE lookahead implementation could lead a potential race on sm120 with config (key_stage=2, pos_stage=1).

The easiest solution is to make all compute warp wait for the mbarrier (originally some of them can skip waiting the barrier if they do not need to write to position buffer). With this approach, I have observed performance regressions up to 1.5%, which I think is acceptable given that this prevents a race.
<!-- upstream-excerpt-end -->
