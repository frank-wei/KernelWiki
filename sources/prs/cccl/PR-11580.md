## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Fixes #10755.

This PR reorganizes groups and cooperative algorithms as:
- groups are moved to `cudax::coop` namespace available through `<cuda/experimental/coop/group>` header
- cooperative algorithms are kept in the `cudax::coop` namespace, but the public header is now `<cuda/experimental/coop/algorithm>`
- the tests are moved to a `coop` folder with it's own `CMakeLists.txt`

The reason why I introduced a new `coop` directory is because I think we should provide individual algorithms in separate include files in the future to save compilation times.
<!-- upstream-excerpt-end -->
