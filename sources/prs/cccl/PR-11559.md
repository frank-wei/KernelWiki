## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Renames the remaining leading-underscore ALL_CAPS template parameters in `cub/cub/`: `_CATEGORY`/`_PRIMITIVE` in `util_type.cuh`'s `BaseTraits` (named `Kind`/`Primitive` — `Kind` rather than `Category` to avoid shadowing the `Category` enum type used as the parameter's own type), and `_POLICY` in `WarpStore`/`WarpLoad`'s private `StoreInternal`/`LoadInternal` helper templates (named `Algorithm`, matching the naming already used for analogous parameters elsewhere in CUB).

This PR was created by Claude.
