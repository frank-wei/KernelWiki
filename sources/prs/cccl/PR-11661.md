## Performance (NVIDIA A100, full nvbench sweep)

Full `nvbench_compare` diffs for every benchmark (all element counts, entropies, size-ratios and key/value types) are posted as **one comment per benchmark** below. Each comment contains two diffs: `upstream/main` → this PR **before** the sm_80 tuning, and **with** it. Aggregated over all 1152 measured configurations (8 benchmarks × full sweep):

| comparison | faster | slower | within noise |
|---|---|---|---|
| `upstream/main` → PR, **untuned** | 138 | 188 | 826 |
| `upstream/main` → PR, **tuned (sm_80)** | **516** | **89** | 547 |

The untuned migration is roughly performance-neutral (most configs within noise), with the register-pressure regressions discussed above. The sm_80 tuning (key-size-dependent block size) turns that into a broad net improvement — ~4× more configurations get faster and the number that regress more than halves, with the residual regressions all small (≤ ~2-3 %, at the measurement-noise/boost-drift level).
