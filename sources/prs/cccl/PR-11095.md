## Description

closes #10641

This PR migrates the host and device key-range `for_each` APIs from `cuco::static_map` to `cudax::cuco::fixed_capacity_map` and adds corresponding tests.

cuco's container-wide `for_each(callback_op, stream)` overload is deliberately not migrated. It is a range level algorithm over the container contents, not a hash table operation, so it belongs in `cuda::std::` rather than as a member of the map.
