## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR adds an additional parameter to `print_latex` and `print_latex_tv` to allow users to pass a render function that accepts the tikz latex code ({tikzpicture} section only) and renders the image. It simplifies the visualization process since now if they have a latex environment they can write a simple function and render the image without having to copy and paste hundreds of lines of code and compile the latex manually. It works even better if they are using jupyter notebook.

For example, I use module `jupyter_tikz` and this is how I render the image directly in my notebook:

```python
from IPython.display import display
from jupyter_tikz import TexFragment

os.environ['JUPYTER_TIKZ_PDFTOCAIROPATH'] = '/home/linuxbrew/.linuxbrew/bin/pdftocairo'

def render_tikz(tikz_code):
    tikz = TexFragment(tikz_code)  # Create the tex template object
    display(tikz.run_latex(tex_program='/home/linuxbrew/.linuxbrew/bin/pdflatex', rasterize=True))
```
