## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`cute.local_partition`'s `index` parameter is annotated `Union[int, Numeric]`, but passing a bare Python `int` fails with an uncaught `AttributeError`:

```
AttributeError: 'int' object has no attribute 'ir_value'
```

The coercion in `core.py` handles `ArithValue` and anything with `.ir_value()`, but never plain `int` — while the `Int64` path right below it raises a deliberate `NotImplementedError`, so the parameter was clearly meant to be validated, not to crash on a documented input type.

This patch adds the missing branch, following the exact pattern `cute.printf` uses for bare ints in the same file (`core.py:2168`):

```python
elif isinstance(index, int):
    index_val = const(index, Int32, loc=loc, ip=ip)
```

Verified on nvidia-cutlass-dsl 4.8.0 with a `(16,)` identity tensor and a 4-thread layout:

| call | before | after |
|---|---|---|
| `local_partition(t, L, 3)` | `AttributeError` | `tensor<3 o (4):(4)>` |
| `local_partition(t, L, Int32(3))` | `tensor<3 o (4):(4)>` | unchanged |
| `local_partition(t, L, Int32(2)*2-1)` (dynamic) | `tensor<3 o (4):(4)>` | unchanged |
| `local_partition(t, L, Int64(3))` | `NotImplementedError` (width guard) | unchanged |
