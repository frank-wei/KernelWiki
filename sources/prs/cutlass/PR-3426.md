## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR introduces cutlass compiler stack including:
- CuTe IR MLIR dialect modelling CuTe algebra and its lowering passes
- Cutegen backend for type inference and lowering of CuTe algebra operations
- Base pseudo-dialect lowering passes which lowers all upstream dialect used by CuTe IR
