## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
The contiguous grouped GEMM example currently selects scalar RMEM operations and O3 for all CUDA 12.9 configurations. Enable vectorized RMEM/O2 for 2CTA while retaining scalar RMEM/O3 for 1CTA. The same predicate continues to select both the RMEM implementation and compilation options; CUDA 13.1+ retains its existing selection.

Validation used the public `nvidia-cutlass-dsl==4.8.0.dev0` wheel (CUDA 12.9 backend) on GB200 at 802 MHz. With M=1024, N=4096, L=16, FP8 E4M3 inputs, BF16 output, a 128x128 MMA tile, fixed M and cold L2:

| Case | Before (us) | After (us) | Latency change |
|---|---:|---:|---:|
| 1CTA, K1024, cluster 1x1 | 27.965 | 27.998 | 0.12% |
| 2CTA, K4096, cluster 2x1 | 100.596 | 90.523 | -10.01% |

Measurements were interleaved A/B/B/A, with 20 warmups, 100 iterations per trial and five trials per process. Each table entry averages the two process medians. The 1CTA kernel cubins are byte-identical.

Ten local reference checks passed: both CTA modes at K1024/K4096, irregular M/N/K and both C-major layouts, plus the baseline controls. Ruff formatting, DSL example lint checks and `git diff --check` passed. This PR changes only the example kernel.
<!-- upstream-excerpt-end -->
